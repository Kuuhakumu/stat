## 2. Definitions & formulas

### 2.1 การแจกแจงเอกรูปชนิดต่อเนื่อง (บริบทของ p-29)

- ถ้าค่า X วัดได้ต่อเนื่องและทุกค่าภายในช่วง [a,b] มีโอกาสเท่า ๆ กัน เขียนว่า X ~ U(a,b) และความหนาแน่นคือ

  `f(x; a,b) = 1/(b−a),  a < x < b` และเป็น 0 นอกช่วง (นิยามอยู่ p-28; ใช้ต่อใน p-29–p-32)

- ความน่าจะเป็นของช่วงย่อย [c,d] ที่อยู่ใน [a,b] คิดจากสัดส่วนความยาว

  `P(c < X < d) = (d−c)/(b−a)` (ปลายช่วงจะเขียน ≤ หรือ < ก็ได้สำหรับตัวแปรต่อเนื่อง เพราะ P(X = จุดใดจุดหนึ่ง) = 0)

- ทฤษฎี 4.6 (p-29):

  `μ = (a+b)/2`

  `σ² = (b−a)²/12`

  โดย a,b คือขอบล่างและขอบบน, μ คือค่าเฉลี่ย, σ² คือความแปรปรวน และ σ = √σ² คือส่วนเบี่ยงเบนมาตรฐาน

### 2.2 การแจกแจงเลขชี้กำลัง

- นิยาม 4.6 (p-33): X คือเวลารอจนกว่าเหตุการณ์ที่สนใจจะเกิด (ดังนั้น x > 0) และมีค่าเฉลี่ยเวลารอ β (หน่วยเดียวกับ x) ความหนาแน่นคือ

  `f(x; β) = (1/β)e^(−x/β),  x > 0`

  β คือ mean waiting time; ถ้า x ≤ 0 ความหนาแน่นเป็น 0

- จากการอินทิเกรตความหนาแน่น (ใช้คำนวณตัวอย่าง):

  `P(X > t) = e^(−t/β)`

  `P(a < X < b) = e^(−a/β) − e^(−b/β)` เมื่อ 0 ≤ a < b

  หรือใช้ CDF `F(t) = P(X ≤ t) = 1 − e^(−t/β)`

- ทฤษฎี 4.6 (p-34):

  `μ = β`,  `σ² = β²` และจึงมี `σ = β` (β > 0)

### 2.3 การแจกแจงปรกติ

- นิยาม 4.6 (p-36): ถ้า X เป็นตัวแปรต่อเนื่อง ค่าเฉลี่ย μ และความแปรปรวน σ² โดย μ เป็นจำนวนจริงใด ๆ และ σ > 0 จะมีความหนาแน่น

  `f(x; μ,σ) = [1/(σ√(2π))] e^{−(1/2)[(x−μ)/σ]²},  −∞ < x < ∞`

  μ เป็นจุดกึ่งกลางของโค้ง และ σ ควบคุมความกว้างของโค้ง (ในสูตรใช้ σ ไม่ใช่ σ²)

- ทฤษฎี 4.6 (p-37):

  `E(X) = μ` และ `Var(X) = σ²`

- คุณสมบัติโค้งปรกติ (p-38):

  1. รูประฆังคว่ำ ปลายโค้งเข้าใกล้แกน X
  2. จุดสูงสุดอยู่ที่ `X = μ`
  3. สมมาตรรอบ `X = μ`
  4. ค่าเฉลี่ย มัธยฐาน และฐานนิยมเท่ากัน
  5. จุดเปลี่ยนโค้งอยู่ที่ `X = μ ± σ`
  6. พื้นที่ใต้โค้งเหนือแกน X รวมเป็น 1

  เขียนเป็นอินทิกรัลได้ว่า `∫₋∞^∞ f(x) dx = 1` และพื้นที่แต่ละข้างของ μ เท่ากับ 0.5: `∫₋∞^μ f(x)dx = 0.5 = ∫_μ^∞ f(x)dx`

- พื้นที่ใต้โค้ง (p-39): สำหรับ x₁ < x₂

  `P(x₁ < X < x₂) = ∫ₓ₁^ₓ₂ f(x) dx`

  `= ∫ₓ₁^ₓ₂ [1/(σ√(2π))]e^{−(1/2)[(x−μ)/σ]²} dx`

  อินทิกรัลนี้มักไม่คำนวณตรง ๆ แต่แปลงเป็น Z แล้วอ่านตาราง

- การทำให้เป็นมาตรฐาน (p-40):

  `Z = (X−μ)/σ`

  เมื่อ X ~ N(μ,σ²) จะได้ `μ_Z = 0` และ `σ_Z² = 1`

- นิยาม 4.7 การแจกแจงปรกติมาตรฐาน (p-41): `Z ~ N(0,1)` และ

  `f(z) = [1/√(2π)]e^(−z²/2),  −∞ < z < ∞`

- แปลงขอบเขตช่วง (p-42): ถ้า X ~ N(μ,σ²), `z₁=(x₁−μ)/σ`, `z₂=(x₂−μ)/σ` แล้ว

  `P(x₁ < X < x₂) = P(z₁ < Z < z₂)`

- ค่าพื้นที่ที่ควรจำจากรูป (p-43):

  `P(μ−σ < X < μ+σ) ≈ 0.6826`, `P(μ−2σ < X < μ+2σ) ≈ 0.9544`, และ `P(μ−3σ < X < μ+3σ) ≈ 0.9974`

- ตารางปกติมาตรฐาน (p-44): ตารางที่สไลด์ระบุเป็น Cumulative Standard Normal Probability Distribution ให้พื้นที่ซ้ายของ z₀

  `Φ(z₀) = P(Z ≤ z₀) = ∫₋∞^{z₀} [1/√(2π)]e^(−z²/2) dz`

  วิธีอ่าน: ใช้เลขหลักหน่วยและทศนิยมหลักแรกของ z เป็นแถว (เช่น 1.1) และทศนิยมหลักที่สองเป็นคอลัมน์ (เช่น .07) เพื่ออ่าน Φ(1.17). สำหรับด้านขวาใช้ `P(Z > z)=1−Φ(z)`; สำหรับช่วงใช้ `P(a<Z<b)=Φ(b)−Φ(a)`; สำหรับค่าลบใช้สมมาตร `Φ(−z)=1−Φ(z)`

  ตัวอย่างประกอบบนสไลด์ p-44 คือ `P(Z < 1.25)=0.9844` (อ่านแถว 1.2 คอลัมน์ .05)

## 3. Worked examples

หมายเหตุ: สไลด์ EX 4.13–4.21 เป็นสไลด์โจทย์ ไม่มีบรรทัดเฉลยตัวเลข ดังนั้น “คำตอบบนสไลด์” ในแต่ละข้อคือ **สไลด์ไม่แสดงคำตอบ**; ค่าด้านล่างเป็นการคำนวณทวนจากโจทย์เอง ไม่มี SLIDE DISCREPANCY ที่เทียบกับตัวเลขบนสไลด์ได้

### EX 4.13 (p-30)

**โจทย์ย่อ:** ยกตัวอย่างสถานการณ์ที่เป็นการแจกแจงเอกรูปชนิดต่อเนื่อง 4 กรณี: (1) เวลามาถึงป้ายรถเมล์สุ่มในช่วง 8:00–9:00, (2) จุดสุ่มบนไม้บรรทัดยาว 1 เมตร ช่วง [0,1], (3) มุมสุ่มจากวงล้อ 0–360 องศา, (4) ระดับน้ำสุ่มในแก้วช่วง [0,h]

**วิธีและเหตุผล:** ทุกกรณีเป็นค่าที่วัดได้ต่อเนื่องและสมมติว่าแต่ละตำแหน่งในช่วงมีโอกาสเท่ากัน จึงจัดเป็น X ~ U(a,b) ไม่ต้องใช้ตาราง

**ขั้น:** ระบุช่วงปลายล่าง a และปลายบน b แล้วใช้ `f(x)=1/(b−a)` หรือสัดส่วนความยาวเมื่อถามความน่าจะเป็น ตัวอย่างเช่น เวลารถเมล์ใช้ a=8,b=9; จุดไม้บรรทัด a=0,b=1; มุม a=0,b=360; ระดับน้ำ a=0,b=h

**คำตอบ:** สไลด์ไม่แสดงคำตอบตัวเลข; ทั้ง 4 กรณีเป็นตัวอย่าง continuous uniform ตามโจทย์

**ตาราง:** ไม่มี

### EX 4.14 (p-31)

**โจทย์ย่อ:** เหตุขัดข้องเกิดแบบสุ่มตลอดเวลาทำงาน 8:00–17:00 (รวม 9 ชั่วโมง) จงหา (1) ระหว่าง 9:00–10:30, (2) หลัง 16:00, (3) เมื่อรู้แล้วว่าเกิดหลัง 11:00 จงหาโอกาสเกิดระหว่าง 14:00–15:30

**วิธี:** T ~ U(8,17) เพราะเวลาทุกจุดใน 9 ชั่วโมงมีโอกาสเท่ากัน ใช้ “ความยาวช่วงที่สนใจ / ความยาวช่วงทั้งหมด”; ข้อ 3 ใช้อัตราส่วนช่วงย่อยต่อช่วงเงื่อนไข

**ขั้นคำนวณ:**

1. 9:00–10:30 ยาว 1.5 ชั่วโมง: `P=(10.5−9)/(17−8)=1.5/9=1/6≈0.1667`
2. หลัง 16:00 ถึง 17:00 ยาว 1 ชั่วโมง: `P=(17−16)/9=1/9≈0.1111`
3. เมื่อจำกัดว่าเกิดหลัง 11:00 ช่วงที่เป็นไปได้ยาว 6 ชั่วโมง (11–17); ช่วง 14–15:30 ยาว 1.5 ชั่วโมง: `P=(15.5−14)/(17−11)=1.5/6=0.25`

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; คำตอบคำนวณได้ตามลำดับคือ `0.1667, 0.1111, 0.25` (หรือ `1/6,1/9,1/4`)

**ตาราง:** ไม่มี

### EX 4.15 (p-32)

**โจทย์ย่อ:** X เป็นค่าที่สุ่มได้ในช่วง (10,30) จงหา (1) P(10 ≤ X ≤ 15), (2) P(X ≤ 14), (3) P(X ≥ 20), (4) P(X ≥ 35)

**วิธี:** X ~ U(10,30) จึงใช้ความยาวช่วง / 20; จุดปลายไม่มีผลเพราะเป็นตัวแปรต่อเนื่อง

**ขั้นคำนวณ:**

1. `P(10≤X≤15)=(15−10)/(30−10)=5/20=0.25`
2. `P(X≤14)=(14−10)/20=4/20=0.20`
3. `P(X≥20)=(30−20)/20=10/20=0.50`
4. 35 อยู่นอกช่วงบน 30 จึง `P(X≥35)=0`

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; `0.25, 0.20, 0.50, 0` ตามลำดับ

**ตาราง:** ไม่มี

### EX 4.16 (p-35)

**โจทย์ย่อ:** เวลารอเครื่อง GC-MS มีค่าเฉลี่ย 5 นาที จงหา (1) โอกาสรอเกิน 10 นาที, (2) โอกาสรอ 3–7 นาที, (3) ค่าเฉลี่ยและความแปรปรวน

**วิธี:** เวลารอเป็นบวกและโจทย์ให้ค่าเฉลี่ย จึงใช้ Exponential โดย β=5 นาที; ใช้ `P(T>t)=e^(−t/β)` และผลต่างของ CDF สำหรับช่วง

**ขั้นคำนวณ:**

1. `P(T>10)=e^(−10/5)=e^(−2)=0.135335…≈0.1353`
2. `P(3<T<7)=F(7)−F(3)=(1−e^(−7/5))−(1−e^(−3/5))`
   `=e^(−0.6)−e^(−1.4)=0.302214…≈0.3022`
3. จากทฤษฎี 4.6: `μ=β=5` นาที และ `σ²=β²=25` นาที² (จึง `σ=5` นาที)

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; `0.1353, 0.3022, μ=5 นาที, σ²=25 นาที²`

**ตาราง:** ไม่มี (คำนวณด้วย e)

### EX 4.17 (p-45)

**โจทย์ย่อ:** ให้ Z ~ N(0,1) จงหา (1) P(Z ≤ 1.17), (2) P(Z > 2.23), (3) P(0.42 < Z < 1.61), (4) P(−1.61 < Z < 0.59)

**วิธี:** ใช้ตาราง Cumulative Standard Normal ซึ่งให้ Φ(z)=P(Z≤z). ด้านขวาใช้ส่วนเติมเต็ม และช่วงใช้ผลต่างของพื้นที่ซ้าย

**ขั้นคำนวณและการอ่านตาราง:**

1. แถว 1.1 คอลัมน์ .07 ได้ `Φ(1.17)=0.8790`
2. แถว 2.2 คอลัมน์ .03 ได้ `Φ(2.23)=0.9871`; ดังนั้น `P(Z>2.23)=1−0.9871=0.0129`
3. อ่าน `Φ(1.61)=0.9463` (แถว 1.6 คอลัมน์ .01) และ `Φ(0.42)=0.6628` (แถว 0.4 คอลัมน์ .02): `0.9463−0.6628=0.2835`
4. อ่าน `Φ(0.59)=0.7224`; ใช้สมมาตร `Φ(−1.61)=1−Φ(1.61)=1−0.9463=0.0537`; ดังนั้น `0.7224−0.0537=0.6687`

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; `0.8790, 0.0129, 0.2835, 0.6687`

**ตาราง:** Cumulative Standard Normal; ตารางต้องอ่านเป็นพื้นที่ซ้ายเสมอ

### EX 4.18 (p-46)

**โจทย์ย่อ:** ความยาวแท่งพอลิเมอร์ X แจกแจงปกติ มี μ=67.56 นิ้ว, σ=2.57 นิ้ว จงหา P(X > 5 ฟุต 2 นิ้ว)

**วิธี:** เป็นค่าต่อเนื่องแบบปกติ จึงแปลงหน่วยและทำมาตรฐานด้วย `Z=(X−μ)/σ` แล้วใช้หางขวาของตาราง

**ขั้นคำนวณ:** `5 ฟุต 2 นิ้ว = 5×12+2=62 นิ้ว`

`z=(62−67.56)/2.57=−2.1634…≈−2.16`

`P(X>62)=P(Z>−2.1634)=1−Φ(−2.1634)=Φ(2.1634)`

ใช้ตารางที่ z=2.16 ได้ `Φ(2.16)=0.9846`; ถ้าไม่ปัด z ก่อน ค่าประมาณเชิงตัวเลขคือ 0.9847

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; รายงานตามความละเอียดตารางได้ `≈0.9846` (คำนวณไม่ปัดระหว่างทาง `≈0.9847`)

**ตาราง:** Cumulative Standard Normal; เปลี่ยนหางซ้ายที่ −2.16 เป็นหางขวาหรือใช้สมมาตรไปที่ +2.16

### EX 4.19 (p-47)

**โจทย์ย่อ:** เม็ดพลาสติก 300 เม็ด แต่ละเม็ดมีน้ำหนัก X ~ N(68,3²) กรัม คาดว่าจะมีกี่เม็ดที่น้ำหนัก 64–72 กรัม

**วิธี:** คำนวณโอกาสของเม็ดหนึ่งเม็ดจาก normal แล้วคูณจำนวนทั้งหมด 300 (ค่าคาดหมาย = Np)

**ขั้นคำนวณ:**

`z₁=(64−68)/3=−1.3333≈−1.33`, `z₂=(72−68)/3=1.3333≈1.33`

`p=P(64<X<72)=Φ(1.33)−Φ(−1.33)=0.9082−0.0918=0.8164`

`จำนวนคาดหมาย=300×0.8164=244.92≈245 เม็ด`

ถ้าใช้ค่า z=±1.3333 โดยไม่ปัด จะได้ p≈0.8176 และ 300p≈245.27 ซึ่งยังปัดเป็น 245 เม็ด

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; ประมาณ `245 เม็ด`

**ตาราง:** Cumulative Standard Normal; อ่านพื้นที่ซ้ายของ +1.33 และ −1.33 แล้วลบกัน

### EX 4.20 (p-48)

**โจทย์ย่อ:** ให้ Z ~ N(0,1) จงหาค่า z₀ จาก (1) P(Z≤z₀)=0.975, (2) P(Z<z₀)=0.1977, (3) P(Z>z₀)=0.05, (4) P(z₀<Z<z₁)=0.9544

**วิธี:** ย้อนตารางจากพื้นที่สะสม (เลือกแถว/คอลัมน์ที่ให้ค่าพื้นที่) และแปลงหางขวาเป็นพื้นที่ซ้ายก่อน

**ขั้นคำนวณ:**

1. หาในตารางพื้นที่ 0.9750 ได้ `z₀=1.96`
2. พื้นที่ซ้าย 0.1977 อยู่ฝั่งลบ; ตารางให้ `z₀=−0.85` เพราะ Φ(−0.85)=0.1977
3. `P(Z>z₀)=0.05` แปลว่า `Φ(z₀)=0.95`; ตารางให้ `z₀≈1.645` (ถ้าตารางสองตำแหน่งจะอยู่ระหว่าง 1.64 และ 1.65)
4. พื้นที่ตรงกลาง 0.9544 เป็นพื้นที่ระหว่าง −2 และ +2 ตามรูป p-43 จึงได้ `z₀=−2, z₁=2` **เมื่อสมมติว่าช่วงสมมาตรรอบ 0**

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; `1.96, −0.85, 1.645, (−2,2)` ตามลำดับ

**ตาราง:** Cumulative Standard Normal; ข้อ 4 ใช้ค่าพื้นที่ตรงกลางจาก p-43 หรืออ่าน Φ(2)−Φ(−2)=0.9772−0.0228=0.9544

### EX 4.21 (p-49)

**โจทย์ย่อ:** อายุแบตเตอรี่ X ~ N(38,2²) เดือน โรงงานรับเปลี่ยนไม่เกิน 5% จงกำหนดระยะเวลารับประกัน

**วิธี:** แบตเตอรี่ที่เสียก่อนครบระยะประกันคือหางซ้าย จึงเลือกค่าประกัน w ให้ `P(X≤w)=0.05` (สำหรับตัวแปรต่อเนื่องใช้ < หรือ ≤ ได้เท่ากัน) แล้วใช้ quantile ของ Z

**ขั้นคำนวณ:** ตารางให้ `Φ(−1.645)=0.05`; ดังนั้น

`w=μ+zσ=38+(−1.645)(2)=34.71 เดือน`

ถ้าใช้ตารางสองตำแหน่ง z=−1.64 ถึง −1.65 จะได้ประมาณ 34.72 ถึง 34.70 เดือน

**คำตอบ:** สไลด์ไม่แสดงคำตอบ; ระยะประกันประมาณ `34.71 เดือน` (ราว 34.7 เดือน)

**ตาราง:** Cumulative Standard Normal; ใช้พื้นที่ซ้าย 0.05 หรือสมมาตรกับพื้นที่ซ้าย 0.95 ที่ z=+1.645 แล้วเปลี่ยนเครื่องหมาย

## 4. Decision rules

- **เริ่มจากชนิดของตัวแปร**
  - ถ้าเป็น “จำนวนครั้ง/จำนวนชิ้น/จำนวนคน” เป็นจำนวนเต็มไม่ติดลบ ให้คิดถึงการแจกแจงไม่ต่อเนื่อง (แต่ตัวอย่าง EX ในช่วง p-29–p-55 เน้นตัวแปรต่อเนื่อง)
  - ถ้าเป็นเวลา ความยาว น้ำหนัก มุม หรือค่าที่วัดได้ มีทศนิยมได้ ให้คิดถึงการแจกแจงต่อเนื่อง
- **ถ้าทุกตำแหน่งในช่วงมีโอกาสเท่ากัน** → Uniform ต่อเนื่อง: ใช้ความยาวช่วงที่ต้องการ ÷ ความยาวช่วงทั้งหมด; ไม่ใช้ตาราง
- **ถ้าคือเวลารอจนเหตุการณ์แรกเกิด และเวลาเป็นบวก** → Exponential: ใช้ β เป็นค่าเฉลี่ย, `P(X>t)=e^(−t/β)`; ไม่ใช้ตารางสถิติ
- **ถ้าโจทย์บอกแจกแจงปกติ/โค้งระฆังและให้ μ, σ** → Normal: แปลงทุกหน่วยให้เหมือนกัน แล้วคำนวณ `z=(x−μ)/σ`
- **เลือกการอ่านตาราง normal หลังได้ z**
  - ต้องการ `P(Z≤z)` หรือพื้นที่ซ้าย → อ่าน Φ(z) ตรง ๆ
  - ต้องการ `P(Z>z)` หรือหางขวา → `1−Φ(z)`
  - ต้องการ `P(a<Z<b)` → `Φ(b)−Φ(a)`
  - มี z ติดลบ → ใช้ `Φ(−z)=1−Φ(z)` หรืออ่านแถวลบในตาราง
  - ต้องการหา z จากความน่าจะเป็น → ค้นค่าพื้นที่ในตัวตาราง แล้วอ่านแถว/คอลัมน์กลับ
  - พื้นที่ตรงกลางสมมาตรรอบ 0 เช่น 0.9544 → ใช้ขอบ `−2,+2`
- **ถ้าถามจำนวนจากประชากร N ชิ้น** หลังหาโอกาสของหนึ่งชิ้น p แล้วใช้ค่าคาดหมาย `Np` และปัดเป็นจำนวนชิ้นอย่างเหมาะสม (EX 4.19)
- **ตรวจขอบเขตและหน่วยก่อนแทนสูตร**: ช่วง (10,30) ยาว 20; 5 ฟุต 2 นิ้วต้องแปลงเป็น 62 นิ้ว; เวลาต้องเปลี่ยนเป็นชั่วโมงหรือเป็นนาทีให้เหมือนกัน

## 5. Prerequisite knowledge

- การแปลงหน่วยและเวลา เช่น 1 ฟุต = 12 นิ้ว, 30 นาที = 0.5 ชั่วโมง
- เลขทศนิยม เศษส่วน ร้อยละ และการปัดเศษ
- ความหมายของช่วงและอสมการ: `<`, `≤`, `>`, `≥`; การหา “ความยาวช่วง” จากปลายบน − ปลายล่าง
- เลขยกกำลังและค่าคงที่ e; รู้ว่า `e^(−u)` เป็นจำนวนบวกน้อยกว่า 1 เมื่อ u>0
- รากที่สองและการยกกำลังสอง เช่น σ=√σ²
- ความหมายของค่าเฉลี่ย μ, ความแปรปรวน σ² และส่วนเบี่ยงเบนมาตรฐาน σ
- แนวคิดตัวแปรสุ่มต่อเนื่อง: ความน่าจะเป็นคือพื้นที่ใต้กราฟ และจุดเดียวมีความน่าจะเป็น 0
- อินทิกรัลในระดับ “พื้นที่ใต้โค้ง” และการอ่านสัญลักษณ์ขอบเขตอินทิกรัล (ไม่จำเป็นต้องอินทิเกรตสูตร normal เอง)
- การหาร/คูณอัตราส่วน และ conditional probability แบบ “ช่วงที่สนใจ ÷ ช่วงที่ยังเป็นไปได้”
- ความสมมาตรของโค้งปกติรอบ 0 และกฎส่วนเติมเต็ม `1−P`
- การอ่านตารางแบบแถว 1.1 คอลัมน์ .07 รวมเป็น z=1.17 และการค้นย้อนจากพื้นที่เป็น z

## 6. Likely multiple-choice traps

- ใช้ `b−a` เป็นความยาวช่วง uniform ไม่ใช่ `a+b`; อย่าลืมว่าช่วงที่สนใจต้องตัดกับช่วงที่เป็นไปได้ก่อน
- Uniform ต่อเนื่อง: `P(X=จุดเดียว)=0` ดังนั้น `<` กับ `≤` ให้ค่าเดียวกัน แต่ห้ามใช้เหตุผลนี้กับตัวแปรนับจำนวน
- Exponential ใช้ β เป็น “ค่าเฉลี่ยเวลา” และความแปรปรวนเป็น β²; อย่าสลับกับอัตรา λ=1/β หรือใช้ σ²=β
- หางขวาต้องใช้ `1−Φ(z)`; อ่าน Φ(z) ตรง ๆ จะได้หางซ้ายและผิดเกือบ 1
- พื้นที่ระหว่างสองค่าต้องลบ “ขอบบน − ขอบล่าง”; ห้ามบวกพื้นที่สองด้านโดยไม่ดูโจทย์
- การทำ z ต้องหารด้วย σ ไม่ใช่ σ² และต้องรักษาเครื่องหมายลบเมื่อค่าต่ำกว่า μ
- ตารางที่สไลด์ใช้เป็นพื้นที่สะสมทางซ้าย ไม่ใช่พื้นที่ระหว่าง 0 ถึง z (ตารางบางเล่มใช้รูปแบบอื่น ต้องอ่านหัวตารางก่อน)
- ค่าลบใช้สมมาตร: `Φ(−1.61)=1−Φ(1.61)` ไม่ใช่ `−Φ(1.61)`
- ค่า z ที่ปัดต่างกัน (เช่น 2.1634 เป็น 2.16) ทำให้ทศนิยมสุดท้ายต่างกันได้ ควรรายงานความละเอียดให้สอดคล้องกับตาราง
- EX 4.18 ต้องแปลง 5 ฟุต 2 นิ้วเป็น 62 นิ้วก่อน ไม่ใช่ 5.2 นิ้วหรือ 5.166 นิ้วแล้วผสมหน่วย
- EX 4.19 คูณโอกาสของเม็ดหนึ่งเม็ดด้วย 300 เพื่อได้ “จำนวนคาดหมาย” ไม่ใช่รายงาน p≈0.8164 เป็นจำนวนเม็ด
- EX 4.20(3) โจทย์เป็นหางขวา 0.05 จึงได้ z บวกประมาณ 1.645; ใช้ −1.645 จะกลับหาง
- EX 4.20(4) พื้นที่ 0.9544 ให้คู่ −2,+2 เมื่อช่วงสมมาตร; ถ้าไม่ระบุสมมาตร สมการเดียวหา z₀,z₁ สองตัวไม่ได้
- EX 4.21 เป็นหางซ้าย 5% เพราะต้องการให้แบตเตอรี่เสียก่อนหมดประกันไม่เกิน 5%; อย่าใช้ z=+1.645 แล้วได้ 41.29 เดือน ซึ่งเป็นควอนไทล์ 95%
- “ไม่เกิน 5%” กับ “น้อยกว่า 5%” ต่างกันเชิงภาษาบางกรณี แต่สำหรับ normal ต่อเนื่องจุดปลายมีความน่าจะเป็น 0
- อย่าสับสน σ (ส่วนเบี่ยงเบนมาตรฐาน) กับ σ² (ความแปรปรวน) ในการแทนค่าและหน่วย

## 7. Possible slide errors / ambiguities

- **เลขนิยาม/ทฤษฎีซ้ำ:** p-29, p-34 และ p-37 ใช้หัวข้อ “ทฤษฎี 4.6” ทั้งที่เป็นคนละการแจกแจง; p-33 และ p-36 ใช้ “นิยาม 4.6” ซ้ำกัน ควรตรวจเลขลำดับในต้นฉบับ (น่าจะมีเลขที่ควรเป็น 4.7, 4.8 ฯลฯ)
- **EX 4.20(4) ไม่พอระบุคำตอบ:** หัวข้อ p-48 บอกให้หาค่า z₀ แต่สมการมีทั้ง z₀ และ z₁: `P(z₀<Z<z₁)=0.9544`. ต้องมีเงื่อนไขว่าช่วงสมมาตรรอบ 0 จึงตอบ `z₀=−2,z₁=2`; หากไม่มีเงื่อนไขจะมีคู่คำตอบได้หลายคู่
- **คำตอบ EX 4.20(4) ไม่ได้พิมพ์บนสไลด์โจทย์:** ควรเขียนเฉลยในเอกสารประกอบให้ชัดว่าคือคู่ `−2,2` ภายใต้สมมติฐานสมมาตร
- **นิยาม continuous ใช้คำว่า “ฟังก์ชันความน่าจะเป็น”:** p-33 และ p-36 เป็นตัวแปรต่อเนื่อง จึงควรเรียก `probability density function (ความหนาแน่นความน่าจะเป็น)` เพื่อไม่ให้เข้าใจว่า f(x) เป็นโอกาสของจุด x โดยตรง
- **EX 4.21 ไม่ระบุเครื่องหมายที่จุดครบกำหนดประกัน:** บอกเพียงจำนวนเปลี่ยน “ไม่เกิน 5%”; ควรระบุว่าเสียก่อน/ไม่เกิน w เดือน แต่สำหรับ normal ต่อเนื่อง `<` และ `≤` ให้ค่าเท่ากัน
- **ความละเอียดของคำตอบที่อ่านจากตาราง:** EX 4.18 ให้ z≈−2.16 จากการปัด จึงได้ 0.9846 ขณะที่คำนวณ z เต็มได้ประมาณ 0.9847; เป็นความต่างจากการปัด ไม่ใช่ความขัดแย้งของแบบจำลอง
- **สไลด์ EX 4.13–4.21 ไม่มีบรรทัดเฉลย:** หากผู้จัดทำต้องการ “คำตอบตามสไลด์” ต้องเพิ่มหน้าคำตอบหรือระบุว่าโจทย์ยังไม่มีเฉลย; ค่าที่รายงานในบันทึกนี้เป็นการคำนวณทวน
- **เฉลยแบบฝึกหัดข้อ 4 บน p-52 ข้ามหมายเลข:** โจทย์มี 3 ข้อย่อย แต่บรรทัดเฉลยพิมพ์ `1) 0.8573, 2) 0.8649, 4) 2,2` จึงน่าจะพิมพ์ `4)` แทน `3)` (คำตอบ 2,2 เป็นค่าคาดหมายและความแปรปรวนของข้อย่อย 3)
- **แบบฝึกหัดข้อ 6(3) บน p-53 ไม่ระบุสมมาตร/ขอบเขตครบ:** โจทย์เขียน `P(z₀ < Z < z₁)=0.9` แต่ให้หาค่า z₀ และมี z₁ อีกตัว; เฉลยพิมพ์ `1.645` ค่าเดียว ซึ่งควรเป็นคู่ประมาณ `−1.645,+1.645` หากตั้งใจให้ช่วงสมมาตรรอบ 0
