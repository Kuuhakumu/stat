## 2. Definitions & formulas

### 2.1 สัญลักษณ์ร่วม

- `X` = ตัวแปรสุ่ม, `x` = ค่าที่เป็นจำนวนเต็มของ X; ในตารางทวินาม/ปัวส์ซง แถว `x` ทำหน้าที่เป็นจุดตัด `r` ในสูตรสะสม
- `r` = ค่าสูงสุดที่รวมในเหตุการณ์สะสม; `Y` = ตัวแปรสุ่มทั่วไปในนิยาม CDF; `N(μ,σ²)` = การแจกแจงปกติที่มีค่าเฉลี่ย μ และความแปรปรวน σ²
- `n` = จำนวนการทดลอง/ขนาดตัวอย่าง, `p` = โอกาสสำเร็จต่อการทดลอง, `1 − p` = โอกาสไม่สำเร็จ
- `n₁,n₂` = ขนาดตัวอย่างจากประชากรกลุ่มที่ 1 และ 2; `x̄` = ค่าเฉลี่ยตัวอย่าง, `s` หรือ `S` = ส่วนเบี่ยงเบนมาตรฐานตัวอย่าง และ `S²` = ความแปรปรวนตัวอย่าง
- `λ` (แลมบ์ดา) = จำนวนเหตุการณ์เฉลี่ยต่อช่วงเวลา/พื้นที่ในปัวส์ซง
- `μ` = ค่าเฉลี่ยประชากร, `μ₀` = ค่าเฉลี่ยที่ระบุในสมมติฐาน, `σ` = ส่วนเบี่ยงเบนมาตรฐานประชากร, `σ²` = ความแปรปรวนประชากร, `σ₀²` = ความแปรปรวนภายใต้สมมติฐานศูนย์
- `F(a) = P(Y ≤ a)` = ความน่าจะเป็นสะสมด้านซ้ายของตัวแปรสุ่ม Y
- `α` = พื้นที่หางที่ต้องการ (ระดับนัยสำคัญในโจทย์ทดสอบสมมติฐาน); `1 − α` = พื้นที่ตรงกลาง/ด้านซ้ายตามบริบท
- `ν` (นิว) หรือ `df` = degrees of freedom (องศาความเป็นอิสระ)
- `e` = ค่าคงที่ออยเลอร์ (ประมาณ 2.71828); `!` = แฟกทอเรียล; `ⁿCₓ` = จำนวนวิธีเลือก x รายการจาก n รายการ
- `Tν`/`tν` และ `χ²ν` = ตัวแปร/การแจกแจง t และไคสแควร์ที่มี df=ν; `tα`/`χ²α,ν` = ค่าวิกฤตตามพื้นที่หาง α

### 2.2 ทวินาม: p-01–p-11

**นิยาม/เงื่อนไขใช้**: ใช้เมื่อมีการทดลองจำนวนคงที่ `n` ครั้ง, แต่ละครั้งมีผลลัพธ์สองแบบ (สำเร็จ/ไม่สำเร็จ), การทดลองเป็นอิสระ และโอกาสสำเร็จคงที่ `p` ทุกครั้ง; `X` คือจำนวนครั้งที่สำเร็จ และ `x = 0,1,…,n` (ไม่มี `df`)

**โครงตาราง**: กลุ่มแถว `n=2,…,25`; ภายในแต่ละกลุ่มแถว `x=0,…,n`; คอลัมน์ `p=0.05,0.10,…,0.50`. หน้า p-02–p-11 เป็นตารางต่อเนื่องจาก p-01 ไม่ได้เริ่มสูตร/ตารางชนิดใหม่

ฟังก์ชันมวลความน่าจะเป็น (ค่าพอดี):

`P(X = x) = ⁿCₓ pˣ(1 − p)ⁿ⁻ˣ`

โดย `ⁿCₓ = n!/[x!(n−x)!]`, `!` = แฟกทอเรียล (`n! = n(n−1)…1`)

สูตรที่พิมพ์บนตาราง (ความน่าจะเป็นสะสมด้านซ้าย):

`P(X ≤ r) = Σₓ₌₀ʳ ⁿCₓ pˣ(1 − p)ⁿ⁻ˣ`

ดังนั้นช่องหนึ่งช่องตอบ “สำเร็จไม่เกิน r ครั้ง” รวม `0,1,…,r` ไม่ใช่ `P(X=r)` เพียงค่าเดียว

ค่าคาดหมายและความแปรปรวนที่ใช้ประกอบการเลือกแบบจำลอง:

`E(X)=μ=np`, `Var(X)=σ²=np(1−p)`

### 2.3 ปัวส์ซง: p-12–p-15

**นิยาม/เงื่อนไขใช้**: ใช้กับจำนวนครั้งของเหตุการณ์ในช่วงเวลา/พื้นที่ที่กำหนด เมื่อเหตุการณ์เกิดโดยเฉลี่ย `λ` ครั้ง และนับเป็นจำนวนเต็มไม่ลบ; `X=0,1,2,…` (ไม่มี `df`)

**โครงตาราง**: แถวคือค่า `x`/จุดตัด `r`; คอลัมน์คือ `λ`. คอลัมน์ที่มีให้คือ 0.1–2.0 เพิ่มครั้งละ 0.1, 2.2–4.0 เพิ่มครั้งละ 0.2, 4.2–6.0 เพิ่มครั้งละ 0.2, 6.5–11.0 เพิ่มครั้งละ 0.5 และ 11.5–16.0 เพิ่มครั้งละ 0.5; จำนวนแถว x ที่พิมพ์ขึ้นกับบล็อกหน้า (p-12–p-15)

ฟังก์ชันมวลความน่าจะเป็น:

`P(X=x) = e⁻λ λˣ/x!`

สูตรที่พิมพ์บนตาราง (สะสมด้านซ้าย):

`P(X ≤ r) = Σₓ₌₀ʳ e⁻λ λˣ/x!`

สำหรับปัวส์ซง `E(X)=μ=λ` และ `Var(X)=σ²=λ` จึงมีส่วนเบี่ยงเบนมาตรฐาน `√λ`

### 2.4 ปกติมาตรฐาน z: p-16–p-17

ถ้า `Y ~ N(μ,σ²)` และ `σ>0` ให้ทำมาตรฐานด้วย

`Z = (Y−μ)/σ ~ N(0,1)`

สำหรับค่าเฉลี่ยตัวอย่าง (เมื่อใช้ได้):

`Z = (x̄−μ)/(σ/√n)` เมื่อทราบ `σ`; ถ้าไม่ทราบ `σ` แต่ `n≥30` มักใช้ `Z=(x̄−μ)/(s/√n)` ตามทฤษฎีลิมิตสู่ส่วนกลาง

**เงื่อนไขเลือก Z ในบทเรียน**: ประชากรปกติและทราบ `σ`, หรือไม่ทราบ `σ` แต่ตัวอย่างใหญ่ `n≥30`; สัดส่วนตัวอย่างก็ใช้ Z เมื่อการประมาณปกติเหมาะสม

ทั้ง p-16 และ p-17 ให้ `F(z)=P(Z<z)` (พื้นที่ใต้โค้งทางซ้ายของ z) ไม่ใช่พื้นที่ระหว่าง 0 กับ z โดยตรง

**โครงตาราง**: p-16 ใช้แถว z ตั้งแต่ 0.0 ถึง 3.9 ทีละ 0.1 และคอลัมน์ 0.00–0.09 เพื่อเติมหลักร้อย; p-17 ใช้แถว −3.9 ถึง 0.0 และคอลัมน์ 0.00–0.09 เพื่อเพิ่มขนาดของค่าติดลบทีละ 0.01. ไม่มี df

การแปลงที่ต้องทำเอง:

- `P(Z>z)=1−F(z)`
- `P(a<Z<b)=F(b)−F(a)`
- สำหรับ `z>0`, พื้นที่ระหว่าง 0 ถึง z คือ `F(z)−0.5`
- สมมาตร: `F(−z)=1−F(z)` และ `P(|Z|>z)=2[1−F(z)]`

### 2.5 t: p-18

**เงื่อนไขเลือก t**: ประชากรปกติ, ไม่ทราบ `σ`, และตัวอย่างเล็ก `n<30` (ตามบทเรียน); สำหรับค่าเฉลี่ยหนึ่งประชากร

`T = (x̄−μ)/(s/√n) ~ tν`, `ν=n−1`

ตารางให้ค่าวิกฤตบวก `t` โดยพื้นที่หางขวา:

`P(Tν > tα)=α`

**โครงตาราง**: แถวคือ `df`; มีแถว df 1–30, 40, 60, 80, 100 และ 1000. คอลัมน์เรียงตาม `t₀.50, t₀.75, t₀.80, t₀.85, t₀.90, t₀.95, t₀.975, t₀.99, t₀.995, t₀.999, t₀.9995`; แถว `One-tail`/`Two-tails` ด้านบนช่วยแปลงหัวคอลัมน์เป็นพื้นที่หาง (p-18)

หัวคอลัมน์ `t₀.90` หมายถึงค่าที่พื้นที่สะสมซ้ายเท่ากับ 0.90 จึงมีหางขวา 0.10; แถว `One-tail` พิมพ์ค่า α ของหางขวา และแถว `Two-tails` พิมพ์พื้นที่รวมสองหาง (`2α` ของหางข้างเดียว)

องศาอิสระที่พบบ่อย:

- ค่าเฉลี่ยหนึ่งกลุ่ม: `ν=n−1`
- สองกลุ่มอิสระ ความแปรปรวนเท่ากัน: `ν=n₁+n₂−2`
- สองกลุ่มอิสระ ความแปรปรวนไม่เท่ากัน: ใช้ Welch–Satterthwaite (ปัด `ν` ลง/ตามคำสั่งโจทย์)
- คู่สัมพันธ์: สร้างผลต่าง `Dᵢ` ก่อน แล้วใช้ `ν=n−1`

### 2.6 Chi-square (χ²): p-19

ตารางนี้ไม่มีตัวอย่างคำนวณหรือสูตรบนหน้าตาราง แต่ใช้กับสถิติไคสแควร์ เช่น การประมาณ/ทดสอบความแปรปรวนของประชากรปกติ:

`χ² = (n−1)S²/σ₀² ~ χ²ν`, `ν=n−1`

ตาราง p-19 เป็น **ค่าวิกฤตที่มีพื้นที่หางขวา α**: `P(χ²ν > χ²α,ν)=α`; แถวคือ `df=ν` และคอลัมน์คือ α ตามหัวตาราง (`0.995, 0.99, 0.975, 0.95, 0.9, 0.1, 0.05, 0.025, 0.01, 0.005`)

**องศาอิสระ**: สำหรับทดสอบความแปรปรวนข้างต้น `ν=n−1`; สำหรับการทดสอบความเป็นอิสระในตารางไขว้ที่มี R แถวและ C คอลัมน์ ใช้ `ν=(R−1)(C−1)`; สำหรับ goodness-of-fit มีรูปทั่วไป `ν=k−1−m` เมื่อมี k กลุ่มและประมาณพารามิเตอร์ m ค่าจากข้อมูล (สูตรสองกรณีหลังเป็นความรู้ประกอบ ไม่ได้พิมพ์บน p-19)

χ² ไม่สมมาตรและมีค่าไม่ติดลบ จึงห้ามใช้กฎสมมาตรของ z/t; ถ้าต้องการพื้นที่ซ้าย `q` ให้เลือกคอลัมน์หางขวา `1−q`

**โครงตาราง**: แถว `df=1,…,50`; คอลัมน์มีเฉพาะ α ตามรายการข้างต้น จึงไม่ใช่ตาราง CDF ที่มีทุกค่า q

## 3. Worked examples (การอ่านค่าจริงจากตาราง)

ตรวจภาพ p-01–p-19 ครบแล้ว **ไม่มีหัวข้อ `EX x.x` อยู่ในเล่มตาราง** จึงไม่มีโจทย์ตัวอย่างจากหน้า booklet ที่ต้องถอดซ้ำตามเลข EX ตัวอย่างต่อไปนี้เป็นตัวอย่างการอ่านตารางที่สร้างจากค่าจริงในเล่มตามข้อกำหนด

### 3.1 ทวินาม (p-01–p-02)

**โจทย์ย่อ**: ให้ `X~Binomial(n=7,p=0.40)` จงหา `P(X≤3)`

**วิธีและเหตุผล**: เป็นการนับจำนวนความสำเร็จจากการทดลองคงที่ 7 ครั้งและ p คงที่ จึงใช้ Cumulative Binomial; เหตุการณ์เป็น “ไม่เกิน” จึงอ่านสะสมโดยตรง

**ขั้นตอน**:

1. เปิด p-01–p-02 ซึ่งมีแถวกลุ่ม `n=7` ต่อเนื่องกัน
2. ในกลุ่มนั้นเลือกแถว `x=3` (นี่คือ `r=3` ใน `P(X≤r)`)
3. เลื่อนไปคอลัมน์ `p=0.40`
4. อ่านค่า `0.7102`
5. ตรวจด้วยสูตร: `Σₓ₌₀³ ⁷Cₓ(0.4)ˣ(0.6)⁷⁻ˣ = 0.710208…` จึงปัดเป็น `0.7102`

**คำตอบ**: `P(X≤3)=0.7102` (ตรงกับค่าตาราง; ไม่มี `SLIDE DISCREPANCY`)

### 3.2 ปัวส์ซง (p-12)

**โจทย์ย่อ**: จำนวนเหตุการณ์มี `X~Poisson(λ=1.0)` จงหา `P(X≤3)`

**วิธีและเหตุผล**: เป็นจำนวนเหตุการณ์ต่อช่วงที่มีค่าเฉลี่ย λ จึงใช้ Cumulative Poisson; จุดตัดคือ 3

**ขั้นตอน**:

1. เปิด p-12 ชุดคอลัมน์แรกและเลือกคอลัมน์ `λ=1.0`
2. เลือกแถว `x=3`
3. อ่านค่า `0.9810`
4. ตรวจด้วยสูตร: `e⁻¹[1 + 1 + 1/2! + 1/3!] = 0.9810118…` ปัดเป็น `0.9810`

**คำตอบ**: `P(X≤3)=0.9810` (ตรงกับค่าตาราง; ไม่มี `SLIDE DISCREPANCY`)

### 3.3 z ค่าบวก (p-16)

**โจทย์ย่อ**: จงหา `P(Z<1.23)` เมื่อ `Z~N(0,1)`

**วิธีและเหตุผล**: ตาราง p-16 ระบุชัดว่าเป็น cumulative left `P(Z<z)` และ z เป็นบวก จึงอ่านตรง ๆ

**ขั้นตอน**:

1. แยก `1.23` เป็นแถว `1.2` และคอลัมน์ส่วนร้อย `0.03`
2. ที่จุดตัดใน p-16 อ่าน `0.8907`
3. ค่านี้คือพื้นที่ซ้ายของ 1.23 แล้ว ไม่ต้องลบจาก 1

**คำตอบ**: `P(Z<1.23)=0.8907` (ค่าคำนวณประมาณ 0.89065 ปัดเป็น 0.8907; ไม่มี `SLIDE DISCREPANCY`)

### 3.4 z ค่าลบ (p-17)

**โจทย์ย่อ**: จงหา `P(Z<−1.23)`

**วิธีและเหตุผล**: เป็นพื้นที่ซ้ายของ z ติดลบ; p-17 มีแถวค่าลบโดยตรง จึงไม่ต้องแปลงเครื่องหมายเอง

**ขั้นตอน**:

1. เปิด p-17 เลือกแถว `−1.2`
2. เลือกคอลัมน์ `0.03`
3. อ่าน `0.1093`
4. ตรวจสมมาตรจาก p-16: `1−P(Z<1.23)=1−0.8907≈0.1093`

**คำตอบ**: `P(Z<−1.23)=0.1093` (ค่าคำนวณประมาณ 0.1093486 ปัดเป็น 0.1093; ไม่มี `SLIDE DISCREPANCY`)

### 3.5 t (p-18)

**โจทย์ย่อ**: เมื่อ `ν=5` จงอ่านค่า `t` ที่ทำให้ `P(T₅>t)=0.10`

**วิธีและเหตุผล**: เป็นหางขวา 0.10 จึงใช้แถว `One-tail=0.1` หรือคอลัมน์ `t₀.90` (พื้นที่สะสมซ้าย 0.90)

**ขั้นตอน**:

1. เปิด p-18 และหาแถว `df=5`
2. หา column `t₀.90`; ตรวจแถวหัวตารางว่า `One-tail=0.1`
3. อ่านค่า `1.476`
4. สรุป `P(T₅>1.476)=0.10` ตามความหมายของคอลัมน์

**คำตอบ**: `t=1.476` (ตรงกับค่าตารางและคำอธิบายบนสไลด์; ไม่มี `SLIDE DISCREPANCY`)

ตัวอย่างอ่านสองหาง: แถว `df=5`, คอลัมน์ `t₀.975` มีค่า `2.571`; แถว `Two-tails=0.05` จึงหมายถึง `P(|T₅|>2.571)=0.05`

### 3.6 χ² (p-19)

**โจทย์ย่อ**: เมื่อ `df=5` จงอ่านค่าวิกฤตที่มีหางขวา `α=0.05`

**วิธีและเหตุผล**: p-19 เป็นตารางค่าวิกฤต χ² ที่หัวคอลัมน์เป็นพื้นที่หางขวาโดยตรง และโจทย์ให้ df=5

**ขั้นตอน**:

1. เปิด p-19 เลือกแถว `df=5`
2. เลือกคอลัมน์ `0.05` (ไม่ใช่ `0.95`; ตารางนี้พิมพ์ α หางขวา)
3. อ่านค่า `11.070`
4. แปลความหมายเป็น `P(χ²₅>11.070)=0.05`

**คำตอบ**: `χ²₀.05,5=11.070` (ตรงกับค่าตาราง; ไม่มี `SLIDE DISCREPANCY`)

## 4. Decision rules (ผังตัดสินใจ)

- **เริ่มจากสิ่งที่กำลังนับ/วัด**
  - นับ “สำเร็จจากการทดลอง n ครั้ง” และมี p เดียวกัน → **ทวินาม**, เปิด p-01–p-11
  - นับ “จำนวนเหตุการณ์ในเวลา/พื้นที่” และรู้ค่าเฉลี่ย λ → **ปัวส์ซง**, เปิด p-12–p-15
  - ค่าต่อเนื่อง/ค่าเฉลี่ยที่แปลงเป็นมาตรฐาน → **ปกติมาตรฐาน Z**, เปิด p-16–p-17
  - ค่าเฉลี่ย, ประชากรปกติ, ไม่รู้ σ, `n<30` → **t**, เปิด p-18
  - ความแปรปรวน/สถิติที่ระบุ χ² หรือการทดสอบที่กำหนด χ² → **chi-square**, เปิด p-19
- **เลือก Z หรือ t สำหรับค่าเฉลี่ย**
  - รู้ σ → Z
  - ไม่รู้ σ และ `n≥30` → Z โดยใช้ s ตามบทเรียน
  - ไม่รู้ σ และ `n<30` พร้อมประชากรปกติ → t, `df=n−1`
- **แปลงเหตุการณ์ให้ตรงกับหัวตาราง**
  - ทวินาม/ปัวส์ซง: ตารางให้ `P(X≤r)`; `P(X≥k)=1−P(X≤k−1)`, `P(X>k)=1−P(X≤k)`; ช่วง `a≤X≤b` = `P(X≤b)−P(X≤a−1)`
  - z: ตารางให้ `P(Z<z)`; หางขวา = `1−F(z)`, ช่วง = ผลต่าง CDF, ค่าลบใช้ p-17 หรือสมมาตร
  - t: อ่านค่าวิกฤตจาก `One-tail` หรือ `Two-tails` ให้ตรงกับโจทย์; หางซ้ายใช้สมมาตรเป็นค่าลบของจุดวิกฤต
  - χ²: เลือก df และ α **หางขวา**; ถ้าต้องการหางซ้าย q ให้ใช้คอลัมน์ `1−q`; ห้ามใช้สมมาตร
- **อ่านพิกัด**
  - ตารางทวินาม: กลุ่มแถว n → แถว x/r → คอลัมน์ p
  - ตารางปัวส์ซง: แถว x/r → คอลัมน์ λ (ตรวจชุดช่วง λ ว่าอยู่หน้าใด)
  - z: แถวทศนิยมหลักหนึ่งตำแหน่ง → คอลัมน์ทศนิยมตำแหน่งที่สอง
  - t/χ²: แถว df → คอลัมน์ probability/α
- ถ้าค่าไม่อยู่ในหัวตาราง ห้ามเดาค่าอีกคอลัมน์หรือสลับตาราง; ใช้ complement/สมมาตรเมื่อทำได้ และทำ interpolation เฉพาะเมื่อโจทย์สั่ง

## 5. Prerequisite knowledge

- การอ่านเครื่องหมาย `<`, `≤`, `>`, `≥` และการกลับเครื่องหมายเมื่อคูณด้วยจำนวนลบ
- เศษส่วน ทศนิยม เปอร์เซ็นต์ และการคูณ/ยกกำลัง
- รากที่สอง เช่น `√n` และการจัดรูป `(x̄−μ)/(σ/√n)`
- แฟกทอเรียล `n!` และการจัดหมู่ `ⁿCₓ`
- ผลรวมซิกมา `Σ` และความหมาย “รวมตั้งแต่ x=0 ถึง r”
- ความน่าจะเป็นสะสม/พื้นที่ใต้กราฟ: ซ้าย + ขวา = 1 และพื้นที่ช่วง = ผลต่างพื้นที่สะสม
- ความสมมาตรของโค้งปกติและ t รอบศูนย์; เข้าใจว่า χ² เบ้ขวาและไม่สมมาตร
- ค่าเฉลี่ย ความแปรปรวน ส่วนเบี่ยงเบนมาตรฐาน และความต่างระหว่าง σ กับ s
- ขนาดตัวอย่าง n และ degrees of freedom (`df=n−1` ในกรณีค่าเฉลี่ยหนึ่งกลุ่ม)
- ความหมายของ “หางเดียว/สองหาง” และการแบ่ง α เป็น α/2 ต่อหาง
- การปัดเศษทศนิยมและการรักษาความละเอียดตามที่ตารางพิมพ์

## 6. Likely multiple-choice traps

- ช่องทวินาม/ปัวส์ซงเป็น `P(X≤r)` ไม่ใช่ `P(X=r)`; ต้องลบ CDF สองจุดเพื่อได้ “ระหว่าง”
- สำหรับจำนวนเต็ม `P(X≥k)` ต้องใช้ `1−P(X≤k−1)`; การใช้ `1−P(X≤k)` จะกลายเป็น `P(X>k)`
- สับสนแถว `n` กับแถว `x/r` ในทวินาม หรือสับสน `λ` กับ `x` ในปัวส์ซง
- ใช้ `p` เป็น `1−p` หรือใช้ λ เป็นเปอร์เซ็นต์แทนค่าเฉลี่ยจำนวนเหตุการณ์
- อ่าน z เป็น “พื้นที่ระหว่าง 0 กับ z” ทั้งที่ p-16/p-17 ให้พื้นที่ซ้ายทั้งหมด; หางขวาต้องทำ `1−F(z)`
- ค่า z ติดลบต้องเลือกแถวติดลบใน p-17 หรือใช้สมมาตร; ห้ามเอา `F(−z)` ไปใช้เป็น `F(z)`
- ลืมว่าตารางตาราง t เป็นค่าวิกฤตหางขวา แม้หัวจะเขียน `Cum.prob`; ใช้แถว `One-tail` กับ `Two-tails` ผิดกัน
- โจทย์สองหางระดับนัยสำคัญ α ต้องใช้ α/2 ต่อหาง; ไม่ใช่คอลัมน์ one-tail α ตรง ๆ
- ใช้ `df=n` แทน `df=n−1` สำหรับ t ค่าเฉลี่ยหนึ่งกลุ่ม หรือใช้ df ของกลุ่มผิดใน two-sample t
- ใช้ t เมื่อ σ รู้ หรือใช้ Z ในตัวอย่างเล็กที่ไม่รู้ σ; ตรวจเงื่อนไขประชากรปกติและ n ก่อน
- อ่าน χ² เป็นพื้นที่ซ้าย: p-19 ใช้ α หางขวา (`0.05` ให้ 11.070 เมื่อ df=5; ไม่ใช่คอลัมน์ 0.95 ซึ่งไม่มีในหัวตาราง)
- ใช้สมมาตรกับ χ² หรือใส่ค่า critical ติดลบ ทั้งที่ χ²≥0 และเบ้ขวา
- ละเลยว่า `<` กับ `≤` ต่างกันในทวินาม/ปัวส์ซง (ตัวแปรไม่ต่อเนื่อง); ใน z/t ต่อเนื่องค่าที่จุดเดียวมีโอกาสศูนย์
- ปัดเร็วเกินไปก่อนทำ complement/ผลต่าง ทำให้คำตอบต่าง 0.0001–0.001

## 7. Possible slide errors/ambiguities

- สูตรทวินามและปัวส์ซงใช้ตัวแปรจุดตัด `r` แต่หัวแถวในตารางพิมพ์ `x`; ควรอ่านแถว `x` เป็นค่า `r` ของ `P(X≤r)` ไม่ใช่ค่าพอดี `P(X=x)`
- p-18 ใช้หัว `Cum.prob` แต่ภาพและคำอธิบายเป็นค่าวิกฤตหางขวา; ความหมายที่สอดคล้องคือ `t_q` มีพื้นที่ซ้าย q และแถว `One-tail`/`Two-tails` ระบุพื้นที่หาง ต้องย้ำก่อนใช้
- p-19 วาดพื้นที่หางขวาและใช้สัญลักษณ์ `χ²α` แต่ไม่ได้พิมพ์คำว่า “right tail” ข้างหัวคอลัมน์โดยตรง; จึงอาจทำให้ผู้เรียนเลือก 0.95 แทน 0.05
- p-19 มีชื่อภาษาอังกฤษในข้อความสกัดเป็น `Chi-squre` (สะกดตกตัว a); ภาพหน้า p-19 อ่านได้ว่า `Chi-square` จึงถือเป็นความคลาดเคลื่อนของข้อความสกัด/การสะกด ไม่ใช่ค่าตาราง
- ตารางปัวส์ซงเปลี่ยนช่วงและความถี่ของ λ: หลัง 2.0 ข้ามเป็น 2.2, 2.4,…; ต่อด้วย 4.2,…,6.0 แล้ว 6.5,…,11.0 และ 11.5,…,16.0 การขาด 2.1/4.1/6.1 ฯลฯ เป็นโครงสร้างตาราง ไม่ใช่ค่าศูนย์หรือค่าที่ควรแทรกเอง
- p-16 และ p-17 ใช้ชื่อ/คำว่า `Cumulative Probability P(Z<z)` เหมือนกัน แต่แบ่งหน้าตาม z บวกและ z ลบ; ต้องเลือกหน้าตามเครื่องหมายของ z
- ใน p-18 คอลัมน์ `t₀.50` มีค่า 0.000 ทุก df ซึ่งถูกต้อง (มัธยฐานของ t อยู่ที่ศูนย์) ไม่ใช่ช่องว่างหรือพิมพ์ผิด
