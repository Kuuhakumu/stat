## 2. Definitions & formulas

### สัญลักษณ์

- N = ขนาดประชากร, n = ขนาดตัวอย่าง, Xᵢ = ข้อมูลตัวที่ i
- μ, σ², σ = ค่าเฉลี่ย, ความแปรปรวน, ส่วนเบี่ยงเบนมาตรฐานประชากร
- x̄, S², S = ค่าเฉลี่ย, ความแปรปรวน, ส่วนเบี่ยงเบนมาตรฐานตัวอย่าง
- p = สัดส่วนประชากร, p̂ = สัดส่วนตัวอย่าง, q̂ = 1 − p̂
- α = โอกาสผิดพลาด/ระดับนัยสำคัญ, 1 − α = ระดับความเชื่อมั่น, Z_{α/2} และ t_{α/2,ν} = ค่าวิกฤตจากตาราง

### Point estimation

นิยาม 6.1 (p-04): ใช้ข้อมูลตัวอย่างให้ค่าประมาณเป็นค่าเดียว เช่น x̄ แทน μ, p̂ แทน p, S² แทน σ²

สูตร p-05:

- μ = (Σᵢ₌₁ᴺ Xᵢ)/N; x̄ = (Σᵢ₌₁ⁿ Xᵢ)/n
- σ² = Σᵢ₌₁ᴺ(Xᵢ − μ)²/N = [Σᵢ₌₁ᴺ Xᵢ² − Nμ²]/N
- S² = Σᵢ₌₁ⁿ(Xᵢ − x̄)²/(n − 1) = [Σᵢ₌₁ⁿ Xᵢ² − n x̄²]/(n − 1)
- σ = √σ²; S = √S²
- p = (Σᵢ₌₁ᴺ Xᵢ)/N; p̂ = (Σᵢ₌₁ⁿ Xᵢ)/n = x/n

### Interval estimation

นิยาม 6.2 (p-08): หา L (ขีดจำกัดล่าง) และ U (ขีดจำกัดบน) ให้ P(L < θ < U) = 1 − α โดย θ คือพารามิเตอร์ที่ต้องการประมาณ

### ค่าเฉลี่ยประชากร

- ประชากรปกติ รู้ σ² (p-09, ทฤษฎี 6.1): x̄ แจกแจง N(μ, σ²/n), Z = (x̄ − μ)/(σ/√n) แจกแจง N(0,1); CI คือ x̄ ± Z_{α/2}σ/√n
- ประชากรไม่ปกติแต่ n ≥ 30 (p-12, ทฤษฎี 6.2): ใช้ Z; รู้ σ ใช้ x̄ ± Z_{α/2}σ/√n, ไม่รู้ใช้ x̄ ± Z_{α/2}S/√n
- ประชากรปกติ ไม่รู้ σ² และ n < 30 (p-14, ทฤษฎี 6.3): T = (x̄ − μ)/(S/√n) แจกแจง t, ν = n − 1; CI คือ x̄ ± t_{α/2,ν}S/√n

### สัดส่วนประชากร

ทฤษฎี 6.4 (p-17): Z = (p̂ − p)/√[p(1 − p)/n] ≈ N(0,1); CI คือ p̂ ± Z_{α/2}√[p̂(1 − p̂)/n] = p̂ ± Z_{α/2}√(p̂q̂/n)

### ผลต่างค่าเฉลี่ยสองประชากร

นิยามบน p-19: x̄₁ − x̄₂ เป็นตัวประมาณ μ₁ − μ₂

- ปกติทั้งคู่ รู้ σ₁²,σ₂² และเป็นอิสระ (p-20, ทฤษฎี 6.5): CI = (x̄₁ − x̄₂) ± Z_{α/2}√(σ₁²/n₁ + σ₂²/n₂)
- ตัวอย่างใหญ่ n₁,n₂ ≥ 30 (p-21, ทฤษฎี 6.6): ใช้ Z; ถ้าไม่รู้ σᵢ แทนด้วย Sᵢ ในสูตรเดียวกัน
- ตัวอย่างเล็ก ไม่รู้ความแปรปรวน (p-23–25, ทฤษฎี 6.7):
  - ถ้าความแปรปรวนเท่ากัน: ν = n₁ + n₂ − 2, Sₚ² = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2), CI = (x̄₁−x̄₂) ± t_{α/2,ν}Sₚ√(1/n₁+1/n₂)
  - ถ้าไม่เท่ากัน: CI = (x̄₁−x̄₂) ± t_{α/2,ν}√(S₁²/n₁+S₂²/n₂), ν = (S₁²/n₁ + S₂²/n₂)² / [(S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1)] (Welch)

### ข้อมูลจับคู่

p-28–29, ทฤษฎี 6.8–6.9: Dᵢ = Xᵢ₁ − Xᵢ₂, D̄ = ΣDᵢ/n, Sᴅ² = Σ(Dᵢ−D̄)²/(n−1), μᴅ = μ₁−μ₂. ถ้า n < 30, T = (D̄−μᴅ)/(Sᴅ/√n), ν=n−1, และ CI = D̄ ± t_{α/2,n−1}Sᴅ/√n; ถ้า n ≥ 30, Z = (D̄−μᴅ)/(Sᴅ/√n), CI = D̄ ± Z_{α/2}Sᴅ/√n

### ผลต่างสัดส่วน

ทฤษฎี 6.10 (p-31): CI = (p̂₁ − p̂₂) ± Z_{α/2}√(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂), q̂ᵢ = 1 − p̂ᵢ

### ค่าวิกฤต

- 90% สองด้าน: Z₀.₀₅ = 1.645; 95%: Z₀.₀₂₅ = 1.960; 99%: Z₀.₀₀₅ = 2.576
- ตาราง t อ่านแถว ν และคอลัมน์หางเดียว α/2; t₀.₀₀₅,₉ = 3.250, t₀.₀₂₅,₉ = 2.262, t₀.₀₂₅,₂₆ ≈ 2.056

## 3. Worked examples

ช่วงทุกตัวอย่างเป็นสองด้าน จึงใช้พื้นที่หางละ α/2; Z อ่านจากตาราง Z และ t อ่านแถว ν กับคอลัมน์ α/2

### EX 6.1 ค่าใช้จ่ายเฉลี่ย (p-06)

โจทย์: ข้อมูลค่าใช้จ่าย 10 คนคือ 120, 145, 185, 100, 95, 65, 120, 100, 80, 90 บาท ต้องการค่าเฉลี่ยประชากร

วิธี: เป็น point estimate ของ μ จึงใช้ x̄ ไม่ใช้ตาราง. ΣXᵢ = 1100, n = 10, x̄ = 1100/10 = 110 บาท

คำตอบบนสไลด์: 110 บาทต่อวัน; ตรงกัน ไม่มี SLIDE DISCREPANCY

### EX 6.2 สัดส่วนอุปกรณ์ (p-07)

คำตอบบนสไลด์: 0.45 หรือร้อยละ 45; ตรงกัน ไม่มี SLIDE DISCREPANCY

คำตอบบนสไลด์: p-32 ไม่มีคำตอบ; ผลคำนวณซ้ำ 0.173 ถึง 0.327 ไม่มี SLIDE DISCREPANCY

## 4. Decision rules

- ถ้าถามค่าประมาณเดียว: ค่าเฉลี่ย → x̄; สัดส่วน → p̂=x/n; ความแปรปรวน → S²
- ถ้าถามช่วงความเชื่อมั่น ให้หา α = 1 − ระดับความเชื่อมั่น และใช้ α/2 ต่อหาง
- ค่าเฉลี่ยหนึ่งประชากร: รู้ σ → Z; ไม่รู้ σ และ n ≥ 30 → Z ใช้ S; ไม่รู้ σ, n < 30 และประชากรปกติ → t, ν=n−1
- สัดส่วนหนึ่งประชากร → สูตร p̂ ± Z√(p̂q̂/n), ตาราง Z
- ผลต่างค่าเฉลี่ย: กลุ่มอิสระ → สูตรสองกลุ่ม; คนเดิม/คู่เดิม → สร้าง Dᵢ ก่อน
- สองกลุ่มอิสระและรู้ σ₁,σ₂ → Z; ไม่รู้แต่ n₁,n₂ ≥ 30 → Z ใช้ S₁,S₂; เล็กและความแปรปรวนเท่ากัน → pooled t; เล็กและไม่เท่ากัน → Welch t
- ผลต่างสัดส่วน → (p̂₁−p̂₂) ± Z√(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂)
- คงลำดับกลุ่ม 1−กลุ่ม 2; สลับลำดับจะเปลี่ยนเครื่องหมายทั้งช่วง
- อ่าน Z จากตาราง Z และ t จากแถว ν กับคอลัมน์ α/2

## 5. Prerequisite knowledge

- ประชากร ตัวอย่าง พารามิเตอร์ และสถิติ
- การบวกหลายค่าและสัญลักษณ์ Σ
- ค่าเฉลี่ย = ผลรวม ÷ จำนวนข้อมูล
- เศษส่วน ทศนิยม ร้อยละ การปัดเลข
- เลขยกกำลังสองและรากที่สอง
- ความแปรปรวน ส่วนเบี่ยงเบนมาตรฐาน และเหตุผลที่ S² หาร n−1
- สัดส่วน x/n และ q=1−p
- รูประฆัง พื้นที่ใต้โค้ง และความสมมาตรของการแจกแจงปกติ
- การทำให้เป็นมาตรฐาน z
- ความน่าจะเป็น อสมการ และการแบ่ง α เป็นสองหาง
- การอ่านตาราง Z/t และองศาอิสระ
- ความแตกต่างของกลุ่มอิสระกับข้อมูลจับคู่

## 6. Likely multiple-choice traps

- ใช้ t ทั้งที่รู้ σ; กรณีรู้ σ ใช้ Z แม้ n<30
- ใช้ Z เมื่อ n<30 ไม่รู้ σ ทั้งที่ประชากรปกติ
- หาร S² ด้วย n แทน n−1 หรือใช้ ν=n แทน ν=n−1
- ใช้ α แทน α/2 ในช่วงสองด้าน
- 99% ต้องใช้ Z₀.₀₀₅=2.576 ไม่ใช่ Z₀.₀₁
- ลืม √n ใน standard error
- ใช้ pooled เมื่อความแปรปรวนไม่เท่ากัน หรือใช้ Welch เมื่อเท่ากัน
- ข้อมูลก่อน–หลังต้องทำ Dᵢ ไม่ใช่ two-independent-sample
- สลับก่อน−หลังหรือกลุ่ม 1−กลุ่ม 2 ทำให้เครื่องหมายกลับ
- ลืม q̂=1−p̂ หรือใช้ผลรวมแทนผลต่างสัดส่วน
- สับสน σ² กับ σ
- ลืมยกกำลังสอง S₁,S₂ ในสูตร
- Welch ν อาจเป็นทศนิยมและสไลด์ไม่บอกวิธีเลือกแถว t
- ปัดเร็วเกินไปจนขอบช่วงไม่ตรงตัวเลือก
- สับสนหน่วย 10,000 ชั่วโมง, กิโลกรัม และชิ้น/ชั่วโมง
