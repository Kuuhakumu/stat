# คู่มือสอบ Final Probability & Statistics (01476011)

นี่คือคู่มือเตรียมสอบวิชา 01476011 ความน่าจะเป็นและสถิติ สำหรับข้อสอบ final แบบปรนัย เนื้อหาหลักอยู่ที่ CH4–CH7 รวมตารางสถิติและแบบฝึกหัดท้ายบท ทุกบทเขียนแบบ Thai-first: อธิบายภาษาคนก่อน แล้วค่อยใส่ศัพท์อังกฤษและสูตรที่ต้องใช้

ถ้าเริ่มจากศูนย์ ไม่เคยเรียนสถิติ หรืออ่านสไลด์แล้วจับภาพรวมไม่ได้ ให้เริ่มที่ [เส้นทางเริ่มจากศูนย์](beginner/README.md) เป้าหมายคืออ่านโจทย์ให้รู้ว่าถามอะไร เลือกวิธีให้ถูก อ่านตารางได้ และทำโจทย์เองจนเลือกคำตอบได้

| โฟลเดอร์หรือไฟล์ | มีอะไรอยู่ข้างใน |

## ทำคู่มือนี้อย่างไร

เริ่มจากสไลด์กับแหล่งข้อมูลใน `sources/` แล้วสรุปเป็นโน้ตตรวจสอบใน `docs/research/` ทุกตัวอย่างสำคัญถูกคำนวณซ้ำและเทียบกับค่าที่พิมพ์ในตารางสอบ จากนั้นเขียนบทเรียนตามแผนใน `docs/plan/` และตรวจรอบใหญ่ไว้ใน [รายงาน audit](docs/audit-report.md) จุดที่สไลด์กับการคำนวณไม่ตรงกันจะมีหมายเหตุไว้ในบทที่เกี่ยวข้อง

ไฟล์ใน `materials/` คือสไลด์และเอกสารตารางสถิติของอาจารย์ ใช้เป็นแหล่งอ้างอิงต้นฉบับของวิชา ส่วน `beginner/` คือคำอธิบายและแบบฝึกที่จัดลำดับใหม่ให้คนเริ่มจากศูนย์อ่านตามได้
