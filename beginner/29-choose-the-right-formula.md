# บทที่ 29: อ่านโจทย์แล้วเลือกวิธีให้ถูก

## เป้าหมาย

หลังจบบทนี้ คุณจะ...

- แยกได้ว่าโจทย์ถามค่าครั้งเดียว ค่าเฉลี่ย สัดส่วน หรือผลต่าง
- เลือกการแจกแจงและสูตร Z หรือ t ก่อนลงมือคำนวณ
- เลือกตารางให้ถูกหน้า และไม่หลงกับคำว่า “อย่างน้อย” หรือ “ก่อน–หลัง”
- เห็นคำใบ้ในโจทย์แล้วตอบได้ทันทีว่าใช้วิธีใด

## ต้องรู้ก่อน

- [การแจกแจงทวินาม](04-binomial.md) และ [ปัวซง](05-poisson.md) สอนการนับเหตุการณ์
- [การแจกแจงต่อเนื่อง](06-continuous-uniform-and-exponential.md) และ [โค้งปกติ](07-normal-and-z-table.md) สอน X และตาราง Z
- [ค่าเฉลี่ยตัวอย่าง](11-sampling-distribution-of-mean.md), [t](12-t-distribution.md) และ [สัดส่วนตัวอย่าง](13-sampling-distribution-of-proportion.md) สอนการเลือก Z/t
- [ผลต่างสองค่าเฉลี่ย](14-difference-of-two-means.md), [ผลต่างสองสัดส่วน](15-difference-of-two-proportions.md) และ [ข้อมูลคู่](20-ci-paired-and-two-proportions.md) สอนโจทย์ที่มีสองกลุ่ม

## นึกภาพก่อน

ลองคิดว่าโจทย์เป็นคนมาขอของจากร้าน เราต้องถามก่อนว่าเขาขออะไร

ถ้าขอ “จำนวนของเสียใน 10 ชิ้น” เรานับความสำเร็จจากจำนวนครั้งที่กำหนด จึงเป็นทวินาม ถ้าขอ “จำนวนคนไข้ในหนึ่งชั่วโมง” เรานับเหตุการณ์ตามเวลา จึงเป็นปัวซง ถ้าขอ “น้ำหนักของชิ้นหนึ่ง” เราดูการแจกแจงของค่าต่อเนื่อง

แต่ถ้าเขาเอาข้อมูลหลายชิ้นมาแล้วถาม “ค่าเฉลี่ยเป็นเท่าไร” เราไม่ได้ดูชิ้นเดียวแล้ว เราดูค่าเฉลี่ยตัวอย่าง ถ้าเขาถาม “ผู้ใช้กี่เปอร์เซ็นต์” เราดูสัดส่วนตัวอย่าง ถ้าเอาสองกลุ่มมาเทียบกัน เราต้องถามต่อว่าเป็นคนละคนหรือเป็นคนเดิมก่อน–หลัง

จำประโยคนี้ไว้: **หาคำตอบว่าโจทย์กำลังวัดอะไร ก่อนจำชื่อสูตร**

| `P` | พีตัวใหญ่ | ความน่าจะเป็นของเหตุการณ์ที่เขียนในวงเล็บ |
| `k` | เค | จำนวนหรือเกณฑ์ที่โจทย์กำหนด เช่น จำนวนที่ต้องการนับ |

| `q` | คิว | ส่วนที่ไม่ใช่สัดส่วนที่สนใจ คำนวณ `q = 1 − p` |

## แผนผังเลือกวิธีในห้องสอบ

อ่านโจทย์หนึ่งรอบ แล้วเดินตามลูกศรนี้ หยุดเมื่อได้วิธีและหน้าตาราง

```text
เริ่ม: โจทย์กำลังถามอะไร?
  |
  +-- ค่าครั้งเดียว X หรือความน่าจะเป็นของเหตุการณ์เดียว
  |     |
  |     +-- นับ “สำเร็จจาก n ครั้ง” และทุกครั้งมีโอกาส p เดียวกัน
  |     |       -> ทวินาม -> ตารางทวินาม p-01 ถึง p-11
  |     |
  |     +-- นับเหตุการณ์ตามเวลา/พื้นที่ และโจทย์ให้ค่าเฉลี่ยต่อช่วง
  |     |       -> ปัวซง -> ตารางปัวซง p-12 ถึง p-15
  |     |
  |     +-- ทุกค่าในช่วงมีโอกาสเท่ากัน
  |     |       -> เอกรูปต่อเนื่อง -> ใช้ความยาวช่วง (ไม่เปิดตาราง)
  |     |
  |     +-- เวลารอจนเกิดเหตุการณ์ถัดไป
  |     |       -> เอ็กซ์โพเนนเชียล -> ใช้สูตรของเวลารอ (ไม่เปิดตาราง)
  |     |
  |     +-- โจทย์บอกโค้งระฆัง/การแจกแจงปกติ
  |             -> การแจกแจงปกติ (Normal) -> แปลงเป็น z -> ตาราง Z p-16 หรือ p-17
  |
  +-- ค่าเฉลี่ย x̄ ของหลายข้อมูล หรือถาม μ ของหนึ่งประชากร
  |     |
  |     +-- รู้ σ และประชากรปกติ หรือ n ≥ 30
  |     |       -> Z; ถ้าไม่รู้ σ แทนด้วย S -> ตาราง Z p-16/17
  |     |
  |     +-- ไม่รู้ σ, n < 30 และประชากรปกติ
  |             -> t หนึ่งกลุ่ม (one-sample t), ν = n − 1 -> ตาราง t p-18
  |
  +-- สัดส่วน p̂ หรือถาม p
  |     |
  |     +-- กลุ่มเดียว
  |     |       -> สัดส่วนหนึ่งกลุ่ม -> Z -> ตาราง Z p-16/17
  |     |
  |     +-- สองกลุ่ม
  |             -> ผลต่างสองสัดส่วน p̂₁ − p̂₂ -> Z -> ตาราง Z p-16/17
  |
  +-- ผลต่างของสองกลุ่ม
        |
        +-- เป็นคนเดิม/คู่เดิม/ก่อน–หลัง
        |       -> ข้อมูลจับคู่ (paired): สร้าง Dᵢ ก่อน -> ค่าเฉลี่ยของ D -> Z หรือ t
        |          (ตัวอย่างเล็กใช้ t ข้อมูลคู่ (paired t))
        |          (n ≥ 30 -> Z; n < 30, ไม่รู้ σ และ D ปกติ -> t)
        |          (กรณี t ใช้ ν = n − 1)
        |
        +-- เป็นคนละกลุ่มและอิสระ
                |
                +-- ผลต่างค่าเฉลี่ย x̄₁ − x̄₂
                |     -> รู้ σ และประชากรปกติ หรือ n₁,n₂ ≥ 30 -> Z
                |     -> สองประชากรปกติ, ตัวอย่างเล็ก + ความแปรปรวนเท่ากัน -> t แบบรวม
                |     -> สองประชากรปกติ, ตัวอย่างเล็ก + ความแปรปรวนไม่เท่ากัน -> t แบบเวลช์ (Welch t)
                |     -> ตาราง Z p-16/17 หรือ t p-18
                |
                +-- ผลต่างสัดส่วน p̂₁ − p̂₂
                      -> Z -> เช็กจำนวนสำเร็จ/ไม่สำเร็จว่าพอ
                      -> ตาราง Z p-16/17
```

**จำเรื่องหาง:** `>` อ่านว่า “มากกว่า” ใช้หางขวา, `<` อ่านว่า “น้อยกว่า” ใช้หางซ้าย, `≠` อ่านว่า “ไม่เท่ากับ” ใช้สองหาง. สัญลักษณ์ `>` และ `<` บอกทิศของ `H₁` ไม่ได้บอกให้เปลี่ยนทิศตามค่าที่คำนวณได้

## กฎเลือกการแจกแจงและตาราง

### 1. แยก “นับครั้ง” กับ “วัดค่า”

ถ้าโจทย์มีคำว่า “จาก 20 ชิ้น มีของเสียกี่ชิ้น” ให้คิดเป็นทวินาม เพราะมีจำนวนครั้ง `n` ชัดเจนและแต่ละครั้งมีสองผล ถ้ามีคำว่า “เฉลี่ย 3 ครั้งต่อชั่วโมง” ให้คิดเป็นปัวซง เพราะนับเหตุการณ์ตามเวลา

ถ้าโจทย์วัดน้ำหนัก เวลา ส่วนสูง หรือระยะทาง ให้คิดเป็นค่าต่อเนื่องก่อน แล้วดูว่าบอกการแจกแจงแบบใด ถ้าบอกค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน แล้วถามพื้นที่ใต้โค้ง ให้ใช้ Z หลังแปลงค่า

อ่าน [ทวินาม](04-binomial.md), [ปัวซง](05-poisson.md) และ [เอกรูป/เอ็กซ์โพเนนเชียล](06-continuous-uniform-and-exponential.md) เมื่อต้องเลือกการแจกแจงของ `X`

### 2. ถามค่าเฉลี่ย: Z หรือ t

เรื่องราวคือ เรามี `x̄` แล้วอยากรู้ `μ` หรืออยากทดสอบคำกล่าวเกี่ยวกับ `μ`

- รู้ `σ` ของประชากร: ใช้ Z ได้ แม้ `n` น้อย
- ไม่รู้ `σ` แต่ `n ≥ 30`: ตามกฎในบทนี้ใช้ Z และแทน `σ` ด้วย `S`
- ไม่รู้ `σ`, `n < 30` และประชากรปกติ: ใช้ t และ `ν = n − 1`
- ถ้าเป็นสองกลุ่ม ให้ตรวจคำว่า “อิสระ”, “ความแปรปรวนเท่ากัน” และขนาด `n₁,n₂` ก่อนเลือก t แบบรวมหรือ t แบบเวลช์

อ่าน [การแจกแจงของค่าเฉลี่ย](11-sampling-distribution-of-mean.md), [t](12-t-distribution.md) และ [ค่าเฉลี่ยสองกลุ่ม](14-difference-of-two-means.md) ประกอบ

### 3. ถามร้อยละ: ใช้สัดส่วน

คำว่า “ร้อยละ”, “เปอร์เซ็นต์”, “กี่ส่วนจากทั้งหมด” หมายถึงสัดส่วน `p̂` ไม่ใช่ค่าเฉลี่ย ถ้ามีกลุ่มเดียวใช้สัดส่วนหนึ่งกลุ่ม ถ้ามีสองกลุ่มให้หาผลต่าง `p̂₁ − p̂₂`

ทั้งช่วงความเชื่อมั่นและการทดสอบสัดส่วนใช้ Z ในบทนี้ ตารางที่เปิดคือ p-16 หรือ p-17 ตามเครื่องหมายของ z อ่าน [สัดส่วนตัวอย่าง](13-sampling-distribution-of-proportion.md), [ช่วงสัดส่วน](18-ci-one-proportion.md) และ [ทดสอบสองสัดส่วน](27-test-two-proportions.md)

ถ้าหา **ช่วงความเชื่อมั่น** ให้ใช้ `p̂` ที่สังเกตได้ในส่วนเบี่ยงเบนมาตรฐาน แต่ถ้า **ทดสอบคำกล่าวอ้าง** ให้ใช้ `p₀` ตาม `H₀`; สองกลุ่มที่ทดสอบให้ใช้สัดส่วนรวมตามบท 27

### 4. ถามผลต่าง: ตรวจว่าคู่กันหรือไม่

“ก่อน–หลัง”, “คนเดิม”, “วัดซ้ำ”, “จับคู่”, หรือ “แฝด” แปลว่าเป็นข้อมูลคู่ สร้าง `Dᵢ` ทีละคู่ก่อน แล้วทำเหมือนโจทย์ค่าเฉลี่ยหนึ่งกลุ่ม ถ้าเป็นคนละคน คนละเครื่อง หรือสุ่มแยกกัน ให้คิดเป็นสองกลุ่มอิสระ

อ่าน [ข้อมูลคู่และผลต่างสองสัดส่วน](20-ci-paired-and-two-proportions.md) และ [ทดสอบข้อมูลคู่](26-test-paired.md)

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** เปรียบเทียบค่าเฉลี่ยของสองกลุ่มที่เป็นคนละกลุ่ม
2. **คำใบ้บอกวิธี:** กลุ่มเป็นอิสระ ตัวอย่างเล็ก และโจทย์ถือว่าความแปรปรวนเท่ากัน จึงใช้ **t แบบรวม** ไม่ใช่ t ข้อมูลคู่

## วิธีเลือกหน้าตาราง

- ตารางทวินาม p-01 ถึง p-11: ใช้เมื่อมีจำนวนครั้ง `n` และโอกาสสำเร็จ `p`
- ตารางปัวซง p-12 ถึง p-15: ใช้เมื่อมีค่าเฉลี่ยเหตุการณ์ `λ` ต่อเวลา/พื้นที่
- ตาราง Z p-16: พื้นที่สะสมทางซ้ายของ z บวก หรือค่าที่แปลงเป็นมาตรฐานแล้ว
- ตาราง Z p-17: พื้นที่สะสมทางซ้ายของ z ลบ
- ตาราง t p-18: เลือกแถว `ν`; เลือกคอลัมน์ one-tail (หางเดียว) หรือ two-tails (สองหาง) ตามโจทย์

ช่วงความเชื่อมั่นสองด้านต้องแบ่ง `α` เป็น `α/2` ก่อนเปิดตาราง เช่น ความเชื่อมั่น 95% ให้ `α = 0.05` และหางละ `0.025` อ่าน [คู่มือตาราง](tables-guide.md) เมื่อพื้นที่อยู่คนละรูปกับหัวตาราง

## กับดักในข้อสอบ

- **ผิด:** เห็น `n = 20` แล้วใช้ t ทันที **ถูก:** ต้องไม่รู้ `σ` และประชากรต้องปกติด้วย
- **ผิด:** เห็นคำว่า “ร้อยละ” แล้วใช้สูตรค่าเฉลี่ย **ถูก:** ใช้ `p̂` และสูตรสัดส่วน
- **ผิด:** ก่อน–หลังใช้สูตรสองกลุ่มอิสระ **ถูก:** สร้าง `Dᵢ` แล้วใช้วิธีข้อมูลคู่
- **ผิด:** สองกลุ่มเล็กใช้ t แบบรวมทุกครั้ง **ถูก:** ใช้เมื่อความแปรปรวนเท่ากัน; ถ้าไม่เท่ากันใช้ t แบบเวลช์
- **ผิด:** ทดสอบแล้วเห็นค่าสถิติติดลบ จึงเปลี่ยนหาง **ถูก:** หางดูจาก `H₁` ที่เขียนก่อนคำนวณ
- **ผิด:** “อย่างน้อย 4” อ่านเป็น `P(X ≤ 4)` **ถูก:** อย่างน้อยคือ `X ≥ 4` ใช้พื้นที่ตรงข้ามหรือรวมค่าตั้งแต่ 4
- **ผิด:** ใช้ตาราง t เมื่อรู้ `σ` **ถูก:** รู้ `σ` ให้ใช้ Z
- **ผิด:** ใช้ `ν = n` **ถูก:** t หนึ่งกลุ่มใช้ `ν = n − 1`; t แบบรวมใช้ `ν = n₁ + n₂ − 2`
- **ผิด:** สลับกลุ่ม 1−กลุ่ม 2 แล้วไม่เปลี่ยนเครื่องหมาย **ถูก:** ผลต่างและช่วงจะเปลี่ยนเครื่องหมายทั้งชุด
- **ผิด:** ใช้ α ทั้งก้อนกับช่วงสองด้าน **ถูก:** แบ่งเป็น `α/2` ต่อหาง

17. **Z สัดส่วนหนึ่งกลุ่ม** — ช่วงความเชื่อมั่นของสัดส่วนหนึ่งกลุ่มใช้ Z
18. **t แบบรวม** — ผลต่างค่าเฉลี่ยของสองกลุ่มอิสระ ตัวอย่างเล็ก และความแปรปรวนเท่ากัน
19. **t แบบเวลช์** — ความแปรปรวนไม่เท่ากัน จึงไม่รวมเป็นแบบรวม
20. **t ข้อมูลคู่** — คนเดิมก่อน–หลัง ต้องสร้าง `Dᵢ` ก่อน แล้วใช้ t เพราะตัวอย่างเล็กและไม่รู้ `σ` ของผลต่าง
21. **Z สัดส่วนหนึ่งกลุ่ม** — การบ้านถามช่วงของสัดส่วนหนึ่งกลุ่ม
22. **t ข้อมูลคู่** — การบ้านระบุข้อมูลจับคู่และช่วงความเชื่อมั่นของผลต่าง
23. **Z หนึ่งค่าเฉลี่ย** — รู้ `σ` และเป็นการทดสอบหางขวา จึงใช้ Z
24. **t แบบรวม** — สองกลุ่มอิสระ ตัวอย่างเล็ก ความแปรปรวนเท่ากัน
25. **t ข้อมูลคู่** — ก่อน–หลังของคนเดิม คือข้อมูลคู่ ไม่ใช่สองกลุ่มอิสระ

</details>

## สรุปจำสั้น

- ถามจำนวนสำเร็จจาก `n` ครั้ง → ทวินาม
- ถามจำนวนเหตุการณ์ตามเวลา/พื้นที่ → ปัวซง
- ถามค่าต่อเนื่องหรือพื้นที่ใต้โค้ง → เอกรูป/เอ็กซ์โพเนนเชียล/ปกติ ตามคำบอก
- ถามค่าเฉลี่ย → รู้ `σ` หรือ `n ≥ 30` ใช้ Z; ไม่รู้ `σ`, `n < 30`, ปกติ ใช้ t
- ถามร้อยละ → สัดส่วนและ Z
- ก่อน–หลัง/คนเดิม → สร้าง `Dᵢ` และใช้ paired
- สองกลุ่มเล็ก ความแปรปรวนเท่ากัน → t แบบรวม; ไม่เท่ากัน → t แบบเวลช์
- `>` หางขวา, `<` หางซ้าย, `≠` สองหาง; ตาราง t ใช้ `ν`
