```text
z = (0.72−0.60)/√[0.60(0.40)/100] = 2.4495 ≈ 2.45
p-value = 1−0.9929 = 0.0071
0.0071 < 0.05  →  ปฏิเสธ H₀
```

กใช้พื้นที่ซ้าย; คกลับผล; งเอา `p̂` ไปแทน `p₀` ในส่วนเบี่ยงเบนมาตรฐาน ทบทวน [บททดสอบหนึ่งสัดส่วน](24-test-one-proportion.md)

**36. ตอบ ข.** ตัวอย่างเล็ก สองกลุ่มอิสระ และความแปรปรวนเท่ากัน = pooled t; Welch ใช้เมื่อความแปรปรวนไม่เท่ากัน ทบทวน [บททดสอบสองค่าเฉลี่ย](25-test-two-means.md)

**37. ตอบ ก.**

```text
t = (52−48)/√(4²/10 + 7²/12)
  = 4/√5.6833
  = 1.6779 ≈ 1.68
df Welch ≈ 17.94  →  ใช้แถว df≈18 ในตาราง
```

ขใช้ผลต่างหารด้วยจำนวนรวม; คลืมส่วนเบี่ยงเบนมาตรฐาน; งใช้ df ผิดแบบ one-sample ทบทวน [บททดสอบสองค่าเฉลี่ย](25-test-two-means.md)

**38. ตอบ ข.** ใช้ผลต่าง 6 คู่ ไม่ใช่ 12 คน

```text
D̄ = (2+4+3+5+1+3)/6 = 3
S_D = 1.4142
t = (3−0)/(1.4142/√6) = 5.1962 ≈ 5.20
df = n−1 = 6−1 = 5
```

กใช้ `df=6`; คนับข้อมูลก่อนและหลังเป็นอิสระ; งใช้ตัวส่วนกลับด้าน ทบทวน [บททดสอบข้อมูลจับคู่](26-test-paired.md)

**39. ตอบ ข.** เมื่อ `H₀` ให้ผลต่างเป็นศูนย์ ต้องใช้ `p̂` รวม

```text
p̂ = (30+20)/(100+100) = 0.25
SE = √[0.25(0.75)(1/100+1/100)] = 0.0612
z = (0.30−0.20)/0.0612 = 1.633 ≈ 1.63
p-value = 1−0.9485 = 0.0515
0.0515 > 0.05  →  ไม่ปฏิเสธ H₀
```

กอ่านพื้นที่ซ้ายเป็น p-value; คกลับการเปรียบเทียบ; งใช้สูตรแยกทั้งที่ `d₀=0` ทบทวน [บททดสอบสองสัดส่วน](27-test-two-proportions.md)
