## ค่าเฉลี่ยและความกระจายของผลต่าง

ถ้ากลุ่มสองกลุ่มสุ่มอย่างอิสระ ค่าเฉลี่ยของผลต่างจะเป็นผลต่างของค่าเฉลี่ย และความแปรปรวนจะเอาความแปรปรวนของแต่ละกลุ่มมาบวกกันหลังหารด้วยขนาดตัวอย่าง

```text
ค่าเฉลี่ยของ D = μ₁ − μ₂
ความแปรปรวนของ D = σ₁²/n₁ + σ₂²/n₂
SE ของ D = √(σ₁²/n₁ + σ₂²/n₂)
```

`SE` เล็กลงเมื่อ `n₁` หรือ `n₂` ใหญ่ขึ้น เพราะค่าเฉลี่ยจากคนจำนวนมากแกว่งน้อยลง

## ตารางตัดสินใจสามกรณี

| ข้อมูลในโจทย์ | ใช้ | ส่วนหารมาตรฐาน | df |
|---|---|---|---|
| รู้ `σ₁,σ₂` หรือทั้งสองกลุ่มมี `n≥30` | Z | `√(σ₁²/n₁+σ₂²/n₂)` ถ้ารู้ σ; ถ้าไม่รู้ใช้ `√(S₁²/n₁+S₂²/n₂)` | ไม่ต้องใช้ |
| `n₁,n₂<30`, ประชากรปกติ, ไม่รู้ σ และรู้ว่าความแปรปรวนเท่ากัน | pooled t | `Sₚ√(1/n₁+1/n₂)` | `n₁+n₂−2` |
| `n₁,n₂<30`, ประชากรปกติ, ไม่รู้ σ และความแปรปรวนไม่เท่ากัน | Welch t | `√(S₁²/n₁+S₂²/n₂)` | สูตร Welch |

> เกณฑ์ “ตัวอย่างใหญ่” ในสไลด์ต้องเป็นทั้ง `n₁≥30` และ `n₂≥30` ไม่ใช่มีแค่กลุ่มเดียวก็พอ

### กรณี 1: Z

ให้ `D=x̄₁−x̄₂` และ `μD=μ₁−μ₂` (มิวดี = ผลต่างค่าเฉลี่ยจริง) สูตรคือ

```text
Z = [D − (μ₁−μ₂)] / √(σ₁²/n₁ + σ₂²/n₂)
```

ถ้าตัวอย่างใหญ่แต่ไม่รู้ σ ให้แทน `σ₁,σ₂` ด้วย `S₁,S₂` ในส่วนราก แล้วอ่านตาราง Z หน้า TABLES p-16–p-17

### กรณี 2: pooled t เมื่อความแปรปรวนเท่ากัน

คำว่า pooled (พูลด์) แปลว่าเอาความแปรปรวนจากสองกลุ่มมารวมเป็นค่ากลางเดียว ก่อนคำนวณ

ในสูตรต่อไป `Sₚ²` อ่านว่า “เอสพีกำลังสอง” = ความแปรปรวนตัวอย่างที่รวมสองกลุ่ม และ `Sₚ` อ่านว่า “เอสพี” = รากที่สองของค่านี้

```text
Sₚ² = [(n₁−1)S₁² + (n₂−1)S₂²] / (n₁+n₂−2)
Sₚ = √Sₚ²
ν = n₁+n₂−2
T = [D − (μ₁−μ₂)] / [Sₚ√(1/n₁+1/n₂)]
```

### กรณี 3: Welch t เมื่อความแปรปรวนไม่เท่ากัน

Welch (เวลช์) ไม่บังคับให้สองกลุ่มมีความแปรปรวนเท่ากัน

```text
T = [D − (μ₁−μ₂)] / √(S₁²/n₁ + S₂²/n₂)

ν = (S₁²/n₁ + S₂²/n₂)²
    ─────────────────────────────────────────
    (S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1)
```

ค่า `ν` อาจเป็นทศนิยม ให้คำนวณเต็มก่อน แล้วปัดเป็นจำนวนเต็มที่ใกล้ที่สุดเพื่อเลือกแถวในตาราง t เช่น `ν=22.99` ปัดเป็น `23` ไม่ใช่ปัดทิ้งเป็น 22

## วิธีทำโจทย์ทุกข้อ

1. เขียนว่ากลุ่ม 1 ลบกลุ่ม 2 และแปลคำว่า “อย่างน้อย” เป็น `≥`
2. ดูว่า σ รู้หรือไม่ ตัวอย่างแต่ละกลุ่มถึง 30 หรือไม่ และความแปรปรวนเท่ากันไหม
3. คำนวณค่าเฉลี่ยผลต่างและ `SE` ตามกรณี
4. แทนค่าเป็น Z หรือ T แล้วเปิดตาราง โดยปัด Z เป็นสองตำแหน่งก่อนอ่าน
5. แปลหางให้ตรงกับโจทย์: `≥` คือหางขวา, `≤` คือหางซ้าย, “ระหว่าง” คือพื้นที่กลาง

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 5.11 (สไลด์ CH5 หน้า 46): หลอดอิเล็กทรอนิกส์

**1) โจทย์ถามอะไร / ข้อมูลที่มี:** โรงงาน 1 มี `μ₁=1400`, `σ₁=200`, `n₁=125`; โรงงาน 2 มี `μ₂=1200`, `σ₂=100`, `n₂=125`; ต้องหา `P(D≥160)`

**2) คำใบ้บอกวิธีไหน:** รู้ σ ของทั้งสองกลุ่มและกลุ่มเป็นอิสระ จึงใช้ Z

**3) คำนวณทีละบรรทัด:**

```text
μ₁−μ₂ = 1400−1200 = 200
SE = √(200²/125 + 100²/125)
   = √(40000/125 + 10000/125)
   = √(320 + 80)
   = √400 = 20
z = (160−200)/20 = −40/20 = −2.00
P(D≥160) = P(Z≥−2.00) = P(Z≤2.00)
```

**4) แปลผล:** ตาราง Z หน้า p-16 ให้ `P(Z≤2.00)=0.9772` ดังนั้นโอกาสที่โรงงาน 1 จะมากกว่าอย่างน้อย 160 ชั่วโมงคือ **0.9772** หรือ 97.72%

### EX 5.12 (สไลด์ CH5 หน้า 47): น้ำหนักกาแฟ

**1) โจทย์ถามอะไร / ข้อมูลที่มี:** A มี `μ₁=102`, `n₁=25`, `σ₁=7.8`; B มี `μ₂=98.7`, `n₂=30`, `σ₂=6.9`; ต้องหา `P(D≥2.5)`

**2) คำใบ้บอกวิธีไหน:** สไลด์ตั้งใจให้ใช้ Z โดยถือค่าเบี่ยงเบนมาตรฐานที่ให้เป็น σ แต่ต้องติดธงว่า `n₁=25<30` จึงไม่ครบเงื่อนไขตัวอย่างใหญ่ของทฤษฎี 5.9 ถ้าประชากรไม่ปกติ ผลลัพธ์นี้เป็นเพียงการทำตามเจตนาของโจทย์

**3) คำนวณทีละบรรทัด:**

```text
μ₁−μ₂ = 102−98.7 = 3.3
SE = √(7.8²/25 + 6.9²/30)
   = √(60.84/25 + 47.61/30)
   = √(2.4336 + 1.5870)
   = √4.0206 ≈ 2.0051
z = (2.5−3.3)/2.0051 ≈ −0.3990 ปัดเป็น −0.40
P(D≥2.5) = P(Z≥−0.40) = P(Z≤0.40)
```

**4) แปลผล:** ตาราง Z หน้า p-16 ให้ `P(Z≤0.40)=0.6554` จึงได้ **0.6554** ตารางใช้ค่า `−0.40` หลังปัด และเงื่อนไข `n₁=25` คือปัญหาของ EX นี้ที่ต้องจำไว้

### EX 5.13 (สไลด์ CH5 หน้า 48): สายการผลิต

**1) โจทย์ถามอะไร / ข้อมูลที่มี:** กลุ่ม 1 มี `n₁=120`, `x̄₁=100.8`, `S₁=1.9`; กลุ่ม 2 มี `n₂=150`, `x̄₂=100.1`, `S₂=2.1`; ต้องหา `P(D≥0.5)`

**2) คำใบ้บอกวิธีไหน:** ทั้งสองตัวอย่างมีอย่างน้อย 30 จึงใช้ Z และใช้ S แทน σ

**3) คำนวณทีละบรรทัด:**

```text
D = x̄₁−x̄₂ = 100.8−100.1 = 0.7
SE = √(1.9²/120 + 2.1²/150)
   = √(3.61/120 + 4.41/150)
   = √(0.030083 + 0.029400)
   = √0.059483 ≈ 0.2439
z = (0.5−0.7)/0.2439 ≈ −0.8200 ปัดเป็น −0.82
P(D≥0.5) = P(Z≥−0.82) = P(Z≤0.82)
```

**4) แปลผล:** ตาราง Z หน้า p-16 ให้ `P(Z≤0.82)=0.7939` คำตอบคือ **0.7939** หรือ 79.39%

### EX 5.14 (สไลด์ CH5 หน้า 51): เวลาผลิตสินค้า A และ B

**1) โจทย์ถามอะไร / ข้อมูลที่มี:** A = 8.2, 5.3, 6.5, 5.1, 9.7, 10.8 (`n₁=6`); B = 9.5, 8.3, 7.5, 10.9, 11.3, 9.3, 8.8, 8.0 (`n₂=8`); โจทย์บอกประชากรปกติ ความแปรปรวนเท่ากัน และ `μ₁−μ₂=0`; หา `P(D≥2)`

**2) คำใบ้บอกวิธีไหน:** ตัวอย่างเล็ก ไม่รู้ σ และความแปรปรวนเท่ากัน จึงใช้ pooled t

**3) คำนวณทีละบรรทัด:**

```text
x̄₁ = 45.6/6 = 7.6
x̄₂ = 73.6/8 = 9.2
S₁² = 27.76/(6−1) = 5.552
S₂² = 12.70/(8−1) = 1.8143
Sₚ² = [5(5.552)+7(1.8143)]/(6+8−2)
    = [27.760+12.7001]/12
    ≈ 3.3717
Sₚ = √3.3717 ≈ 1.8362
SE = 1.8362√(1/6+1/8) ≈ 0.9917
ν = 6+8−2 = 12
t = (2−0)/0.9917 ≈ 2.0168
```

**4) แปลผล:** เป็นหางขวา ตาราง t หน้า p-18 แถว `df=12` ให้ `t=1.782` ที่หาง 0.05 และ `t=2.179` ที่หาง 0.025 ดังนั้น `2.0168` อยู่ระหว่างสองค่านี้ คำตอบจากตารางอยู่ระหว่าง **0.0250 และ 0.0500** (ค่าประมาณละเอียด 0.0333)

> สไลด์บอก “ค่าเฉลี่ยเท่ากัน” ให้ตีความเป็น `μ₁=μ₂` ไม่ใช่ค่าเฉลี่ยตัวอย่าง เพราะข้อมูลจริงมี `7.6` กับ `9.2`

### EX 5.15 (สไลด์ CH5 หน้า 52): ผลผลิตสองหน่วย

**1) โจทย์ถามอะไร / ข้อมูลที่มี:** `μ₁=9900`, `μ₂=9400`, `n₁=10`, `S₁=200`, `n₂=15`, `S₂=300`; ความแปรปรวนไม่เท่ากัน; หา `P(D≥550)`

**2) คำใบ้บอกวิธีไหน:** ตัวอย่างเล็ก ประชากรปกติ ไม่รู้ σ และความแปรปรวนไม่เท่ากัน จึงใช้ Welch t

**3) คำนวณทีละบรรทัด:**

```text
μ₁−μ₂ = 9900−9400 = 500
SE = √(200²/10 + 300²/15)
   = √(40000/10 + 90000/15)
   = √(4000+6000) = √10000 = 100
t = (550−500)/100 = 0.50
ν = (4000+6000)² / [(4000²/9)+(6000²/14)]
  = 100000000 / [1777777.78+2571428.57]
  ≈ 22.99 → 23
```

**4) แปลผล:** เปิดตาราง t หน้า p-18 แถว `df=23` ค่า `t=0.685` อยู่ที่พื้นที่สะสม 0.75 (หางขวา 0.25) และ `t=0.000` อยู่ที่พื้นที่สะสม 0.50 ดังนั้นที่ `t=0.50` หางขวาอยู่ระหว่าง **0.2500 และ 0.5000**; ค่าประมาณจากการคำนวณคือ **0.3110**

## วิธีอ่านตารางให้ไม่หลง

- ตาราง Z หน้า p-16–p-17 ให้พื้นที่สะสมทางซ้าย เช่น `z=0.82` อ่าน `0.7939`; ถ้าเป็นหางขวาให้ทำ `1−0.7939`
- ตาราง t หน้า p-18 ให้ค่าจุดตัดตาม `df`; แถว `df=12` คอลัมน์หางขวา 0.05 คือ `1.782` และคอลัมน์ 0.025 คือ `2.179`
- ถ้าค่า t อยู่ระหว่างสองช่อง ให้ตอบเป็นช่วงที่ตารางบอก อย่าแกล้งทำว่าตารางให้เลขละเอียด
- ปัด Z เป็นสองตำแหน่งก่อนเปิดตาราง เช่น `−0.3990` เป็น `−0.40`

## กับดักในข้อสอบ

- สลับลำดับกลุ่ม: ถ้าเปลี่ยนเป็นกลุ่ม 2 ลบกลุ่ม 1 เครื่องหมายของผลต่างและ z/t จะเปลี่ยน
- ใช้ `σ/√n` เมื่อโจทย์ให้ σ; ถ้าไม่รู้ σ และเป็นตัวอย่างเล็กให้ใช้ S และ t
- เห็น `n₁=30` กลุ่มเดียวแล้วรีบใช้ Z ทั้งที่อีกกลุ่มยังเล็ก สไลด์กำหนดให้ทั้งสองกลุ่มถึง 30
- ใช้ `n₁+n₂−1` แทน pooled df ที่ถูกต้องคือ `n₁+n₂−2`
- เอา `S₁²` กับ `S₂²` มารวมแบบเฉลี่ยธรรมดาแทนสูตร `Sₚ²` ที่ถ่วงด้วย `n−1`
- Welch df เป็น 22.99 ต้องปัดเป็น 23 เพื่อหาแถว ไม่ใช่ใช้ 22 โดยไม่บอก
- “อย่างน้อย” คือหางขวา ถ้า z เป็นลบ หางขวาอาจมากกว่า 0.5 เช่น `P(Z≥−2)=0.9772`

2. กลุ่มปกติสองกลุ่มมีความแปรปรวนเท่ากัน `n₁=8,n₂=10`, `x̄₁−x̄₂=2`, `μ₁−μ₂=0`, `S₁=S₂=2` จงหา t และบอกช่วงหางขวาจากตาราง
3. กลุ่มปกติสองกลุ่มมี `n₁=6,S₁=2,n₂=10,S₂=4`, `μ₁−μ₂=5` จงหา `P(D≥6)` ด้วย Welch และปัด df เพื่ออ่านตาราง

## สรุปจำสั้น ๆ

- ผลต่างต้องเรียง `กลุ่ม 1−กลุ่ม 2` ให้เหมือนกันทั้งโจทย์และสูตร
- รู้ σ หรือทั้งสอง n อย่างน้อย 30 → Z
- n ทั้งคู่เล็ก รู้ความแปรปรวนเท่ากัน → pooled t, `df=n₁+n₂−2`
- n ทั้งคู่เล็ก ความแปรปรวนไม่เท่ากัน → Welch t
- Welch df ต้องคำนวณแล้วปัดเป็นแถวในตาราง
- ตาราง Z ใช้พื้นที่ซ้าย; ตาราง t หน้า p-18 ใช้ค่า t วิกฤตตาม df และหาง
