# บทที่ 11: ค่าเฉลี่ยตัวอย่างก็มีการแจกแจงของมันเอง

## เป้าหมาย

- เข้าใจว่าค่าเฉลี่ยจากตัวอย่างหลายชุดเปลี่ยนไปได้ จึงมีการแจกแจงของค่าเฉลี่ยตัวอย่าง (sampling distribution of the sample mean)
- หา **ส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยตัวอย่าง** หรือ standard error และรู้ว่าทำไมตัวอย่างใหญ่แล้วโค้งแคบลง
- เลือกใช้ Z ให้ถูกใน 3 กรณี: รู้ `σ`, ไม่รู้ `σ` แต่ `n≥30`, และประชากรไม่ปกติแต่ `n≥30`
- ทำ EX 5.4, EX 5.5 หน้า 29 และ EX 5.8 พร้อมอ่านตาราง Z ได้

## นึกภาพก่อน

โรงงานมีขวด 10,000 ขวด แต่เราไม่อยากชั่งทุกขวด จึงสุ่มมา 5 ขวดแล้วหา “น้ำหนักเฉลี่ย” พรุ่งนี้สุ่มอีก 5 ขวด ค่าเฉลี่ยอาจไม่เท่ากัน เพราะตัวที่หยิบมาไม่เหมือนกัน
ถ้าทำแบบนี้ซ้ำเป็นพันครั้ง แล้วจดค่าเฉลี่ยของทุกชุด เราจะได้กองค่าเฉลี่ยหลายค่า กองนี้คือ **การแจกแจงของค่าเฉลี่ยตัวอย่าง** จุดกลางจะอยู่ใกล้ค่าเฉลี่ยประชากร `μ` และเมื่อเพิ่มจำนวนขวดในแต่ละชุด ค่าเฉลี่ยจะเหวี่ยงน้อยลง
ลองเทียบง่าย ๆ: การดูขวดเดียวมีโอกาสเจอขวดหนักหรือเบามาก แต่การเอาหลายขวดมาเฉลี่ยทำให้ความบังเอิญของแต่ละขวดหักล้างกัน ค่าเฉลี่ยจึงนิ่งกว่า

## ค่าเฉลี่ยตัวอย่างมีการแจกแจงอะไร

### สัญลักษณ์ที่ใช้

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `Xᵢ` | เอ็กซ์ไอ | ค่าของหน่วยที่ `i` ในตัวอย่าง เช่น ขวดใบที่ `i` |
| `X̄` | เอ็กซ์บาร์ใหญ่ | ค่าเฉลี่ยของตัวอย่างก่อนสุ่มจริง จึงยังเปลี่ยนได้จากชุดหนึ่งไปอีกชุด |
| `x̄` | เอ็กซ์บาร์เล็ก | ค่าเฉลี่ยที่คำนวณได้จากตัวอย่างจริง: บวกทุกค่าแล้วหารด้วย `n` |
| `μ` | มิว | ค่าเฉลี่ยจริงของประชากรทั้งหมด |
| `σ` | ซิกมา | ส่วนเบี่ยงเบนมาตรฐานจริงของประชากร |
| `σ²` | ซิกมากำลังสอง | ความแปรปรวนจริงของประชากร; ต้องถอดรากก่อนจึงได้ `σ` |
| `S` | เอส | ส่วนเบี่ยงเบนมาตรฐานที่คำนวณจากตัวอย่าง |
| `n` | เอ็น | จำนวนหน่วยในตัวอย่างหนึ่งชุด |
| `N` | เอ็นใหญ่ | จำนวนหน่วยทั้งหมดในประชากร |
| `SE` | เอสอี | standard error หรือส่วนเบี่ยงเบนมาตรฐานของ `x̄` |
| `Z`, `z` | แซด | `Z` คือตัวแปรสุ่มมาตรฐาน; `z` คือตัวเลขที่คำนวณได้จากข้อมูล |
| `Φ(z)` | ฟีของแซด | พื้นที่สะสมทางซ้ายของค่า `z` ในตาราง Z |
| `Σ` | ซิกมาใหญ่ | ให้บวกค่าหลายค่าเข้าด้วยกัน |

`μ_X̄` อ่านว่า “มิวของเอ็กซ์บาร์ใหญ่” คือค่าเฉลี่ยของการแจกแจง `X̄`; `σ_X̄` คือส่วนเบี่ยงเบนมาตรฐานของการแจกแจงนั้น และ `σ²_X̄` คือความแปรปรวน `P(A)` อ่านว่า “พีของเอ” คือโอกาสของเหตุการณ์ `A`; `√n` อ่านว่า “รากที่สองของเอ็น”; `≤` คือไม่เกิน และ `≥` คืออย่างน้อย `N(0,1)` อ่านว่า “เอ็นศูนย์หนึ่ง” คือโค้งปกติมาตรฐานที่มีค่าเฉลี่ย 0 และความแปรปรวน 1; `~` อ่านว่า “แจกแจงเป็น” ส่วน `≈` อ่านว่า “ประมาณเท่ากับ”
ก่อนสุ่ม `x̄` ยังเปลี่ยนได้ จึงมองเป็นตัวแปรสุ่ม เมื่อสุ่มจริงแล้วจึงได้ค่าเฉลี่ยหนึ่งค่า เช่น `x̄=12.4`.

### กฎของการแจกแจง

ถ้าสุ่มตัวอย่างขนาด `n` จากประชากรที่มีค่าเฉลี่ย `μ` และส่วนเบี่ยงเบนมาตรฐาน `σ`:

1. ค่าเฉลี่ยของค่าเฉลี่ยตัวอย่างยังเท่ากับ `μ` ไม่ได้เลื่อนหนีไปไหน
2. ความแปรปรวนของ `x̄` คือ `σ²/n`
3. ดังนั้น standard error ของ `x̄` คือ `σ/√n`

เขียนเป็นสูตรได้ว่า
```text
μ_X̄ = μ
σ²_X̄ = σ²/n
SE(X̄) = σ_X̄ = σ/√n
```
คำว่า “แคบลง” มาจาก `√n` อยู่ข้างล่าง ยิ่ง `n` มาก ตัวหารยิ่งมาก และ `SE` ยิ่งเล็ก ตัวอย่างเช่น ถ้า `σ=10`:
```text
n=4:   SE = 10/√4  = 10/2 = 5
n=16:  SE = 10/√16 = 10/4 = 2.5
```
ดังนั้นสุ่ม 16 ค่า ค่าเฉลี่ยจะแกว่งแค่ครึ่งหนึ่งของการสุ่ม 4 ค่าโดยประมาณ กราฟ p-24 วาดเส้น `n=5, 20, 100`: ทุกเส้นอยู่กลางเดียวกัน แต่เส้นของ `n=100` แคบและสูงที่สุด

## เลือกสูตร Z ให้ตรงกับข้อมูล

ให้ถามก่อนว่า “ประชากรปกติไหม รู้ `σ` ไหม และ `n` เท่าไร”

### 1) ประชากรปกติและรู้ `σ`

กรณีนี้ใช้ได้แม้ `n<30` เพราะเรารู้การกระจายและรู้ส่วนเบี่ยงเบนมาตรฐานจริงของประชากร การแปลงเป็น Z คือ
```text
Z = (x̄ − μ)/(σ/√n)
```
`x̄−μ` อ่านว่า “เอ็กซ์บาร์ลบมิว” คือค่าเฉลี่ยตัวอย่างห่างจากค่าเฉลี่ยประชากรเท่าไร ส่วน `σ/√n` คือหน่วยความเหวี่ยงของค่าเฉลี่ย เมื่อแทนค่าแล้ว `Z` มีการแจกแจงปกติมาตรฐาน (standard normal distribution) ซึ่งมีค่าเฉลี่ย 0 และความแปรปรวน 1

### 2) ประชากรปกติ ไม่รู้ `σ` แต่ `n≥30`

เราใช้ `S` จากตัวอย่างแทน `σ` เพราะตัวอย่างใหญ่พอให้การประมาณใกล้เคียง กฎบนสไลด์ p-28 คือ
```text
Z = (x̄ − μ)/(S/√n)  ≈  N(0,1)
```
เครื่องหมาย `≈` อ่านว่า “ประมาณเท่ากับ” หมายถึงใกล้เคียง ไม่ใช่เท่ากันเป๊ะทุกครั้ง `S` อ่านว่า “เอส” และคือส่วนเบี่ยงเบนมาตรฐานที่คำนวณจากตัวอย่าง อย่าใช้ `S/ n` เพราะต้องหารด้วย `√n`

### 3) ประชากรไม่ปกติ แต่ `n≥30`: Central Limit Theorem

**ทฤษฎีลิมิตสู่ส่วนกลาง (Central Limit Theorem หรือ CLT)** บอกว่า แม้ข้อมูลเดิมจะเบ้หรือรูปร่างแปลก ถ้าสุ่มอิสระและมี `n≥30` การแจกแจงของ `x̄` จะเข้าใกล้โค้งปกติ
ถ้ารู้ `σ` ใช้
```text
Z = (x̄ − μ)/(σ/√n)
```
ถ้าไม่รู้ `σ` และมีเพียง `S` ให้ถือว่าเป็นการประมาณแบบตัวอย่างใหญ่ตามกฎของวิชานี้
จำเป็นตารางเดียว:

| สถานการณ์ | ตัวส่วนของ Z | หมายเหตุ |
|---|---|---|
| ปกติ, รู้ `σ` | `σ/√n` | ใช้ได้ทุก `n` |
| ปกติ, ไม่รู้ `σ`, `n≥30` | `S/√n` | Z แบบประมาณ |
| ไม่ปกติ, `n≥30`, รู้ `σ` | `σ/√n` | ใช้ CLT |

กรณีประชากรปกติ ไม่รู้ `σ` และ `n<30` ใช้ t และองศาอิสระ นั่นคือบทถัดไป [การแจกแจง t](12-t-distribution.md) ไม่ใช่สูตร Z ในบทนี้

## หนึ่งค่า X กับค่าเฉลี่ยของ n ค่า

ในบท 07 เราแปลง **ค่าหนึ่งค่า `X`** ด้วย `Z=(X−μ)/σ` จึงใช้ `σ` เป็นความเหวี่ยงของค่าคนเดียว
บทนี้แปลง **ค่าเฉลี่ย `x̄` ของ `n` ค่า** จึงใช้ `σ/√n` เป็นความเหวี่ยงของค่าเฉลี่ย การใส่ `√n` สำคัญมาก:

| สิ่งที่ถาม | ตัวแปร | ส่วนเบี่ยงเบนมาตรฐานที่ใช้ |
|---|---|---|
| น้ำหนักของขวดหนึ่งใบ | `X` | `σ` |
| น้ำหนักเฉลี่ยของ 25 ใบ | `x̄` | `σ/√25 = σ/5` |
| ผลรวมน้ำหนัก 25 ใบ | `ΣXᵢ` | `σ√25 = 5σ` |

ค่าเฉลี่ยจึงแคบลง แต่ผลรวมกลับกระจายกว้างขึ้น จำว่า `x̄` หารด้วย `√n`; ผลรวมคูณด้วย `√n`

### EX 5.4: น้ำหนักฝักถั่วลิสง (สไลด์ CH5 หน้า 27)

ถั่วลิสงมีการแจกแจงปกติ `μ=1` ออนซ์, `σ=0.05` ออนซ์ สุ่ม `n=24` ฝัก

#### ข้อ 1: ค่าเฉลี่ยไม่เกิน 1.02 ออนซ์

**1) โจทย์ถามอะไร / ข้อมูลที่มี**
ต้องหา `P(x̄≤1.02)` โดยมี `μ=1`, `σ=0.05`, `n=24`
**2) คำใบ้บอกวิธีไหน**
ประชากรปกติและรู้ `σ` จึงใช้ Z ได้ แม้ `n` จะน้อยกว่า 30 คำว่า “อย่างมาก” แปลว่า `≤` จึงต้องอ่านพื้นที่ซ้าย
**3) คำนวณทีละบรรทัด**
```text
SE = σ/√n
   = 0.05/√24
   = 0.05/4.8990
   = 0.0102062 ออนซ์
z = (x̄−μ)/SE
  = (1.02−1)/0.0102062
  = 0.02/0.0102062
  = 1.9596 ≈ 1.96
P(x̄≤1.02) = P(Z≤1.96)
            = Φ(1.96)
            = 0.9750
```
**4) แปลผลเป็นภาษาคน**
โอกาสที่ค่าเฉลี่ยน้ำหนักของ 24 ฝักจะไม่เกิน 1.02 ออนซ์ ประมาณ **0.9750 หรือ 97.50%**

#### ข้อ 2: ผลรวมอยู่ระหว่าง 24.5 ถึง 25.5 ออนซ์

**1) โจทย์ถามอะไร / ข้อมูลที่มี**
ให้ `T=ΣXᵢ` อ่านว่า “ทีเท่ากับซิกมาของเอ็กซ์ไอ” หมายถึงผลรวมน้ำหนักทั้ง 24 ฝัก ต้องหา `P(24.5≤T≤25.5)`
**2) คำใบ้บอกวิธีไหน**
ผลรวมของตัวแปรปกติอิสระมีค่าเฉลี่ย `nμ=24` และส่วนเบี่ยงเบนมาตรฐาน `σ√n` ไม่ใช่ `σ/√n`
**3) คำนวณทีละบรรทัด**
```text
μT = nμ = 24(1) = 24 ออนซ์
σT = σ√n = 0.05√24 = 0.244949 ออนซ์
zล่าง = (24.5−24)/0.244949 = 2.0412 ≈ 2.04
zบน  = (25.5−24)/0.244949 = 6.1237 ≈ 6.12
P(24.5≤T≤25.5)
 = Φ(6.12)−Φ(2.04)
 = 1.0000−0.9793
 = 0.0207
```
**4) แปลผลเป็นภาษาคน**
โอกาสที่ผลรวมจะอยู่ในช่วงนี้ประมาณ **0.0207 หรือ 2.07%** ค่าแบบไม่ปัด z ได้ 0.0206 แต่ข้อสอบใช้ค่าจากตารางหลังปัด z เป็น 2 ตำแหน่ง จึงตอบ 0.0207

### EX 5.5: ความสูงคนไทยอายุ 20 ปี (สไลด์ CH5 หน้า 29)

ประชากรปกติมีค่าเฉลี่ย 150 ซม. และ “ความแปรปรวน 25 ซม.²” สุ่ม 50 คน ต้องหา `P(145<x̄<155)`

> ⚠️ สไลด์ไม่ได้เขียนชัดว่า 25 เป็น `σ²` ของประชากรหรือ `S²` ของตัวอย่าง ที่นี่ตีความตามวิธีของโจทย์ว่าเป็น `σ²=25` ที่ทราบ จึงใช้ `σ=√25=5` และ Z

**1) โจทย์ถามอะไร / ข้อมูลที่มี**
ต้องหาความน่าจะเป็นที่ค่าเฉลี่ยของ 50 คนอยู่ระหว่าง 145 และ 155 ซม.; `μ=150`, `σ²=25`, `n=50`
**2) คำใบ้บอกวิธีไหน**
ประชากรปกติและถือว่ารู้ความแปรปรวนประชากร จึงใช้ `Z=(x̄−μ)/(σ/√n)`
**3) คำนวณทีละบรรทัด**
```text
σ = √σ² = √25 = 5 ซม.
SE = σ/√n = 5/√50 = 5/7.0711 = 0.7071 ซม.
zล่าง = (145−150)/0.7071 = −5/0.7071 = −7.0711 ≈ −7.07
zบน  = (155−150)/0.7071 =  5/0.7071 =  7.0711 ≈  7.07
P(145<x̄<155)
 = Φ(7.07)−Φ(−7.07)
 ≈ 1.0000−0.0000
 = 1.0000
```
**4) แปลผลเป็นภาษาคน**
โอกาสได้ค่าเฉลี่ยอยู่ระหว่าง 145 ถึง 155 ซม. สูงมากจนตารางปัดเป็น **1.0000 หรือ 100.00%**

### EX 5.8: ความหนาแน่นกรด (สไลด์ CH5 หน้า 36)

โรงงานวัดความหนาแน่นของกรด มีค่าเฉลี่ย `μ=180` กิโลกรัมต่อลูกบาศก์เมตร และ `σ=5` สุ่ม `n=75` ถัง ต้องหาโอกาสที่ค่าเฉลี่ยอยู่ระหว่าง 179 และ 181
**1) โจทย์ถามอะไร / ข้อมูลที่มี**
ต้องหา `P(179<x̄<181)` โดย `μ=180`, `σ=5`, `n=75`
**2) คำใบ้บอกวิธีไหน**
ตัวอย่างใหญ่กว่า 30 และโจทย์ให้ `σ` จึงใช้ Z ได้ ถ้ารูปร่างประชากรไม่ปกติก็อาศัย CLT; ถ้าปกติก็ใช้ได้เช่นกัน
**3) คำนวณทีละบรรทัด**
```text
SE = σ/√n = 5/√75 = 5/8.6603 = 0.5774
zล่าง = (179−180)/0.5774 = −1.7321 ≈ −1.73
zบน  = (181−180)/0.5774 =  1.7321 ≈  1.73
P(179<x̄<181)
 = Φ(1.73)−Φ(−1.73)
 = 0.9582−0.0418
 = 0.9164
```
**4) แปลผลเป็นภาษาคน**
โอกาสที่ค่าเฉลี่ยของ 75 ถังอยู่ในช่วง 179–181 ประมาณ **0.9164 หรือ 91.64%** ค่าคำนวณละเอียดก่อนปัด z คือ 0.9167 แต่คำตอบจากค่าที่พิมพ์ในตารางคือ 0.9164

## วิธีอ่านตาราง Z

ตารางในข้อสอบที่ใช้คือ [ตาราง Z ค่าบวก p-16](../sources/pages/TABLES/p-16.png) และ [ตาราง Z ค่าลบ p-17](../sources/pages/TABLES/p-17.png) หัวตารางเขียน `Cumulative Probability P(Z<z)` คือพื้นที่สะสมทางซ้าย
ทำตามนี้:

1. แปลงค่าที่ถามเป็น `z` แล้วปัด `z` เหลือ 2 ตำแหน่งก่อนเปิดตาราง
2. `z` บวกใช้ p-16, `z` ลบใช้ p-17
3. แถวให้เลขหลักหน่วยกับทศนิยมตำแหน่งแรก เช่น 1.9; คอลัมน์ให้ทศนิยมตำแหน่งที่สอง เช่น .06; จุดตัดคือ `Φ(1.96)=0.9750`
4. ถ้าถามด้านขวา ให้ทำ `1−Φ(z)`; ถ้าถามระหว่างสองค่า ให้ทำพื้นที่ซ้ายของขอบบนลบพื้นที่ซ้ายของขอบล่าง

ตัวอย่างพื้นที่:
```text
P(Z≤1.96) = Φ(1.96) = 0.9750
P(Z>1.96) = 1−0.9750 = 0.0250
P(−1.73<Z<1.73) = 0.9582−0.0418 = 0.9164
```
## กับดักในข้อสอบ

- **ผิด:** ใช้ `σ/n` เป็น standard error  **ถูก:** ใช้ `σ/√n`
- **ผิด:** โจทย์ให้ `σ²=25` แล้วใช้ 25 เป็น `σ`  **ถูก:** ถอดราก `σ=√25=5`
- **ผิด:** เห็น `n=24` แล้วห้ามใช้ Z ทุกกรณี  **ถูก:** ถ้าประชากรปกติและรู้ `σ` ใช้ Z ได้
- **ผิด:** เห็น `n≥30` แล้วใช้ Z โดยไม่ดูข้อมูล  **ถูก:** ถ้าไม่ปกติต้องเป็นตัวอย่างใหญ่ และต้องมีค่าเฉลี่ย/ความแปรปรวนที่เหมาะสม
- **ผิด:** ใช้ `σ√n` กับค่าเฉลี่ย  **ถูก:** `σ√n` เป็น SD ของผลรวม ส่วนค่าเฉลี่ยใช้ `σ/√n`
- **ผิด:** คำว่า “อย่างมาก 1.02” แล้วอ่านหางขวา  **ถูก:** “อย่างมาก” คือ `≤` อ่านพื้นที่ซ้าย
- **ผิด:** ตาราง p-16 เป็นพื้นที่ระหว่าง 0 กับ z  **ถูก:** ตารางนี้เป็นพื้นที่สะสมจากซ้ายสุด
- **ผิด:** ไม่ปัด z ก่อนอ่านตาราง  **ถูก:** ปัด z เป็น 2 ตำแหน่งตามกติกาข้อสอบ
- **ผิด:** สลับ `X` กับ `x̄`  **ถูก:** ค่าหนึ่งตัวใช้ `σ`; ค่าเฉลี่ยของ n ตัวใช้ `σ/√n`

## แบบฝึกหัดปิดหนังสือ

### คำถามเขียนตอบ

**ข้อ 1** ประชากรปกติมี `μ=80`, `σ=10` สุ่ม 25 ค่า จงหา `P(x̄≥84)`

<details><summary>เปิดดูเฉลยข้อ 1</summary>
```text
SE = 10/√25 = 10/5 = 2
z = (84−80)/2 = 2.00
P(x̄≥84) = P(Z≥2.00)
              = 1−0.9772
              = 0.0228
```
เพราะรู้ `σ` และประชากรปกติ ใช้ Z ได้ คำตอบคือ **0.0228**
</details>

**ข้อ 2** ประชากรปกติมี `μ=50`, `σ=12` สุ่ม 36 ค่า จงหา `P(47<x̄<53)`

<details><summary>เปิดดูเฉลยข้อ 2</summary>
```text
SE = 12/√36 = 12/6 = 2
zล่าง = (47−50)/2 = −1.50
zบน  = (53−50)/2 =  1.50
P = Φ(1.50)−Φ(−1.50)
  = 0.9332−0.0668
  = 0.8664
```
คำตอบจากตารางคือ **0.8664**
</details>

**ข้อ 3** ประชากรไม่ปกติ แต่มี `μ=120`, `σ=16` และสุ่ม 64 ค่า จงหา `P(x̄≤123)`

<details><summary>เปิดดูเฉลยข้อ 3</summary>

`n=64≥30` จึงใช้ CLT และ Z ได้
```text
SE = 16/√64 = 16/8 = 2
z = (123−120)/2 = 1.50
P(x̄≤123) = Φ(1.50) = 0.9332
```
คำตอบคือ **0.9332**
</details>

### คำถามปรนัย

**ข้อ 4** ถ้า `σ=18` และ `n=9` ค่า standard error ของ `x̄` เท่ากับเท่าไร
ก. 2  
ข. 6  
ค. 9  
ง. 54

<details><summary>เปิดดูเฉลยข้อ 4</summary>
```text
SE = σ/√n = 18/√9 = 18/3 = 6
```
ตอบ **ข. 6** ตัวเลือก ก หารด้วย `n` แทน `√n`, ค หารด้วย 2 แทน 3, และ ง คูณ `18×3` แทนการหาร
</details>

**ข้อ 5** ประชากรไม่ปกติ มี `σ=14`, `μ=100`, สุ่ม 49 ค่า ความน่าจะเป็น `P(x̄>102)` ใกล้เคียงเท่าไร
ก. 0.1587  
ข. 0.3413  
ค. 0.8413  
ง. 0.9772

<details><summary>เปิดดูเฉลยข้อ 5</summary>
```text
n=49≥30 จึงใช้ CLT
SE = 14/√49 = 14/7 = 2
z = (102−100)/2 = 1.00
P(x̄>102) = 1−Φ(1.00)
            = 1−0.8413
            = 0.1587
```
ตอบ **ก. 0.1587** ข คือพื้นที่ระหว่าง 0 ถึง 1, ค คือหางซ้าย (ลืม `1−`), ง ใช้ z=2 แทน z=1
</details>

**ข้อ 6** ข้อใดถูกต้องที่สุดเมื่อเปรียบเทียบการสุ่มตัวแปรหนึ่งค่าและค่าเฉลี่ยของ 16 ค่า โดยมี `σ=10`
ก. SD ของ `X` และ `x̄` เท่ากันคือ 10  
ข. SD ของ `X` คือ 10 และ SE ของ `x̄` คือ 2.5  
ค. SD ของ `X` คือ 2.5 และ SE ของ `x̄` คือ 10  
ง. SD ของ `X` คือ 160 และ SE ของ `x̄` คือ 10

<details><summary>เปิดดูเฉลยข้อ 6</summary>
```text
SD(X) = σ = 10
SE(x̄) = σ/√n = 10/√16 = 10/4 = 2.5
```
ตอบ **ข.** ก ไม่ได้ลดความเหวี่ยงของค่าเฉลี่ย, ค สลับ SD ของ `X` กับ SE ของ `x̄`, ง คูณ `σ×n` แทนการหารด้วย `√n`
</details>

## สรุปจำสั้น

- `x̄` คือค่าเฉลี่ยของตัวอย่างหลายค่าจากประชากร
- ค่าเฉลี่ยของ `x̄` เท่ากับ `μ`
- ความแปรปรวนของ `x̄` คือ `σ²/n`
- standard error คือ `σ/√n`; `n` ใหญ่ทำให้โค้งแคบ
- รู้ `σ` ใช้ `Z=(x̄−μ)/(σ/√n)`
- ไม่รู้ `σ` แต่ปกติและ `n≥30` ใช้ `S/√n` แบบประมาณ
- ไม่ปกติแต่ `n≥30` ใช้ CLT แล้วใช้ Z ได้เมื่อมี `σ`
- อ่านตาราง Z เป็นพื้นที่ซ้าย ปัด z สองตำแหน่งก่อนอ่าน
