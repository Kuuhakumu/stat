# บทที่ 24: ทดสอบสัดส่วนหนึ่งประชากร

## เป้าหมาย

- แยกให้ออกว่าโจทย์กำลังทดสอบสัดส่วนของกลุ่มเดียว
- เขียนสมมติฐานหลักและสมมติฐานทางเลือกให้ถูกหาง
- คำนวณค่าสถิติทดสอบของสัดส่วน โดยใช้สัดส่วนตามสมมติฐานในส่วนเบี่ยงเบนมาตรฐาน
- อ่านตารางมาตรฐานและสรุปว่า “ปฏิเสธ” หรือ “ไม่ปฏิเสธ” สมมติฐานหลักได้

## ต้องรู้ก่อน

- [การแจกแจงของสัดส่วนตัวอย่าง](13-sampling-distribution-of-proportion.md) — สัดส่วนตัวอย่างและการแปลงเป็นเลขมาตรฐาน
- [พื้นฐานการทดสอบสมมติฐาน](22-hypothesis-testing-idea.md) — สมมติฐานหลัก/ทางเลือก ระดับนัยสำคัญ หางซ้าย/ขวา/สองหาง และค่า p
- [การแจกแจงปกติและตารางมาตรฐาน](07-normal-and-z-table.md) — การอ่านพื้นที่สะสมทางซ้าย

## นึกภาพก่อน

ผู้จัดการบอกว่าเครื่องจักรทำของเสียไม่เกิน 3% เราไม่ต้องตรวจสินค้าทุกชิ้น แค่สุ่มมาตรวจบางส่วนแล้วนับของเสียก็พอ คำถามคือ ของเสียที่เห็นมากพอจะบอกว่าเครื่องจักรผิดปกติจริงหรือยัง หรือเป็นความแกว่งจากการสุ่มเท่านั้น

เราจึงเริ่มจากข้ออ้างเดิมก่อน แล้วดูว่าสัดส่วนที่สุ่มได้ห่างจากข้ออ้างกี่ “ส่วนเบี่ยงเบนมาตรฐาน” ถ้าห่างไปทางที่คำถามกำหนดไว้มากพอ จึงปฏิเสธข้ออ้างเดิม

## สัญลักษณ์และกติกา

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `p` | พี | สัดส่วนจริงของประชากรทั้งหมด ค่าที่เราอยากรู้ |
| `p₀` | พีศูนย์ | สัดส่วนที่สมมติไว้ใน H₀ ใช้เป็นค่ากลางตอนคำนวณ |
| `p̂` | พีแฮต | สัดส่วนที่คำนวณจากตัวอย่าง |
| `X` | เอ็กซ์ตัวใหญ่ | จำนวนหน่วยที่มีลักษณะที่เราสนใจ เช่น จำนวนของเสีย |
| `n` | เอ็น | จำนวนหน่วยที่ตรวจทั้งหมด |
| `Z` | แซดตัวใหญ่ | ค่าที่บอกว่าสัดส่วนตัวอย่างห่างจาก p₀ กี่ส่วนเบี่ยงเบนมาตรฐาน |
| `α` | แอลฟา | ระดับนัยสำคัญ หรือโอกาสยอมปฏิเสธ H₀ ทั้งที่ H₀ จริง |
| `√` | รากที่สอง | จำนวนที่คูณตัวเองแล้วได้ค่าข้างใน |
| `=` | เท่ากับ | ค่าซ้ายและขวามีค่าเดียวกัน |
| `−` | ลบ | หาผลต่าง หรือหาส่วนที่เหลือ |
| `/` | หาร | แบ่งค่าบนด้วยค่าล่าง |
| `>` | มากกว่า | ค่าด้านซ้ายมากกว่าด้านขวา หางขวา |
| `<` | น้อยกว่า | ค่าด้านซ้ายน้อยกว่าด้านขวา หางซ้าย |
| `≠` | ไม่เท่ากับ | ต่างจากค่าเดิม ใช้สองหาง |
| `≈` | ใกล้เคียงกับ | ค่าใกล้กัน ใช้เมื่อปัดเศษ |
| `≥` | มากกว่าหรือเท่ากับ | ค่าด้านซ้ายมากกว่าหรือเท่ากับด้านขวา |
| `≤` | น้อยกว่าหรือเท่ากับ | ค่าด้านซ้ายน้อยกว่าหรือเท่ากับด้านขวา |

| `|Z|` | ค่าสัมบูรณ์ของแซด | ขนาดของ Z โดยไม่สนใจเครื่องหมายบวกหรือลบ |

### ตั้งสมมติฐานจากคำถาม

ให้ H₀ มีเครื่องหมาย `=` เสมอ แล้วให้ทิศทางของคำถามอยู่ใน H₁

| คำในโจทย์ | H₀ | H₁ | หาง |
|---|---|---|---|
| “มากกว่า”, “เกิน” | `p = p₀` | `p > p₀` | ขวา |
| “น้อยกว่า”, “ต่ำกว่า” | `p = p₀` | `p < p₀` | ซ้าย |
| “แตกต่าง”, “ไม่เท่ากัน” | `p = p₀` | `p ≠ p₀` | สองหาง |

ถ้าโจทย์พูดว่า “อย่างน้อย 90%” ข้ออ้างเดิมคือ `p ≥ 0.90` จึงใส่ข้ออ้างไว้ใน H₀ และใช้ค่าขอบ `p₀ = 0.90` ตอนคำนวณ หลักฐานที่จะโต้แย้งข้ออ้างคือ `H₁: p < 0.90` ไม่ใช่ `p > 0.90`

## สูตรทดสอบสัดส่วนหนึ่งประชากร

เริ่มจากเปลี่ยนจำนวนที่พบเป็นสัดส่วนก่อน

```text
p̂ = X/n
```

จากนั้นคำนวณค่าทดสอบตามทฤษฎี 7.4 (สไลด์ CH7 หน้า 26)

```text
             p̂ − p₀
Z = -------------------------
    √[p₀(1 − p₀)/n]
```

จุดที่ต้องจำคือ **ใต้รากใช้ p₀ ไม่ใช่ p̂** เพราะส่วนเบี่ยงเบนมาตรฐานนี้บอกการกระจายของ p̂ ในกรณีที่ H₀ เป็นจริง เราจึงต้องใช้ค่าที่ H₀ สมมติไว้

ถ้าโจทย์ให้เป็นเปอร์เซ็นต์ ให้หาร 100 ก่อน เช่น 3% = 0.03 และ 90% = 0.90 ตัวเลข p̂, p₀ ต้องอยู่ระหว่าง 0 ถึง 1

## วิธีตัดสินผล

1. เขียน H₀ และ H₁ เพื่อรู้หางก่อนคำนวณ
2. หา p̂ แล้วแทนค่าลงสูตร Z ทีละบรรทัด
3. ปัด Z เป็น 2 ตำแหน่งก่อนเปิดตาราง ตามกติกาข้อสอบ
4. วิธีค่าวิกฤต: ถ้า Z อยู่ในหางวิกฤต ให้ปฏิเสธ H₀
5. วิธีค่า p: ถ้า p-value ≤ α ให้ปฏิเสธ H₀ ถ้า p-value > α ให้ไม่ปฏิเสธ H₀

ถ้าโจทย์ไม่ให้ α เช่น EX 7.8 ให้สมมติ `α = 0.05` แล้วบอกด้วยว่าถ้าใช้ `α = 0.01` ผลจะเปลี่ยนหรือไม่ อย่าเขียนว่า “ยอมรับ H₀” ให้เขียนว่า “ไม่ปฏิเสธ H₀ เพราะหลักฐานยังไม่พอ”

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 7.8 (สไลด์ CH7 หน้า 27): ของเสียเกิน 3% หรือไม่

**1) โจทย์ถามอะไร / ข้อมูลที่มี** เครื่องจักรปกติควรมีของเสียไม่เกิน 3% สุ่มตรวจ 500 ชิ้น พบของเสีย 22 ชิ้น ต้องตรวจว่าผิดปกติหรือไม่

```text
X = 22
n = 500
p₀ = 0.03
```

**2) คำใบ้บอกให้ใช้วิธีไหน** เป็นสัดส่วนของประชากรกลุ่มเดียว คำว่า “ผิดปกติ” ในบริบทนี้หมายถึงของเสีย **เกิน** 3% จึงตั้งเป็นหางขวา

```text
H₀: p = 0.03
H₁: p > 0.03
```

สไลด์ไม่ได้ให้ α จึงสมมติ `α = 0.05` และตรวจเพิ่มที่ `α = 0.01`

**3) คำนวณทีละบรรทัด**

```text
p̂ = X/n
   = 22/500
   = 0.044

ส่วนเบี่ยงเบนมาตรฐาน
= √[p₀(1 − p₀)/n]
= √[0.03(1 − 0.03)/500]
= √[0.03×0.97/500]
= √[0.0291/500]
= √0.0000582
= 0.0076288924

Z = (p̂ − p₀)/ส่วนเบี่ยงเบนมาตรฐาน
  = (0.044 − 0.03)/0.0076288924
  = 0.014/0.0076288924
  = 1.8351288
  ≈ 1.84
```

บนเครื่องคิดเลขให้กด `0.03 × 0.97 ÷ 500` แล้วกด `√` จากนั้นกด `(0.044 − 0.03) ÷` ค่าที่ได้

**4) แปลผลเป็นภาษาคน** ตาราง Z หน้า TABLES p-16 แถว `1.8` คอลัมน์ `0.04` ให้พื้นที่ซ้ายของ `Z = 1.84` เท่ากับ **0.9671** พื้นที่หางขวาจึงเป็น

```text
p-value = 1 − 0.9671
        = 0.0329
```

ค่าจาก Z จริงก่อนปัดให้ p≈0.0332 แต่คำตอบที่ใช้ในข้อสอบคือ 0.0329 ตามค่าที่พิมพ์ในตาราง

ที่ `α = 0.05`, `0.0329 ≤ 0.05` จึงปฏิเสธ H₀ มีหลักฐานว่าของเสียเกิน 3% และเครื่องจักรอาจผิดปกติ

ที่ `α = 0.01`, `0.0329 > 0.01` จึงไม่ปฏิเสธ H₀ หลักฐานยังไม่แรงพอที่ระดับเข้มงวด 1% สไลด์หน้า 27 ให้โจทย์และคำถาม แต่ไม่มี α และไม่มีเฉลยตัวเลข จึงต้องระบุสมมติฐาน α แบบนี้

### EX 7.9 (สไลด์ CH7 หน้า 28): คำกล่าวอ้างอย่างน้อย 90%

**1) โจทย์ถามอะไร / ข้อมูลที่มี** โรงงานอ้างว่าสินค้าอย่างน้อย 90% ถูกซื้อหรือจำหน่ายภายใน 72 ชั่วโมง สุ่ม 150 ล็อต พบ 129 ล็อตที่ทันเวลา โจทย์ให้ทดสอบที่ `α = 0.025`

```text
X = 129
n = 150
p₀ = 0.90
α = 0.025
```

**2) คำใบ้บอกให้ใช้วิธีไหน** เป็นสัดส่วนของประชากรกลุ่มเดียว ข้ออ้าง “อย่างน้อย” อยู่ฝั่งข้ออ้างเดิม จึงเขียนเต็ม ๆ ว่า `H₀: p ≥ 0.90` แต่ตอนคำนวณใช้ค่าขอบ `p₀ = 0.90` หลักฐานที่จะล้มข้ออ้างคือ “ต่ำกว่า 90%”

```text
H₀: p ≥ 0.90  (คำนวณที่ p₀ = 0.90)
H₁: p < 0.90
```

ดังนั้น H₁ อยู่หางซ้าย ถ้าเขียน H₁ เป็น `p > 0.90` จะกำลังถามคนละเรื่อง

**3) คำนวณทีละบรรทัด**

```text
p̂ = X/n
   = 129/150
   = 0.86

ส่วนเบี่ยงเบนมาตรฐาน
= √[p₀(1 − p₀)/n]
= √[0.90(1 − 0.90)/150]
= √[0.90×0.10/150]
= √[0.09/150]
= √0.0006
= 0.0244948974

Z = (p̂ − p₀)/ส่วนเบี่ยงเบนมาตรฐาน
  = (0.86 − 0.90)/0.0244948974
  = −0.04/0.0244948974
  = −1.6329932
  ≈ −1.63
```

**4) แปลผลเป็นภาษาคน** ตาราง Z หน้า TABLES p-17 แถว `−1.6` คอลัมน์ `0.03` ให้พื้นที่หางซ้ายเท่ากับ **0.0516** ซึ่งเป็น p-value แบบตาราง

```text
p-value = 0.0516
```

ถ้าใช้ค่า Z จริงก่อนปัดจะได้ p≈0.0512 แต่ให้ใช้ 0.0516 ซึ่งเป็นค่าที่อ่านจากตารางสอบ

ค่าวิกฤตหางซ้ายเมื่อ `α = 0.025` อยู่ใกล้ `Z = −1.96` และ `−1.63` ยังไม่ไกลไปถึงหางนั้น หรือดูจากค่า p ก็ได้ว่า

```text
0.0516 > 0.025
```

จึงไม่ปฏิเสธ H₀ สรุปเป็นภาษาคนว่า **ยังไม่มีหลักฐานพอจะล้มคำกล่าวอ้างว่าอย่างน้อย 90% ทันเวลา** ไม่ได้แปลว่าพิสูจน์แล้วว่าสัดส่วนจริงอย่างน้อย 90% แน่นอน สไลด์หน้า 28 มีโจทย์และ α แต่ไม่มีวิธีทำหรือเฉลย จึงเป็นผลคำนวณตรวจสอบใหม่

## วิธีอ่านตาราง Z

- ตาราง Z หน้า TABLES p-16 ให้พื้นที่สะสมทางซ้ายสำหรับค่า Z บวก เช่น `Z = 1.84` ได้ `0.9671`
- ตาราง Z หน้า TABLES p-17 ให้พื้นที่สะสมทางซ้ายสำหรับค่า Z ลบ เช่น `Z = −1.63` ได้ `0.0516`
- หางขวาใช้ `1 − พื้นที่ซ้าย`
- หางซ้ายใช้พื้นที่ซ้ายตรง ๆ
- สองหางใช้พื้นที่หางเดียวคูณ 2 เมื่อใช้ `|Z|` เช่น ถ้าพื้นที่หางเดียวเป็น 0.0100 ก็ได้ p-value = `2×0.0100 = 0.0200`

การอ่าน `Z = 1.84`: ไปแถว `1.8` แล้วไปคอลัมน์ `0.04` การอ่าน `Z = −1.63`: ไปแถว `−1.6` แล้วไปคอลัมน์ `0.03` อย่าเอาพื้นที่ซ้ายของหางซ้ายไปใช้เป็นหางขวาโดยไม่ลบออกจาก 1

## กับดักในข้อสอบ

- **ผิด:** ใช้ `p̂` ใต้รากทุกครั้งเพราะเพิ่งคำนวณได้ **ถูก:** การทดสอบใช้ `p₀` เพราะกำลังดูการกระจายเมื่อ H₀ เป็นจริง
- **ผิด:** แทน 3% เป็น `3` **ถูก:** 3% = `3/100 = 0.03`
- **ผิด:** ใช้ 22 เป็น p̂ **ถูก:** `p̂ = 22/500 = 0.044`
- **ผิด:** เห็น p̂ สูงกว่า p₀ แล้วเขียน H₁ เป็น `p > p₀` ทันที **ถูก:** ดูคำถามก่อน เช่น “ผิดปกติ” ของเครื่องจักรข้อนี้หมายถึงของเสียเกินเกณฑ์ จึงเป็นหางขวา
- **ผิด:** “อย่างน้อย 90%” แล้วเขียน H₁ เป็น `p > 0.90` **ถูก:** ข้ออ้างอยู่ใน H₀ และสิ่งที่ต้องหาหลักฐานคือ `H₁: p < 0.90`
- **ผิด:** อ่านพื้นที่ซ้าย 0.9671 เป็น p-value ของหางขวา **ถูก:** หางขวาคือ `1 − 0.9671 = 0.0329`
- **ผิด:** ไม่ปฏิเสธ H₀ แล้วพูดว่า H₀ จริงแน่นอน **ถูก:** พูดว่าหลักฐานยังไม่พอที่จะปฏิเสธ
- **ผิด:** สองหางใช้ α เต็มที่ด้านเดียว **ถูก:** แบ่ง α เป็น α/2 ต่อหาง หรือคูณพื้นที่หางเดียวด้วย 2
- **ผิด:** ปัด p̂ หรือส่วนเบี่ยงเบนมาตรฐานเร็วเกินไป **ถูก:** เก็บเลขหลายตำแหน่งไว้ แล้วปัด Z เป็น 2 ตำแหน่งก่อนเปิดตาราง

## แบบฝึกหัดปิดหนังสือ

ลองทำเองก่อนเปิดเฉลย ทุกข้อใช้สูตรทดสอบสัดส่วนหนึ่งประชากร และปัด Z เป็น 2 ตำแหน่งก่อนอ่านตาราง

### คำถามเขียนวิธีทำ

1. ตรวจสินค้า 400 ชิ้น พบเสีย 30 ชิ้น ทดสอบว่าอัตราเสียมากกว่า 5% หรือไม่ที่ `α = 0.05` และบอกผลถ้าใช้ `α = 0.01`
2. สุ่มผู้โดยสาร 200 คน พบ 32 คนมาสาย ทดสอบว่าอัตรามาสายน้อยกว่า 20% หรือไม่ที่ `α = 0.05`
3. สุ่มชิ้นงาน 250 ชิ้น พบผ่านมาตรฐาน 47 ชิ้น ทดสอบสองทางว่าอัตราผ่านต่างจาก 20% หรือไม่ที่ `α = 0.01`

<details><summary>เปิดดูเฉลยคำถามเขียนวิธีทำ</summary>

**ข้อ 1**

```text
H₀: p = 0.05, H₁: p > 0.05
p̂ = 30/400 = 0.075
ส่วนเบี่ยงเบนมาตรฐาน
= √[0.05×0.95/400]
= √0.00011875
= 0.0108972474
Z = (0.075 − 0.05)/0.0108972474
  = 0.025/0.0108972474
  = 2.2941573
  ≈ 2.29
```

ตาราง p-16 ที่ `Z = 2.29` ให้พื้นที่ซ้าย 0.9890 จึงได้ p-value = `1 − 0.9890 = 0.0110` ที่ α = 0.05 ปฏิเสธ H₀ เพราะ 0.0110 ≤ 0.05 แต่ที่ α = 0.01 ไม่ปฏิเสธ H₀ เพราะ 0.0110 > 0.01 สรุปว่า หลักฐานพอที่ 5% แต่ยังไม่พอที่ 1% (คำนวณจาก Z จริงได้ p≈0.0109)

**ข้อ 2**

```text
H₀: p = 0.20, H₁: p < 0.20
p̂ = 32/200 = 0.16
ส่วนเบี่ยงเบนมาตรฐาน
= √[0.20×0.80/200]
= √0.0008
= 0.0282842712
Z = (0.16 − 0.20)/0.0282842712
  = −0.04/0.0282842712
  = −1.4142136
  ≈ −1.41
```

ตาราง p-17 ที่ `Z = −1.41` ให้ p-value = 0.0793 ซึ่งมากกว่า 0.05 จึงไม่ปฏิเสธ H₀ หลักฐานยังไม่พอว่าอัตรามาสายน้อยกว่า 20% (คำนวณจาก Z จริงได้ p≈0.0786)

**ข้อ 3**

```text
H₀: p = 0.20, H₁: p ≠ 0.20
p̂ = 47/250 = 0.188
ส่วนเบี่ยงเบนมาตรฐาน
= √[0.20×0.80/250]
= √0.00064
= 0.0252982213
Z = (0.188 − 0.20)/0.0252982213
  = −0.012/0.0252982213
  = −0.4743416
  ≈ −0.47
```

ตาราง p-17 ที่ `Z = −0.47` ให้พื้นที่หางซ้าย 0.3192 สองหางจึงมี p-value = `2×0.3192 = 0.6384` มากกว่า 0.01 จึงไม่ปฏิเสธ H₀ (คำนวณจาก Z จริงได้ p≈0.6353)

</details>

### คำถามปรนัย

4. ตรวจสินค้า 100 ชิ้น พบเสีย 18 ชิ้น ทดสอบ `H₁: p > 0.10` ที่ α = 0.05 ข้อใดถูกต้อง

ก. `Z = 0.80` จึงไม่ปฏิเสธ H₀

ข. `Z = 2.67` และปฏิเสธ H₀

ค. `Z = 2.67` และไม่ปฏิเสธ H₀ เพราะใช้หางซ้าย

ง. ใช้ p̂ ใต้ราก จึงได้ `Z = 2.07` และปฏิเสธ H₀

5. สุ่ม 80 คน พบ 34 คนมีอาการ ทดสอบ `H₁: p < 0.50` โดย `p₀ = 0.50`, α = 0.05 ข้อใดถูกต้อง

ก. `Z = 1.34` จึงปฏิเสธ H₀

ข. `Z = −1.34` จึงปฏิเสธ H₀ เพราะติดลบ

ค. `Z = −1.34`, p-value จากตาราง 0.0901 จึงไม่ปฏิเสธ H₀

ง. ใช้ t เพราะไม่รู้ p จึงต้องหาองศาอิสระ

6. สุ่ม 300 ชิ้น พบผ่านมาตรฐาน 93 ชิ้น ทดสอบสองทางว่า `p ≠ 0.30` ที่ α = 0.10 ข้อใดถูกต้อง

ก. `Z = 0.38`, p-value สองทาง = 0.7040 จึงไม่ปฏิเสธ H₀

ข. `Z = 0.38`, ใช้ 0.6480 เป็น p-value สองทาง จึงปฏิเสธ H₀

ค. `Z = −0.38` เพราะโจทย์เป็นสองทาง และ p-value = 0.3520

ง. ใช้ `p̂ = 0.30` ใต้ราก จึงได้ `Z = 0.40`

<details><summary>เปิดดูเฉลยคำถามปรนัย</summary>

**ข้อ 4 ตอบ ข.**

```text
p̂ = 18/100 = 0.18
ส่วนเบี่ยงเบนมาตรฐาน = √[0.10×0.90/100]
                     = √0.0009
                     = 0.03
Z = (0.18 − 0.10)/0.03
  = 0.08/0.03
  = 2.6666667
  ≈ 2.67
```

ตาราง p-16 ที่ 2.67 ให้พื้นที่ซ้าย 0.9962 จึง p-value = `1 − 0.9962 = 0.0038` และ 0.0038 ≤ 0.05 จึงปฏิเสธ H₀ ข้อ ก คำนวณผิด ข้อ ค ใช้หางผิด และข้อ ง ใช้ p̂ ใต้รากผิด (คำนวณจาก Z จริงก็ได้ 0.0038)

**ข้อ 5 ตอบ ค.**

```text
p̂ = 34/80 = 0.425
ส่วนเบี่ยงเบนมาตรฐาน = √[0.50×0.50/80]
                     = √0.003125
                     = 0.0559016994
Z = (0.425 − 0.50)/0.0559016994
  = −0.075/0.0559016994
  = −1.3416408
  ≈ −1.34
```

ตาราง p-17 ที่ −1.34 ให้ p-value = 0.0901 มากกว่า 0.05 จึงไม่ปฏิเสธ H₀ ข้อ ก เปลี่ยนเครื่องหมายโดยไม่มีเหตุผล ข้อ ข คิดว่าค่าติดลบก็ต้องปฏิเสธ และข้อ ง การทดสอบสัดส่วนหนึ่งประชากรใช้ Z ไม่ใช่ t (คำนวณจาก Z จริงได้ p≈0.0899)

**ข้อ 6 ตอบ ก.**

```text
p̂ = 93/300 = 0.31
ส่วนเบี่ยงเบนมาตรฐาน = √[0.30×0.70/300]
                     = √0.0007
                     = 0.0264575131
Z = (0.31 − 0.30)/0.0264575131
  = 0.01/0.0264575131
  = 0.3779645
  ≈ 0.38
```

ตาราง p-16 ที่ 0.38 ให้พื้นที่ซ้าย 0.6480 พื้นที่หางขวาเท่ากับ `1 − 0.6480 = 0.3520` และสองหางคือ `2×0.3520 = 0.7040` มากกว่า 0.10 จึงไม่ปฏิเสธ H₀ ข้อ ข ลืมคูณสอง ข้อ ค เปลี่ยนเครื่องหมายและคูณผิด ข้อ ง ใช้ p̂ ใต้รากแทน p₀ (คำนวณจาก Z จริงได้ p≈0.7055)

</details>

## สรุปจำสั้น ๆ

- สัดส่วนตัวอย่างคือ `p̂ = X/n`
- สูตรทดสอบคือ `Z = (p̂ − p₀)/√[p₀(1 − p₀)/n]`
- ใต้รากใช้ `p₀` เพราะคำนวณภายใต้ H₀
- `>` คือหางขวา, `<` คือหางซ้าย, `≠` คือสองหาง
- ตาราง p-16 ใช้ Z บวก และ p-17 ใช้ Z ลบ
- หางขวา = 1 ลบพื้นที่ซ้าย; สองหาง = หางเดียวคูณ 2
- p-value ≤ α จึงปฏิเสธ H₀
- ไม่ปฏิเสธ H₀ แปลว่าหลักฐานยังไม่พอ ไม่ได้แปลว่าพิสูจน์ H₀ จริง
