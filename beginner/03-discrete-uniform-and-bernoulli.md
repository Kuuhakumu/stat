# บทที่ 03: แบบเอกรูปไม่ต่อเนื่องและแบร์นูลลี

## เป้าหมาย

- หลังจบบทนี้คุณจะแยกได้ว่าโจทย์ไหนเป็น discrete uniform และโจทย์ไหนเป็น Bernoulli
- คุณจะหาความน่าจะเป็น ค่าเฉลี่ย และค่าเบี่ยงเบนมาตรฐานของสองแบบนี้ได้
- คุณจะตั้งความหมายของ `X=1` และ `X=0` ให้ชัดเจนก่อนแทนค่า
- คุณจะเห็นจุดที่สไลด์พิมพ์คลุมเครือ และไม่เลือกคำตอบผิดเพราะจุดนั้น

## ต้องรู้ก่อน

บท [ความน่าจะเป็นและตัวแปรสุ่ม](02-probability-and-random-variables.md) อธิบาย `X`, ค่าเฉลี่ย `μ`, ความแปรปรวน `σ²` และค่าเบี่ยงเบนมาตรฐาน `σ` แล้ว บท [เครื่องมือคณิต](01-math-toolkit.md) ช่วยเรื่องเปอร์เซ็นต์ เศษส่วน และการถอดราก

## นึกภาพก่อน

มีลูกเต๋าเที่ยงตรง 1 ลูก แต้ม 1 ถึง 6 มีโอกาสเท่ากันทุกหน้า นี่คือเกมที่ “ทุกตัวเลือกเสมอกัน”

เปลี่ยนเป็นการตรวจสินค้า 1 ชิ้น ผลมีแค่ “ผ่าน” หรือ “ไม่ผ่าน” นี่คือเกมที่มีสองผลลัพธ์ เราตั้งเลข 1 ให้ผลที่สนใจ และตั้งเลข 0 ให้อีกผลหนึ่ง แล้วค่อยคำนวณ

สองภาพนี้ต่างกันตรงสำคัญมาก: แบบเอกรูปมีหลายค่าที่โอกาสเท่ากัน ส่วนแบร์นูลลีมีการทดลองครั้งเดียวและมีเพียงสองผล

## ตัดสินใจก่อนใช้สูตร

ถามตัวเองตามลำดับนี้

1. ค่าที่เป็นไปได้มีจำนวนจำกัดและทุกค่ามีโอกาสเท่ากันหรือไม่ ถ้าใช่ ใช้แบบเอกรูปไม่ต่อเนื่อง
2. ทดลองเพียงครั้งเดียว และผลมีสองแบบหรือไม่ ถ้าใช่ ใช้แบร์นูลลี
3. ถ้าทดลองหลายครั้งแล้วถาม “สำเร็จกี่ครั้ง” นั่นเป็นทวินาม ซึ่งอยู่บทถัดไป ไม่ใช่แบร์นูลลีครั้งเดียว

## การแจกแจงแบบเอกรูปชนิดไม่ต่อเนื่อง

### กฎจากเรื่องลูกเต๋า

ตัวแปรสุ่ม `X` อ่านว่า “เอ็กซ์” หมายถึงเลขที่เราใช้แทนผลสุ่ม เช่น แต้มลูกเต๋า

ถ้า `X` มีค่าที่เป็นไปได้ `x₁, x₂, …, xₖ` และแต่ละค่ามีโอกาสเท่ากัน เราเรียกการแจกแจงนี้ว่าแบบเอกรูปชนิดไม่ต่อเนื่อง (discrete uniform distribution)

`xᵢ` อ่านว่า “เอ็กซ์ไอ” หมายถึงค่าที่เป็นไปได้ลำดับที่ `i` โดย `i` อ่านว่า “ไอ” และหมายถึงเลขลำดับ ส่วน `k` อ่านว่า “เค” หมายถึงจำนวนค่าที่เป็นไปได้ทั้งหมด

ฟังก์ชัน `f(x; k)` อ่านว่า “เอฟของเอ็กซ์ เมื่อเค” หมายถึงโอกาสของค่าหนึ่ง ๆ ในการแจกแจงนี้ จึงเป็น

```text
f(x; k) = P(X=x) = 1/k
```

คำว่า `P(X=x)` อ่านว่า “ความน่าจะเป็นที่เอ็กซ์เท่ากับเอ็กซ์เล็ก” หมายถึงโอกาสที่ X ออกค่าที่กำลังสนใจ ถ้ามี 6 หน้า แต่ละหน้าจึงมีโอกาส `1/6`

### ค่าเฉลี่ยและการกระจาย

`μ` อ่านว่า “มิว” หมายถึงค่าเฉลี่ยระยะยาวของ X และ `E(X)` อ่านว่า “อีของเอ็กซ์” หมายถึงค่าคาดหมาย ซึ่งก็คือค่าเฉลี่ยนี้

`Σ` อ่านว่า “ซิกมา” หมายถึงให้บวกค่าตามดัชนีที่กำกับไว้ ดังนั้นสูตรค่าเฉลี่ยที่ถูกต้องคือ

```text
μ = E(X) = (1/k) Σᵢ₌₁ᵏ xᵢ
```

อ่านว่า “มิวเท่ากับหนึ่งส่วนเค คูณผลบวกของเอ็กซ์ไอ ตั้งแต่ไอเท่ากับหนึ่งถึงเค” แปลว่าเอาค่าที่เป็นไปได้ทุกค่ามาบวกกัน แล้วหารด้วยจำนวนค่า

`σ²` อ่านว่า “ซิกมากำลังสอง” หมายถึงความแปรปรวน หรือความกว้างของการกระจายรอบค่าเฉลี่ย

```text
σ² = Var(X) = (1/k) Σᵢ₌₁ᵏ (xᵢ − μ)²
```

`Var(X)` อ่านว่า “แวเรียนซ์ของเอ็กซ์” หมายถึงความแปรปรวนของ X ส่วน `xᵢ−μ` คือระยะของแต่ละค่าจากค่าเฉลี่ย และเลขยกกำลัง 2 ทำให้ระยะติดลบไม่หักล้างระยะบวก

`σ` อ่านว่า “ซิกมา” หมายถึงค่าเบี่ยงเบนมาตรฐาน ต้องถอดรากความแปรปรวน

```text
σ = √σ²
```

### ระวังสูตรที่พิมพ์ผิด

สไลด์ CH4 หน้า 5 พิมพ์ `μ = 1/k` แต่แบบเอกรูปทั่วไปต้องเอาค่าทุกค่ามาเฉลี่ยก่อน คือ `μ = (1/k)Σxᵢ` ถ้าใช้ `1/k` ตรง ๆ จะได้เพียงโอกาสของแต่ละค่า ไม่ใช่ค่าเฉลี่ย

> ⚠️ สไลด์หน้า p-05 เขียน `μ=1/k` แต่ที่ถูกคือ `μ=(1/k)Σxᵢ` เพราะค่าเฉลี่ยต้องรวมค่าที่เป็นไปได้ทุกค่า ลูกเต๋าจึงมีค่าเฉลี่ย 3.5 ไม่ใช่ 1/6

## การแจกแจงแบบแบร์นูลลี

### การทดลองมีสองผล

การทดลองแบบแบร์นูลลี (Bernoulli distribution) คือการทดลอง 1 ครั้งที่มีผลเพียงสองแบบ เช่น ผ่าน/ไม่ผ่าน หรือได้มาตรฐาน/ไม่ได้มาตรฐาน

`p` อ่านว่า “พี” หมายถึงโอกาสของผลที่เราเรียกว่า “สำเร็จ” และ `q` อ่านว่า “คิว” หมายถึงโอกาสของผลที่ไม่สำเร็จ

```text
P(สำเร็จ) = p
P(ไม่สำเร็จ) = q = 1−p
```

เครื่องหมาย `1−p` อ่านว่า “หนึ่งลบพี” เพราะสองผลรวมกันต้องมีโอกาส 1 และ `0 ≤ p ≤ 1` อ่านว่า “พีอยู่ระหว่างศูนย์ถึงหนึ่ง”

### ตั้งรหัส 1 กับ 0

`X` อ่านว่า “เอ็กซ์” ในแบร์นูลลีเป็นตัวชี้วัดผลการทดลอง ให้กำหนดก่อนว่าอะไรคือผลที่สนใจ

```text
X = 1 เมื่อเกิดความสำเร็จ
X = 0 เมื่อไม่เกิดความสำเร็จ
```

`x` อ่านว่า “เอ็กซ์เล็ก” หมายถึงค่าที่ X รับจริง จึงมีได้แค่ 0 หรือ 1 ฟังก์ชันความน่าจะเป็นของแบร์นูลลีคือ

```text
f(x; p) = pˣ(1−p)¹⁻ˣ,  x = 0, 1
```

เครื่องหมาย `pˣ` อ่านว่า “พียกกำลังเอ็กซ์” และ `1−x` อ่านว่า “หนึ่งลบเอ็กซ์” เมื่อ `x=1` สูตรเหลือ `p` เมื่อ `x=0` สูตรเหลือ `1−p`

### ค่าเฉลี่ยและความแปรปรวน

จากการตั้งรหัสนี้ ค่าเฉลี่ยคือโอกาสสำเร็จ และความแปรปรวนใช้สูตรสั้น ๆ

```text
μ = E(X) = p
σ² = Var(X) = p(1−p)
σ = √[p(1−p)]
```

วงเล็บเหลี่ยม `[...]` อ่านว่า “วงเล็บเหลี่ยม” ช่วยบอกให้ถอดรากของทั้งก้อน `p(1−p)`

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 4.1 (สไลด์ CH4 หน้า 6): ลูกเต๋าเที่ยงตรง

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** `X` คือแต้มของลูกเต๋า 1 ลูก 1 ครั้ง ต้องหาโอกาสได้อย่างมาก 4 แต้ม ค่าเฉลี่ย และค่าเบี่ยงเบนมาตรฐาน
2. **คำใบ้บอกวิธีไหน:** แต้ม 1, 2, 3, 4, 5, 6 มีโอกาสเท่ากัน จึงใช้แบบเอกรูป โดย `k=6`
3. **คำนวณทีละบรรทัด:**

```text
P(X≤4) = 4/6 = 2/3 = 0.6667

μ = (1+2+3+4+5+6)/6
  = 21/6 = 3.5

σ² = [(1−3.5)²+(2−3.5)²+(3−3.5)²
      +(4−3.5)²+(5−3.5)²+(6−3.5)²]/6
    = [6.25+2.25+0.25+0.25+2.25+6.25]/6
    = 17.5/6 = 2.9167

σ = √2.9167 = 1.7078
```

4. **แปลผลเป็นภาษาคน:** โอกาสได้ไม่เกิน 4 แต้มคือ 0.6667 ค่าเฉลี่ยระยะยาวคือ 3.5 แต้ม และค่าที่ออกมักห่างจากค่าเฉลี่ยประมาณ 1.7078 แต้ม

### EX 4.2 (สไลด์ CH4 หน้า 10): ตัวอย่างการทดลองแบร์นูลลี

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** สไลด์ให้จำแนกตัวอย่างการทดลอง ได้แก่ เพศของทารก ผลสอบคัดเลือก และผลตรวจโรค
2. **คำใบ้บอกวิธีไหน:** แต่ละกรณีมีผลสองประเภทจากการทดลองหนึ่งครั้ง จึงเป็นแบร์นูลลี
3. **คำนวณทีละบรรทัด:** สไลด์ไม่ได้ให้ค่า `p` จึงคำนวณเป็นตัวเลขไม่ได้ แต่ถ้าเลือกผลที่สนใจเป็น `X=1` จะได้

```text
P(X=1) = p
P(X=0) = q = 1−p
μ = p
σ² = p(1−p)
σ = √[p(1−p)]
```

4. **แปลผลเป็นภาษาคน:** ทั้งสามอย่างเป็นแบร์นูลลีได้เมื่อเราบันทึกผลเป็นสองแบบ แต่ต้องบอกก่อนว่าอะไรคือ 1 และต้องรู้ `p` จึงจะได้คำตอบเป็นตัวเลข

### EX 4.3 (สไลด์ CH4 หน้า 11): สินค้าไม่ได้มาตรฐาน 5%

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** สุ่มสินค้า พบ 5% ไม่ได้มาตรฐาน ให้ `X` แทนประเภทสินค้า แล้วหา `μ` และ `σ`
2. **คำใบ้บอกวิธีไหน:** มีสองประเภท จึงใช้แบร์นูลลี ในที่นี้กำหนด “ไม่ได้มาตรฐาน” เป็นความสำเร็จ และให้ `X=1`
3. **คำนวณทีละบรรทัด:**

```text
p = 5% = 5/100 = 0.05
q = 1−p = 1−0.05 = 0.95
μ = p = 0.05
σ² = p(1−p) = 0.05×0.95 = 0.0475
σ = √0.0475 = 0.2179
```

4. **แปลผลเป็นภาษาคน:** เมื่อเลข 1 หมายถึงสินค้าไม่ได้มาตรฐาน ค่าเฉลี่ยของตัวชี้วัดคือ 0.05 และค่าเบี่ยงเบนมาตรฐานประมาณ 0.2179

> ⚠️ EX 4.3 หน้า p-11 ไม่บอกว่า “ประเภท” ไหนคือ `X=1` ถ้าให้ `X=1` = ไม่ได้มาตรฐาน จะได้ `μ=0.05`; ถ้าให้ `X=1` = ได้มาตรฐาน จะได้ `p=0.95` และ `μ=0.95` แต่ `σ=0.2179` เท่าเดิม

## กับดักในข้อสอบ

- **ใช้ `1/k` เป็นค่าเฉลี่ย:** ผิด เพราะ `1/k` คือโอกาสของแต่ละค่า ต้องบวกค่าทั้งหมดแล้วหารด้วย `k`
- **ใช้แบบเอกรูปทั้งที่โอกาสไม่เท่ากัน:** ถ้าโจทย์ให้โอกาสแต่ละผลไม่เท่ากัน ห้ามใช้ `1/k`
- **สับสน `σ²` กับ `σ`:** `σ²` ยังไม่ถอดราก ส่วนคำว่า “ค่าเบี่ยงเบนมาตรฐาน” ต้องใช้ `σ`
- **ลืมแปลงเปอร์เซ็นต์:** 5% คือ `0.05` ไม่ใช่ 5
- **ไม่กำหนด `X=1`:** ใน EX 4.3 เปลี่ยนว่าอะไรเป็น 1 แล้ว `μ` เปลี่ยน ต้องเขียนกำกับเสมอ
- **เรียกการทดลองหลายครั้งว่าแบร์นูลลี:** แบร์นูลลีคือ 1 ครั้ง 2 ผล ถ้านับความสำเร็จจากหลายครั้งให้ดูบททวินาม

## แบบฝึกหัดปิดหนังสือ

ลองทำก่อนเปิดเฉลย ตัวเลขไม่ซ้ำกับตัวอย่างบนสไลด์

### คำถามเขียนตอบ

1. `X` มีค่าเป็น 2, 4, 6, 8 และทุกค่ามีโอกาสเท่ากัน จงหา `P(X=6)`, `μ` และ `σ`
2. การตรวจหนึ่งครั้งมีโอกาส “ผ่าน” `p=0.30` ให้ `X=1` เมื่อผ่าน จงหา `q`, `μ`, `σ²` และ `σ`
3. วงล้อมีเลข 1, 2, 3, 4 โอกาสเท่ากัน ให้ `X` เป็นเลขที่ลูกศรชี้ จงหา `P(X≤2)`, `μ`, `σ²` และ `σ`

### คำถามเลือกตอบ

4. ถ้าแบบเอกรูปมีค่าที่เป็นไปได้ 5 ค่า โอกาสของค่าหนึ่งค่าคือเท่าไร?  ก. 0.05  ข. 0.20  ค. 0.25  ง. 5.00
5. แบร์นูลลีมี `p=0.80` ค่าเบี่ยงเบนมาตรฐานเท่าไร?  ก. 0.16  ข. 0.20  ค. 0.40  ง. 0.80
6. สินค้าได้มาตรฐาน 95% และกำหนด `X=1` เมื่อได้มาตรฐาน ค่าเฉลี่ยของ X เท่าไร?  ก. 0.05  ข. 0.95  ค. 1.05  ง. 19

<details>
<summary>เปิดดูเฉลย</summary>

**ข้อ 1**

มี 4 ค่าและโอกาสเท่ากัน จึง `k=4`

```text
P(X=6) = 1/4 = 0.2500
μ = (2+4+6+8)/4 = 20/4 = 5
σ² = [(2−5)²+(4−5)²+(6−5)²+(8−5)²]/4
    = (9+1+1+9)/4 = 20/4 = 5
σ = √5 = 2.2361
```

**ข้อ 2**

```text
p = 0.30
q = 1−p = 1−0.30 = 0.70
μ = p = 0.30
σ² = p(1−p) = 0.30×0.70 = 0.21
σ = √0.21 = 0.4583
```

**ข้อ 3**

```text
P(X≤2) = 2/4 = 0.5000
μ = (1+2+3+4)/4 = 10/4 = 2.5
σ² = [(1−2.5)²+(2−2.5)²+(3−2.5)²+(4−2.5)²]/4
    = (2.25+0.25+0.25+2.25)/4 = 5/4 = 1.25
σ = √1.25 = 1.1180
```

**ข้อ 4: ข. 0.20**

```text
P(ค่าหนึ่งค่า) = 1/k = 1/5 = 0.20
```

ก. ลืมว่าต้องหารด้วย 5, ค. ใช้ 1/4 ซึ่งเป็นจำนวนผิด และ ง. ไม่ใช่ค่าความน่าจะเป็น

**ข้อ 5: ค. 0.40**

```text
σ = √[p(1−p)] = √[0.80×(1−0.80)]
  = √(0.80×0.20) = √0.16 = 0.40
```

ก. คือความแปรปรวน `σ²`, ข. ถอดรากผิด และ ง. คือ p ไม่ใช่ส่วนเบี่ยงเบนมาตรฐาน

**ข้อ 6: ข. 0.95**

เมื่อกำหนด “ได้มาตรฐาน” เป็น `X=1` ผลที่สนใจมีโอกาส `p=0.95`

```text
μ = p = 0.95
```

ก. เป็นโอกาสสินค้าที่ไม่ได้มาตรฐาน, ค. บวกเกิน 1 และ ง. เอาเปอร์เซ็นต์ไปคูณ 20 จึงผิด

</details>

## สรุปจำสั้น

- แบบเอกรูปไม่ต่อเนื่อง: ค่ามีจำนวนจำกัดและทุกค่ามีโอกาสเท่ากัน
- ถ้ามี `k` ค่า โอกาสของแต่ละค่าคือ `1/k`
- ค่าเฉลี่ยที่ถูกต้องคือ `μ=(1/k)Σxᵢ` ไม่ใช่ `1/k` เฉย ๆ
- ความแปรปรวนคือ `σ²`; ค่าเบี่ยงเบนมาตรฐานคือ `σ=√σ²`
- แบร์นูลลี: ทดลอง 1 ครั้ง มี 2 ผล และ `q=1−p`
- กำหนด `X=1` ให้ผลที่สนใจ และ `X=0` ให้อีกผลก่อนคำนวณ
- แบร์นูลลีใช้ `μ=p`, `σ²=p(1−p)`, `σ=√[p(1−p)]`
- EX 4.3 จะได้ `μ=0.05` หรือ `0.95` ตามความหมายของ `X=1` แต่ `σ` เท่ากัน
