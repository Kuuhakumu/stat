# บทที่ 25: ทดสอบผลต่างค่าเฉลี่ยของสองกลุ่ม

## เป้าหมาย

- แยกให้ออกว่าสองกลุ่มเป็นอิสระกัน และเลือกวิธีทดสอบให้เหมาะกับข้อมูลได้
- ตั้งสมมติฐานหลักและทางเลือกสำหรับผลต่างค่าเฉลี่ย โดยใส่ค่าผลต่างที่กำหนดให้ครบ
- คำนวณ EX 7.10, EX 7.11 และ EX 7.12 ตามสไลด์ทีละบรรทัด
- อ่านตารางโค้งปกติและตารางที แล้วตัดสินใจที่ระดับนัยสำคัญ 0.05 หรือ 0.01

## ต้องรู้ก่อน

- [ไอเดียการทดสอบสมมติฐาน](22-hypothesis-testing-idea.md) — สมมติฐานหลัก/ทางเลือก หางซ้าย/ขวา/สองหาง และค่า p
- [ทดสอบค่าเฉลี่ยหนึ่งประชากร](23-test-one-mean.md) — การเลือกสถิติ ระดับนัยสำคัญ และการปัดค่าเพื่ออ่านตาราง
- [ผลต่างของค่าเฉลี่ยสองกลุ่ม](14-difference-of-two-means.md) — สูตรของสถิติสามแบบสำหรับสองกลุ่ม
- [การแจกแจงที](12-t-distribution.md) — องศาอิสระและตาราง t

## นึกภาพก่อน

สมมติว่าโรงงานมีสายการผลิต A กับ B เราสุ่มคนจากแต่ละสายแล้วได้คะแนนเฉลี่ยสองค่า การเห็นค่าเฉลี่ย A สูงกว่า B ยังไม่พอที่จะบอกว่าต่างกันจริง เพราะตัวอย่างที่สุ่มมาอาจแกว่งได้

เราจึงถามว่า “ผลต่างที่เห็น ห่างจากค่าผลต่างที่ตั้งไว้เป็นหลักกี่หน่วยความแกว่ง?” ถ้าห่างมาก ก็มีหลักฐานพอจะปฏิเสธข้ออ้างเดิม คำว่า “สองกลุ่ม” ในบทนี้หมายถึงคนละกลุ่มและสุ่มแยกกัน ถ้าเป็นคนเดิมวัดก่อน–หลัง ให้ไปบทถัดไปเรื่องข้อมูลจับคู่

## คำที่ใช้และสัญลักษณ์

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `μ₁` | มิวหนึ่ง | ค่าเฉลี่ยจริงของประชากรกลุ่ม 1 |
| `μ₂` | มิวสอง | ค่าเฉลี่ยจริงของประชากรกลุ่ม 2 |
| `μ₁−μ₂` | มิวหนึ่งลบมิวสอง | ผลต่างค่าเฉลี่ยจริง โดยเอากลุ่ม 1 ลบกลุ่ม 2 |

| `x̄₁−x̄₂` | เอ็กซ์บาร์หนึ่งลบเอ็กซ์บาร์สอง | ผลต่างที่เห็นจากตัวอย่าง |
| `d₀` | ดีศูนย์ | ผลต่างที่สมมติไว้ใน H₀ เช่น 5 คะแนน; ไม่จำเป็นต้องเป็น 0 |
| `σ₁², σ₂²` | ซิกมากำลังสองหนึ่ง, สอง | ความแปรปรวนจริงของประชากรแต่ละกลุ่ม |
| `S₁², S₂²` | เอสกำลังสองหนึ่ง, สอง | ความแปรปรวนที่คำนวณจากตัวอย่าง |
| `Sₚ²` | เอสพีกำลังสอง | ความแปรปรวนตัวอย่างที่รวมสองกลุ่มเมื่อสมมติว่าเท่ากัน |
| `Sₚ` | เอสพี | รากที่สองของ `Sₚ²` |
| `n₁, n₂` | เอ็นหนึ่ง, เอ็นสอง | จำนวนข้อมูลของกลุ่ม 1 และกลุ่ม 2 |
| `SE` | เอสอี | ส่วนเบี่ยงเบนมาตรฐานของผลต่าง หรือ standard error |

| `α` | แอลฟา | ระดับนัยสำคัญ หรือพื้นที่หางที่ยอมให้ปฏิเสธ H₀ |
| `α/2` | แอลฟาหารสอง | ครึ่งหนึ่งของ α เมื่อเป็นการทดสอบสองหาง |
| `p-value` | พีแวลยู | โอกาสได้ค่าที่สุดโต่งเท่านี้หรือมากกว่า ถ้าถือว่า H₀ จริง |

| `|T|` | ค่าสัมบูรณ์ของที | ตัดเครื่องหมายลบ เหลือระยะห่างจากศูนย์ |

## กฎเลือกวิธีและตั้งสมมติฐาน

เริ่มจากถามสามเรื่อง: รู้ σ หรือไม่, ตัวอย่างทั้งสองใหญ่หรือไม่, และความแปรปรวนเท่ากันหรือไม่

| เงื่อนไขในโจทย์ | วิธี | ตัวหารของสถิติ | องศาอิสระ |
|---|---|---|---|
| รู้ `σ₁²,σ₂²` หรือ `n₁≥30` และ `n₂≥30` | Z | `√(σ₁²/n₁ + σ₂²/n₂)` ถ้าไม่รู้ σ ในตัวอย่างใหญ่ ใช้ `S` แทน | ไม่ต้องใช้ |
| ตัวอย่างทั้งคู่เล็ก, ประชากรปกติ, ไม่รู้ σ และบอกว่าความแปรปรวนเท่ากัน | pooled t | `Sₚ√(1/n₁ + 1/n₂)` | `n₁+n₂−2` |
| ตัวอย่างทั้งคู่เล็ก, ประชากรปกติ, ไม่รู้ σ และบอกว่าความแปรปรวนไม่เท่ากัน | Welch t | `√(S₁²/n₁ + S₂²/n₂)` | สูตร Welch |

ตัวอย่างใหญ่ต้องเป็นทั้งสองกลุ่ม ไม่ใช่มีแค่กลุ่มเดียวถึง 30 ถ้าโจทย์ไม่พูดว่าความแปรปรวนเท่ากัน ห้ามสร้าง `Sₚ²` เอง ให้ใช้ Welch

ให้เขียนสมมติฐานโดยใช้ผลต่างก่อนเสมอ

```text
H₀: μ₁−μ₂ = d₀
H₁: μ₁−μ₂ > d₀   เมื่อถามว่ากลุ่ม 1 สูงกว่า
H₁: μ₁−μ₂ < d₀   เมื่อถามว่ากลุ่ม 1 ต่ำกว่า
H₁: μ₁−μ₂ ≠ d₀   เมื่อถามว่าต่างกัน
```

ถ้า `d₀=5` ตัวเศษต้องเป็น `(x̄₁−x̄₂)−5` ไม่ใช่แค่ `x̄₁−x̄₂` ถ้าโจทย์ไม่ให้ α ให้สมมติ `α=0.05` และรายงานด้วยว่าเมื่อ `α=0.01` ผลเปลี่ยนหรือไม่

## สูตรที่ใช้

เมื่อรู้ความแปรปรวนประชากร หรือเป็นตัวอย่างใหญ่ ใช้ Z

```text
Z = [(x̄₁−x̄₂)−d₀] / √(σ₁²/n₁ + σ₂²/n₂)
```

ถ้าเป็นตัวอย่างใหญ่แต่ไม่รู้ σ ให้แทน `σ₁²,σ₂²` ด้วย `S₁²,S₂²` ในสูตรเดียวกัน

เมื่อเป็นตัวอย่างเล็กและความแปรปรวนเท่ากัน ให้รวมความแปรปรวนก่อน

```text
Sₚ² = [(n₁−1)S₁² + (n₂−1)S₂²] / (n₁+n₂−2)
Sₚ = √Sₚ²
ν = n₁+n₂−2
T = [(x̄₁−x̄₂)−d₀] / [Sₚ√(1/n₁ + 1/n₂)]
```

เมื่อความแปรปรวนไม่เท่ากัน ใช้ Welch โดยไม่รวมความแปรปรวน

```text
T = [(x̄₁−x̄₂)−d₀] / √(S₁²/n₁ + S₂²/n₂)

ν = (S₁²/n₁ + S₂²/n₂)²
    ─────────────────────────────────────────
    (S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1)
```

ค่า `ν` ของ Welch มักเป็นทศนิยม ให้คำนวณก่อนแล้วปัดเป็นแถวใกล้ที่สุดตามวิธีที่ใช้ในบทก่อน

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 7.10 (สไลด์ CH7 หน้า 34): คะแนนสายการผลิต

**1) โจทย์ถามอะไร / ข้อมูลที่มี** สาย A มีคะแนน `81, 86, 71, 77, 80, 81, 75, 72, 98, 74` และสาย B มี `89, 65, 69, 64, 57, 58, 55, 57, 65, 68, 72, 71, 69` โจทย์สมมติความแปรปรวนเท่ากัน และถามว่าค่าเฉลี่ยต่างกัน 5 คะแนนหรือไม่ สไลด์หน้า p-34 ไม่ระบุ `α` จึงสมมติ `α=0.05` และตรวจเพิ่มที่ `α=0.01`

```text
n₁=10,  n₂=13
ผลต่างที่ตั้งไว้ d₀=5
H₀: μ₁−μ₂=5
H₁: μ₁−μ₂≠5
```

**2) คำใบ้บอกวิธีไหน** ตัวอย่างทั้งคู่เล็ก ไม่รู้ σ แต่โจทย์บอกความแปรปรวนเท่ากัน จึงใช้ pooled t และเป็นสองหาง

**3) คำนวณทีละบรรทัด**

```text
x̄₁ = (81+86+71+77+80+81+75+72+98+74)/10
    = 795/10
    = 79.5000

x̄₂ = (89+65+69+64+57+58+55+57+65+68+72+71+69)/13
    = 859/13
    = 66.0769

S₁² = 574.5000/(10−1) = 574.5000/9 = 63.8333
S₂² = 964.9231/(13−1) = 964.9231/12 = 80.4103

Sₚ² = [9(63.8333)+12(80.4103)]/(10+13−2)
     = [574.4997+964.9236]/21
     = 1539.4233/21
     = 73.3059
Sₚ = √73.3059 = 8.5619

ν = 10+13−2 = 21
SE = 8.5619√(1/10+1/13)
   = 8.5619√(0.1000+0.0769231)
   = 8.5619√0.1769231
   = 8.5619(0.4206220)
   = 3.6013

T = [(79.5000−66.0769)−5]/3.6013
  = (13.4231−5)/3.6013
  = 8.4231/3.6013
  = 2.3389 ≈ 2.34
```

**4) แปลผลเป็นภาษาคน** ตาราง t หน้า TABLES p-18 แถว `ν=21` ให้ค่าความเข้มสองหาง `0.05 → 2.080` และ `0.02 → 2.518` ค่านี้อยู่ระหว่างสองค่า จึงได้ `0.0200 < p-value < 0.0500` ที่ `α=0.05` ปฏิเสธ H₀ เพราะ 2.34 มากกว่า 2.080 มีหลักฐานว่าผลต่างจริงไม่เท่ากับ 5 คะแนน ที่ `α=0.01` ยังไม่ปฏิเสธ เพราะค่า 2.34 ยังไม่ถึงค่าที่เข้มกว่าในตาราง

### EX 7.11 (สไลด์ CH7 หน้า 35): อายุเครื่องยนต์สองรุ่น

**1) โจทย์ถามอะไร / ข้อมูลที่มี** รุ่น A มี 10 ค่า `218, 236, 178, 244, 148, 171, 198, 168, 160, 174` เดือน รุ่น B มี 21 ค่า `178, 184, 146, 176, 185, 158, 175, 172, 163, 181, 162, 152, 164, 180, 157, 164, 182, 169, 178, 154, 148` เดือน โจทย์บอกว่าความแปรปรวนไม่เท่ากัน และถามว่าค่าเฉลี่ยต่างกันหรือไม่ สไลด์หน้า p-35 ไม่ระบุ `α` จึงสมมติ `α=0.05` และตรวจเพิ่มที่ `α=0.01`

```text
n₁=10, n₂=21, d₀=0
H₀: μ₁−μ₂=0
H₁: μ₁−μ₂≠0
```

**2) คำใบ้บอกวิธีไหน** ตัวอย่างเล็ก ไม่รู้ σ และความแปรปรวนไม่เท่ากัน จึงใช้ Welch t ไม่ใช้ `Sₚ²`

**3) คำนวณทีละบรรทัด**

```text
x̄₁ = 1895/10 = 189.5000
x̄₂ = 3528/21 = 168.0000

S₁² = 9786.5000/9 = 1087.3889
S₂² = 3034.0000/20 = 151.7000

S₁²/n₁ = 1087.3889/10 = 108.7389
S₂²/n₂ = 151.7000/21 = 7.2238
SE = √(108.7389+7.2238)
   = √115.9627
   = 10.7686

T = [(189.5000−168.0000)−0]/10.7686
  = 21.5000/10.7686
  = 1.9965 ≈ 2.00

ν = (108.7389+7.2238)²
    / [(108.7389²/9)+(7.2238²/20)]
  = 13447.35/(1313.7943+2.6092)
  = 10.2152 ≈ 10
```

**4) แปลผลเป็นภาษาคน** ตาราง t หน้า TABLES p-18 แถว `ν=10` ให้สองหาง `0.10 → 1.812` และ `0.05 → 2.228` ค่า `|T|=2.00` อยู่ระหว่าง จึงได้ `0.0500 < p-value < 0.1000` ที่ `α=0.05` ไม่ปฏิเสธ H₀ หลักฐานยังไม่พอจะบอกว่าอายุเฉลี่ยต่างกัน ที่ `α=0.01` ก็ไม่ปฏิเสธเช่นกัน

### EX 7.12 (สไลด์ CH7 หน้า 36): วิเคราะห์แมงกานีสด้วยสองวิธี

**1) โจทย์ถามอะไร / ข้อมูลที่มี** วิธี 1 ได้ `3.3, 3.7, 3.5, 4.1, 3.4, 3.5, 4.0, 3.8, 3.2, 3.7` จำนวน 10 ครั้ง วิธี 2 ได้ `3.2, 3.6, 3.1, 3.4, 3.0, 3.4, 2.8, 3.1, 3.3` จำนวน 9 ครั้ง ต้องตรวจว่าวิธี 1 มีค่าเฉลี่ยผลวิเคราะห์สูงกว่าวิธี 2 หรือไม่

```text
n₁=10, n₂=9, d₀=0
H₀: μ₁−μ₂=0
H₁: μ₁−μ₂>0
```

**2) คำใบ้บอกวิธีไหน** ตัวอย่างทั้งคู่เล็ก ไม่รู้ σ และสไลด์ไม่ได้บอกว่าความแปรปรวนเท่ากัน จึงใช้ Welch t การตีความ “ประสิทธิภาพดีกว่า” เป็น “ค่าเฉลี่ยวิธี 1 สูงกว่า” เพราะสไลด์ไม่ได้ให้นิยามคำว่าประสิทธิภาพไว้ชัดเจน

**3) คำนวณทีละบรรทัด**

```text
x̄₁ = 36.2/10 = 3.6200
x̄₂ = 28.9/9 = 3.2111

S₁² = 0.7760/9 = 0.0862222
S₂² = 0.4688889/8 = 0.0586111

S₁²/n₁ = 0.0862222/10 = 0.0086222
S₂²/n₂ = 0.0586111/9 = 0.0065123
SE = √(0.0086222+0.0065123)
   = √0.0151345
   = 0.1230

T = [(3.6200−3.2111)−0]/0.1230
  = 0.4089/0.1230
  = 3.3237 ≈ 3.32

ν = (0.0086222+0.0065123)²
    / [(0.0086222²/9)+(0.0065123²/8)]
  = 16.8899 ≈ 17
```

**4) แปลผลเป็นภาษาคน** ตาราง t หน้า TABLES p-18 แถว `ν=17` ให้หางเดียว `0.005 → 2.898` และ `0.001 → 3.646` ค่า `T=3.32` มากกว่า 2.898 จึง `p-value < 0.0050` ที่ `α=0.05` และ `α=0.01` ต่างก็ปฏิเสธ H₀ มีหลักฐานว่าวิธี 1 ให้ค่าเฉลี่ยสูงกว่าวิธี 2 ตามการตีความนี้

> ⚠️ สไลด์หน้า p-36 ไม่บอก α ไม่บอกสมมติฐานเรื่องความแปรปรวน และใช้คำว่า “ประสิทธิภาพดีกว่า” กว้าง ๆ คำตอบข้างบนจึงสมมติ `α=0.05` และตีความว่าคือค่าเฉลี่ยสูงกว่า ถ้าอาจารย์กำหนดความหมายอื่น ให้เปลี่ยน H₁ ให้ตรงคำนั้น

## วิธีอ่านตาราง

- **ตาราง Z:** ถ้าเป็น Z ให้ปัดเป็น 2 ตำแหน่งก่อนอ่าน ตารางหน้า TABLES p-16–p-17 ให้พื้นที่สะสมทางซ้าย
- **ตาราง t:** ไปแถว `ν` ก่อน แล้วเลือกคอลัมน์ one-tail หรือ two-tails ให้ตรงกับ H₁ ตารางหน้า TABLES p-18 มีค่าที่พิมพ์ เช่น แถว 21 สองหาง 0.05 ให้ 2.080 และแถว 17 หางเดียว 0.005 ให้ 2.898
- หางขวา `>` ใช้ค่า t บวก ถ้า `T` เป็นลบก็ยังดูทิศทางจาก H₁ ไม่ใช่เปลี่ยนหางตามเลขที่คำนวณ
- สองหาง `≠` ใช้คอลัมน์ two-tails และเทียบ `|T|` กับค่าบวกในตาราง

## กับดักในข้อสอบ

- **ผิด:** ลืม `d₀` ในตัวเศษ — **ถูก:** ใช้ `[(x̄₁−x̄₂)−d₀]` ทุกครั้ง เช่น EX 7.10 ต้องลบ 5
- **ผิด:** เห็นตัวอย่างกลุ่มหนึ่งมี 30 แล้วใช้ Z — **ถูก:** ต้องมีทั้ง `n₁≥30` และ `n₂≥30`
- **ผิด:** ตัวอย่างเล็กแต่ใช้ pooled ทุกข้อ — **ถูก:** pooled ใช้เมื่อโจทย์บอกความแปรปรวนเท่ากันเท่านั้น ถ้าไม่เท่ากันใช้ Welch
- **ผิด:** ใช้ `n₁+n₂−2` กับ Welch — **ถูก:** Welch ต้องใช้สูตร `ν` เฉพาะของมัน
- **ผิด:** สองหางใช้คอลัมน์ one-tail — **ถูก:** ใช้ two-tails หรือแบ่ง `α` เป็น `α/2`
- **ผิด:** ไม่ปฏิเสธ H₀ แล้วพูดว่า H₀ จริงแน่นอน — **ถูก:** พูดว่าหลักฐานยังไม่พอ
- **ผิด:** เปลี่ยนกลุ่ม 1 ลบกลุ่ม 2 เป็นกลุ่ม 2 ลบกลุ่ม 1 กลางโจทย์ — **ถูก:** กำหนดลำดับให้ชัดตั้งแต่ตั้ง H₀
- **ผิด:** เปลี่ยนหางเพราะ T ออกมาเป็นลบ — **ถูก:** หางมาจากเครื่องหมายใน H₁

## แบบฝึกหัดปิดหนังสือ

### คำถามเขียนตอบ

1. รู้ `σ₁=10`, `σ₂=8`, `n₁=40`, `n₂=50`, `x̄₁=52`, `x̄₂=45` จงทดสอบ `H₁: μ₁−μ₂>5` ที่ `α=0.05` และบอกผลที่ `α=0.01`
2. ประชากรปกติ ตัวอย่างเล็ก ความแปรปรวนเท่ากัน มี `n₁=8`, `n₂=7`, `x̄₁−x̄₂=3`, `S₁=2`, `S₂=3` จงทดสอบสองหางที่ `d₀=0`, `α=0.05`
3. ประชากรปกติ ตัวอย่างเล็ก ความแปรปรวนไม่เท่ากัน มี `n₁=6`, `n₂=9`, `x̄₁−x̄₂=6`, `d₀=2`, `S₁=1.5`, `S₂=3.2` จงทดสอบ `H₁: μ₁−μ₂>2` ที่ `α=0.05`

<details><summary>เปิดดูเฉลยคำถามเขียนตอบ</summary>

**ข้อ 1**

```text
H₀: μ₁−μ₂=5, H₁: μ₁−μ₂>5
ใช้ Z เพราะรู้ σ₁ และ σ₂
SE = √(10²/40 + 8²/50)
   = √(100/40 + 64/50)
   = √(2.5000+1.2800)
   = √3.7800 = 1.9442
Z = [(52−45)−5]/1.9442
  = 2/1.9442
  = 1.0287 ≈ 1.03
```

ตาราง Z หน้า p-16 ที่ `z=1.03` ให้พื้นที่ซ้าย 0.8485 ดังนั้น p-value หางขวา `1−0.8485=0.1515` มากกว่า 0.05 และ 0.01 จึงไม่ปฏิเสธ H₀ ทั้งสองระดับ

**ข้อ 2**

```text
H₀: μ₁−μ₂=0, H₁: μ₁−μ₂≠0
Sₚ² = [7(2²)+6(3²)]/(8+7−2)
     = (28+54)/13
     = 6.3077
Sₚ = √6.3077 = 2.5115
ν = 8+7−2 = 13
SE = 2.5115√(1/8+1/7)
   = 2.5115√0.2679
   = 1.2999
T = (3−0)/1.2999 = 2.3079 ≈ 2.31
```

ตาราง t แถว 13 สองหางให้ `0.05 → 2.160` และ `0.02 → 2.650` ดังนั้น `0.0200 < p-value < 0.0500` และปฏิเสธ H₀ ที่ α=0.05

**ข้อ 3**

```text
H₀: μ₁−μ₂=2, H₁: μ₁−μ₂>2
SE = √(1.5²/6 + 3.2²/9)
   = √(2.25/6 + 10.24/9)
   = √(0.3750+1.1378)
   = √1.5128 = 1.22995
T = [(6)−2]/1.22995
  = 4/1.22995
  = 3.2522 ≈ 3.25
ν = (0.3750+1.1378)²
    / [(0.3750²/5)+(1.1378²/8)]
  = 12.0484 ≈ 12
```

ตาราง t แถว 12 หางเดียวให้ `0.005 → 3.055` ค่า 3.25 มากกว่า 3.055 จึง `p-value < 0.0050 < 0.05` และปฏิเสธ H₀

## สรุปจำสั้น ๆ

- กำหนดผลต่างเป็นกลุ่ม 1 ลบกลุ่ม 2 และใช้ `H₀: μ₁−μ₂=d₀`
- `d₀` อาจไม่ใช่ 0; ต้องลบมันในตัวเศษ
- รู้ σ หรือทั้งสอง `n≥30` → Z
- ตัวอย่างเล็ก ความแปรปรวนเท่ากัน → pooled t, `ν=n₁+n₂−2`
- ตัวอย่างเล็ก ความแปรปรวนไม่เท่ากัน → Welch t และ df สูตร Welch
- `>` หางขวา, `<` หางซ้าย, `≠` สองหาง
- ตาราง t หน้า p-18 ต้องเลือกแถว df และคอลัมน์ one-tail/two-tails ให้ตรง
- p-value `≤ α` จึงปฏิเสธ H₀; ถ้ามากกว่า α ให้ไม่ปฏิเสธ
