ขใช้ SE แบบ `σ/n`; คใช้ `σ` เป็น SE โดยตรง; งใช้ค่า z ของช่วง 90% แทน 95% ทบทวน [บทช่วงความเชื่อมั่นหนึ่งค่าเฉลี่ย](17-ci-one-mean.md)

**25. ตอบ ก.** ไม่รู้ `σ` และมีตัวอย่างเล็ก จึงใช้ t ที่ `df=10−1=9`

```text
SE = S/√n = 5/√10 = 1.5811
ส่วนเผื่อ = 2.262(1.5811) = 3.5765
ช่วง = 31 ± 3.5765 = [27.4235, 34.5765]
     ≈ [27.42, 34.58]
```

ขใช้ Z แทน t; คหารด้วย `n` แทน `√n`; งใช้ค่า t จากแถว df ผิด ทบทวน [บทช่วงความเชื่อมั่นหนึ่งค่าเฉลี่ย](17-ci-one-mean.md)

```text
   = √(4.5+10) = √14.5 = 3.8079

   = 210.25 / (2.8929+11.1111)
   = 15.0136 ≈ 15
```

**38. ตอบ ข.** เป็นคนเดิมวัดสองครั้ง ให้ใช้ paired t และใช้ 5 คู่ ไม่ใช่ 10 ค่าแยกกัน

```text
D̄ = (5+3+4+2+6)/5 = 20/5 = 4
Σ(Dᵢ−D̄)² = 1+1+0+4+4 = 10
S_D = √[10/(5−1)] = √2.5 = 1.5811
SE = 1.5811/√5 = 0.7071
t = (4−0)/0.7071 = 5.6569 ≈ 5.66
df = 5−1 = 4
```
