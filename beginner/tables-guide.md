# คู่มือเปิดตารางสถิติในเล่มข้อสอบ

## เป้าหมาย

หลังอ่านหน้านี้ คุณจะรู้ว่าโจทย์แบบไหนต้องเปิดตารางหน้าไหน และอ่านแถวกับคอลัมน์อย่างไรโดยไม่สลับหาง

- อ่านตารางทวินาม ปัวส์ซง z t และ χ² ได้
- เปลี่ยนคำว่า “ไม่เกิน”, “อย่างน้อย”, “ระหว่าง” ให้ตรงกับหัวตาราง
- เลือกตารางจากเรื่องที่โจทย์กำลังถาม

## ต้องรู้ก่อน

- [คณิตศาสตร์ที่ใช้ในวิชานี้](01-math-toolkit.md) เรื่องเศษส่วน รากที่สอง และเครื่องหมาย `<`, `≤`, `>`, `≥`
- [ทวินาม](04-binomial.md), [ปัวส์ซง](05-poisson.md) และ [ตาราง Z](07-normal-and-z-table.md)
- [การแจกแจงของค่าเฉลี่ยตัวอย่าง](11-sampling-distribution-of-mean.md) และ [การแจกแจง t](12-t-distribution.md)

## นึกภาพก่อน

เล่มตารางเหมือนตู้ลิ้นชัก แต่ละลิ้นชักตอบคำถามคนละแบบ ก่อนเปิดต้องรู้ว่าเรากำลังนับ “ความสำเร็จ”, นับ “เหตุการณ์”, หาพื้นที่ใต้โค้ง หรือหาค่าจุดตัด ถ้าเปิดผิดตาราง ต่อให้กดเลขถูกก็ได้คำตอบผิด

ตารางสะสมส่วนใหญ่ให้พื้นที่ด้านซ้าย ส่วนโจทย์ “อย่างน้อย” หรือ “มากกว่า” มักต้องเอา 1 ลบ พื้นที่ที่ตารางให้มา ตาราง t และ χ² เป็นข้อยกเว้นสำคัญ เพราะเป็นตารางค่าวิกฤตที่ผูกกับหางขวา

## 1. ตารางทวินาม: p-01 ถึง p-11

### นึกภาพพื้นที่

คิดว่ามีการโยนเหรียญ `n` ครั้ง แล้วนับจำนวนครั้งที่ออกหัว ตารางนี้รวมแท่งตั้งแต่ `0` ถึงแถวที่เราเลือก จึงเป็นพื้นที่ “ซ้ายสุดถึง r” ไม่ใช่แท่งเดียว

### กฎและวิธีเปิด

ทวินาม (binomial) ใช้เมื่อมีการทดลองจำนวนคงที่ มีผลสองแบบ ทดลองเป็นอิสระ และโอกาสสำเร็จ `p` เท่าเดิมทุกครั้ง ตัวแปร `X` คือจำนวนครั้งที่สำเร็จ

หัวตารางเขียนว่า `P(X ≤ r)` อ่านว่า “ความน่าจะเป็นที่ X ไม่เกิน r” ตารางแบ่งเป็นกลุ่มตาม `n` แล้วมีแถว `x` และคอลัมน์ `p`

```text
เปิด p-01 ถึง p-11
1) หาแถวกลุ่ม n
2) ในกลุ่มนั้นหาแถว x ซึ่งทำหน้าที่เป็น r
3) เลื่อนไปคอลัมน์ p
4) อ่าน P(X ≤ r)
```

ถ้าต้องการจำนวนพอดี ใช้ผลต่างของตารางสะสม หรือใช้สูตรของบท [ทวินาม](04-binomial.md)

```text
P(X = r) = P(X ≤ r) − P(X ≤ r−1)
P(X ≥ k) = 1 − P(X ≤ k−1)
P(X > k) = 1 − P(X ≤ k)
P(a ≤ X ≤ b) = P(X ≤ b) − P(X ≤ a−1)
```

### แบบฝึกอ่านจากค่าพิมพ์จริง

**ดริลล์ 1: “ไม่เกิน”**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `n=7`, `p=0.40`, ต้องการ `P(X≤3)`
2. คำใบ้: คำว่า “ไม่เกิน” ตรงกับหัวตารางพอดี
3. คำนวณทีละขั้น: กลุ่ม `n=7` → แถว `x=3` → คอลัมน์ `p=0.40` → อ่าน `0.7102`
4. แปลผล: โอกาสสำเร็จไม่เกิน 3 ครั้งคือ `0.7102`

**ดริลล์ 2: “อย่างน้อย”**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `n=5`, `p=0.50`, ต้องการ `P(X≥4)`
2. คำใบ้: “อย่างน้อย 4” รวม 4 และ 5 จึงต้องลบแถวก่อนหน้า คือ `X≤3`
3. คำนวณทีละขั้น: ตารางแถว `x=3`, คอลัมน์ `p=0.50` ให้ `0.8125` → `1−0.8125=0.1875`
4. แปลผล: โอกาสสำเร็จอย่างน้อย 4 ครั้งคือ `0.1875`

**ดริลล์ 3: “ระหว่าง”**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `n=6`, `p=0.30`, ต้องการ `P(2≤X≤4)`
2. คำใบ้: เอาพื้นที่ถึง 4 ลบพื้นที่ถึง 1
3. คำนวณทีละขั้น: แถว `x=4` ให้ `0.9891`; แถว `x=1` ให้ `0.4202`; ดังนั้น `0.9891−0.4202=0.5689`
4. แปลผล: โอกาสสำเร็จตั้งแต่ 2 ถึง 4 ครั้งคือ `0.5689`

### ข้อสอบที่ต้องเปิดตารางนี้

- โจทย์นับจำนวนครั้งที่สำเร็จจากการทดลองคงที่: [บททวินาม](04-binomial.md)
- การบ้านบท 4 ที่ถามทวินาม: [การบ้าน CH4](09-homework-ch4.md)

### กับดัก

- แถว `x` ของเล่มคือจุดตัด `r` ของ `P(X≤r)` ไม่ใช่ `P(X=x)` พอดี
- `P(X≥4)` ต้องใช้ `1−P(X≤3)` ไม่ใช่ `1−P(X≤4)`
- อย่าสลับ `n` กับ `p`: `n` หาเป็นกลุ่มแถว ส่วน `p` หาเป็นคอลัมน์

## 2. ตารางปัวส์ซง: p-12 ถึง p-15

### นึกภาพพื้นที่

ลองนับจำนวนลูกค้าที่เข้าร้านในหนึ่งชั่วโมง `X` อาจเป็น 0, 1, 2, … ตารางรวมพื้นที่ตั้งแต่ไม่มาเลยจนถึงจำนวนที่อยู่ในแถวที่เลือก

### กฎและวิธีเปิด

ปัวส์ซง (Poisson) ใช้กับจำนวนเหตุการณ์ในเวลา/พื้นที่หนึ่งช่วง เมื่อรู้ค่าเฉลี่ย `λ` หัวตารางก็เขียน `P(X≤r)` เช่นกัน แต่คอลัมน์เป็น `λ` ไม่ใช่ `p`

```text
เปิด p-12 ถึง p-15
1) หาแถว x ซึ่งทำหน้าที่เป็น r
2) ตรวจชุดคอลัมน์ λ ว่าอยู่หน้าใด
3) เลือกคอลัมน์ λ ให้ตรง
4) อ่าน P(X ≤ r)
```

คอลัมน์ `λ` ไม่ได้เพิ่มเท่ากันตลอดเล่ม: มี 0.1 ถึง 2.0 ทีละ 0.1, แล้ว 2.2 ถึง 6.0 ทีละ 0.2, จากนั้น 6.5 ถึง 16.0 ทีละ 0.5 สังเกตว่าไม่มี 2.1, 4.1 หรือ 6.1 ห้ามเติมเอง

```text
P(X ≥ k) = 1 − P(X ≤ k−1)
P(a ≤ X ≤ b) = P(X ≤ b) − P(X ≤ a−1)
```

### แบบฝึกอ่านจากค่าพิมพ์จริง

**ดริลล์ 1: “ไม่เกิน”**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `λ=1.0`, ต้องการ `P(X≤3)`
2. คำใบ้: ใช้แถว `x=3` และชุดคอลัมน์ 0.1–2.0 ใน p-12
3. คำนวณทีละขั้น: แถว `x=3` → คอลัมน์ `λ=1.0` → อ่าน `0.9810`
4. แปลผล: โอกาสเกิดเหตุการณ์ไม่เกิน 3 ครั้งคือ `0.9810`

**ดริลล์ 2: “อย่างน้อย”**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `λ=2.2`, ต้องการ `P(X≥4)`
2. คำใบ้: ต้องลบพื้นที่ถึง 3 เพราะ “อย่างน้อย 4” เริ่มหลัง 3
3. คำนวณทีละขั้น: ตารางแถว `x=3`, คอลัมน์ `λ=2.2` ให้ `0.8194` → `1−0.8194=0.1806`
4. แปลผล: โอกาสเกิดอย่างน้อย 4 ครั้งคือ `0.1806`

**ดริลล์ 3: “ระหว่าง”**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `λ=5.0`, ต้องการ `P(2≤X≤5)`
2. คำใบ้: ใช้พื้นที่ถึง 5 ลบพื้นที่ถึง 1
3. คำนวณทีละขั้น: แถว `x=5` ให้ `0.6160`; แถว `x=1` ให้ `0.0404`; ดังนั้น `0.6160−0.0404=0.5756`
4. แปลผล: โอกาสเกิด 2 ถึง 5 ครั้งคือ `0.5756`

### ข้อสอบที่ต้องเปิดตารางนี้

- โจทย์นับเหตุการณ์ต่อเวลา/พื้นที่: [บทปัวส์ซง](05-poisson.md)
- โจทย์การบ้าน CH4 ที่ใช้ปัวส์ซง: [การบ้าน CH4](09-homework-ch4.md)

### กับดัก

- `λ` เป็นค่าเฉลี่ยจำนวนเหตุการณ์ ไม่ใช่เปอร์เซ็นต์
- เช็กช่วงของ `λ` ก่อน เพราะคอลัมน์ต่อเนื่องอยู่หลายหน้าและมีช่วงกระโดด
- ตารางเป็นสะสม `≤` เสมอ การถาม `>` ต้องลบจาก 1

## 3. ตาราง Z ค่าบวก: p-16

### นึกภาพพื้นที่

โค้งปกติมีศูนย์อยู่ตรงกลาง ถ้า z เป็นบวก จุดตัดอยู่ขวาศูนย์ ตาราง p-16 ระบายพื้นที่ตั้งแต่หางซ้ายสุดมาถึงจุดตัดนั้น จึงมีค่าเกิน 0.5000

### กฎและวิธีเปิด

ตารางเขียน `Cumulative Probability P(Z<z)` อ่านว่า “พื้นที่สะสมทางซ้ายของ z” เปิด p-16 เมื่อ z ไม่ติดลบ แยก z เป็นเลขแถวหนึ่งตำแหน่งกับเลขคอลัมน์ส่วนร้อย

```text
z = 1.23  → แถว 1.2 และคอลัมน์ 0.03
F(z) = P(Z<z)
P(Z>z) = 1 − F(z)
P(a<Z<b) = F(b) − F(a)
```

ถ้าโจทย์ให้ค่าเฉลี่ยเดิม `Y` ต้องแปลงเป็น z ใน [ตาราง Z และโค้งระฆัง](07-normal-and-z-table.md) ก่อน จึงค่อยเปิด p-16

### แบบฝึกอ่านจากค่าพิมพ์จริง

**ดริลล์ 1: พื้นที่ซ้าย**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `P(Z<1.23)`
2. คำใบ้: เป็นพื้นที่ซ้ายและ z เป็นบวก จึงอ่านตรง ๆ
3. คำนวณทีละขั้น: แถว `1.2` → คอลัมน์ `0.03` → อ่าน `0.8907`
4. แปลผล: พื้นที่ซ้ายของ 1.23 คือ `0.8907`

**ดริลล์ 2: หางขวา**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `P(Z>1.64)`
2. คำใบ้: ตารางให้ซ้าย ต้องเอา 1 ลบ
3. คำนวณทีละขั้น: p-16 แถว `1.6`, คอลัมน์ `0.04` ให้ `0.9495` → `1−0.9495=0.0505`
4. แปลผล: พื้นที่หางขวาหลัง 1.64 คือ `0.0505`

**ดริลล์ 3: พื้นที่ช่วง**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `P(0.45<Z<1.28)`
2. คำใบ้: พื้นที่ช่วง = พื้นที่ซ้ายขอบขวา ลบพื้นที่ซ้ายขอบซ้าย
3. คำนวณทีละขั้น: `F(1.28)=0.8997`; `F(0.45)=0.6736`; `0.8997−0.6736=0.2261`
4. แปลผล: พื้นที่ระหว่าง 0.45 กับ 1.28 คือ `0.2261`

### ข้อสอบที่ต้องเปิดตารางนี้

- พื้นที่หรือการย้อนหาค่า z: [บทตาราง Z](07-normal-and-z-table.md)
- โจทย์ค่า X ที่ต้องแปลงเป็น z: [โจทย์ปกติแบบคำพูด](08-normal-word-problems.md)
- ค่าเฉลี่ย/สัดส่วนตัวอย่าง: [การแจกแจงค่าเฉลี่ย](11-sampling-distribution-of-mean.md) และ [การแจกแจงสัดส่วน](13-sampling-distribution-of-proportion.md)
- ช่วงความเชื่อมั่นและการทดสอบที่ใช้ Z: [ช่วงความเชื่อมั่นหนึ่งค่าเฉลี่ย](17-ci-one-mean.md), [ช่วงความเชื่อมั่นหนึ่งสัดส่วน](18-ci-one-proportion.md), [ทดสอบหนึ่งค่าเฉลี่ย](23-test-one-mean.md), [ทดสอบหนึ่งสัดส่วน](24-test-one-proportion.md)

### กับดัก

- p-16 ให้พื้นที่ซ้ายทั้งหมด ไม่ใช่พื้นที่ระหว่าง 0 ถึง z
- หางขวาต้องทำ `1−F(z)`
- อ่านแถว 1.2 กับคอลัมน์ 0.03 จึงได้ 1.23 ไม่ใช่ 1.20 หรือ 1.30

## 4. ตาราง Z ค่าลบ: p-17

### นึกภาพพื้นที่

เมื่อ z ติดลบ จุดตัดอยู่ซ้ายศูนย์ ตาราง p-17 ระบายพื้นที่จากหางซ้ายสุดถึงจุดตัด จึงมีค่าน้อยกว่า 0.5000 ยิ่ง z ติดลบมาก พื้นที่ซ้ายยิ่งเล็ก

### กฎและวิธีเปิด

เปิด p-17 เมื่อ z มีเครื่องหมายลบ แถวเขียน `−1.2` และคอลัมน์ `0.03` หมายถึง `−1.23` ตารางนี้ก็ให้ `P(Z<z)` เหมือน p-16

```text
P(Z<−z) = ตาราง p-17 โดยตรง
P(Z>−z) = 1 − P(Z<−z)
F(−z) = 1 − F(z)  (ใช้สมมาตรได้)
```

### แบบฝึกอ่านจากค่าพิมพ์จริง

**ดริลล์ 1: พื้นที่ซ้ายของค่าลบ**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `P(Z<−1.23)`
2. คำใบ้: ใช้หน้าค่าลบโดยตรง ไม่ต้องทำให้เป็นบวก
3. คำนวณทีละขั้น: แถว `−1.2` → คอลัมน์ `0.03` → อ่าน `0.1093`
4. แปลผล: พื้นที่ซ้ายของ −1.23 คือ `0.1093`

**ดริลล์ 2: หางขวาของค่าลบ**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `P(Z>−0.84)`
2. คำใบ้: อ่านพื้นที่ซ้ายก่อน แล้วลบจาก 1
3. คำนวณทีละขั้น: p-17 แถว `−0.8`, คอลัมน์ `0.04` ให้ `0.2005` → `1−0.2005=0.7995`
4. แปลผล: พื้นที่ทางขวาของ −0.84 คือ `0.7995`

**ดริลล์ 3: พื้นที่ช่วงด้านซ้าย**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `P(−1.28<Z<−0.45)`
2. คำใบ้: ขอบขวาอยู่ใกล้ศูนย์กว่า จึงลบพื้นที่ซ้ายของขอบซ้ายออก
3. คำนวณทีละขั้น: `F(−0.45)=0.3264`; `F(−1.28)=0.1003`; `0.3264−0.1003=0.2261`
4. แปลผล: พื้นที่ระหว่าง −1.28 กับ −0.45 คือ `0.2261`

### ข้อสอบที่ต้องเปิดตารางนี้

- โจทย์พื้นที่ z ติดลบและการใช้สมมาตร: [บทตาราง Z](07-normal-and-z-table.md)
- โจทย์ปกติที่ขอบเขตอยู่ซ้ายของค่าเฉลี่ย: [โจทย์ปกติแบบคำพูด](08-normal-word-problems.md)
- ค่าเฉลี่ยและสัดส่วนที่คำนวณ z แล้วติดลบ: [การแจกแจงค่าเฉลี่ย](11-sampling-distribution-of-mean.md), [การแจกแจงสัดส่วน](13-sampling-distribution-of-proportion.md), [ทดสอบหนึ่งค่าเฉลี่ย](23-test-one-mean.md), [ทดสอบหนึ่งสัดส่วน](24-test-one-proportion.md)

### กับดัก

- −1.23 ต้องใช้แถว `−1.2` กับคอลัมน์ `0.03` ไม่ใช่แถว `1.2`
- `F(−1.23)=0.1093` คือพื้นที่ซ้าย ไม่ใช่พื้นที่ขวา
- ถ้าใช้สมมาตร ต้องทำ `1−F(1.23)` ให้ได้ `0.1093`

## 5. ตาราง t: p-18

### นึกภาพพื้นที่

โค้ง t ก็มีศูนย์กลางที่ 0 แต่หางหนากว่าโค้ง Z ตาราง p-18 ไม่ได้ให้พื้นที่สะสมทุกค่าแบบ p-16 ตารางนี้ให้ “ค่าจุดตัดบวก” แล้วบอกว่าหางขวาเหลือเท่าไร

### กฎและวิธีเปิด

t (t-distribution) ใช้กับค่าเฉลี่ยเมื่อประชากรปกติ ไม่รู้ `σ` และตัวอย่างเล็ก โดยทั่วไป `n<30` แถวคือ `df` และสำหรับค่าเฉลี่ยหนึ่งกลุ่ม `df=n−1`

หัว `Cum.prob` อ่านว่า “ความน่าจะเป็นสะสม” และชื่อคอลัมน์ `t₀.90` หมายถึงพื้นที่ซ้าย 0.90 จึงเหลือหางขวา 0.10 ค่าในช่องคือค่า t ไม่ใช่พื้นที่

```text
P(Tν > tα) = α
One-tail = พื้นที่หางขวาข้างเดียว
Two-tails = พื้นที่รวมสองหาง
```

ขั้นตอนคือหาแถว `df` ก่อน แล้วเลือกคอลัมน์จากแถว `One-tail` หรือ `Two-tails` ให้ตรงกับโจทย์ ถ้าโจทย์เป็นหางซ้าย ใช้สมมาตรแล้วใส่เครื่องหมายลบให้ค่าจุดตัด

### แบบฝึกอ่านจากค่าพิมพ์จริง

**ดริลล์ 1: หางเดียว**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `df=5`, ต้องการ `P(T₅>t)=0.10`
2. คำใบ้: ใช้แถว `One-tail=0.10` หรือคอลัมน์ `t₀.90`
3. คำนวณทีละขั้น: แถว `df=5` → คอลัมน์ `t₀.90` → อ่าน `t=1.476`
4. แปลผล: `P(T₅>1.476)=0.10`

**ดริลล์ 2: สองหาง**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `df=18`, ต้องการพื้นที่รวมสองหาง `0.05`
2. คำใบ้: สองหาง 0.05 แบ่งเป็นหางละ 0.025 ใช้ `One-tail=0.025` หรือ `Two-tails=0.05`
3. คำนวณทีละขั้น: แถว `df=18` → คอลัมน์ `t₀.975` → อ่าน `2.101`
4. แปลผล: `P(−2.101<T₁₈<2.101)=0.95` หรือ `P(|T₁₈|>2.101)=0.05`

**ดริลล์ 3: หางเดียวเล็ก**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `df=12`, ต้องการ `P(T₁₂>t)=0.01`
2. คำใบ้: เลือกแถว `One-tail=0.01` ซึ่งตรงกับ `t₀.99`
3. คำนวณทีละขั้น: แถว `df=12` → คอลัมน์ `t₀.99` → อ่าน `t=2.681`
4. แปลผล: ค่าที่หางขวาเหลือ 0.01 คือ `2.681`

### ข้อสอบที่ต้องเปิดตารางนี้

- ค่าเฉลี่ยตัวอย่างเล็กที่ไม่รู้ σ: [การแจกแจง t](12-t-distribution.md)
- ช่วงความเชื่อมั่นของค่าเฉลี่ยที่ใช้ t: [ช่วงความเชื่อมั่นหนึ่งค่าเฉลี่ย](17-ci-one-mean.md) และ [ช่วงความเชื่อมั่นสองค่าเฉลี่ย](19-ci-two-means.md)
- การทดสอบค่าเฉลี่ยที่ใช้ t: [ทดสอบหนึ่งค่าเฉลี่ย](23-test-one-mean.md), [ทดสอบสองค่าเฉลี่ย](25-test-two-means.md), [ทดสอบข้อมูลคู่](26-test-paired.md)

### กับดัก

- เห็น `Cum.prob` แล้วอย่าอ่านช่องเป็นพื้นที่ ช่องนั้นเป็นค่าตัด t
- สองหางระดับ `α` ต้องใช้หางละ `α/2`
- ค่าเฉลี่ยหนึ่งกลุ่มใช้ `df=n−1` ไม่ใช่ `df=n`
- ถ้าโจทย์เป็นหางซ้าย ให้ใช้ค่าบวกจากตารางแล้วเปลี่ยนเป็นค่าลบด้วยสมมาตร

## 6. ตาราง χ²: p-19

### นึกภาพพื้นที่

โค้ง χ² เริ่มที่ 0 แล้วลากหางยาวไปทางขวา ไม่มีหางซ้ายติดลบและไม่สมมาตรเหมือน z หรือ t ตาราง p-19 จึงระบุ “พื้นที่หางขวา α” ที่หัวคอลัมน์โดยตรง

### กฎและวิธีเปิด

χ² (chi-square) ในเล่มมีไว้ให้เปิดถ้าโจทย์ระบุสถิติไคสแควร์หรือถามการอ่านค่าวิกฤต ตารางนี้ **อยู่ใน booklet แต่สไลด์ CH4–CH7 ที่ตรวจแล้วไม่ใช้สูตร χ² โดยตรง** ดังนั้นคาดว่าจะเจออย่างมากเป็นข้ออ่านตาราง

แถวคือ `df` และคอลัมน์คือ `α` หางขวา เช่น คอลัมน์ `0.05` หมายถึงเลือกค่าให้พื้นที่ด้านขวา 0.05

```text
P(χ²ν > χ²α,ν) = α
ถ้าต้องการพื้นที่ซ้าย q ให้เลือกคอลัมน์ 1−q
```

### แบบฝึกอ่านจากค่าพิมพ์จริง

**ดริลล์ 1: หางขวา 0.05**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `df=5`, ต้องการค่าวิกฤตหางขวา `α=0.05`
2. คำใบ้: p-19 ให้ α หางขวาโดยตรง ไม่ใช่พื้นที่ซ้าย
3. คำนวณทีละขั้น: แถว `df=5` → คอลัมน์ `0.05` → อ่าน `11.070`
4. แปลผล: `P(χ²₅>11.070)=0.05`

**ดริลล์ 2: หางขวา 0.10**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `df=10`, ต้องการ `α=0.10`
2. คำใบ้: เลือกคอลัมน์ 0.1 ทางขวาของหัวตาราง
3. คำนวณทีละขั้น: แถว `df=10` → คอลัมน์ `0.1` → อ่าน `15.987`
4. แปลผล: `P(χ²₁₀>15.987)=0.10`

**ดริลล์ 3: หางขวา 0.01**

1. โจทย์ถามอะไร/มีข้อมูลอะไร: `df=8`, ต้องการ `α=0.01`
2. คำใบ้: ใช้คอลัมน์ 0.01 ไม่ใช่ 0.99 เพราะเล่มพิมพ์หางขวา
3. คำนวณทีละขั้น: แถว `df=8` → คอลัมน์ `0.01` → อ่าน `20.090`
4. แปลผล: `P(χ²₈>20.090)=0.01`

### ข้อสอบที่ต้องเปิดตารางนี้

- เปิด p-19 เฉพาะเมื่อโจทย์ระบุ χ², ความแปรปรวน หรือค่าวิกฤตไคสแควร์โดยตรง
- บทเรียน [การทดสอบสมมติฐาน](22-hypothesis-testing-idea.md) อธิบายการเลือกหางและค่า α ซึ่งเป็นพื้นฐานในการอ่านตารางนี้
- ในเนื้อหา CH4–CH7 ที่ใช้ทำคู่มือนี้ ยังไม่มีโจทย์คำนวณ χ² โดยตรง

### กับดัก

- `0.05` ใน p-19 คือหางขวา ไม่ใช่พื้นที่ซ้าย 0.05
- χ² ไม่มีค่าติดลบและใช้สมมาตรแบบ z/t ไม่ได้
- อย่าอ่านแถว `df` เป็นค่า α หรืออ่านคอลัมน์ α เป็น df

## สรุปจำสั้น ๆ

- ทวินาม: นับความสำเร็จจาก `n` ครั้ง → p-01–p-11 → แถว `n`, `x/r`, คอลัมน์ `p`
- ปัวส์ซง: นับเหตุการณ์ตามค่าเฉลี่ย `λ` → p-12–p-15 → แถว `x/r`, คอลัมน์ `λ`
- z บวก: พื้นที่ซ้ายของ z บวก → p-16
- z ลบ: พื้นที่ซ้ายของ z ลบ → p-17
- t: หา `df` แล้วเลือก `One-tail` หรือ `Two-tails` → p-18
- χ²: หา `df` แล้วเลือก α หางขวา → p-19
- ตารางสะสม: “อย่างน้อย” มักใช้ `1−` และ “ระหว่าง” ใช้การลบพื้นที่สองจุด

## เปิดตารางไหนดี

```text
เริ่ม
  |
  | กำลังนับอะไร?
  |
  +-- สำเร็จจากการทดลอง n ครั้ง และมี p เดียวกัน
  |       -> ทวินาม -> p-01 ถึง p-11
  |
  +-- เหตุการณ์ในเวลา/พื้นที่ และมีค่าเฉลี่ย λ
  |       -> ปัวส์ซง -> p-12 ถึง p-15
  |
  +-- ค่าต่อเนื่องหรือค่าเฉลี่ยที่แปลงเป็นมาตรฐาน
  |       -> Z -> z บวกเปิด p-16, z ลบเปิด p-17
  |
  +-- ค่าเฉลี่ย ประชากรปกติ ไม่รู้ σ และ n<30
  |       -> t -> p-18; ใช้ df
  |
  +-- โจทย์ระบุ χ² หรือค่าวิกฤตความแปรปรวน
          -> χ² -> p-19; ใช้ df และ α หางขวา
```

ถ้ายังไม่แน่ใจ ให้กลับไปอ่านบทเรียนที่มีลิงก์ในหัวข้อ “ข้อสอบที่ต้องเปิดตารางนี้” แล้วค่อยกลับมาเลือกหน้าอีกครั้ง
