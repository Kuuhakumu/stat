# บทที่ 16: การประมาณค่าแบบจุดและแบบช่วง


## เป้าหมาย

- บอกได้ว่าทำไมเราต้องใช้ข้อมูลตัวอย่างประมาณค่าของคนทั้งกลุ่ม
- แยกการประมาณค่าแบบจุดออกจากการประมาณค่าแบบช่วง
- หาโอกาสผิดพลาดและอ่านค่าที่ใช้กับความเชื่อมั่น 90%, 95% และ 99% จากตารางสอบ
- เข้าใจว่าช่วงจะกว้างหรือแคบขึ้นเพราะความเชื่อมั่นและขนาดตัวอย่างอย่างไร

## นึกภาพก่อน

อยากรู้ค่าใช้จ่ายเฉลี่ยของนักศึกษาทั้งคณะ แต่เราไม่มีเวลาถามทุกคน จึงสุ่มถามบางคนแล้วใช้ข้อมูลนั้นเดาค่าของทั้งคณะ การเดาแบบนี้เรียกว่า **การประมาณค่า (estimation)**
ถ้าตอบเป็นเลขเดียว เช่น “ประมาณ 110 บาท” นั่นคือการประมาณค่าแบบจุด ถ้าตอบเป็นช่วง เช่น “น่าจะอยู่ระหว่าง 105 ถึง 115 บาท” นั่นคือการประมาณค่าแบบช่วง ช่วงให้ข้อมูลเรื่องความไม่แน่นอนเพิ่มขึ้นด้วย

## ทำไมต้องประมาณค่า

การวัดคนทั้งประชากรอาจแพง ใช้เวลานาน หรือทำไม่ได้จริง เราจึงเก็บข้อมูลจากตัวอย่าง แล้วใช้สถิติของตัวอย่างเป็นตัวแทนพารามิเตอร์ของประชากร
คำว่า **พารามิเตอร์ (parameter)** หมายถึงค่าจริงของประชากร เช่น ค่าเฉลี่ยจริงของนักศึกษาทั้งคณะ แต่เราเกือบไม่รู้ค่าจริงนั้น จึงใช้ **ตัวสถิติ (statistic)** จากตัวอย่างมาช่วยประมาณ

## การประมาณค่าแบบจุด

ลองนึกว่ามีลูกบอลจำนวนมากอยู่ในกล่อง เราไม่รู้ค่าเฉลี่ยหรือสัดส่วนของลูกบอลทั้งหมด จึงหยิบขึ้นมาบางลูกแล้วสรุปเป็นเลขเดียว เลขเดียวนั้นคือ point estimate

### สัญลักษณ์ที่ใช้

- `μ` อ่านว่า “มิว” = ค่าเฉลี่ยจริงของประชากร สิ่งที่อยากรู้
- `N` อ่านว่า “เอ็นใหญ่” = จำนวนข้อมูลทั้งหมดในประชากร
- `x̄` อ่านว่า “เอ็กซ์บาร์” = ค่าเฉลี่ยของข้อมูลตัวอย่าง ใช้ประมาณ `μ`
- `p` อ่านว่า “พี” = สัดส่วนจริงของประชากร
- `p̂` อ่านว่า “พีแฮต” = สัดส่วนของตัวอย่าง ใช้ประมาณ `p`
- `σ²` อ่านว่า “ซิกมากำลังสอง” = ความแปรปรวนจริงของประชากร
- `σ` อ่านว่า “ซิกมา” = ส่วนเบี่ยงเบนมาตรฐานจริงของประชากร และ `σ = √σ²`
- `√` อ่านว่า “รากที่สอง” = จำนวนที่คูณตัวเองแล้วได้ค่าข้างใน; `Xᵢ²` อ่านว่า “เอ็กซ์ไอกำลังสอง” = `Xᵢ` คูณตัวเอง
- `S²` อ่านว่า “เอสกำลังสอง” = ความแปรปรวนของตัวอย่าง ใช้ประมาณ `σ²`
ดังนั้นจำคู่ให้ได้: `x̄` คู่กับ `μ`, `p̂` คู่กับ `p`, และ `S²` คู่กับ `σ²`

### สูตรที่ใช้เป็นเลขเดียว

`n` อ่านว่า “เอ็นเล็ก” = จำนวนข้อมูลในตัวอย่าง, `Xᵢ` อ่านว่า “เอ็กซ์ไอ” = ข้อมูลตัวที่ `i`, และ `i` อ่านว่า “ไอ” = ลำดับของข้อมูล เช่น 1, 2, 3, … ส่วน `Σ` อ่านว่า “ซิกมา” = ให้บวกค่าทุกตัวที่อยู่ข้างหลัง
สไลด์แยกสูตรของประชากรทั้งกลุ่มกับสูตรของตัวอย่าง ดังนี้; ในสูตรสัดส่วนให้ `Xᵢ=1` ถ้ามีลักษณะที่สนใจ และ `Xᵢ=0` ถ้าไม่มี

```text
μ = ΣXᵢ / N
σ² = Σ(Xᵢ − μ)² / N
   = [ΣXᵢ² − Nμ²] / N
σ = √σ²
p = ΣXᵢ / N
```

ค่าเฉลี่ยตัวอย่างคำนวณจากผลรวมข้อมูลหารด้วยจำนวนข้อมูล

```text
x̄ = ΣXᵢ / n
```
สัดส่วนตัวอย่างคือจำนวนที่สนใจหารด้วยจำนวนทั้งหมด ถ้า `x` อ่านว่า “เอ็กซ์” = จำนวนหน่วยที่มีลักษณะที่สนใจ ก็เขียนได้ว่า

```text
p̂ = ΣXᵢ / n = x / n
```
ความแปรปรวนตัวอย่างใช้ประมาณความแปรปรวนประชากร

```text
S² = Σ(Xᵢ − x̄)² / (n − 1)
   = [ΣXᵢ² − n x̄²] / (n − 1)
```
`n − 1` อ่านว่า “เอ็นลบหนึ่ง” เป็นตัวส่วนของความแปรปรวนตัวอย่าง อย่าเปลี่ยนเป็น `n` ในข้อนี้

และส่วนเบี่ยงเบนมาตรฐานตัวอย่างคือ `S` อ่านว่า “เอส” = รากที่สองของความแปรปรวนตัวอย่าง

```text
S = √S²
```

### จุดแข็งและข้อจำกัด

point estimate ตอบเร็วและใช้คำนวณง่าย แต่ไม่บอกว่าค่าจริงอาจห่างจากเลขนี้เท่าไร ถ้าตัวอย่างเปลี่ยน เลขเดียวนี้ก็อาจเปลี่ยนตาม จึงต้องใช้ interval estimate เมื่ออยากสื่อความไม่แน่นอนด้วย

## การประมาณค่าแบบช่วง

แทนที่จะบอกเลขเดียว เราสร้าง “ขอบล่างถึงขอบบน” ให้ครอบค่าจริงที่ต้องการ ช่วงนี้เรียกว่า **ช่วงความเชื่อมั่น (confidence interval)**
`L` อ่านว่า “แอล” = ขอบล่างของช่วง และ `U` อ่านว่า “ยู” = ขอบบนของช่วง ส่วน `θ` อ่านว่า “ทีตา” = พารามิเตอร์ตัวจริงที่เรากำลังประมาณ เช่น `μ`, `p` หรือ `σ²`
`P(…)` อ่านว่า “ความน่าจะเป็นของ…” หมายถึงโอกาสของเหตุการณ์ในวงเล็บ นิยามของช่วงเขียนสั้น ๆ ได้ว่า

```text
P(L < θ < U) = 1 − α
```
เครื่องหมาย `<` อ่านว่า “น้อยกว่า” ดังนั้น `L < θ < U` แปลว่า θ อยู่ระหว่างขอบล่างกับขอบบน
ช่วงทั่ว ๆ ไปมีหน้าตาแบบนี้

```text
ค่าประมาณ ± (ค่าวิกฤต × standard error)
```
`±` อ่านว่า “บวกหรือลบ” หมายถึงเอาค่าที่คูณได้ไปบวกและลบจากค่าประมาณ ส่วน **standard error (SE)** อ่านว่า “เอสอี” = ขนาดความแกว่งของค่าประมาณจากตัวอย่างหนึ่งไปอีกตัวอย่างหนึ่ง ค่าวิกฤตคือเลขจากตารางที่กำหนดว่าต้องเผื่อกว้างแค่ไหน
ถ้าให้ `E` อ่านว่า “อี” = ระยะเผื่อ (margin of error) ก็เขียนได้ว่า

```text
E = ค่าวิกฤต × SE
ช่วง = ค่าประมาณ − E ถึง ค่าประมาณ + E
```


## ความเชื่อมั่น 95% แปลว่าอะไร

สมมติสุ่มตัวอย่างแบบเดิมซ้ำ ๆ แล้วสร้างช่วงด้วยวิธีเดิมทุกครั้ง ถ้าใช้ความเชื่อมั่น 95% ประมาณ 95% ของช่วงที่สร้างได้จะครอบพารามิเตอร์จริง และประมาณ 5% จะไม่ครอบ
พอเราเก็บตัวอย่างชุดเดียวและได้ช่วงเดียวแล้ว พารามิเตอร์จริงเป็นค่าคงที่ ไม่ได้สุ่มไปมา คำพูด “มีโอกาส 95% ที่ μ จะอยู่ในช่วงนี้” จึงไม่ใช่คำอธิบายที่ถูกต้องของวิธีนี้ ให้พูดว่า “วิธีสร้างช่วงนี้มีความสำเร็จ 95% ในระยะยาว” แทน
`α` อ่านว่า “แอลฟา” = โอกาสที่วิธีสร้างช่วงพลาด หรือระดับนัยสำคัญ และ `1 − α` อ่านว่า “หนึ่งลบแอลฟา” = ระดับความเชื่อมั่น

```text
ระดับความเชื่อมั่น = 1 − α
α = 1 − ระดับความเชื่อมั่น
```
ตัวอย่างเช่น ความเชื่อมั่น 95% ให้ `α = 1 − 0.95 = 0.05` ถ้าเป็นช่วงสองด้าน เราแบ่งความผิดพลาดไปหางซ้ายและขวาเท่า ๆ กัน จึงใช้ `α/2` ในแต่ละหาง

## หา Z จากตารางสอบ

`Z` อ่านว่า “แซด” = ค่ามาตรฐานจากโค้งปกติ และ `z` อ่านว่า “แซดเล็ก” = ตัวเลขตำแหน่งที่เราเปิดหาในตาราง พอเป็นค่าวิกฤตของช่วงจึงเขียนเป็น `Z_{α/2}`

`Z_{α/2}` อ่านว่า “แซดซับแอลฟาหารสอง” = ค่าวิกฤตของโค้งปกติมาตรฐานที่เหลือพื้นที่ `α/2` ในแต่ละหาง ตัวเลขนี้อ่านจากตาราง Z หน้า p-16 และ p-17 ในข้อสอบ ตารางให้พื้นที่สะสมทางซ้าย `P(Z < z)`
ทำตามสามขั้น: หา α, หารสอง, แล้วหาเป้าหมายพื้นที่ด้านซ้ายเป็น `1 − α/2`

### ความเชื่อมั่น 90%

```text
α = 1 − 0.90 = 0.10
α/2 = 0.10/2 = 0.05
พื้นที่ซ้ายที่ต้องหา = 1 − 0.05 = 0.9500
```
ในตาราง p-16 ค่า 1.64 ให้ 0.9495 และค่า 1.65 ให้ 0.9505 ดังนั้นค่ากึ่งกลางคือ `Z₀.₀₅ ≈ 1.645`

### ความเชื่อมั่น 95%

```text
α = 1 − 0.95 = 0.05
α/2 = 0.05/2 = 0.025
พื้นที่ซ้ายที่ต้องหา = 1 − 0.025 = 0.9750
```
ในตาราง p-16 แถว 1.9 คอลัมน์ 0.06 ให้ 0.9750 พอดี จึงได้ `Z₀.₀₂₅ = 1.96`

### ความเชื่อมั่น 99%

```text
α = 1 − 0.99 = 0.01
α/2 = 0.01/2 = 0.005
พื้นที่ซ้ายที่ต้องหา = 1 − 0.005 = 0.9950
```
ในตาราง p-16 ค่า 2.57 ให้ 0.9949 และค่า 2.58 ให้ 0.9951 จึงเลือกค่าที่พิมพ์เป็นสองตำแหน่งคือ `Z₀.₀₀₅ = 2.58` เมื่อต้องแทนในสูตร
| ระดับความเชื่อมั่น | α | α/2 | พื้นที่ซ้าย | Z จากตาราง/ค่าที่ใช้ |
|---|---:|---:|---:|---:|
| 90% | 0.10 | 0.05 | 0.9500 | 1.645 |
| 95% | 0.05 | 0.025 | 0.9750 | 1.96 |
| 99% | 0.01 | 0.005 | 0.9950 | 2.58 (ค่าที่ใช้จากตาราง) |

## ความกว้างของช่วงเปลี่ยนอย่างไร

จำจากรูป `ค่าประมาณ ± (ค่าวิกฤต × SE)` ได้สามเรื่อง
1. เพิ่มระดับความเชื่อมั่นจาก 90% เป็น 95% หรือ 99% ค่าวิกฤตใหญ่ขึ้น จึงต้องเผื่อมากขึ้นและช่วงกว้างขึ้น
2. ลดระดับความเชื่อมั่น ค่าวิกฤตเล็กลง ช่วงจึงแคบลง แต่มีโอกาสพลาดมากขึ้น
3. เพิ่ม `n` ซึ่งอ่านว่า “เอ็นเล็ก” และหมายถึงจำนวนคนหรือหน่วยในตัวอย่าง ทำให้ SE เล็กลงโดยทั่วไป ช่วงจึงแคบลง
ถ้าเพิ่มขนาดตัวอย่างเป็น 4 เท่า ส่วนที่มี `√n` ในตัวส่วนจะทำให้ SE เหลือครึ่งหนึ่งโดยประมาณ ช่วงจึงแคบลงมากโดยไม่ต้องเปลี่ยนระดับความเชื่อมั่น

## ตัวอย่างจากสไลด์ทำทีละขั้น


### EX 6.1 (สไลด์ CH6 หน้า 6): ค่าใช้จ่ายเฉลี่ยนักศึกษา

**1) โจทย์ถามอะไร / ข้อมูลที่มี**
สุ่มนักศึกษา 10 คน ได้ค่าใช้จ่ายต่อวัน (บาท): 120, 145, 185, 100, 95, 65, 120, 100, 80, 90 ต้องการประมาณค่าเฉลี่ยของนักศึกษากลุ่มนี้ทั้งประชากร
**2) คำใบ้ในโจทย์บอกว่าใช้วิธีไหน (และเพราะอะไร)**
โจทย์ขอค่าเฉลี่ยประชากร `μ` เพียงค่าเดียว จึงใช้ค่าเฉลี่ยตัวอย่าง `x̄` เป็น point estimate ไม่ต้องใช้ตาราง Z
**3) คำนวณทีละบรรทัด**

```text
ผลรวม = 120 + 145 = 265
      265 + 185 = 450
      450 + 100 = 550
      550 + 95  = 645
      645 + 65  = 710
      710 + 120 = 830
      830 + 100 = 930
      930 + 80  = 1010
      1010 + 90 = 1100
n = 10
x̄ = ผลรวม / n
  = 1100 / 10
  = 110
```
**4) แปลผลเป็นภาษาคน**
ค่าประมาณแบบจุดของค่าใช้จ่ายเฉลี่ยต่อวันคือ **110 บาทต่อวัน**

### EX 6.2 (สไลด์ CH6 หน้า 7): สัดส่วนอุปกรณ์ที่ใช้งานได้นาน

**1) โจทย์ถามอะไร / ข้อมูลที่มี**
สุ่มอุปกรณ์ไฟฟ้า 150 ชิ้น พบว่า 68 ชิ้นใช้งานได้อย่างน้อย 100 ชั่วโมง ต้องการประมาณสัดส่วนจริงของอุปกรณ์ที่มีคุณสมบัตินี้
**2) คำใบ้ในโจทย์บอกว่าใช้วิธีไหน (และเพราะอะไร)**
โจทย์ขอสัดส่วนประชากร `p` เพียงค่าเดียว จึงใช้สัดส่วนตัวอย่าง `p̂ = x/n` เป็น point estimate
**3) คำนวณทีละบรรทัด**

```text
x = 68
n = 150
p̂ = x / n
   = 68 / 150
   = 0.453333…
   ≈ 0.45
```
เปลี่ยนเป็นเปอร์เซ็นต์โดยคูณ 100

```text
0.45 × 100 = 45%
```
**4) แปลผลเป็นภาษาคน**
สัดส่วนตัวอย่างที่ใช้งานได้อย่างน้อย 100 ชั่วโมงคือ **ประมาณ 0.45 หรือ 45%** (ค่าก่อนปัดคือ 45.33%)

## วิธีอ่านตารางให้ไม่หลง

1. เห็นคำว่า “ค่าเดียว” ให้คิด point estimate: ค่าเฉลี่ยใช้ `x̄`, สัดส่วนใช้ `p̂`, ความแปรปรวนใช้ `S²`
2. เห็นคำว่า “ช่วงความเชื่อมั่น” ให้คิดค่าประมาณ ± ค่าวิกฤต × SE
3. เห็น 90%, 95% หรือ 99% ให้หา α ก่อน แล้วใช้ α/2 เพราะเป็นช่วงสองด้าน
4. ถ้าอ่านพื้นที่ 0.9950 แล้วอยู่ระหว่าง 2.57 กับ 2.58 ให้ใช้ 2.58 ซึ่งเป็นค่าที่พิมพ์สองตำแหน่งในตารางสอบ

## กับดักในข้อสอบ

- **ผิด:** คิดว่า 95% คือโอกาสที่ μ จะสุ่มอยู่ในช่วงนี้
  **ถูก:** วิธีสร้างช่วงจะครอบค่าจริงประมาณ 95% เมื่อทำซ้ำหลายครั้ง
- **ผิด:** ใช้ `α = 0.95` เมื่อโจทย์ให้ความเชื่อมั่น 95%
  **ถูก:** `α = 1 − 0.95 = 0.05`
- **ผิด:** ใช้ α ทั้งก้อนในตารางสองด้าน
  **ถูก:** แบ่งเป็น `α/2` ต่อหาง เช่น 95% ใช้ 0.025
- **ผิด:** เลือก 2.58 สำหรับความเชื่อมั่น 95%
  **ถูก:** 95% ใช้ 1.96; 2.58 เป็นค่าที่ปัดมาจาก 99%
- **ผิด:** ใช้ `n` เป็นตัวส่วนของ `S²`
  **ถูก:** ความแปรปรวนตัวอย่างใช้ `n − 1`
- **ผิด:** ลืมว่าเพิ่มความเชื่อมั่นแล้วช่วงต้องกว้างขึ้น
  **ถูก:** ค่าวิกฤตใหญ่ขึ้น จึงมีระยะเผื่อมากขึ้น

### คำถามเขียนตอบ

1. ข้อมูลเวลารอรถ (นาที) ของผู้โดยสาร 5 คนคือ 12, 15, 9, 14, 10 จงหาค่าประมาณแบบจุดของค่าเฉลี่ยประชากร
2. สุ่มลูกค้า 120 คน พบว่า 45 คนเลือกแพ็กเกจ A จงหาค่าประมาณแบบจุดของสัดส่วนประชากร และตอบเป็นเปอร์เซ็นต์
3. ค่าประมาณแบบจุดเท่ากับ 50 และ SE = 2 ถ้าต้องการความเชื่อมั่น 95% ให้ใช้ Z = 1.96 จงหาช่วงโดยใช้รูป ค่าประมาณ ± (ค่าวิกฤต × SE) และอธิบายความหมายของ 95% ให้ถูกต้อง

<summary>เปิดดูเฉลยคำถามเขียนตอบ</summary>

ดังนั้นค่าประมาณแบบจุดของค่าเฉลี่ยประชากรคือ **12 นาที**

n = 120
p̂ = x / n

## สรุปจำสั้น ๆ

- `x̄` ใช้ประมาณ `μ`, `p̂` ใช้ประมาณ `p`, `S²` ใช้ประมาณ `σ²`
- point estimate = คำตอบเลขเดียว; interval estimate = ขอบล่างถึงขอบบน
- ช่วงทั่วไป = ค่าประมาณ ± (ค่าวิกฤต × SE)
- `α = 1 − ความเชื่อมั่น` และช่วงสองด้านใช้ `α/2` ต่อหาง
- 90% → 1.645, 95% → 1.96, 99% → 2.58 จากค่าที่ใช้ในตารางสอบ
- ความเชื่อมั่นสูงขึ้นทำให้ช่วงกว้างขึ้น; `n` มากขึ้นทำให้ SE และช่วงเล็กลง
- 95% เป็นผลงานของวิธีเมื่อทำซ้ำหลายครั้ง ไม่ใช่โอกาสของค่าจริงในช่วงเดียว
