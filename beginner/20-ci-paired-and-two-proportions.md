# บทที่ 20: ช่วงความเชื่อมั่นข้อมูลจับคู่และผลต่างสัดส่วน

## เป้าหมาย

- แยกให้ออกว่าโจทย์เป็นข้อมูลจับคู่หรือสองกลุ่มอิสระ
- สร้างผลต่างรายคู่ ค่าเฉลี่ยผลต่าง และส่วนเบี่ยงเบนมาตรฐานจากข้อมูลก่อน–หลังทีละขั้น
- สร้างช่วงความเชื่อมั่นของข้อมูลจับคู่ด้วย t และองศาอิสระจำนวนคู่ลบหนึ่ง
- สร้างช่วงความเชื่อมั่นของผลต่างสัดส่วนสองกลุ่ม และแปลผลเป็นภาษาคน

## นึกภาพก่อน

ถ้าอยากรู้ว่ายาลดความดันได้กี่หน่วย เราวัดคนเดิมก่อนกินยาและหลังยา ข้อมูลสองตัวนี้เดินมาคู่กันเสมอ คนที่ 1 ก่อนต้องเทียบกับคนที่ 1 หลัง ห้ามเอาไปปนกับคนอื่น

แต่ถ้าเปรียบเทียบหญิงกลุ่มหนึ่งกับชายอีกกลุ่มหนึ่ง แต่ละคนไม่ใช่คู่ของกันและกัน แบบนั้นเป็นสองกลุ่มอิสระ บทนี้มีวิธีทำสองแบบ จึงต้องอ่านคำในโจทย์ก่อนแทนสูตร

## จับคู่หรืออิสระ ดูจากคำในโจทย์

### ข้อมูลจับคู่ (paired data)

ให้เลือกเป็นข้อมูลจับคู่เมื่อข้อมูลสองคอลัมน์มาจากหน่วยเดิมหรือคู่ที่ตั้งใจจับกัน เช่น

- คนเดิมวัด **ก่อน–หลัง** ยา การฝึก หรือการสอน
- เครื่องจักรชิ้นเดิมวัด **ก่อน–หลัง** การปรับตั้ง
- ฝาแฝดหรือคนสองคนที่จับคู่ตามคุณสมบัติ แล้ววัดผลเดียวกัน

การทำคือหาผลต่างของแต่ละคู่ก่อน แล้ววิเคราะห์ผลต่างชุดเดียว

### สองกลุ่มอิสระ (independent groups)

ถ้าสุ่มคนกลุ่ม 1 และกลุ่ม 2 แยกกัน คนหนึ่งไม่ได้เป็นคู่กับอีกคน เช่น นักศึกษาห้อง A เทียบห้อง B หรือหญิงเทียบชาย ให้ใช้สูตรของสองกลุ่มอิสระจาก [บทที่ 19](19-ci-two-means.md) หรือสูตรสองสัดส่วนด้านล่าง

**กับดัก:** มีคำว่า “ก่อนและหลัง” เมื่อไร ให้คิดถึงคนเดิมและข้อมูลจับคู่ทันที อย่าใช้สูตร two-independent-sample

## ช่วงความเชื่อมั่นของข้อมูลจับคู่

### กฎก่อนคำนวณ

จับคู่ข้อมูลให้ถูกแถว แล้วกำหนดทิศทางให้ชัด เช่น “ก่อน−หลัง” ถ้าสลับเป็น “หลัง−ก่อน” เครื่องหมายของผลต่างและช่วงจะกลับทั้งหมด แต่ความกว้างช่วงเท่าเดิม

เมื่อได้ผลต่าง `Dᵢ` แล้ว ข้อมูลที่นำไปคิดมีเพียงชุด D ชุดเดียว ถ้า `n < 30` และไม่รู้ส่วนเบี่ยงเบนมาตรฐานจริง ให้ใช้ t และ `ν = n−1` ตามสไลด์หน้า 28–29

```text
Dᵢ = Xᵢ₁ − Xᵢ₂
D̄ = ΣDᵢ/n
S_D² = Σ(Dᵢ−D̄)²/(n−1)
S_D = √S_D²
ν = n−1
ช่วงความเชื่อมั่น = D̄ ± t_{α/2,ν} × S_D/√n
```

ทฤษฎี 6.8 ระบุว่า `T = (D̄−μ_D)/(S_D/√n)` มีการแจกแจง t เมื่อ `n<30` และถ้า `n≥30` ใช้ `Z = (D̄−μ_D)/(S_D/√n) ≈ N(0,1)`

ถ้า `n ≥ 30` สไลด์ให้ใช้ Z แทน t แต่ยังใช้ `D̄ ± Z_{α/2}S_D/√n` เหมือนเดิม เปลี่ยนเฉพาะค่าวิกฤต

### แปลเครื่องหมาย

ถ้าเลือกก่อน−หลังและช่วงเป็นบวกทั้งช่วง แปลว่าค่าเฉลี่ยก่อนสูงกว่าหลังในค่าที่ช่วงรองรับ ถ้าช่วงติดลบทั้งช่วง แปลว่าหลังสูงกว่าก่อน ถ้าช่วงคร่อม 0 ยังสรุปทิศทางไม่ได้

## ช่วงความเชื่อมั่นของผลต่างสองสัดส่วน

เรื่องนี้ใช้กับคนหรือสิ่งของ **คนละกลุ่ม** เช่น สัดส่วนหญิงที่มีบัตรเครดิตลบสัดส่วนชายที่มีบัตรเครดิต ไม่ได้จับคู่หญิงกับชายทีละคน

หา `p̂₁` และ `p̂₂` จากจำนวนที่พบหารด้วยจำนวนทั้งหมดของแต่ละกลุ่ม แล้วหาส่วนที่เหลือ `q̂₁` และ `q̂₂` จากหนึ่งลบสัดส่วน เมื่อใช้ช่วงสองด้าน ให้ `α = 1−ระดับความเชื่อมั่น` และแบ่งเป็น `α/2`

```text
p̂₁ = x₁/n₁       q̂₁ = 1−p̂₁
p̂₂ = x₂/n₂       q̂₂ = 1−p̂₂
ช่วงความเชื่อมั่นของ p₁−p₂
= (p̂₁−p̂₂) ± Z_{α/2}√(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂)
```

ทฤษฎี 6.10 ใช้ `Z = [(p̂₁−p̂₂)−(p₁−p₂)] / √[p₁q₁/n₁+p₂q₂/n₂] ≈ N(0,1)` แล้วแทน `pᵢ,qᵢ` ที่ไม่รู้ด้วย `p̂ᵢ,q̂ᵢ` ในช่วงความเชื่อมั่น

คงลำดับกลุ่มให้ตรงกับคำถาม เช่น “หญิง−ชาย” ต้องใช้หญิงเป็นกลุ่ม 1 ทุกครั้ง ถ้าสลับจะได้ช่วงที่เป็นลบของคำตอบเดิม

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 6.10 (สไลด์ CH6 หน้า 30): ความดันก่อน−หลังยา

**1) โจทย์ถามอะไร / ข้อมูลที่มี** ผู้ป่วย 10 คนถูกวัดก่อนและหลังยา ต้องหาช่วงความเชื่อมั่น 95% ของค่าเฉลี่ยผลต่าง ก่อน−หลัง ข้อมูลจากตารางคือ

```text
ก่อน: 175, 179, 165, 170, 160, 180, 177, 178, 173, 176
หลัง: 152, 153, 135, 143, 162, 150, 182, 139, 155, 151
```

**2) คำใบ้บอกวิธีไหน** เป็นคนเดิม 10 คนวัดสองครั้ง จึงเป็นข้อมูลจับคู่ สร้าง `Dᵢ = ก่อน−หลัง` และเพราะ `n=10<30` จึงใช้ t, `ν=10−1=9` ความเชื่อมั่น 95% ให้ `α/2=0.025` จากตาราง t แถว 9 ได้ `t₀.₀₂₅,₉ = 2.262` (TABLES หน้า p-18)

**3) คำนวณทีละบรรทัด**

```text
Dᵢ = ก่อน−หลัง
    = 23, 26, 30, 27, −2, 30, −5, 39, 18, 25
n = 10
ΣDᵢ = 23+26+30+27−2+30−5+39+18+25
     = 211
D̄ = ΣDᵢ/n
   = 211/10
   = 21.1

Σ(Dᵢ−D̄)²
= (23−21.1)²+(26−21.1)²+(30−21.1)²+(27−21.1)²
 + (−2−21.1)²+(30−21.1)²+(−5−21.1)²
 + (39−21.1)²+(18−21.1)²+(25−21.1)²
= 1780.9
S_D² = 1780.9/(10−1)
     = 197.8778
S_D = √197.8778
   = 14.0669
ν = 10−1 = 9
SE = S_D/√n
   = 14.0669/√10
   = 14.0669/3.1623
   = 4.4483
E = 2.262×4.4483
  = 10.0622
ขอบล่าง = D̄−E = 21.1−10.0622 = 11.0378
ขอบบน   = D̄+E = 21.1+10.0622 = 31.1622
```

**4) แปลผลเป็นภาษาคน** ช่วงความเชื่อมั่น 95% ของค่าเฉลี่ย “ก่อน−หลัง” อยู่ที่ **11.0378 ถึง 31.1622 หน่วยความดัน** หรือปัดเป็น 11.04 ถึง 31.16 หน่วย ช่วงเป็นบวกทั้งช่วง จึงชี้ว่าความดันก่อนยาสูงกว่าหลังยาในช่วงที่คำนวณได้ สไลด์หน้า 30 ให้โจทย์อย่างเดียว ไม่มีเฉลยตัวเลข

### EX 6.11 (สไลด์ CH6 หน้า 32): สัดส่วนหญิง−ชายที่มีบัตรเครดิต

**1) โจทย์ถามอะไร / ข้อมูลที่มี** สุ่มหญิง 600 คน พบมีบัตร 300 คน สุ่มชาย 400 คน พบมีบัตร 100 คน ต้องหาช่วงความเชื่อมั่น 99% ของสัดส่วนหญิง−ชาย

**2) คำใบ้บอกวิธีไหน** เป็นคนละกลุ่มและถามผลต่างสัดส่วน จึงใช้สูตรสองสัดส่วนและ Z ความเชื่อมั่น 99% ให้ `α/2=0.005` ใช้ `Z₀.₀₀₅=2.58` ตามค่าที่ใช้จากตารางสอบ (TABLES หน้า p-16)

**3) คำนวณทีละบรรทัด**

```text
p̂₁ = 300/600 = 0.50       q̂₁ = 1−0.50 = 0.50
p̂₂ = 100/400 = 0.25       q̂₂ = 1−0.25 = 0.75
p̂₁−p̂₂ = 0.50−0.25 = 0.25

SE = √(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂)
   = √(0.50×0.50/600 + 0.25×0.75/400)
   = √(0.25/600 + 0.1875/400)
   = √(0.0004167 + 0.0004688)
   = √0.0008854
   = 0.0297560
E = 2.58×0.0297560
  = 0.0767704
ขอบล่าง = 0.25−0.0767704 = 0.1732296
ขอบบน   = 0.25+0.0767704 = 0.3267704
```

**4) แปลผลเป็นภาษาคน** ช่วงความเชื่อมั่น 99% ของสัดส่วนวัยรุ่นหญิงที่มีบัตรลบสัดส่วนวัยรุ่นชายที่มีบัตรคือ **0.1732 ถึง 0.3268** หรือประมาณ 17.32 ถึง 32.68 จุดเปอร์เซ็นต์ สไลด์หน้า 32 ให้โจทย์อย่างเดียว ไม่มีเฉลยตัวเลข

## วิธีอ่านตาราง

- **ตาราง t:** ช่วง 95% สองด้านมี `α/2=0.025` จึงอ่านคอลัมน์ `t₀.₉₇₅` ในตาราง (แถว 9 ได้ 2.262) ตารางพิมพ์ค่านี้ที่ TABLES หน้า p-18 แถว df 9
- **ตาราง Z:** ช่วง 99% สองด้านมีพื้นที่ทางซ้าย `1−0.005=0.995` ใช้ค่าวิกฤตบวก 2.58 ตามค่าที่ใช้จากตารางสอบ TABLES หน้า p-16
- ในช่วงสองด้านอย่าอ่านคอลัมน์หางเดียว `α` เพราะต้องแบ่งโอกาสผิดพลาดเป็นสองหางก่อน

## กับดักในข้อสอบ

- **ผิด:** เห็นก่อน–หลังแล้วเอาค่าเฉลี่ยก่อนลบค่าเฉลี่ยหลัง แต่ไม่สร้างผลต่างรายคน **ถูก:** จับคู่แถวเดียวกันก่อน แล้วสร้าง Dᵢ ทุกคู่
- **ผิด:** สลับเป็นหลัง−ก่อนกลางทาง **ถูก:** เขียนทิศทางไว้บรรทัดแรกและใช้ทิศทางเดิมจนจบ
- **ผิด:** ใช้ `ν=n` หรือหาร S_D² ด้วย n **ถูก:** ใช้ `ν=n−1` และหารความแปรปรวนด้วย n−1
- **ผิด:** ใช้ Z กับข้อมูลจับคู่เล็กที่ไม่รู้ σ **ถูก:** ใช้ t เมื่อ n<30 ตามเงื่อนไข
- **ผิด:** ลืม `√n` ใน `S_D/√n` **ถูก:** ใส่รากครอบ n ทั้งหมด
- **ผิด:** ใช้สูตรสองกลุ่มอิสระกับคนเดิมก่อน–หลัง **ถูก:** ลดข้อมูลให้เป็น D ชุดเดียวแล้วใช้สูตร paired
- **ผิด:** ผลต่างสัดส่วนใช้ `p̂₁+p̂₂` **ถูก:** ใช้ `p̂₁−p̂₂` ตามลำดับที่โจทย์ถาม
- **ผิด:** ลืม `q̂ᵢ` หรือใช้ `q̂ᵢ=p̂ᵢ` **ถูก:** `q̂ᵢ=1−p̂ᵢ`
- **ผิด:** ใช้ t กับผลต่างสองสัดส่วน **ถูก:** สูตรนี้ใช้ Z
- **ผิด:** 99% ใช้ 2.326 หรือใช้ α เต็มหนึ่งหาง **ถูก:** 99% ใช้ `α/2=0.005` และ `Z=2.58` ตามตารางสอบ
- **ผิด:** แปลช่วง 0.1733 ถึง 0.3267 เป็น 0.17% ถึง 0.33% **ถูก:** ถ้าเขียนเป็นเปอร์เซ็นต์ต้องคูณ 100 ได้ 17.33% ถึง 32.67%

## สรุปจำสั้น

- คนเดิมก่อน–หลัง หรือคู่ที่จับกัน = ข้อมูลจับคู่
- จับคู่ให้ถูก แล้วสร้าง `Dᵢ = Xᵢ₁−Xᵢ₂`
- `D̄ = ΣDᵢ/n`, `S_D² = Σ(Dᵢ−D̄)²/(n−1)`
- paired เล็ก: `D̄ ± t_{α/2,n−1}S_D/√n`
- สองสัดส่วน: `(p̂₁−p̂₂) ± Z√(p̂₁q̂₁/n₁+p̂₂q̂₂/n₂)`
- รักษาลำดับกลุ่ม 1−กลุ่ม 2 เครื่องหมายจึงไม่กลับ
- ช่วงคร่อม 0 = ยังสรุปทิศทางไม่ได้

| สูตรช่วงความเชื่อมั่น | ใช้เมื่อ |
|---|---|
| `x̄ ± Zσ/√n` | ค่าเฉลี่ยหนึ่งกลุ่ม รู้ σ |
| `x̄ ± ZS/√n` | ค่าเฉลี่ยหนึ่งกลุ่ม ตัวอย่างใหญ่ |
| `x̄ ± tS/√n` | ค่าเฉลี่ยหนึ่งกลุ่ม ตัวอย่างเล็ก ไม่รู้ σ |
| `(x̄₁−x̄₂) ± Z√(σ₁²/n₁+σ₂²/n₂)` | สองกลุ่มอิสระ รู้ σ หรือทั้งคู่ใหญ่ |
| `(x̄₁−x̄₂) ± tSₚ√(1/n₁+1/n₂)` | สองกลุ่มอิสระเล็ก ความแปรปรวนเท่ากัน |
| `(x̄₁−x̄₂) ± t√(S₁²/n₁+S₂²/n₂)` | สองกลุ่มอิสระเล็ก ความแปรปรวนไม่เท่ากัน |
| `D̄ ± tS_D/√n` | คนเดิมหรือคู่เดิม, `n<30` |
| `(p̂₁−p̂₂) ± Z√(p̂₁q̂₁/n₁+p̂₂q̂₂/n₂)` | ผลต่างสัดส่วนสองกลุ่ม |
