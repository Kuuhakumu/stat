# บทที่ 18: ช่วงความเชื่อมั่น (confidence interval) ของสัดส่วนหนึ่งประชากร

## เป้าหมาย

- หาสัดส่วนจากจำนวนที่พบและจำนวนที่ตรวจทั้งหมด
- เลือกสูตรช่วงความเชื่อมั่นของสัดส่วนหนึ่งประชากรได้
- แทนค่าลงสูตรทีละขั้นและอ่านค่า Z จากตารางสอบได้
- แปลขอบล่างและขอบบนเป็นภาษาคนได้

## นึกภาพก่อน

อยากรู้ว่าในคนทั้งมหาวิทยาลัย มีคนเป็นโรคกี่ส่วน แต่เราไปตรวจทุกคนไม่ได้ จึงสุ่มตรวจบางคน เช่น ตรวจ 400 คน พบ 224 คนเป็นโรค เราเห็นจากตัวอย่างว่า 224 ÷ 400 = 0.56 หรือ 56%

เลข 0.56 มาจากคนที่สุ่มมาตรวจ ถ้าสุ่มคนชุดใหม่ก็อาจได้เลขไม่เท่าเดิม ช่วงความเชื่อมั่นจึงเอา 0.56 มาทำขอบล่างกับขอบบน เพื่อบอกว่าสัดส่วนจริงของคนทั้งมหาวิทยาลัยน่าจะอยู่แถวไหน

สูตรของบทนี้มีรูปแบบคล้ายช่วงของค่าเฉลี่ย คือเอาค่าจากตัวอย่างบวกและลบระยะเผื่อ แต่ระยะเผื่อของสัดส่วนต้องคำนวณจากสัดส่วนตัวอย่างและส่วนที่เหลือ

## สัญลักษณ์ที่ใช้

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `p` | พี | สัดส่วนจริงของประชากรทั้งหมด เป็นค่าที่เราต้องการประมาณ |
| `p̂` | พีแฮต | สัดส่วนที่คำนวณจากตัวอย่าง ใช้ประมาณ `p` |
| `q̂` | คิวแฮต | สัดส่วนในตัวอย่างที่ไม่มีลักษณะที่สนใจ เท่ากับหนึ่งลบ `p̂` |
| `x` | เอ็กซ์ | จำนวนคนหรือหน่วยในตัวอย่างที่มีลักษณะที่สนใจ |
| `n` | เอ็น | จำนวนคนหรือหน่วยทั้งหมดในตัวอย่าง |
| `α` | แอลฟา | โอกาสผิดพลาดที่อยู่นอกช่วงความเชื่อมั่น |
| `α/2` | แอลฟาหารสอง | ครึ่งหนึ่งของโอกาสผิดพลาด ใช้กับหางแต่ละข้างของช่วงสองด้าน |
| `1 − α` | หนึ่งลบแอลฟา | ระดับความเชื่อมั่น เช่น 0.90 คือ 90% |
| `Z` | แซดตัวใหญ่ | ค่าวิกฤตจากตารางโค้งปกติมาตรฐาน |
| `Z_{α/2}` | แซดห้อยแอลฟาหารสอง | ค่า Z ที่แบ่งโอกาสผิดพลาดครึ่งหนึ่งไว้ที่หางแต่ละข้าง |
| `SE` | เอสอี | ค่าความคลาดเคลื่อนมาตรฐาน (standard error) ของสัดส่วนตัวอย่าง |
| `E` | อี | ระยะเผื่อจากค่ากลางไปถึงขอบช่วง |
| `√` | รากที่สอง | จำนวนที่คูณตัวเองแล้วได้ค่าข้างใน |
| `±` | บวกหรือลบ | ลบเพื่อหาขอบล่าง และบวกเพื่อหาขอบบน |
| `=` | เท่ากับ | ค่าทางซ้ายและขวามีค่าเดียวกัน |
| `−` | ลบ | หาผลต่าง หรือหาค่าที่เหลือ |
| `×` | คูณ | คูณค่าหนึ่งด้วยอีกค่า |
| `/` หรือ `÷` | หาร | แบ่งค่าหนึ่งด้วยอีกค่า |
| `%` | เปอร์เซ็นต์ | หนึ่งส่วนจาก 100 เช่น 56% = 0.56 |
| `N(0,1)` | เอ็นศูนย์หนึ่ง | การแจกแจงปกติมาตรฐานที่มีค่าเฉลี่ย 0 และความแปรปรวน 1 |
| `≈` | ใกล้เคียงกับ | สองค่าเกือบเท่ากัน |

จำคู่ให้แม่น: `p` คือค่าจริงที่ยังไม่รู้ ส่วน `p̂` คือค่าที่คำนวณจากตัวอย่างแล้ว

## จากจำนวนเป็นสัดส่วน

ถ้า `x` คือจำนวนที่พบลักษณะที่สนใจ และ `n` คือจำนวนที่ตรวจทั้งหมด ให้หารกันก่อน สัดส่วนที่เหลือคือหนึ่งลบสัดส่วนที่สนใจ

```text
p̂ = x/n
q̂ = 1 − p̂
```

ตัวอย่าง ตรวจสินค้า 250 ชิ้น พบเสีย 35 ชิ้น

```text
p̂ = 35/250
   = 0.14
q̂ = 1 − 0.14
   = 0.86
```

ดังนั้นสัดส่วนตัวอย่างคือ 0.14 หรือ 14% ไม่ใช่เลข 14 ในสูตร ถ้าโจทย์ให้เปอร์เซ็นต์ ให้ย้ายจุดทศนิยมสองตำแหน่งก่อน เช่น 8% = 0.08

## สูตรช่วงความเชื่อมั่น

เมื่อการกระจายของสัดส่วนตัวอย่างใกล้โค้งปกติ เราใช้ค่า Z จากตารางได้ หลักคือหาค่าความคลาดเคลื่อนมาตรฐานก่อน แล้วคูณด้วยค่าวิกฤตเพื่อได้ระยะเผื่อ

ทฤษฎี 6.4 เขียนการแปลงเป็นมาตรฐานได้ว่า

```text
Z = (p̂ − p) / √[p(1−p)/n] ≈ N(0,1)
```

จึงสร้างช่วงของ `p` ด้วย `p̂` และความคลาดเคลื่อนมาตรฐานจากตัวอย่าง

```text
SE = √(p̂q̂/n)
E = Z_{α/2} × SE
ช่วงความเชื่อมั่นของ p = p̂ ± E
```

เขียนรวมเป็นสูตรเดียวได้ว่า p̂ บวกหรือลบ Z_{α/2} คูณรากที่สองของ p̂q̂ หาร n

```text
p̂ ± Z_{α/2}√(p̂q̂/n)
```

ขอบล่างคือ p̂ − E และขอบบนคือ p̂ + E. ช่วงสองด้านแบ่งโอกาสผิดพลาด α เป็นสองส่วนเท่ากัน. เช่น ความเชื่อมั่น 90% หมายถึง 1 − α = 0.90, ดังนั้น α = 0.10 และ α/2 = 0.05 ต่อหาง.

## วิธีอ่านตาราง Z

ตาราง Z อยู่ที่ TABLES หน้า p-16 และ p-17. หน้า p-16 ใช้กับค่า Z บวก และหน้า p-17 ใช้กับค่า Z ลบ. ช่วงความเชื่อมั่นสองด้านใช้ค่าวิกฤตด้านบวก จึงอ่านหน้า p-16. ช่วง 90% มีพื้นที่หางละ 0.05 จึงต้องหา 1 − 0.05 = 0.9500 ทางซ้าย.

ในแถว 1.6 คอลัมน์ 0.04 มีค่า 0.9495 และคอลัมน์ 0.05 มีค่า 0.9505. พื้นที่ 0.9500 อยู่กึ่งกลางระหว่างสองค่านี้ จึงใช้ Z_{0.05} = 1.645 ตามวิธีใน [บทพื้นฐานการประมาณค่า](16-estimation-basics.md). ค่าพื้นที่ที่อ่านจากตารางข้างต้นเป็นค่าตามที่พิมพ์ไว้ในข้อสอบ.

จำค่าวิกฤตที่ใช้บ่อยได้ดังนี้

| ความเชื่อมั่น | α | α/2 | ค่า Z ที่ใช้ |
|---|---:|---:|---:|
| 90% | 0.10 | 0.05 | 1.645 |
| 95% | 0.05 | 0.025 | 1.960 |
| 99% | 0.01 | 0.005 | 2.58 |

สำหรับ 95% พื้นที่ทางซ้าย 0.9750 อยู่ในแถว 1.9 คอลัมน์ 0.06 พอดี. สำหรับ 99% พื้นที่ 0.9950 อยู่ระหว่างค่าในตารางของ Z = 2.57 และ Z = 2.58; ใช้ Z = 2.58 ตามกติกาปัด Z เป็นสองตำแหน่งของบทก่อนหน้า.

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 6.6 บุคลากรความดันโลหิตสูง (สไลด์ CH6 หน้า 18)

**1) โจทย์ถามอะไร / ข้อมูลที่มี** สอบถามบุคลากร 400 คน พบเป็นโรคความดันโลหิตสูง 224 คน ต้องหาช่วงความเชื่อมั่น 90% ของสัดส่วนบุคลากรทั้งหมดที่เป็นโรค.

```text
n = 400
x = 224
ความเชื่อมั่น = 0.90
```

**2) คำใบ้บอกให้ใช้วิธีไหน** โจทย์ถามสัดส่วนของประชากรหนึ่งกลุ่ม จึงใช้สูตรช่วงความเชื่อมั่นของสัดส่วน และใช้ Z.

**3) คำนวณทีละบรรทัด**

```text
p̂ = x/n
   = 224/400
   = 0.56

q̂ = 1 − p̂
   = 1 − 0.56
   = 0.44

α = 1 − 0.90
  = 0.10
α/2 = 0.10/2
     = 0.05
Z_{α/2} = 1.645

SE = √(p̂q̂/n)
   = √(0.56×0.44/400)
   = √(0.2464/400)
   = √0.000616
   = 0.0248193473

E = Z_{α/2}×SE
  = 1.645×0.0248193473
  = 0.0408278263

ขอบล่าง = p̂ − E
        = 0.56 − 0.0408278263
        = 0.5191721737
ขอบบน   = p̂ + E
        = 0.56 + 0.0408278263
        = 0.6008278263
```

เครื่องคิดเลข: กด 0.56 × 0.44 ÷ 400 แล้วกด √. จากนั้นคูณผลด้วย 1.645 เพื่อหา E.

**4) แปลผลเป็นภาษาคน** ช่วงความเชื่อมั่น 90% ของสัดส่วนบุคลากรที่เป็นโรคอยู่ที่ประมาณ 0.5192 ถึง 0.6008 หรือ 51.92% ถึง 60.08%. สไลด์หน้า 18 ให้โจทย์อย่างเดียว ไม่มีคำตอบตัวเลข; ผลคำนวณซ้ำได้ช่วงเดียวกันเมื่อปัดเป็นสี่ตำแหน่ง.

## กับดักในข้อสอบ

- **ผิด:** ใช้ 56 แทน p̂ เมื่อโจทย์พูดว่า 56%. **ถูก:** ใช้ p̂ = 0.56 เพราะสูตรใช้สัดส่วนตั้งแต่ 0 ถึง 1.
- **ผิด:** เห็น 8% แล้วแทนเป็น 0.8. **ถูก:** 8% = 8 ÷ 100 = 0.08.
- **ผิด:** ใช้ q̂ = p̂. **ถูก:** q̂ = 1 − p̂.
- **ผิด:** เขียน SE = p̂q̂/n แล้วหยุด. **ถูก:** ต้องถอดราก: SE = √(p̂q̂/n).
- **ผิด:** หารด้วย n − 1 แบบความแปรปรวนตัวอย่าง. **ถูก:** สูตรช่วงสัดส่วนใช้ n ตรง ๆ ไม่ใช้ n − 1.
- **ผิด:** ลืมรากที่สองของ n. **ถูก:** เขียนเศษส่วนทั้งหมดใต้ราก √(p̂q̂/n).
- **ผิด:** ใช้ t เพราะจำว่าตัวอย่างมีการแกว่ง. **ถูก:** ช่วงสัดส่วนหนึ่งประชากรในบทนี้ใช้ Z.
- **ผิด:** ใช้ α = 0.10 ที่หางข้างเดียวของช่วง 90%. **ถูก:** แบ่งเป็น α/2 = 0.05 ต่อหาง.
- **ผิด:** ใช้ Z = 1.960 กับช่วง 90%. **ถูก:** 90% ใช้ 1.645; 95% ใช้ 1.960; 99% ใช้ 2.58 ตามตารางสอบ.
- **ผิด:** แปล 0.5192 เป็น 0.5192%. **ถูก:** 0.5192 ในรูปสัดส่วนเท่ากับ 51.92%.

## แบบฝึกหัดปิดหนังสือ

2. ตรวจสินค้า 160 ชิ้น พบตำหนิ 48 ชิ้น. จงหาช่วงความเชื่อมั่น 90% ของสัดส่วนสินค้าที่มีตำหนิ.

```text
   ≈ 0.0339
```

ก. เป็นความแปรปรวน ไม่ใช่ SE เพราะยังไม่ได้ถอดราก; ข. ลืมคูณด้วย q̂ และใช้ √(p̂/n); ง. ลืมหารด้วย n ก่อนถอดราก.

**ข้อ 6 ตอบ ก.**

```text
p̂ = 40/100 = 0.40
q̂ = 1 − 0.40 = 0.60
ช่วง = p̂ ± Z_{α/2}√(p̂q̂/n)
     = 0.40 ± 1.645√(0.40×0.60/100)
```

ข. ผิดเพราะใช้ n − 1; ค. ผิดเพราะลืมรากที่สอง; ง. ผิดเพราะใช้เปอร์เซ็นต์ 40 และ 60 แทนสัดส่วน 0.40 และ 0.60.
</details>

## สรุปจำสั้น ๆ

- p̂ = x/n คือสัดส่วนจากตัวอย่าง; q̂ = 1 − p̂ คือส่วนที่เหลือ.
- เปลี่ยนเปอร์เซ็นต์เป็นทศนิยมก่อนแทนสูตร เช่น 56% = 0.56.
- ช่วงสัดส่วนหนึ่งประชากรใช้ p̂ ± Z_{α/2}√(p̂q̂/n).
- ตัวส่วนคือ n อยู่ใต้ราก ไม่ใช่ n − 1.
- ช่วง 90%, 95%, 99% ใช้ Z ตามลำดับ 1.645, 1.960, 2.58 ตามตารางสอบ.
- หาค่า E ก่อน แล้วหาขอบล่าง p̂ − E และขอบบน p̂ + E.
- สัดส่วน 0.52 เท่ากับ 52%.
