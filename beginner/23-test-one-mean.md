## นึกภาพก่อน: ตรวจเครื่องจักร

โรงงานบอกว่าเครื่องจักรผลิตได้เฉลี่ย 30,000 กิโลกรัมต่อวัน เราสุ่มดูบางวันแล้วได้ค่าเฉลี่ย 30,800 กิโลกรัม คำถามคือ 800 กิโลกรัมที่เพิ่มขึ้นมากพอจะเชื่อว่าเครื่องดีขึ้นจริงหรือยัง หรือเป็นความแกว่งจากการสุ่มตัวอย่างเฉย ๆ

การทดสอบจะตั้งค่าเดิมไว้ก่อน แล้ววัดว่าค่าเฉลี่ยตัวอย่างห่างจากค่าเดิมกี่ “หน่วยมาตรฐาน” ถ้าห่างมากพอจึงปฏิเสธค่าเดิม การไม่ปฏิเสธไม่ได้แปลว่าพิสูจน์ว่าค่าเดิมจริง แต่แปลว่าหลักฐานยังไม่แรงพอ

## สัญลักษณ์และสูตรที่ต้องใช้

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `μ` | มิว | ค่าเฉลี่ยจริงของประชากรที่เราสนใจ |
| `μ₀` | มิวศูนย์ | ค่าเฉลี่ยที่ H₀ กำหนดไว้ |
| `x̄` | เอ็กซ์บาร์ | ค่าเฉลี่ยที่คำนวณจากตัวอย่าง |
| `n` | เอ็น | จำนวนข้อมูลในตัวอย่าง |
| `σ` | ซิกมา | ส่วนเบี่ยงเบนมาตรฐานของประชากร ซึ่งเป็นค่าที่รู้แล้ว |
| `σ²` | ซิกมากำลังสอง | ความแปรปรวนของประชากร; ถ้ารู้ค่านี้ก็รู้ σ ด้วย |
| `S` | เอส | ส่วนเบี่ยงเบนมาตรฐานที่คำนวณจากตัวอย่าง ใช้แทน σ เมื่อไม่รู้ σ |
| `√n` | รากที่สองของเอ็น | กดรากที่สองของจำนวนข้อมูล เช่น `√100 = 10` |
| `Z` | แซดตัวใหญ่ | สถิติทดสอบที่เทียบกับการแจกแจงปกติมาตรฐาน |
| `T` | ทีตัวใหญ่ | สถิติทดสอบที่เทียบกับการแจกแจง t |
| `ν` | นิว | องศาอิสระของ t; กรณีนี้ `ν = n − 1` |
| `df` | ดีเอฟ | คำย่อของ degrees of freedom หรือองศาอิสระ เท่ากับ `ν` ในบทนี้ |
| `α` | แอลฟา | ระดับนัยสำคัญ หรือโอกาสผิดพลาดชนิดที่ 1 |
| `α/2` | แอลฟาหารสอง | ครึ่งหนึ่งของพื้นที่หาง เมื่อการทดสอบมีสองหาง |
| `p-value` | พีแวลยู | โอกาสได้ผลที่สุดโต่งเท่านี้หรือมากกว่า เมื่อถือว่า H₀ จริง |
| `P(…)` | ความน่าจะเป็นของ | โอกาสของเหตุการณ์ในวงเล็บ เช่น `P(Z < z)` |
| `Zα` | แซดห้อยแอลฟา | ค่าวิกฤตบวกของ Z ที่เหลือพื้นที่หางขวา `α` |
| `tα,ν` | ทีห้อยแอลฟาจุลภาคนิว | ค่าวิกฤตบวกของ t ที่เหลือพื้นที่หางขวา `α` ที่องศาอิสระ `ν` |
| `H₀` | เอชศูนย์ | สมมติฐานหลัก มีเครื่องหมายเท่ากับ |
| `H₁` | เอชหนึ่ง | สมมติฐานทางเลือก สิ่งที่โจทย์อยากหาหลักฐานสนับสนุน |
| `>` | มากกว่า | ค่าทางซ้ายสูงกว่าค่าทางขวา; หางขวา |
| `<` | น้อยกว่า | ค่าทางซ้ายต่ำกว่าค่าทางขวา; หางซ้าย |
| `≠` | ไม่เท่ากับ | สูงกว่าหรือต่ำกว่าก็ได้; สองหาง |
| `|Z|` หรือ `|T|` | ค่าสัมบูรณ์ของแซดหรือที | ตัดเครื่องหมายลบออก เหลือระยะห่างจากศูนย์ |

### เลือกสูตรจากข้อมูล

1. ประชากรแจกแจงปกติและรู้ `σ` ใช้ Z ไม่ว่าจะมีตัวอย่างกี่ตัว ตามทฤษฎี 7.1 (สไลด์ p-19)

```text
Z = (x̄ − μ₀) / (σ/√n)
```

2. ไม่รู้ `σ` แต่ตัวอย่างใหญ่ `n ≥ 30` ใช้ Z และใส่ `S` แทน `σ` ตามทฤษฎี 7.2 (สไลด์ p-20)

```text
Z = (x̄ − μ₀) / (S/√n)
```

3. ประชากรปกติ ไม่รู้ `σ` และตัวอย่างเล็ก `n < 30` ใช้ t ตามทฤษฎี 7.3 (สไลด์ p-21)

```text
T = (x̄ − μ₀) / (S/√n)
ν = n − 1
```

ตัวหาร `σ/√n` หรือ `S/√n` เรียกส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยตัวอย่าง ยิ่ง `n` มาก ตัวหารยิ่งเล็ก และค่าเฉลี่ยตัวอย่างยิ่งบอกข้อมูลได้ชัดขึ้น

## ค่าวิกฤตกับค่า p

เริ่มจากดูเครื่องหมายใน H₁ ไม่ใช่ดูว่าค่าเฉลี่ยที่คำนวณได้สูงหรือต่ำ

| H₁ | เขตปฏิเสธด้วย Z | เมื่อใช้ t |
|---|---|---|
| `μ > μ₀` | `Z > Zα` | `T > tα,ν` |
| `μ < μ₀` | `Z < −Zα` | `T < −tα,ν` |
| `μ ≠ μ₀` | `|Z| > Zα/2` | `|T| > tα/2,ν` |

ค่าวิกฤต (critical value) คือเส้นแบ่งที่ทำให้พื้นที่หางเท่ากับ `α` สำหรับสองทางต้องแบ่งเป็น `α/2` ต่อหาง ตัวอย่างที่ `α = 0.05` สองทางใช้พื้นที่หางละ 0.025

ตาราง Z ในข้อสอบหน้า 16–17 ให้พื้นที่สะสมทางซ้าย `P(Z < z)` เช่น แถว 2.0 คอลัมน์ 0.00 ให้ `0.9773` ดังนั้นหางขวาคือ `1 − 0.9773 = 0.0227` ตาราง t หน้า 18 ให้ค่า t บวกตามพื้นที่หางขวาและองศาอิสระ ต้องเลือกแถว `ν` และคอลัมน์ one-tail หรือ two-tails ให้ตรงกัน

ถ้าโจทย์ไม่ให้ `α` ให้เขียน **สมมติ α = 0.05** ก่อนทำเสมอ แล้วบอกด้วยว่าเมื่อใช้ `α = 0.01` ผลเปลี่ยนหรือไม่

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 7.4 (สไลด์ CH7 หน้า 22): ผลิตได้มากขึ้นหรือไม่

โรงงานเคยผลิตเฉลี่ย 30,000 กิโลกรัมต่อวัน และรู้ `σ = 4,000` กิโลกรัม หลังปรับกระบวนการสุ่ม 100 วัน ได้ `x̄ = 30,800` กิโลกรัม สไลด์ไม่ได้ให้ `α` จึงสมมติ `α = 0.05` และจะเทียบกับ `α = 0.01` ด้วย

**1) โจทย์ถามอะไร / ข้อมูลที่มี** ต้องการตรวจว่าค่าเฉลี่ยใหม่สูงกว่า 30,000 หรือไม่ ข้อมูลคือ `μ₀ = 30,000`, `σ = 4,000`, `n = 100`, `x̄ = 30,800`

**2) ตั้งสมมติฐานและกำหนด α** คำว่า “สูงขึ้น” เป็นหางขวา

```text
H₀: μ = 30,000
H₁: μ > 30,000
α = 0.05 (สมมติ)
```

**3) เลือกสถิติทดสอบ** รู้ `σ` จึงใช้ Z ตามทฤษฎี 7.1

**4) หาค่าวิกฤต** ตาราง Z ต้องการพื้นที่ซ้าย 0.9500 ค่านี้อยู่ระหว่าง `z = 1.64` ที่ 0.9495 และ `z = 1.65` ที่ 0.9505 จึงใช้ `Zα ≈ 1.645` เป็นค่ากลาง

**5) คำนวณ ตัดสิน และแปลผล**

```text
Z = (30,800 − 30,000) / (4,000/√100)
  = 800 / (4,000/10)
  = 800 / 400
  = 2.00
```

- วิธีค่าวิกฤต: `2.00 > 1.645` ตกเขตขวา จึง **ปฏิเสธ H₀**
- วิธีค่า p: ตารางที่ `z = 2.00` ให้พื้นที่ซ้าย 0.9773; p-value = `1 − 0.9773 = 0.0227`; เพราะ `0.0227 < 0.05` จึง **ปฏิเสธ H₀**
- แปลผล: ที่ระดับ 5% มีหลักฐานว่าการปรับกระบวนการทำให้ค่าเฉลี่ยผลิตสูงขึ้น
- ถ้า `α = 0.01`: ตารางให้ 0.9898 ที่ `z = 2.32` และ 0.9901 ที่ `z = 2.33` จึงประมาณค่าวิกฤต 2.326; `2.00 < 2.326` และ `0.0227 > 0.01` จึง **ไม่ปฏิเสธ H₀**

### EX 7.5 (สไลด์ CH7 หน้า 23): อายุเก็บรักษาต่ำกว่า 20 เดือนหรือไม่

ผู้ผลิตอ้างว่าอายุเก็บเฉลี่ย 20 เดือน มีตัวอย่าง `n = 32`, `x̄ = 18.9`, `S = 2.7` เดือน และสไลด์กำหนด `α = 0.01`

**1) โจทย์ถามอะไร / ข้อมูลที่มี** ผู้บริโภคสงสัยว่าค่าเฉลี่ยต่ำกว่า 20 เดือน จึงมี `μ₀ = 20`, `n = 32`, `x̄ = 18.9`, `S = 2.7`

**2) ตั้งสมมติฐานและกำหนด α** คำว่า “ต่ำกว่า” เป็นหางซ้าย

```text
H₀: μ = 20
H₁: μ < 20
α = 0.01
```

**3) เลือกสถิติทดสอบ** `n = 32 ≥ 30` และไม่รู้ `σ` จึงใช้ Z โดยใส่ `S` ในตัวหาร

**4) หาค่าวิกฤต** หางซ้าย 0.01 ใช้ค่าลบของค่าที่มีพื้นที่ซ้าย 0.99 ตารางให้ `z = 2.32` ที่ 0.9898 และ `z = 2.33` ที่ 0.9901 จึงใช้ `−Zα ≈ −2.326`

**5) คำนวณ ตัดสิน และแปลผล**

```text
Z = (18.9 − 20) / (2.7/√32)
  = −1.1 / (2.7/5.6569)
  = −1.1 / 0.4773
  = −2.3046 ≈ −2.30
```

- วิธีค่าวิกฤต: `−2.30` ไม่ต่ำกว่า `−2.326` จึง **ไม่ปฏิเสธ H₀**
- วิธีค่า p: ตารางลบที่ `z = −2.30` ให้พื้นที่ซ้าย 0.0107; p-value = 0.0107 ซึ่งมากกว่า 0.01 จึง **ไม่ปฏิเสธ H₀** (ค่าละเอียดประมาณ 0.0106)
- แปลผล: ที่ระดับ 1% หลักฐานยังไม่พอจะสรุปว่าอายุเก็บเฉลี่ยต่ำกว่า 20 เดือน
- ถ้าใช้ `α = 0.05`: ค่าวิกฤตประมาณ −1.645 และ `−2.30 < −1.645`; จึงปฏิเสธ H₀ ผลจะเปลี่ยนตามระดับนัยสำคัญ

### EX 7.6 (สไลด์ CH7 หน้า 24): ปริมาณนิโคตินเปลี่ยนไปหรือไม่

บุหรี่เคยมีนิโคตินเฉลี่ย 20 มิลลิกรัม สุ่ม 36 มวนได้ `x̄ = 22` และ `S = 4` มิลลิกรัม สไลด์ไม่ได้ให้ `α` จึงสมมติ `α = 0.05` และตรวจ `α = 0.01` ด้วย

**1) โจทย์ถามอะไร / ข้อมูลที่มี** คำว่า “เปลี่ยนไป” แปลว่าสูงขึ้นหรือต่ำลงก็ได้ ข้อมูลคือ `μ₀ = 20`, `n = 36`, `x̄ = 22`, `S = 4`

**2) ตั้งสมมติฐานและกำหนด α** เป็นการทดสอบสองทาง

```text
H₀: μ = 20
H₁: μ ≠ 20
α = 0.05 (สมมติ)
```

**3) เลือกสถิติทดสอบ** `n = 36 ≥ 30` และไม่รู้ `σ` จึงใช้ Z กับ `S`

**4) หาค่าวิกฤต** สองทางใช้ `α/2 = 0.025` ต่อหาง ตารางให้พื้นที่ซ้าย 0.9750 ที่ `z = 1.96` จึงใช้ `±1.96`

**5) คำนวณ ตัดสิน และแปลผล**

```text
Z = (22 − 20) / (4/√36)
  = 2 / (4/6)
  = 2 / 0.6667
  = 3.00
```

- วิธีค่าวิกฤต: `|3.00| > 1.96` จึง **ปฏิเสธ H₀**
- วิธีค่า p: ตารางที่ `z = 3.00` ให้พื้นที่ซ้าย 0.9987; หางขวา = `1 − 0.9987 = 0.0013`; สองหาง p-value = `2(0.0013) = 0.0026`
- แปลผล: ที่ระดับ 5% มีหลักฐานว่าค่าเฉลี่ยนิโคตินเปลี่ยนจาก 20 มิลลิกรัม
- ถ้า `α = 0.01`: ตารางให้ 0.9949 ที่ `z = 2.57` และ 0.9951 ที่ `z = 2.58` จึงประมาณค่าวิกฤต `±2.576`; `|3.00| > 2.576` และ `0.0026 < 0.01` จึงยัง **ปฏิเสธ H₀** (ค่าละเอียดของ p-value ประมาณ 0.0027)

### EX 7.7 (สไลด์ CH7 หน้า 25): มาตรการลดก๊าซได้จริงหรือไม่

ก่อนมีมาตรการ ค่าเฉลี่ยคาร์บอนมอนอกไซด์เท่ากับ 9.4 ppm สุ่ม 18 จุด ได้ข้อมูล 18 ค่าในสไลด์: 8.6, 6.4, 7.2, 10.5, 8.7, 10.7, 5.4, 5.7, 3.9, 4.5, 3.6, 7.6, 6.8, 10.9, 10.2, 7.9, 9.4, 7.9 ppm สไลด์ไม่ให้ `α` จึงสมมติ `α = 0.05` และตรวจ `α = 0.01` ด้วย

**1) โจทย์ถามอะไร / ข้อมูลที่มี** คำว่า “ลด” หมายถึง `μ < 9.4`; จากข้อมูลคำนวณได้ `n = 18`, `x̄ = 7.55`, `S = 2.3168`

**2) ตั้งสมมติฐานและกำหนด α** เป็นหางซ้าย

```text
H₀: μ = 9.4
H₁: μ < 9.4
α = 0.05 (สมมติ)
```

**3) เลือกสถิติทดสอบ** `n = 18 < 30`, ไม่รู้ `σ`, และสมมติประชากรปกติ จึงใช้ t โดย `ν = 18 − 1 = 17`

**4) หาค่าวิกฤต** ตาราง t แถว `ν = 17` คอลัมน์ one-tail 0.05 ให้ `t = 1.740`; หางซ้ายจึงใช้ `−1.740`

**5) คำนวณ ตัดสิน และแปลผล**

```text
S/√n = 2.3168/√18
     = 2.3168/4.2426
     = 0.5461
T = (7.55 − 9.4)/0.5461
  = −1.85/0.5461
  = −3.388
```

- วิธีค่าวิกฤต: `−3.388 < −1.740` จึง **ปฏิเสธ H₀**
- วิธีค่า p: ใช้ `|T| = 3.388` ตารางแถว 17 ให้ one-tail 0.005 ที่ 2.898 และ 0.001 ที่ 3.646 ดังนั้น `0.001 < p-value < 0.005`; จึงน้อยกว่า 0.05 และ **ปฏิเสธ H₀**
- แปลผล: มีหลักฐานว่ามาตรการทำให้ค่าเฉลี่ยก๊าซลดลง
- ถ้า `α = 0.01`: แถว 17 one-tail 0.01 ให้ `t = 2.567`; `−3.388 < −2.567` และ p-value ยังน้อยกว่า 0.01 เพราะอยู่ต่ำกว่า 0.005 จึง **ปฏิเสธ H₀** เช่นเดิม

## วิธีอ่านตารางในห้องสอบ

1. ตาราง Z หน้า 16 เป็นพื้นที่สะสมซ้าย ถ้าต้องการหางขวาให้ทำ `1 − พื้นที่ซ้าย` เสมอ ตัวอย่าง `z = 2.00` ได้ 0.9773 จึงหางขวา 0.0227
2. หางซ้ายของค่า z ลบ อ่านจากตารางหน้า 17 โดยตรง เช่น `z = −2.30` ได้ 0.0107
3. สองทางต้องคูณพื้นที่หางเดียวด้วย 2 หลังจากใช้ `|z|` เช่น 0.0013 × 2 = 0.0026
4. ตาราง t หน้า 18 มีแถว `df` หรือ `ν` และคอลัมน์ one-tail/two-tails ถ้าเป็นหางซ้ายใช้เครื่องหมายลบหน้าค่าบวกในตาราง
5. ตาราง t บอกช่วงของ p-value ได้ เช่น ค่า 3.388 ที่ df 17 อยู่ระหว่างคอลัมน์ one-tail 0.005 (2.898) และ 0.001 (3.646)

## กับดักในข้อสอบ

- เขียน H₀ เป็น `μ > μ₀` หรือ `μ < μ₀`: ให้ใส่เครื่องหมาย `=` ใน H₀ แล้วใส่ทิศทางไว้ใน H₁
- เห็น x̄ สูงกว่าแล้วเปลี่ยนเป็นหางขวา: หางต้องดูจาก H₁ ที่เขียนก่อนคำนวณ
- ใช้ `σ/n` แทน `σ/√n`: ตัวหารต้องมีรากที่สอง
- `n ≥ 30` แต่ไม่รู้ σ แล้วหยิบ t มาใช้: ตามสไลด์ช่วงนี้ใช้ Z และแทน σ ด้วย S
- ใช้ t เมื่อรู้ σ: ถ้ารู้ σ ให้ใช้ Z ตามทฤษฎี 7.1
- ใช้ `n` เป็นองศาอิสระ: one-sample t ใช้ `ν = n − 1`
- สองทางใช้ค่า one-tail: ต้องแบ่ง `α/2` และใช้ `|Z|` หรือ `|T|`
- อ่านพื้นที่ซ้ายเป็น p-value ของหางขวาทันที: หางขวาต้องลบจาก 1 ก่อน
- เขียนว่า “ยอมรับ H₀ เพราะพิสูจน์แล้ว”: ใช้คำว่า “ไม่ปฏิเสธ H₀ เพราะหลักฐานยังไม่พอ”
- โจทย์ไม่ให้ α แล้วฟันธงทันที: เขียนสมมติ `α = 0.05` และบอกผลเมื่อ `α = 0.01` ด้วย

## แบบฝึกหัดปิดหนังสือ

### ข้อเขียน

1. โรงงานอ้างว่าน้ำหนักเฉลี่ย 50 กรัม รู้ `σ = 8` กรัม สุ่ม 64 ชิ้นได้ `x̄ = 52` กรัม จงทดสอบว่าค่าเฉลี่ยมากกว่า 50 หรือไม่ที่ `α = 0.05` และบอกผลที่ `α = 0.01`
2. คะแนนเฉลี่ยเดิมคือ 30 สุ่มนักเรียน 40 คนได้ `x̄ = 29.2`, `S = 4` จงทดสอบว่าค่าเฉลี่ยต่ำกว่า 30 หรือไม่ที่ `α = 0.05` (ไม่รู้ σ)
3. เวลาเฉลี่ยที่อ้างคือ 100 นาที ประชากรปกติ สุ่ม 16 คนได้ `x̄ = 104`, `S = 6` จงทดสอบว่าค่าเฉลี่ยมากกว่า 100 หรือไม่ที่ `α = 0.05` และบอกผลที่ `α = 0.01`

<details><summary>เปิดดูเฉลยข้อเขียน</summary>

**ข้อ 1**

```text
H₀: μ = 50, H₁: μ > 50, ใช้ Z เพราะรู้ σ
Z = (52 − 50)/(8/√64) = 2/(8/8) = 2.00
```

ตารางให้พื้นที่ซ้าย 0.9773 จึง p-value = `1 − 0.9773 = 0.0227` และค่าวิกฤตที่ α = 0.05 ประมาณ 1.645: `2.00 > 1.645` จึงปฏิเสธ H₀. ที่ α = 0.01 ใช้ประมาณ 2.326; `2.00 < 2.326` และ 0.0227 > 0.01 จึงไม่ปฏิเสธ H₀

**ข้อ 2**

```text
H₀: μ = 30, H₁: μ < 30, ใช้ Z เพราะ n = 40 ≥ 30 และไม่รู้ σ
Z = (29.2 − 30)/(4/√40)
  = −0.8/(4/6.3249)
  = −0.8/0.6325
  = −1.2649 ≈ −1.26
```

ตารางหน้า 17 ให้ p-value = 0.1038 ที่ `z = −1.26`; ค่าวิกฤตซ้าย α = 0.05 ประมาณ −1.645. เนื่องจาก `−1.26 > −1.645` และ 0.1038 > 0.05 จึงไม่ปฏิเสธ H₀: หลักฐานยังไม่พอว่าค่าเฉลี่ยต่ำกว่า 30

**ข้อ 3**

```text
H₀: μ = 100, H₁: μ > 100, ใช้ t เพราะ n = 16 < 30 และประชากรปกติ
ν = 16 − 1 = 15
T = (104 − 100)/(6/√16) = 4/(6/4) = 2.6667
```

ตาราง t แถว 15 ให้ one-tail 0.05 ที่ 1.753 และ one-tail 0.01 ที่ 2.602. ที่ α = 0.05, `2.6667 > 1.753` จึงปฏิเสธ H₀; p-value อยู่ระหว่าง 0.005 และ 0.01. ที่ α = 0.01, `2.6667 > 2.602` และ p-value < 0.01 จึงยังปฏิเสธ H₀

</details>

### ปรนัย

4. รู้ `σ`, `n = 25`, `x̄ = 62`, `μ₀ = 60` และทดสอบ `H₁: μ > 60` ที่ α = 0.05 ข้อใดถูกต้อง

ก. ใช้ t เพราะ n < 30 และไม่ปฏิเสธ H₀

ข. ใช้ Z, `Z = 2.00` และปฏิเสธ H₀

ค. ใช้ Z, `Z = 0.40` และไม่ปฏิเสธ H₀

ง. ใช้ t, `ν = 25` และปฏิเสธ H₀

5. ไม่รู้ σ, `n = 49`, `x̄ = 48.6`, `μ₀ = 50`, `S = 4.2` และทดสอบสองทางที่ α = 0.05 ข้อใดถูกต้อง

ก. `Z = −2.33`, p-value จากสองหางประมาณ 0.0198 จึงปฏิเสธ H₀

ข. `T = −2.33`, ใช้ df = 48 และไม่ปฏิเสธ H₀ เพราะใช้ one-tail

ค. `Z = −0.39`, p-value = 0.0198 จึงปฏิเสธ H₀

ง. `Z = −2.33`, ใช้ p-value 0.0099 เป็นคำตอบสองทาง จึงไม่ปฏิเสธ H₀

6. ประชากรปกติ ไม่รู้ σ, `n = 12`, `x̄ = 15.8`, `μ₀ = 16`, `S = 1.5` และทดสอบ `H₁: μ < 16` ที่ α = 0.05 ข้อใดถูกต้อง

ก. ใช้ Z เพราะทุกการทดสอบค่าเฉลี่ยใช้ Z

ข. ใช้ t, `ν = 12`, และปฏิเสธ H₀ เพราะ −0.46 < −1.796

ค. ใช้ t, `ν = 11`, `T ≈ −0.46`; p-value มากกว่า 0.25 จึงไม่ปฏิเสธ H₀

ง. ใช้ t, `ν = 11`, แต่กลับหางเป็นขวาเพราะ T ติดลบ

<details><summary>เปิดดูเฉลยปรนัย</summary>

**ข้อ 4 ตอบ ข.**

```text
Z = (62 − 60)/(5/√25)
  = 2/(5/5)
  = 2.00
```

รู้ `σ` จึงใช้ Z แม้ `n < 30` และ `2.00 > 1.645` จึงปฏิเสธ H₀. ข้อ ก และ ง เลือก t ผิด; ข้อ ค ลืมหารด้วย `√n` แบบถูกต้อง

**ข้อ 5 ตอบ ก.**

```text
Z = (48.6 − 50)/(4.2/√49)
  = −1.4/(4.2/7)
  = −1.4/0.6
  = −2.3333 ≈ −2.33
```

ตารางหน้า 17 ที่ −2.33 ให้พื้นที่หางซ้าย 0.0099; สองทางคือ `2(0.0099) = 0.0198 < 0.05` จึงปฏิเสธ H₀. ข้อ ข ใช้ t ทั้งที่ n ≥ 30 และใช้หางผิด; ข้อ ค คำนวณค่า Z ผิด; ข้อ ง ลืมคูณสอง

**ข้อ 6 ตอบ ค.**

```text
ν = 12 − 1 = 11
T = (15.8 − 16)/(1.5/√12)
  = −0.2/(1.5/3.4641)
  = −0.2/0.4330
  = −0.4619 ≈ −0.46
```

ตาราง t แถว 11 ให้ one-tail 0.25 ที่ 0.697; `|T| = 0.46 < 0.697` จึง p-value > 0.25 และไม่ปฏิเสธ H₀. ข้อ ก ใช้ Z ผิด; ข้อ ข ใช้ df เป็น n และเปรียบเทียบผิดทิศ; ข้อ ง เปลี่ยนหางตามค่าที่คำนวณ ซึ่งห้ามทำ

## สรุปจำสั้น ๆ

- รู้ `σ` → Z
- ไม่รู้ `σ` และ `n ≥ 30` → Z โดยใช้ S
- ไม่รู้ `σ`, `n < 30`, ประชากรปกติ → t และ `ν = n − 1`
- `>` หางขวา, `<` หางซ้าย, `≠` สองหาง
- วิธีค่าวิกฤต: สถิติอยู่ในเขตปฏิเสธจึงปฏิเสธ H₀
- วิธีค่า p: p-value `≤ α` จึงปฏิเสธ H₀
- ตาราง Z ให้พื้นที่สะสมซ้าย; หางขวาต้อง `1 − พื้นที่ซ้าย`
- ไม่มี α ให้สมมติ 0.05 และรายงานสิ่งที่เกิดเมื่อใช้ 0.01
