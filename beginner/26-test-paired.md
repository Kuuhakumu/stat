# บทที่ 26: ทดสอบข้อมูลจับคู่ ก่อน–หลัง

## เป้าหมาย

- แยกข้อมูลจับคู่ออกจากสองกลุ่มอิสระได้
- สร้างผลต่าง ค่าเฉลี่ยผลต่าง และส่วนเบี่ยงเบนมาตรฐานจากข้อมูลทีละคู่
- เลือกสถิติจากโค้งทีเมื่อคู่มีน้อย หรือจากโค้งปกติเมื่อมีอย่างน้อย 30 คู่
- ตั้งทิศทางของผลต่างให้ตรงกับคำถาม และรู้ว่าการสลับทิศทางทำให้หางของคำถามสลับด้วย

## ต้องรู้ก่อน

- [ไอเดียการทดสอบสมมติฐาน](22-hypothesis-testing-idea.md) — สมมติฐานหลัก สมมติฐานทางเลือก และหางซ้าย/ขวา/สองหาง
- [การแจกแจงที](12-t-distribution.md) — องศาอิสระและตาราง t
- [ช่วงความเชื่อมั่นข้อมูลจับคู่](20-ci-paired-and-two-proportions.md) — การจับคู่และการสร้างผลต่าง
- [ทดสอบผลต่างค่าเฉลี่ยของสองกลุ่ม](25-test-two-means.md) — ทำไมข้อมูลคนละกลุ่มจึงใช้สูตรอีกแบบ

## นึกภาพก่อน: คนเดิมวัดสองครั้ง

ถ้าวัดความดันคนเดิมก่อนกินยาและหลังยา ค่าของคนที่ 1 ต้องเทียบกับค่าของคนที่ 1 เท่านั้น คนที่ 2 ก็เทียบกับคนที่ 2 การจับคู่แบบนี้ช่วยตัดความแตกต่างระหว่างคนออก เหลือคำถามง่าย ๆ ว่า “โดยเฉลี่ยแล้วค่าครั้งที่หนึ่งต่างจากครั้งที่สองหรือไม่”

ถ้าเป็นร้านเดิมที่วางสินค้าในระดับสายตาและต่ำกว่าสายตาคนละสัปดาห์ ร้านหนึ่งก็เป็นหนึ่งคู่ เราจึงไม่เอาข้อมูลทั้งหมดของแถวแรกไปลบกับข้อมูลทั้งหมดของแถวที่สองแบบสุ่ม ๆ แต่ลบเป็นคู่ ๆ ก่อน

## จับคู่หรือสองกลุ่มอิสระ

ให้คิดว่าเป็น **ข้อมูลจับคู่ (paired data)** เมื่อเป็นหน่วยเดิมวัดสองครั้ง เช่น คนเดิมก่อน–หลังยา ร้านเดิมใช้วิธีที่ 1–2 หรือคู่ที่จับกันตามคุณสมบัติ ถ้าสุ่มคนกลุ่ม A และกลุ่ม B แยกกัน แต่ละคนไม่มีคู่ตายตัว ให้ใช้บท [ทดสอบผลต่างค่าเฉลี่ยของสองกลุ่ม](25-test-two-means.md)

เมื่อจับคู่แล้ว จะวิเคราะห์ผลต่างชุดเดียว ไม่ใช่เอาจำนวนข้อมูลของสองแถวมาบวกกัน และไม่ใช้ค่าเฉลี่ยของสองแถวเป็นตัวอย่างอิสระสองตัวอย่าง

## สัญลักษณ์และการเลือกทิศทาง

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `Xᵢ₁` | เอ็กซ์ไอหนึ่ง | ค่าครั้งที่ 1 ของคู่ที่ `i` เช่น ค่าก่อน |
| `Xᵢ₂` | เอ็กซ์ไอสอง | ค่าครั้งที่ 2 ของคู่ที่ `i` เช่น ค่าหลัง |
| `i` | ไอ | ลำดับคู่ เช่น 1, 2, … |
| `Dᵢ` | ดีไอ | ผลต่างของคู่ที่ `i`, `Dᵢ = Xᵢ₁ − Xᵢ₂` |
| `D` | ดี | ชุดผลต่างทั้งหมด |
| `D̄` | ดีบาร์ | ค่าเฉลี่ยของผลต่างทุกคู่ |
| `μ_D` | มิวซับดี | ค่าเฉลี่ยผลต่างจริงของประชากร |
| `D₀` | ดีศูนย์ | ผลต่างที่กำหนดไว้ใน `H₀`; มักเป็น 0 |
| `S_D` | เอสซับดี | ส่วนเบี่ยงเบนมาตรฐานของผลต่างจากตัวอย่าง |
| `S_D²` | เอสซับดีกำลังสอง | ความแปรปรวนของผลต่างจากตัวอย่าง |
| `n` | เอ็น | จำนวนคู่ข้อมูล ไม่ใช่จำนวนข้อมูลสองแถวรวมกัน |
| `ν` | นิว | องศาอิสระ ใช้เลือกแถวในตาราง t |
| `H₀` | เอชศูนย์ | สมมติฐานหลัก ต้องมีเครื่องหมาย `=` |
| `H₁` | เอชหนึ่ง | สมมติฐานทางเลือกตามคำถาม |
| `T` | ทีตัวใหญ่ | ค่าสถิติทดสอบเมื่อใช้การแจกแจง t |
| `Z` | แซดตัวใหญ่ | ค่าสถิติทดสอบเมื่อใช้การแจกแจงปกติมาตรฐาน |
| `SE` | เอสอี | ค่าคลาดเคลื่อนมาตรฐานของ `D̄` |
| `α` | แอลฟา | ระดับนัยสำคัญ หรือพื้นที่หางที่ยอมให้ปฏิเสธ `H₀` |
| `√` | รากที่สอง | จำนวนที่คูณตัวเองแล้วได้ค่าข้างใน |
| `Σ` | ซิกมา | ให้บวกค่าทุกตัวตามที่ระบุ |
| `=` | เท่ากับ | ค่าซ้ายและขวามีค่าเดียวกัน |
| `−` | ลบ | หาผลต่างหรือลบจำนวนออก |
| `/` | หาร | แบ่งจำนวนด้านหน้าออกด้วยจำนวนด้านหลัง |
| `+` | บวก | รวมจำนวนเข้าด้วยกัน |
| `≈` | ใกล้เคียงกับ | ค่าที่ปัดแล้วใกล้กับค่าจริง |
| `≥` | มากกว่าหรือเท่ากับ | ค่าซ้ายไม่น้อยกว่าค่าขวา |
| `|T|` | ค่าสัมบูรณ์ของที | ตัดเครื่องหมายลบของ `T` ออก เหลือระยะห่างจากศูนย์ |
| `p-value` | พีแวลยู | โอกาสได้ค่าสถิติที่สุดโต่งเท่านี้หรือมากกว่า ถ้า `H₀` เป็นจริง |
| `>` | มากกว่า | หางขวา |
| `<` | น้อยกว่า | หางซ้าย |
| `≠` | ไม่เท่ากับ | สองหาง สูงกว่าหรือต่ำกว่าก็ได้ |

กำหนด `D` ก่อนคำนวณเสมอ ตัวอย่างเช่น

```text
D = ก่อน − หลัง
```

ถ้าความเชื่อคือ “ก่อนสูงกว่าหลัง” จะได้ `H₁: μ_D > 0` เพราะผลต่างก่อน−หลังควรเป็นบวก ถ้าเปลี่ยนเป็น `D = หลัง−ก่อน` ผลต่างทุกตัวและค่า `T` จะเปลี่ยนเครื่องหมาย ความเชื่อเดิมต้องเขียนเป็น `H₁: μ_D < 0` แทน สำหรับการทดสอบสองหาง เครื่องหมายของ `T` เปลี่ยน แต่ใช้ `|T|` อ่านตาราง จึงได้ข้อสรุปเดิม

## สูตรทดสอบผลต่าง

เริ่มจากหาผลต่างทีละคู่ แล้วหาค่าเฉลี่ยและการกระจายของผลต่าง

```text
Dᵢ = Xᵢ₁ − Xᵢ₂
D̄ = ΣDᵢ/n
S_D² = Σ(Dᵢ−D̄)²/(n−1)
S_D = √S_D²
SE = S_D/√n
```

ถ้า `n < 30` ให้สมมติว่าผลต่างในประชากรมีการแจกแจงปกติ และไม่รู้ส่วนเบี่ยงเบนมาตรฐานจริง จึงใช้ t

```text
T = (D̄−D₀)/(S_D/√n)
ν = n−1
```

ถ้า `n ≥ 30` ใช้ Z โดยยังใช้ `S_D` จากผลต่างเป็นตัวประมาณส่วนเบี่ยงเบนมาตรฐาน

```text
Z = (D̄−D₀)/(S_D/√n)
```

สังเกตว่า `D₀` ต้องอยู่ในตัวเศษด้วย ถ้า `H₀` บอกว่าผลต่างเท่ากับ 3 ก็ต้องลบ 3 ไม่ใช่ลบ 0

> ⚠️ สไลด์ CH7 หน้า 39 เขียนตัวเศษเป็น `D̄−μ_D` แต่เมื่อตั้ง `H₀` ให้ผลต่างเท่ากับ `D₀` ต้องแทนค่าที่สมมติไว้ จึงคำนวณเป็น `D̄−D₀`

## ตั้งสมมติฐานจากคำถาม

ให้ `D = วิธีที่ 1−วิธีที่ 2` และให้ `D₀` เป็นค่าที่ต้องการทดสอบ

```text
H₀: μ_D = D₀
H₁: μ_D > D₀   เมื่อวิธีที่ 1 ต้องการให้สูงกว่า
H₁: μ_D < D₀   เมื่อวิธีที่ 1 ต้องการให้ต่ำกว่า
H₁: μ_D ≠ D₀   เมื่อถามว่าต่างกันหรือไม่
```

`H₀` อ่านว่า “เอชศูนย์” และเป็นเรื่องเดิมที่ถือไว้ก่อน ส่วน `H₁` อ่านว่า “เอชหนึ่ง” และเป็นทิศทางที่โจทย์อยากหาหลักฐาน ถ้าโจทย์ไม่ให้ `α` ต้องรายงานค่า `p-value` หรือเขียนผลแบบมีเงื่อนไข เช่น “ถ้า α=0.05 จึงปฏิเสธ” อย่าฟันธงแทนโจทย์

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 7.13 (สไลด์ CH7 หน้า 40): ยอดขายระดับสายตา

**1) โจทย์ถามอะไร / ข้อมูลที่มี** ร้านเดิม 10 แห่งวางแชมพูระดับสายตาหนึ่งสัปดาห์และต่ำกว่าสายตาอีกหนึ่งสัปดาห์ ต้องตรวจว่าระดับสายตาขายได้สูงกว่า ข้อมูลเป็นพันบาทต่อสัปดาห์

```text
ระดับสายตา:       181 172 190 187 210 202 166 173 183 184
ต่ำกว่าสายตา:     178 172 185 184 201 201 160 168 180 179
```

**2) คำใบ้บอกวิธีไหน** ร้านเดียวกันถูกวัดสองตำแหน่ง จึงเป็นข้อมูลจับคู่ กำหนด `D = ระดับสายตา−ต่ำกว่าสายตา` คำว่า “สูงกว่า” เป็นหางขวา

```text
n = 10,  D₀ = 0
H₀: μ_D = 0
H₁: μ_D > 0
```

`n=10<30` จึงใช้การทดสอบทีของข้อมูลจับคู่ (paired t) และ `ν=10−1=9`

**3) คำนวณทีละบรรทัด**

```text
Dᵢ = 181−178, 172−172, 190−185, 187−184, 210−201,
     202−201, 166−160, 173−168, 183−180, 184−179
   = 3, 0, 5, 3, 9, 1, 6, 5, 3, 5

ΣDᵢ = 3+0+5+3+9+1+6+5+3+5 = 40
D̄ = ΣDᵢ/n = 40/10 = 4.0000

Σ(Dᵢ−D̄)²
= (3−4)²+(0−4)²+(5−4)²+(3−4)²+(9−4)²
 + (1−4)²+(6−4)²+(5−4)²+(3−4)²+(5−4)²
= 1+16+1+1+25+9+4+1+1+1 = 60

S_D² = 60/(10−1) = 60/9 = 6.6667
S_D = √6.6667 = 2.5820
SE = S_D/√n = 2.5820/√10 = 2.5820/3.1623 = 0.8165
T = (D̄−D₀)/SE = (4.0000−0)/0.8165 = 4.8990
ν = n−1 = 9
```

**4) แปลผลเป็นภาษาคน** ตาราง t หน้า TABLES p-18 แถว `ν=9` คอลัมน์หางเดียว (one-tail) ให้ `α=0.05 → 1.833`, `α=0.01 → 2.821` และ `α=0.001 → 4.297` ซึ่งเป็นค่าที่พิมพ์ในตาราง ค่า `T=4.8990` มากกว่าทั้งหมด ดังนั้นจากตารางได้ `p-value < 0.0010` ถ้ากำหนด `α=0.05` หรือ `0.01` ให้ปฏิเสธ `H₀` และมีหลักฐานว่าวางระดับสายตาขายได้สูงกว่า แต่สไลด์ไม่กำหนด `α` จึงต้องเขียนเป็นเงื่อนไข

### EX 7.14 (สไลด์ CH7 หน้า 41): ความดันก่อนและหลังลดน้ำหนัก

**1) โจทย์ถามอะไร / ข้อมูลที่มี** ผู้ใหญ่ 7 คนถูกวัดความดันก่อนและหลังใช้วิธีลดน้ำหนัก 3 เดือน ต้องตรวจว่าค่าเฉลี่ยก่อนกับหลังแตกต่างกันหรือไม่

```text
ก่อน:  210 180 195 220 231 199 224
หลัง:  193 186 186 223 220 183 233
```

**2) คำใบ้บอกวิธีไหน** เป็นคนเดิมวัดสองครั้ง จึงจับคู่และกำหนด `D=ก่อน−หลัง` คำว่า “แตกต่าง” ใช้สองหาง

```text
n = 7,  D₀ = 0
H₀: μ_D = 0
H₁: μ_D ≠ 0
```

เพราะ `n=7<30` ใช้ t และ `ν=7−1=6`

**3) คำนวณทีละบรรทัด**

```text
Dᵢ = 210−193, 180−186, 195−186, 220−223,
     231−220, 199−183, 224−233
   = 17, −6, 9, −3, 11, 16, −9

ΣDᵢ = 17−6+9−3+11+16−9 = 35
D̄ = 35/7 = 5.0000

Σ(Dᵢ−D̄)²
= (17−5)²+(−6−5)²+(9−5)²+(−3−5)²
 + (11−5)²+(16−5)²+(−9−5)²
= 144+121+16+64+36+121+196 = 698

S_D² = 698/(7−1) = 698/6 = 116.3333
S_D = √116.3333 = 10.7858
SE = 10.7858/√7 = 10.7858/2.6458 = 4.0766
T = (5.0000−0)/4.0766 = 1.2265
ν = 6
```

**4) แปลผลเป็นภาษาคน** ตาราง t หน้า TABLES p-18 แถว `ν=6` แบบ two-tails ให้ `0.30 → 1.134` และ `0.20 → 1.440` ค่า `|T|=1.2265` อยู่ระหว่างสองค่านี้ จึงได้ `0.2000 < p-value < 0.3000` ถ้า `α=0.05` ใช้ค่าวิกฤต two-tails `2.447` และไม่ปฏิเสธ `H₀`; ถ้า `α=0.01` ใช้ `3.707` และยังไม่ปฏิเสธ สรุปได้แค่ว่าหลักฐานยังไม่พอจะบอกว่าค่าเฉลี่ยต่างกัน เพราะสไลด์ไม่ได้ให้ `α`

## วิธีอ่านตาราง

- **ตาราง t หน้า TABLES p-18:** หาแถว `ν=n−1` ก่อน ถ้า `H₁` เป็น `>` หรือ `<` ให้ใช้แถวหางเดียว ถ้า `H₁` เป็น `≠` ให้ใช้แถวสองหาง (two-tailed test) คอลัมน์ เช่น สองหาง `0.05` คือแบ่งพื้นที่ผิดพลาดรวม 5% เป็นหางละ 2.5%
- **ตาราง Z หน้า TABLES p-16–p-17:** ใช้เมื่อ `n≥30` ตารางเป็นพื้นที่สะสมทางซ้าย ปัด `Z` เป็น 2 ตำแหน่งก่อนอ่าน ตาราง p-16 ใช้ค่า z บวก ส่วน p-17 ใช้ค่า z ลบ
- ค่าในตารางต้องใช้ตามที่พิมพ์ เช่น แถว `ν=6` two-tails `0.05` คือ `2.447` ไม่ใช่ค่าที่คำนวณละเอียดจากโปรแกรม

## กับดักในข้อสอบ

- **ผิด:** เห็นก่อน–หลังแล้วใช้สูตรสองกลุ่มอิสระ  **ถูก:** สร้าง `Dᵢ` ก่อน และใช้จำนวนคู่ `n`
- **ผิด:** ตั้ง `D=ก่อน−หลัง` แต่เขียนว่าหลังสูงกว่าเป็น `H₁:μ_D>0`  **ถูก:** ถ้าหลังสูงกว่า ต้องเป็น `H₁:μ_D<0`
- **ผิด:** ใช้ `ν=n`  **ถูก:** paired t ใช้ `ν=n−1`
- **ผิด:** หาค่า `S_D` จากส่วนเบี่ยงเบนมาตรฐานของสองแถวแยกกัน  **ถูก:** คำนวณจากชุด `Dᵢ` ชุดเดียว
- **ผิด:** ใช้คอลัมน์ one-tail กับคำว่า “แตกต่าง”  **ถูก:** `≠` เป็น two-tails
- **ผิด:** สรุปปฏิเสธหรือไม่ปฏิเสธทั้งที่โจทย์ไม่ให้ `α`  **ถูก:** รายงานช่วง p-value หรือเขียนเงื่อนไขที่ `α=0.05` และ `α=0.01`

## แบบฝึกหัดปิดหนังสือ

### คำถามเขียนวิธีทำ

1. คน 6 คนมีค่าก่อน `80,76,90,85,88,79` และค่าหลัง `84,80,92,89,90,84` สมมติว่าผลต่างประชากรแจกแจงปกติ จงทดสอบว่าค่าเฉลี่ยหลังสูงกว่าก่อนหรือไม่ โดยใช้ `α=0.05`
2. ผลต่าง `D=วิธีที่ 1−วิธีที่ 2` ของคู่ 5 คู่คือ `3,5,4,6,2` สมมติว่าผลต่างประชากรแจกแจงปกติ จงทดสอบ `H₀:μ_D=3` เทียบ `H₁:μ_D>3` ที่ `α=0.05`
3. มีคู่ข้อมูล 36 คู่ สรุปได้ `D̄=−1.8`, `S_D=3.6` จงทดสอบ `H₀:μ_D=0` เทียบ `H₁:μ_D<0` ที่ `α=0.05` และ `α=0.01`

<details><summary>เปิดดูเฉลยข้อเขียน</summary>

**ข้อ 1** กำหนด `D=ก่อน−หลัง` เพราะคำถามคือหลังสูงกว่า จึงเป็น `H₁:μ_D<0`

```text
D = −4, −4, −2, −4, −2, −5
n=6,  ΣDᵢ=−21,  D̄=−21/6=−3.5000
Σ(Dᵢ−D̄)² = 7.5
S_D² = 7.5/(6−1)=1.5000
S_D = √1.5 = 1.2247
SE = 1.2247/√6 = 0.5000
T = (−3.5000−0)/0.5000 = −7.0000
ν=5
```

ตาราง t แถว `ν=5` one-tail `α=0.05` ให้ `2.015` ดังนั้นเขตซ้ายคือ `−2.015` และ `T=−7.0000` อยู่ในเขตปฏิเสธ จึงปฏิเสธ `H₀` มีหลักฐานว่าค่าเฉลี่ยหลังสูงกว่าก่อน

**ข้อ 2** ผลต่างกำหนดไว้แล้ว จึงไม่ต้องสร้างใหม่

```text
n=5,  D̄=(3+5+4+6+2)/5=20/5=4.0000
Σ(Dᵢ−D̄)² = 1+1+0+4+4 = 10
S_D²=10/(5−1)=2.5000
S_D=√2.5=1.5811
SE=1.5811/√5=0.7071
T=(4.0000−3)/0.7071=1.4142
ν=4
```

ตาราง t แถว `ν=4` one-tail `α=0.05` ให้ `2.132` แต่ `1.4142<2.132` จึงไม่ปฏิเสธ `H₀` หลักฐานยังไม่พอจะบอกว่าค่าเฉลี่ยผลต่างมากกว่า 3

**ข้อ 3** `n=36≥30` จึงใช้ Z ไม่ต้องใช้ `ν`

```text
SE=S_D/√n=3.6/√36=3.6/6=0.6000
Z=(−1.8−0)/0.6000=−3.0000
```

ตาราง Z หน้า TABLES p-17 ที่ `z=−3.00` ให้พื้นที่ซ้าย `0.0013` จึงได้ p-value=`0.0013` โดยใช้ค่าพิมพ์ในตาราง ที่ `α=0.05` และ `α=0.01` ต่างก็ปฏิเสธ `H₀` มีหลักฐานว่าค่าเฉลี่ยผลต่างต่ำกว่า 0

</details>

### คำถามปรนัย

1. ถ้ามีข้อมูลจับคู่ 12 คู่ องศาอิสระของ paired t เท่ากับเท่าไร  
ก. 10  ข. 11  ค. 12  ง. 24
2. ถ้ากำหนด `D=หลัง−ก่อน` และต้องการทดสอบว่า “ก่อนสูงกว่าหลัง” สมมติฐานทางเลือกควรเป็นข้อใด  
ก. `H₁:μ_D>0`  ข. `H₁:μ_D<0`  ค. `H₁:μ_D=0`  ง. `H₁:μ_D≠0`
3. ผลต่าง 4 คู่คือ `2,1,1,1` และ `D₀=0` ค่า `T` เท่ากับเท่าไร  
ก. 1.25  ข. 2.50  ค. 5.00  ง. 10.00

<details><summary>เปิดดูเฉลยปรนัย</summary>

1. **ข. 11** เพราะ `ν=n−1=12−1=11` ตัวเลือก ก ใช้ลบ 2 แบบสองกลุ่มอิสระ ส่วน ค ลืมลบ 1 และ ง เอาจำนวนข้อมูลสองแถวมาบวก
2. **ข. `H₁:μ_D<0`** เพราะเมื่อ `D=หลัง−ก่อน` ค่า “ก่อนสูงกว่า” ทำให้หลัง−ก่อนติดลบ ตัวเลือก ก เป็นทิศทางกลับกัน ค คือ `H₀` และ ง เป็นคำถามสองทางที่โจทย์ไม่ได้ถาม
3. **ค. 5.00**

```text
D̄=(2+1+1+1)/4=5/4=1.25
S_D²=[(2−1.25)²+3(1−1.25)²]/(4−1)
    =(0.5625+0.1875)/3=0.2500
S_D=√0.25=0.5000
SE=0.5000/√4=0.2500
T=(1.25−0)/0.2500=5.00
```

ตัวเลือก ก คือ `D̄` ยังไม่ได้หารด้วย `SE` ข ลืมใช้ `√n` ให้ถูก ง คูณค่าที่ผิด จึงไม่ใช่ค่าสถิติทดสอบ

</details>

## สรุปจำสั้น ๆ

- คนเดิมหรือหน่วยเดิมวัดสองครั้ง = จับคู่
- เลือกทิศทางก่อน แล้วคำนวณ `Dᵢ = Xᵢ₁−Xᵢ₂` ให้เหมือนกันทุกคู่
- `D̄=ΣDᵢ/n`, `S_D²=Σ(Dᵢ−D̄)²/(n−1)`
- `n<30` ใช้ `T=(D̄−D₀)/(S_D/√n)`, `ν=n−1`
- `n≥30` ใช้ `Z=(D̄−D₀)/(S_D/√n)`
- สลับ `ก่อน−หลัง` เป็น `หลัง−ก่อน` เครื่องหมาย `D̄`, `T` และทิศทาง `H₁` สลับ
- `>` และ `<` ใช้ one-tail; `≠` ใช้ two-tails
- ไม่มี `α` ให้รายงาน p-value หรือสรุปแบบมีเงื่อนไข
