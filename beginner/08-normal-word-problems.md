# บทที่ 08: โจทย์คำพูดของการแจกแจงปกติ (Normal distribution)

## เป้าหมาย

- แปลงหน่วยในโจทย์ให้เป็นหน่วยเดียวกันก่อนคำนวณ
- หาความน่าจะเป็นของค่าปกติ แล้วเปลี่ยนเป็น “กี่ชิ้น” ด้วยการคูณจำนวนทั้งหมด
- หาค่าตัดจากเปอร์เซ็นต์ เช่น ระยะรับประกัน ด้วยการย้อนจาก z กลับเป็นหน่วยจริง
- ใช้สูตร 5 ขั้นกับโจทย์ปกติแบบใหม่ได้ด้วยตัวเอง

## ต้องรู้ก่อน

- [คณิตศาสตร์ที่ใช้ในวิชานี้](01-math-toolkit.md) — เศษส่วน ร้อยละ การปัดเศษ และการแปลงหน่วย
- [ความน่าจะเป็นและตัวแปรสุ่ม](02-probability-and-random-variables.md) — ตัวแปรต่อเนื่องและพื้นที่ใต้โค้ง
- [โค้งระฆังและตาราง Z](07-normal-and-z-table.md) — `Z=(X−μ)/σ` และการอ่านพื้นที่ซ้ายจากตาราง

## นึกภาพก่อน

โจทย์ปกติที่ยาว ๆ มักเป็นเรื่องใกล้ตัว เช่น ความยาวแท่ง น้ำหนักเม็ดพลาสติก หรืออายุแบตเตอรี่ เราไม่ได้ต้องจำเรื่องราวทั้งหมด ให้เปลี่ยนเรื่องนั้นเป็นภาพง่าย ๆ: มีโค้งระฆัง มีจุดกลาง และมีพื้นที่ที่โจทย์ถาม

เช่น “ยาวกว่า 5 ฟุต 2 นิ้ว” ต้องถามตัวเองก่อนว่า 5 ฟุต 2 นิ้วคือกี่นิ้ว แล้วจึงวางจุดนั้นบนโค้ง ถ้าโจทย์ถามจำนวนเม็ด ให้หาโอกาสของเม็ดหนึ่งเม็ดก่อน แล้วคูณจำนวนเม็ดทั้งหมด ถ้าถามระยะรับประกัน ให้ย้อนจากเปอร์เซ็นต์ไปหาจุดบนแกน แล้วแปลงกลับเป็นหน่วยจริง

## สูตร 5 ขั้นใช้ได้กับทุกโจทย์

1. **อ่านว่าโจทย์ถามอะไรและจดข้อมูล**: ระบุ `X` อ่านว่า “เอ็กซ์” = ค่าที่วัดได้, `μ` อ่านว่า “มิว” = ค่าเฉลี่ย, `σ` อ่านว่า “ซิกมา” = ส่วนเบี่ยงเบนมาตรฐาน, `σ²` อ่านว่า “ซิกมากำลังสอง” = ความแปรปรวน และหน่วยให้ครบ
2. **ดูคำใบ้เพื่อเลือกพื้นที่**: `>` อ่านว่า “มากกว่า” = หางขวา, `<` อ่านว่า “น้อยกว่า” = หางซ้าย, `≤` อ่านว่า “น้อยกว่าหรือเท่ากับ” และ “ไม่เกิน 5%” ของอายุที่เสียก่อนกำหนดคือหางซ้าย 5%
3. **ทำหน่วยให้เหมือนกัน แล้วทำมาตรฐาน**: `x` อ่านว่า “เอ็กซ์ตัวเล็ก” = ค่าจริงที่โจทย์ถาม; `z` อ่านว่า “แซดตัวเล็ก” = จุดของค่าจริงหลังเทียบเป็นหน่วย `σ`; `=` อ่านว่า “เท่ากับ”, `−` อ่านว่า “ลบ”, `/` อ่านว่า “หาร”, `+` อ่านว่า “บวก”, `≈` อ่านว่า “ประมาณเท่ากับ” และวงเล็บ `( )` ใช้ครอบส่วนที่คำนวณด้วยกัน สูตรคือ `z = (x−μ)/σ`
4. **อ่านตาราง Z**: `Z` อ่านว่า “ซีตัวใหญ่” = ค่ามาตรฐานที่ได้หลังแปลง, ตารางให้พื้นที่ซ้าย `P(Z<z)`; `P( )` อ่านว่า “พีของ” = ความน่าจะเป็น และ `Φ(z)` อ่านว่า “ฟีของแซด” = พื้นที่ใต้โค้งทางซ้ายของ z; หางขวาใช้ `1−Φ(z)` และช่วงใช้พื้นที่ขอบบนลบขอบล่าง
5. **แปลกลับเป็นภาษาคน**: ถ้าถามจำนวน ให้คูณ `N` อ่านว่า “เอ็น” = จำนวนชิ้นทั้งหมด กับ `p` อ่านว่า “พี” = โอกาสของหนึ่งชิ้น; `×` อ่านว่า “คูณ”; ถ้าถามค่าจริงจาก z ให้ใช้ `x = μ + zσ`

> จำสั้น ๆ: หน่วยเดียวกัน → หา z → ระบายหางให้ถูก → อ่านตาราง → แปลเป็นคำตอบ

## หน่วยต้องตรงกันก่อน

ถ้าโจทย์ให้ค่าเฉลี่ยและ σ เป็นนิ้ว ทุกค่าที่นำไปแทนต้องเป็นนิ้วด้วย `1 ฟุต = 12 นิ้ว` อย่าเอา 5 ฟุตไปลบกับ 67.56 นิ้วตรง ๆ

ถ้าเป็นเวลา น้ำหนัก หรือเงิน ก็ใช้หลักเดียวกัน เช่น เปลี่ยนนาทีเป็นชั่วโมง หรือกรัมเป็นกิโลกรัมให้เหมือนกับค่าเฉลี่ยและ σ ก่อน

## จากโอกาสเป็นจำนวนชิ้น

ถ้ามีของ `N` ชิ้น และโอกาสที่ของหนึ่งชิ้นอยู่ในช่วงที่สนใจคือ `p` จำนวนที่คาดว่าจะพบอ่านว่า “เอ็นพี” และคำนวณด้วย

```text
จำนวนคาดหมาย = N × p
```

นี่เป็น “จำนวนโดยเฉลี่ยที่คาดไว้” จึงอาจเป็นทศนิยมระหว่างคำนวณ แต่คำตอบสุดท้ายของจำนวนเม็ดหรือชิ้นให้ปัดเป็นจำนวนเต็มที่เหมาะสม

## จากเปอร์เซ็นต์ย้อนกลับเป็นค่าจริง

ถ้าตารางบอกพื้นที่และเราต้องหาค่าจริง ให้หา z ก่อน แล้วใช้ `x = μ + zσ` โดย `x` อ่านว่า “เอ็กซ์ตัวเล็ก” = ค่าจริงที่ต้องการหา เครื่องหมาย `+` อ่านว่า “บวก” และ `−` อ่านว่า “ลบ”

ถ้าเป็น 5% ทางซ้าย z จะติดลบ เพราะอยู่ต่ำกว่าค่าเฉลี่ย ถ้าเป็น 5% ทางขวา z จะเป็นบวก อย่าสลับหาง

ในโจทย์ที่มีช่วง `z₁` อ่านว่า “แซดหนึ่ง” = จุดมาตรฐานของขอบล่าง และ `z₂` อ่านว่า “แซดสอง” = จุดมาตรฐานของขอบบน ส่วน `₁` และ `₂` อ่านว่า “หนึ่ง” กับ “สอง” ใช้แยกจุดสองจุดออกจากกัน

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 4.18 (สไลด์ CH4 หน้า 46): แปลง 5 ฟุต 2 นิ้ว

**1) โจทย์ถามอะไร / ข้อมูลที่มี**

ความยาวแท่งพอลิเมอร์ `X` แจกแจงปกติ มี `μ=67.56 นิ้ว` และ `σ=2.57 นิ้ว` ต้องหา `P(X>5 ฟุต 2 นิ้ว)` โดย `P( )` อ่านว่า “พีของ” = ความน่าจะเป็น และ `>` อ่านว่า “มากกว่า”

**2) คำใบ้บอกวิธีไหน**

คำว่า “มากกว่า” ให้ใช้หางขวา และหน่วยต้องเป็นนิ้วทั้งหมด จึงใช้ z แล้วอ่านพื้นที่หางขวา

**3) คำนวณทีละบรรทัด**

```text
5 ฟุต 2 นิ้ว = (5 × 12) + 2 = 62 นิ้ว

z = (x−μ)/σ
  = (62−67.56)/2.57
  = −5.56/2.57
  = −2.1634... ≈ −2.16

P(X>62) = P(Z>−2.16)
          = 1−Φ(−2.16)
          = Φ(2.16)
          = 0.9846  (ตาราง p-16)
```

**4) แปลผลเป็นภาษาคน**

โอกาสที่แท่งยาวกว่า 5 ฟุต 2 นิ้วประมาณ **0.9846 หรือ 98.46%**

> ⚠️ ถ้าไม่ปัด z ระหว่างทาง ค่าคำนวณเต็มประมาณ 0.9847 แต่ข้อสอบใช้ z=−2.16 แล้วอ่านค่าพิมพ์ในตาราง จึงตอบ 0.9846

### EX 4.19 (สไลด์ CH4 หน้า 47): จากโอกาสเป็นจำนวนเม็ด

**1) โจทย์ถามอะไร / ข้อมูลที่มี**

มีเม็ดพลาสติก `N=300` เม็ด น้ำหนัก `X` มี `μ=68 กรัม` และ `σ=3 กรัม` ต้องคาดว่ามีกี่เม็ดที่หนักระหว่าง 64 ถึง 72 กรัม

**2) คำใบ้บอกวิธีไหน**

คำว่า “ระหว่าง” ให้หาพื้นที่กลางของโค้งก่อน แล้วคำว่า “กี่เม็ด” ให้คูณด้วย `N=300`

**3) คำนวณทีละบรรทัด**

```text
z₁ = (64−68)/3 = −4/3 = −1.3333... ≈ −1.33
z₂ = (72−68)/3 =  4/3 =  1.3333... ≈  1.33

p = P(64<X<72)
  = Φ(1.33)−Φ(−1.33)
  = 0.9082−0.0918
  = 0.8164

จำนวนคาดหมาย = N×p
              = 300×0.8164
              = 244.92
              ≈ 245 เม็ด
```

**4) แปลผลเป็นภาษาคน**

คาดว่าจะมีเม็ดหนักระหว่าง 64 ถึง 72 กรัมประมาณ **245 เม็ด** ไม่ใช่ตอบเพียง 0.8164 เพราะค่านั้นเป็นโอกาสของเม็ดหนึ่งเม็ด

เครื่องหมาย `±` อ่านว่า “บวกลบ” = ใช้ทั้งค่าบวกและค่าลบที่มีขนาดเท่ากัน ถ้าใช้ z=±1.3333... โดยไม่ปัดก่อน จะได้ p≈0.8176 และจำนวน≈245.27; ใช้ค่าจากตารางที่ z=±1.33 แล้วตอบตามตารางเป็น 245 เม็ด

### EX 4.21 (สไลด์ CH4 หน้า 49): หาระยะรับประกันจาก 5%

**1) โจทย์ถามอะไร / ข้อมูลที่มี**

อายุแบตเตอรี่ `X` แจกแจงปกติ มี `μ=38 เดือน` และ `σ=2 เดือน` โรงงานจะรับเปลี่ยนไม่เกิน 5% ต้องหาค่าระยะรับประกัน `x`

**2) คำใบ้บอกวิธีไหน**

แบตเตอรี่ที่เสียก่อนครบประกันอยู่ด้านซ้ายของจุดรับประกัน ดังนั้นต้องให้ `P(X≤x)=0.05` แล้วหา z ของพื้นที่ซ้าย 0.05 ซึ่งคือประมาณ `−1.645`

**3) คำนวณทีละบรรทัด**

```text
z = −1.645
x = μ + zσ
  = 38 + (−1.645)(2)
  = 38 − 3.290
  = 34.710 เดือน
  ≈ 34.71 เดือน
```

ถ้าตารางมี z สองตำแหน่ง ให้ใช้ค่าระหว่าง −1.64 และ −1.65 จึงได้ประมาณ 34.72 ถึง 34.70 เดือน

**4) แปลผลเป็นภาษาคน**

โรงงานควรกำหนดประกันประมาณ **34.71 เดือน** หรือราว 34.7 เดือน เพื่อให้แบตเตอรี่ที่เสียก่อนครบประกันมีไม่เกิน 5%

## วิธีอ่านตาราง

ใช้ตารางพื้นที่สะสมของการแจกแจงปกติมาตรฐาน (Cumulative Standard Normal) ในเอกสารตารางสอบ หน้า **p-16–p-17** ตารางนี้ให้พื้นที่ซ้าย `P(Z<z)`

- z บวก เช่น `2.16`: เปิด p-16, เลือกแถว `2.1` และคอลัมน์ `.06` ได้ `0.9846`
- z ลบ เช่น `−1.33`: เปิด p-17, เลือกแถว `−1.3` และคอลัมน์ `.03` ได้ `0.0918`
- ถ้าต้องการขวา: ทำ `1−พื้นที่ซ้าย` หรือใช้สมมาตร เช่น `P(Z>−2.16)=Φ(2.16)`
- ถ้าต้องการช่วง: ทำ `พื้นที่ซ้ายของขอบบน − พื้นที่ซ้ายของขอบล่าง`
- ถ้าตารางมีค่า 0.05 ทางซ้าย: หา z ประมาณ `−1.645`; ค่านี้อยู่ระหว่างแถว −1.6 คอลัมน์ .04 และ .05

## แบบฝึกหัดปิดหนังสือ

### คำถามเขียนตอบ

1. ความยาวสายไฟมี `μ=50` ซม. และ `σ=4` ซม. จงหาโอกาสที่สายไฟยาวกว่า 56 ซม.
2. น้ำหนักขวดมี `μ=500` กรัม และ `σ=20` กรัม ถ้าผลิต 200 ขวด คาดว่าจะมีกี่ขวดที่หนักระหว่าง 480 ถึง 520 กรัม
3. อายุหลอดไฟมี `μ=1,000` ชั่วโมง และ `σ=100` ชั่วโมง ถ้ารับประกันให้เสียก่อนกำหนดไม่เกิน 10% ควรรับประกันกี่ชั่วโมง (ใช้ z≈−1.28)

<details><summary>เปิดดูเฉลยคำถามเขียนตอบ</summary>

**ข้อ 1**

```text
z = (56−50)/4 = 6/4 = 1.50
P(X>56) = 1−Φ(1.50)
         = 1−0.9332
         = 0.0668
```

ตอบประมาณ 0.0668 หรือ 6.68%

**ข้อ 2**

```text
z₁ = (480−500)/20 = −1.00
z₂ = (520−500)/20 =  1.00
p = Φ(1.00)−Φ(−1.00)
  = 0.8413−0.1587
  = 0.6826
จำนวน = 200×0.6826 = 136.52 ≈ 137 ขวด
```

ตอบประมาณ 137 ขวด

**ข้อ 3**

```text
x = μ + zσ
  = 1000 + (−1.28)(100)
  = 1000 − 128
  = 872 ชั่วโมง
```

ตอบประมาณ 872 ชั่วโมง

## สรุปจำสั้น

- แปลงทุกหน่วยให้เหมือนกับหน่วยของ μ และ σ
- “มากกว่า” = หางขวา, “น้อยกว่า” = หางซ้าย, “ระหว่าง” = ลบพื้นที่สะสมสองขอบ
- ทำ `z=(x−μ)/σ` แล้วปัด z เป็น 2 ตำแหน่งก่อนอ่านตาราง
- ตาราง p-16–p-17 ให้พื้นที่ซ้าย
- ถ้าถามจำนวนชิ้น ใช้ `N×p`
- ถ้าหาค่าจริงจากเปอร์เซ็นต์ ใช้ `x=μ+zσ`
- 5% ทางซ้ายใช้ z ติดลบ
