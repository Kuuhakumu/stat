# แผนที่ทั้งวิชา: โรงงานน้ำขวดหนึ่งเรื่อง พาไปถึงข้อสอบ

## เป้าหมาย

- เห็นภาพว่าบท 4 ถึงบท 7 ต่อกันเป็นเรื่องเดียว ไม่ใช่สูตรคนละกอง
- อ่านโจทย์โรงงานแล้วบอกได้ว่าต้องไปบทหรือบทเรียนไหน
- รู้ว่าจากการนับข้อมูล เราค่อย ๆ ไปสู่การประมาณและการตรวจคำกล่าวอ้างได้อย่างไร
- ใช้แผนภาพนี้เป็นสารบัญ แล้วค่อยกดลิงก์ไปเรียนวิธีคำนวณละเอียด

## นึกภาพก่อน: วันหนึ่งที่โรงงานน้ำขวด

โรงงานเติมน้ำลงขวดวันละหลายพันขวด ผู้จัดการอยากตอบคำถามง่าย ๆ แต่สำคัญมาก

1. จากขวด 100 ขวด มีขวดชำรุดกี่ขวด และโอกาสจะเจอขวดชำรุดกี่ขวด
2. ในหนึ่งชั่วโมงมีเหตุขวดรั่วกี่ครั้ง
3. ปริมาณน้ำในขวดแต่ละใบกระจายมากน้อยแค่ไหน
4. ถ้าหยิบขวดมา 36 ใบ ค่าเฉลี่ยของ 36 ใบจะใกล้ค่าเฉลี่ยของทั้งโรงงานแค่ไหน
5. จากตัวอย่าง 36 ใบ เราจะประมาณค่าเฉลี่ยจริงของทั้งโรงงานเป็นช่วงได้อย่างไร
6. ถ้าโรงงานอ้างว่าเติมได้เฉลี่ย 500 ml เรามีหลักฐานพอจะค้านคำอ้างนี้หรือยัง

คำถามทั้งหกข้อใช้ข้อมูลชุดเดียวกัน แต่ใช้เครื่องมือคนละช่วง การรู้ว่า “กำลังถามเรื่องอะไร” สำคัญกว่าการรีบจำสูตร

## สัญลักษณ์ที่เจอระหว่างทาง

สัญลักษณ์จะโผล่ในบทถัด ๆ ไป จึงแนะนำให้รู้ชื่อและหน้าที่ไว้ก่อน

| สัญลักษณ์ | อ่านว่า | หมายถึงแบบภาษาคน |
|---|---|---|
| `X` | เอ็กซ์ตัวใหญ่ | จำนวนหรือค่าที่สุ่มได้ เช่น จำนวนขวดชำรุด |
| `x` | เอ็กซ์ตัวเล็ก | ค่าหนึ่งค่าที่เป็นไปได้ของ `X` |
| `n` | เอ็น | จำนวนขวดที่หยิบมาเป็นตัวอย่าง |
| `p` | พี | โอกาสหรือสัดส่วนจริงของสิ่งที่สนใจ เช่น สัดส่วนขวดชำรุด |
| `λ` | แลมบ์ดา | จำนวนเหตุการณ์เฉลี่ยในช่วงที่กำหนด เช่น ขวดรั่วต่อชั่วโมง |
| `μ` | มิว | ค่าเฉลี่ยจริงของประชากร เช่น ปริมาณน้ำเฉลี่ยของขวดทุกใบ |
| `σ` | ซิกมา | ส่วนเบี่ยงเบนมาตรฐานจริง บอกว่าค่าต่าง ๆ กระจายกว้างแค่ไหน |
| `x̄` | เอ็กซ์บาร์ | ค่าเฉลี่ยของตัวอย่างที่เราเก็บมา |
| `p̂` | พีแฮต | สัดส่วนที่คำนวณจากตัวอย่าง ไม่ใช่สัดส่วนจริงทั้งโรงงาน |
| `Z` | แซด | ค่าที่บอกว่าข้อมูลห่างจากค่าเฉลี่ยกี่ส่วนเบี่ยงเบนมาตรฐานในโค้งปกติ |
| `t` | ที | ค่าที่ใช้แทนแซดเมื่อเป็นตัวอย่างเล็กและไม่รู้ `σ` |
| `H₀` | เอชศูนย์ | คำกล่าวตั้งต้นที่ถือไว้ก่อน เช่น ค่าเฉลี่ยเท่ากับ 500 ml |
| `H₁` | เอชหนึ่ง | คำกล่าวที่เราต้องการหาหลักฐานสนับสนุน เช่น ค่าเฉลี่ยไม่เท่ากับ 500 ml |
| `α` | แอลฟา | ระดับความเสี่ยงที่ยอมให้ปฏิเสธ `H₀` ทั้งที่ `H₀` จริง |

เครื่องหมาย `≤` อ่านว่า “น้อยกว่าหรือเท่ากับ” และ `≥` อ่านว่า “มากกว่าหรือเท่ากับ” ส่วน `≠` อ่านว่า “ไม่เท่ากับ” เครื่องหมายเหล่านี้บอกทิศทางของช่วงหรือของคำถาม

## บท 4: การแจกแจงความน่าจะเป็น

**คำถามใหญ่ของบทนี้:** “ถ้าทำการสุ่มแบบนี้ ผลลัพธ์แต่ละแบบมีโอกาสเท่าไร?”

ในโรงงาน เราเริ่มจากสิ่งที่เกิดขึ้นหนึ่งครั้งหรือในช่วงเวลาหนึ่ง

- **ขวดชำรุดจากจำนวนขวดที่ตรวจคงที่**: ถ้ามีจำนวนครั้งแน่นอน แต่ละครั้งมีแค่ “ชำรุด/ไม่ชำรุด” และโอกาสเดิม ๆ ให้ไปเรื่องทวินาม
- **เหตุขวดรั่วในหนึ่งชั่วโมง**: ถ้านับจำนวนเหตุการณ์ในช่วงเวลา ให้ไปเรื่องปัวซอง
- **ปริมาณน้ำของขวดหนึ่งใบ**: ถ้าวัดได้ต่อเนื่อง เช่น 499.6 หรือ 500.2 ml ให้ดูการแจกแจงต่อเนื่องและโค้งปกติ
- **ตาราง Z**: ใช้แปลงค่าปริมาณน้ำให้เทียบกับโค้งปกติมาตรฐาน แล้วอ่านพื้นที่ความน่าจะเป็นจากตารางสอบ

## บท 5: การสุ่มตัวอย่างและการแจกแจงของตัวอย่าง

**คำถามใหญ่ของบทนี้:** “ถ้าหยิบขวดมาเป็นตัวอย่าง ค่าเฉลี่ยหรือสัดส่วนที่ได้จะแกว่งแค่ไหน?”

เราไม่มีเวลาวัดขวดทุกใบ จึงหยิบมา 36 ใบ ตัวเลขของ 36 ใบเป็นเพียงตัวอย่าง ตัวอย่างคนละชุดอาจได้ค่าเฉลี่ยไม่เท่ากัน บทนี้สอนตั้งแต่เลือกตัวอย่าง ไปจนถึงดูการกระจายของค่าเฉลี่ยและสัดส่วนจากตัวอย่าง

- เรียกขวดทุกใบที่โรงงานผลิตว่า **ประชากร** และ 36 ใบที่หยิบมาว่า **ตัวอย่าง**
- ค่าที่บอกทั้งโรงงาน เช่น `μ` หรือ `p` เป็นค่าประชากร เรามักไม่รู้ตรง ๆ
- ค่าที่คำนวณจาก 36 ใบ เช่น `x̄` หรือ `p̂` เป็นค่าสถิติ เราใช้เป็นเบาะแสของค่าประชากร
- เมื่อ `n = 36` เราจะเห็นแนวคิดลิมิตสู่ส่วนกลาง (Central Limit Theorem) ช่วยให้การกระจายของค่าเฉลี่ยใกล้โค้งปกติในหลายกรณี
- ถ้าตัวอย่างเล็กและไม่รู้ส่วนเบี่ยงเบนมาตรฐานจริง จะเจอการแจกแจง `t`

## บท 6: การประมาณค่า

**คำถามใหญ่ของบทนี้:** “จาก 36 ขวด เราจะบอกค่าเฉลี่ยจริงของขวดทุกใบเป็นค่าหรือเป็นช่วงได้อย่างไร?”

สมมติ 36 ขวดมี `x̄` ใกล้ 499.6 ml เรารู้ว่าค่านี้ไม่ตรงกับ `μ` ทุกครั้ง จึงรายงานเป็นช่วงที่มีความเชื่อมั่น เช่น ช่วงที่คาดว่าครอบคลุมค่าเฉลี่ยจริง การเลือกใช้ `Z` หรือ `t` ขึ้นกับขนาดตัวอย่างและรู้ `σ` หรือไม่

- **ค่าประมาณจุด**: ใช้ตัวเลขเดียวจากตัวอย่างเป็นค่าประมาณ เช่น ใช้ `x̄` แทน `μ`
- **ช่วงความเชื่อมั่น (Confidence interval)**: ใช้ค่าประมาณบวกและลบความคลาดเคลื่อน เพื่อให้ได้ช่วงล่างถึงช่วงบน
- ถ้าถามสัดส่วนขวดชำรุด ให้ใช้ `p̂` เป็นจุดเริ่ม แล้วทำช่วงให้ `p`
- ถ้าถามสองสายการผลิต ให้สร้างช่วงของผลต่างค่าเฉลี่ยหรือผลต่างสัดส่วน

## บท 7: การทดสอบสมมติฐาน

**คำถามใหญ่ของบทนี้:** “หลักฐานจาก 36 ขวดแรงพอให้ปฏิเสธคำอ้างของโรงงานหรือยัง?”

ผู้จัดการอ้างว่า `μ = 500 ml` เราตั้ง `H₀` เป็นคำกล่าวตั้งต้น แล้วตั้ง `H₁` เป็นสิ่งที่ต้องการตรวจ เช่น “ค่าเฉลี่ยน้อยกว่า 500” หรือ “ไม่เท่ากับ 500” จากนั้นเลือกสถิติทดสอบ อ่านค่าจากตาราง และเทียบกับ `α`

- คำว่า **มากกว่า** มักพาไปหางขวา คำว่า **น้อยกว่า** พาไปหางซ้าย และคำว่า **แตกต่าง/ไม่เท่ากัน** ใช้สองหาง
- ค่าเฉลี่ยหนึ่งกลุ่มอาจใช้ `Z` หรือ `t` ตามข้อมูลที่มี
- สองกลุ่มที่เป็นคนละขวดใช้กรณีอิสระ ถ้าเป็นขวดคู่เดียวกันก่อนและหลังการปรับเครื่องจักร ให้ใช้กรณีจับคู่
- สัดส่วนของสองสายการผลิตใช้บททดสอบสัดส่วนสองประชากร
- สรุปว่า “ไม่ปฏิเสธ `H₀`” ยังไม่ใช่การพิสูจน์ว่า `H₀` จริง แปลว่า หลักฐานยังไม่แรงพอตาม `α`

ตัวอย่างนี้เป็นแผนที่การเลือกบท ไม่ใช่บทคำนวณเต็ม ให้ตามคำถามของโรงงานทีละขั้น

### ขั้นที่ 1: ขวด 120 ใบ มีชำรุดกี่ใบ

1. **โจทย์ถามอะไร / มีข้อมูลอะไร:** ตรวจขวด 120 ใบ แล้วนับจำนวนชำรุด
2. **คำใบ้และวิธี:** เป็นการนับผลสำเร็จจากจำนวนครั้งคงที่ จึงไป [ทวินาม](04-binomial.md)
3. **คำนวณที่บทนั้น:** ระบุจำนวนครั้ง `n` โอกาสชำรุด `p` และจำนวนที่ต้องการนับ `X`
4. **แปลเป็นภาษาคน:** ได้โอกาสที่ใน 120 ใบจะชำรุดตามจำนวนที่โจทย์ถาม

### ขั้นที่ 2: ในหนึ่งชั่วโมงเกิดรั่ว 3 ครั้ง

1. **โจทย์ถามอะไร / มีข้อมูลอะไร:** นับเหตุรั่วในช่วงเวลาหนึ่ง ไม่ได้กำหนดจำนวนการตรวจเป็นครั้ง ๆ
2. **คำใบ้และวิธี:** เป็นจำนวนเหตุการณ์ต่อช่วงเวลา จึงไป [ปัวซอง](05-poisson.md)
3. **คำนวณที่บทนั้น:** ใช้ `λ` เป็นจำนวนเหตุเฉลี่ยต่อชั่วโมง แล้วดูโอกาสของจำนวนเหตุที่โจทย์ถาม
4. **แปลเป็นภาษาคน:** บอกได้ว่าในหนึ่งชั่วโมง โอกาสเกิดรั่ว 0 ครั้ง 1 ครั้ง หรือหลายครั้งเป็นเท่าไร

### ขั้นที่ 3: ค่าเฉลี่ยของขวด 36 ใบคือ 499.6 ml

1. **โจทย์ถามอะไร / มีข้อมูลอะไร:** ต้องการใช้ตัวอย่าง 36 ใบพูดถึงขวดทุกใบ
2. **คำใบ้และวิธี:** แยกก่อนว่าโจทย์ถามการแกว่งของตัวอย่าง ให้ไป [การแจกแจงค่าเฉลี่ยตัวอย่าง](11-sampling-distribution-of-mean.md) หรือถามช่วงของค่าเฉลี่ยจริง ให้ไป [ช่วงความเชื่อมั่นค่าเฉลี่ยหนึ่งประชากร](17-ci-one-mean.md)
3. **คำนวณที่บทนั้น:** ใช้ `x̄` ของ 36 ใบ และข้อมูลการกระจายที่โจทย์ให้ เพื่อหาความคลาดเคลื่อนหรือขอบช่วง
4. **แปลเป็นภาษาคน:** เราไม่ได้บอกว่าขวดทุกใบมี 499.6 ml แต่บอกว่าค่าเฉลี่ยจริงน่าจะอยู่ช่วงใด

### ขั้นที่ 4: ตรวจคำอ้างว่าเฉลี่ย 500 ml

1. **โจทย์ถามอะไร / มีข้อมูลอะไร:** ต้องการตัดสินคำกล่าวอ้างของโรงงานจากตัวอย่าง 36 ใบ
2. **คำใบ้และวิธี:** คำว่า “ตรวจคำอ้าง” ให้ไป [แนวคิดการทดสอบสมมติฐาน](22-hypothesis-testing-idea.md) แล้วเลือกบททดสอบค่าเฉลี่ย
3. **คำนวณที่บทนั้น:** ตั้ง `H₀` และ `H₁` เลือก `Z` หรือ `t` หา `α` และเปรียบเทียบค่าสถิติทดสอบกับค่าจากตาราง
4. **แปลเป็นภาษาคน:** ตัดสินว่าหลักฐานพอให้ปฏิเสธคำอ้างที่ระดับความเสี่ยงที่กำหนดหรือยัง
