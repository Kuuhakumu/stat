# บทที่ 04: ทวินาม นับจำนวนครั้งที่สำเร็จ

## เป้าหมาย

- หลังจบบทนี้คุณจะเช็กได้ว่าโจทย์เหมาะกับทวินามหรือไม่
- หลังจบบทนี้คุณจะหาความน่าจะเป็นที่สำเร็จพอดีจำนวนหนึ่งได้
- หลังจบบทนี้คุณจะอ่านตารางสะสมและแปลงคำว่า อย่างน้อย มากกว่า และช่วง ได้
- หลังจบบทนี้คุณจะหาค่าเฉลี่ยและความแปรปรวนของจำนวนครั้งที่สำเร็จได้

## นึกภาพก่อน

ลองตรวจสินค้าทีละชิ้น โดยแต่ละชิ้นมีแค่สองผล: ผ่านหรือไม่ผ่าน ถ้าตรวจไว้ 10 ชิ้น เรารู้จำนวนชิ้นทั้งหมด แต่ยังไม่รู้ว่าจะผ่านกี่ชิ้น

การแจกแจงทวินาม (Binomial distribution) ใช้หาความน่าจะเป็นของจำนวนครั้งที่ได้ผลที่เราสนใจ เช่น ผ่านกี่ชิ้น หรือหายกี่คน มันต่อยอดจากเบอร์นูลลีที่เรียนบทก่อน: เบอร์นูลลีมองหนึ่งครั้ง ส่วนทวินามนับผลสำเร็จจากหลายครั้ง

## เช็ก 4 เงื่อนไขก่อนใช้

นึกถึงการโยนเหรียญหลายครั้ง แต่ละครั้งมีแค่หัวหรือก้อย เราจะนับจำนวนหัวได้เมื่อเงื่อนไขเหล่านี้เป็นจริง:

1. รู้จำนวนครั้งทั้งหมดล่วงหน้า และจำนวนนี้ไม่เปลี่ยน
2. แต่ละครั้งมีผลได้แค่สองแบบ: สำเร็จหรือไม่สำเร็จ
3. โอกาสสำเร็จเท่ากันทุกครั้ง
4. ผลของแต่ละครั้งไม่ไปเปลี่ยนโอกาสของครั้งอื่น หรือพูดว่าแต่ละครั้งเป็นอิสระกัน

ถ้าข้อใดไม่จริง อย่ารีบใช้สูตรทวินาม ให้กลับไปดูว่าตัวแปรสุ่มของโจทย์นับอะไร

ก่อนใช้สูตร ให้รู้จักสัญลักษณ์เหล่านี้:

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `X` | เอ็กซ์ตัวใหญ่ | จำนวนครั้งที่สำเร็จจากการทดลองทั้งหมด |
| `x` | เอ็กซ์ตัวเล็ก | จำนวนสำเร็จที่โจทย์กำลังถาม |
| `Yᵢ` | วายไอ | ตัวชี้วัดของการทดลองครั้งที่ `i` มีค่า 1 เมื่อสำเร็จ และ 0 เมื่อไม่สำเร็จ |
| `i` | ไอ | เลขลำดับของการทดลอง ตั้งแต่ 1 ถึง `n` |
| `Σ` | ซิกมา | ให้บวกค่าตามลำดับที่กำกับไว้ |
| `n` | เอ็น | จำนวนครั้งที่ทดลองทั้งหมด |
| `p` | พี | โอกาสสำเร็จในแต่ละครั้ง |
| `q` | คิว | โอกาสไม่สำเร็จในแต่ละครั้ง โดย `q=1−p` เสมอ |
| `P( )` | พีของ | โอกาสที่เหตุการณ์ในวงเล็บเกิดขึ้น |
| `=` | เท่ากับ | สองข้างมีค่าเท่ากัน |
| `−` | ลบ | นำค่าหลังเครื่องหมายออกจากค่าก่อนหน้า |
| `+` | บวก | รวมค่าตั้งแต่สองค่าขึ้นไป |
| `%` | เปอร์เซ็นต์ | จำนวนส่วนจาก 100 เช่น 25% คือ 25/100 |
| `…` | จุดไข่ปลา | บอกว่าลำดับตัวเลขยังต่อไปตามแบบเดิม |

ในสไลด์ p-12 ใช้ `Yᵢ` แทนผลของการทดลองครั้งที่ `i` แต่ตัวแปรที่เรานับจริง ๆ คือผลรวมของทุกครั้ง:

```text
X = Σᵢ₌₁ⁿ Yᵢ
```

`Σ` อ่านว่า “ซิกมา” = ให้บวกตั้งแต่ครั้งที่ 1 ถึงครั้งที่ `n` ดังนั้น `X` จึงเป็นจำนวนครั้งที่สำเร็จทั้งหมด ไม่ใช่รายการ `Y₁,Y₂,…,Yₙ` ที่ยังไม่ได้บวก

## สูตรหาจำนวนที่สำเร็จพอดี

เมื่อทั้ง 4 เงื่อนไขผ่าน เราเลือกได้ว่าใน `n` ครั้ง จะให้มีครั้งไหนสำเร็จบ้าง แล้วคูณโอกาสของรูปแบบนั้น สูตรจึงมีทั้งจำนวนวิธีเลือกและโอกาสของผลแต่ละครั้ง

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `C(n,x)` หรือ `ⁿCₓ` | เอ็นเลือกเอ็กซ์ | จำนวนวิธีเลือก x ครั้งจาก n ครั้งให้สำเร็จ |
| `!` | แฟกทอเรียล | คูณจำนวนเต็มลดลงไปจนถึง 1 เช่น `4! = 4×3×2×1` |
| `pˣ` | พียกกำลังเอ็กซ์ | โอกาสสำเร็จ x ครั้งคูณกัน |
| `qⁿ⁻ˣ` | คิวยกกำลังเอ็นลบเอ็กซ์ | โอกาสไม่สำเร็จในครั้งที่เหลือ |
| `×` | คูณ | นำค่ามาคูณกัน |
| `/` | หาร | นำค่าด้านบนหารด้วยค่าด้านล่าง |
| `≈` | ประมาณเท่ากับ | ค่าที่ปัดแล้วใกล้กับค่าจริง |

```text
P(X=x) = C(n,x) pˣqⁿ⁻ˣ
C(n,x) = n! / [x!(n−x)!]
```

ในบท 02 เราประกาศว่า `q=1−p` ดังนั้นบทนี้เขียน `q` แทน `1−p` ในสูตรทุกครั้ง

`P(X=x)` อ่านว่า “โอกาสที่เอ็กซ์เท่ากับเอ็กซ์ตัวเล็ก” หมายถึงโอกาสสำเร็จพอดี x ครั้ง ค่า x ต้องเป็นจำนวนเต็มตั้งแต่ 0 ถึง n

> ⚠️ หัวข้อทวินามบนสไลด์ CH4 หน้า 12 เขียนเลข `3.3` แต่ลำดับหัวข้อควรเป็น `1.3` น่าจะเป็นเลขหัวข้อพิมพ์ผิด

> ⚠️ สไลด์หน้า p-12 เขียน `X=Y₁,Y₂,…,Yₙ` เหมือนเป็นรายการค่า แต่ถ้าจะสื่อ “จำนวนสำเร็จ” ต้องเป็น `X=Σᵢ₌₁ⁿYᵢ` ตามคำอธิบายข้างบน

ตัวอย่างสั้น ๆ: ถ้าโยนเหรียญ 4 ครั้งแล้วถามว่าหัวพอดี 2 ครั้ง เราเลือกตำแหน่งของหัวได้ `C(4,2)=6` แบบ แต่ละแบบมีโอกาส `(1/2)²(1/2)²` จึงต้องนับทั้ง 6 แบบ ไม่ใช่นับแค่ “หัวสองครั้งแรก” แบบเดียว

## ค่าเฉลี่ยและความแปรปรวน

ถ้าทำการทดลองแบบเดิมซ้ำไปเรื่อย ๆ จำนวนสำเร็จเฉลี่ยจะเข้าใกล้ `n` คูณโอกาสสำเร็จต่อครั้ง ส่วนความแปรปรวนบอกว่าจำนวนสำเร็จแกว่งจากค่าเฉลี่ยแค่ไหน

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `μ` | มิว | ค่าเฉลี่ยจำนวนครั้งที่สำเร็จ |
| `E(X)` | อีของเอ็กซ์ | ค่าเฉลี่ยหรือค่าคาดหมายของ X |
| `σ²` | ซิกมากำลังสอง | ความแปรปรวนของจำนวนครั้งที่สำเร็จ |
| `Var(X)` | แวเรียนซ์ของเอ็กซ์ | อีกชื่อของความแปรปรวน |
| `n` | เอ็น | จำนวนครั้งที่ทดลองทั้งหมด |
| `p` | พี | โอกาสสำเร็จต่อครั้ง |

```text
μ = E(X) = np
σ² = Var(X) = npq
```

## วิธีอ่านตารางทวินาม

หนังสือตารางสอบมีตารางสะสมทวินาม (Cumulative Binomial Probability Distribution) อยู่หน้า 1–11 ตารางแต่ละช่องให้โอกาสสะสมจากศูนย์ถึงค่าที่เลือก ไม่ได้ให้โอกาสของค่านั้นค่าเดียว

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `F(r)` | เอฟของอาร์ | โอกาสสะสมจาก 0 ถึง r |
| `r` | อาร์ | ค่าสูงสุดที่รวมในโอกาสสะสม |
| `≤` | น้อยกว่าหรือเท่ากับ | รวมค่านั้นด้วย |
| `≥` | มากกว่าหรือเท่ากับ | รวมค่านั้นด้วย |
| `<` | น้อยกว่า | ไม่รวมค่านั้น |
| `>` | มากกว่า | ไม่รวมค่านั้น |
| `a`, `b` | เอ, บี | ขอบล่างและขอบบนของช่วง |

```text
F(r) = P(X≤r)
```

`P(X≤r)` อ่านว่า “โอกาสที่ X ไม่เกิน r” คือรวมกรณี `X=0,1,2,…,r` เข้าด้วยกัน ในภาพประกอบสไลด์ CH4 หน้า 15 พื้นที่ที่ระบายสีเริ่มจาก 0 แล้วจบที่ r

วิธีเปิดตาราง:

1. หาแถวกลุ่ม `n` ให้ตรงกับจำนวนครั้งทั้งหมด
2. ในกลุ่มนั้นหาแถว `x` ซึ่งทำหน้าที่เป็นค่า r ที่เราต้องการ
3. ไล่ไปยังคอลัมน์ `p` ที่ตรงกับโอกาสสำเร็จ
4. อ่านตัวเลข 4 ตำแหน่ง ตารางมี `n` ตั้งแต่ 2 ถึง 25 และ `p` ตั้งแต่ 0.05 ถึง 0.50

แปลงคำถามเป็นค่าจากตารางแบบนี้:

| โจทย์ถาม | แปลงเป็นตารางสะสม |
|---|---|
| `P(X=x)` สำเร็จพอดี x ครั้ง | `F(x)−F(x−1)`; ถ้า x=0 ให้ใช้ `F(−1)=0` |
| `P(X≥r)` อย่างน้อย r ครั้ง | `1−F(r−1)` |
| `P(X>r)` มากกว่า r ครั้ง | `1−F(r)` |
| `P(X<r)` น้อยกว่า r ครั้ง | `F(r−1)` |
| `P(a≤X≤b)` ตั้งแต่ a ถึง b รวมปลายทั้งคู่ | `F(b)−F(a−1)` |

ในตาราง `P(X≤r)` ให้รวมแถวศูนย์ถึงแถว r แม้หัวแถวพิมพ์เป็น `x` ก็ตาม หัวแถวนั้นคือจุดหยุดของผลรวมสะสม ไม่ใช่คำตอบ `P(X=x)` โดยตรง

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 4.4 (สไลด์ CH4 หน้า 14): โยนลูกเต๋า 5 ครั้ง

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** โยนลูกเต๋าเที่ยงตรง 5 ครั้ง หาโอกาสได้แต้ม 1 ในครั้งแรกและครั้งสุดท้าย, ได้แต้ม 1 พอดี 2 ครั้ง, ได้แต้ม 1 อย่างมาก 2 ครั้ง และหาจำนวนครั้งเฉลี่ยที่ได้แต้ม 1
2. **คำใบ้บอกวิธีไหน:** แต่ละการโยนมีโอกาสได้ 1 เท่ากับ `1/6` และมีทั้งหมด 5 ครั้ง จึงนับจำนวนครั้งที่ได้ 1 ด้วยทวินาม ส่วนข้อแรกกำหนดแค่ครั้งแรกกับครั้งสุดท้าย ไม่ได้ห้ามได้ 1 ตรงกลาง
3. **คำนวณทีละบรรทัด:**

```text
(1) P(ได้ 1 ครั้งแรกและครั้งสุดท้าย)
  = 1/6 × 1/6
  = 1/36 ≈ 0.0278

(2) P(X=2) = C(5,2)(1/6)²(5/6)³
  C(5,2) = 5!/[2!3!] = (5×4)/(2×1) = 10
  = 10 × (1/36) × (125/216)
  = 1250/7776 ≈ 0.160751 ≈ 0.1608

(3) P(X≤2) = P(X=0)+P(X=1)+P(X=2)
  = (5/6)⁵ + 5(1/6)(5/6)⁴ + 10(1/6)²(5/6)³
  = 3125/7776 + 3125/7776 + 1250/7776
  = 7500/7776 ≈ 0.964506 ≈ 0.9645

(4) μ = np = 5 × (1/6) = 5/6 ≈ 0.8333 ครั้ง
```

4. **แปลผลเป็นภาษาคน:** โอกาสได้แต้ม 1 ที่การโยนแรกและครั้งสุดท้ายคือประมาณ 0.0278; โอกาสได้แต้ม 1 รวมพอดีสองครั้งคือ 0.1608; อย่างมากสองครั้งคือ 0.9645 และค่าเฉลี่ยระยะยาวคือประมาณ 0.8333 ครั้งต่อการโยน 5 ครั้ง

### EX 4.5 (สไลด์ CH4 หน้า 16): ยาชนิด A

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** โอกาสคนหนึ่งหายเท่ากับ 0.40 ใช้ยากับ 20 คน หาโอกาสหายอย่างน้อย 10 คน, ตั้งแต่ 3 ถึง 8 คน และพอดี 5 คน
2. **คำใบ้บอกวิธีไหน:** จำนวนคนคงที่ ผลมีสองแบบ โอกาสหายเท่ากัน และถือว่าแต่ละคนเป็นอิสระ จึงใช้ทวินาม `n=20`, `p=0.40` แล้วอ่านค่าจากตารางสะสม
3. **คำนวณทีละบรรทัด:** เลือกกลุ่มแถว `n=20` แล้วอ่านคอลัมน์ `p=0.40` ได้ `F(9)=0.7553`, `F(8)=0.5956`, `F(2)=0.0036`, `F(5)=0.1256`, `F(4)=0.0510` ตามที่พิมพ์ในตารางสอบ

```text
(1) P(X≥10) = 1−F(9) = 1−0.7553 = 0.2447
(2) P(3≤X≤8) = F(8)−F(2) = 0.5956−0.0036 = 0.5920
(3) P(X=5) = F(5)−F(4) = 0.1256−0.0510 = 0.0746
```

4. **แปลผลเป็นภาษาคน:** โอกาสมีคนหายอย่างน้อย 10 คนคือ 0.2447; โอกาสมีคนหายตั้งแต่ 3 ถึง 8 คนคือ 0.5920; และโอกาสมีคนหายพอดี 5 คนคือ 0.0746

### EX 4.6 (สไลด์ CH4 หน้า 17): น้ำบาดาลเป็นน้ำกระด้าง

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** แต่ละจุดมีโอกาสเจอน้ำกระด้าง 25% ขุด 12 จุด หาโอกาสอย่างน้อย 6 จุด, อย่างมาก 3 จุด และพอดี 5 จุด
2. **คำใบ้บอกวิธีไหน:** จำนวนจุดคงที่ มีสองผล โอกาสเท่ากัน และถือว่าแต่ละจุดเป็นอิสระ จึงใช้ทวินาม `n=12`, `p=0.25`
3. **คำนวณทีละบรรทัด:** จากตารางสอบแถว `n=12`, คอลัมน์ `p=0.25` ได้ `F(5)=0.9456`, `F(3)=0.6488` และ `F(4)=0.8424`

```text
(1) P(X≥6) = 1−F(5) = 1−0.9456 = 0.0544
(2) P(X≤3) = F(3) = 0.6488
(3) P(X=5) = F(5)−F(4) = 0.9456−0.8424 = 0.1032
```

4. **แปลผลเป็นภาษาคน:** โอกาสเจอน้ำกระด้างอย่างน้อย 6 จุดคือ 0.0544; อย่างมาก 3 จุดคือ 0.6488; และพอดี 5 จุดคือ 0.1032

### EX 4.7 (สไลด์ CH4 หน้า 18): กำไรจากเครื่องจักรขัดข้อง

1. **โจทย์ถามอะไร / ข้อมูลที่มี:** โรงงานทำงาน 5 วัน เครื่องจักรขัดข้องในแต่ละวันด้วยโอกาส 0.05; ถ้าไม่ขัดข้องเลยได้ 10,000 บาท, ขัดข้อง 1–2 ครั้งได้ 7,000 บาท และตั้งแต่ 3 ครั้งขึ้นไปขาดทุน 4,000 บาท ต้องหากำไรเฉลี่ยต่อสัปดาห์
2. **คำใบ้บอกวิธีไหน:** จำนวนวันคงที่และโอกาสขัดข้องเท่ากัน จึงให้ X เป็นจำนวนวันที่เครื่องขัดข้อง ใช้ทวินาม `n=5`, `p=0.05` แล้วเฉลี่ยกำไรตามโอกาสของแต่ละช่วง
3. **คำนวณทีละบรรทัด:** ตารางสอบให้ `F(0)=0.7738` และ `F(2)=0.9988` ที่ `n=5`, `p=0.05`

```text
P(X=0) = F(0) = 0.7738
P(1≤X≤2) = F(2)−F(0) = 0.9988−0.7738 = 0.2250
P(X≥3) = 1−F(2) = 1−0.9988 = 0.0012

กำไรเฉลี่ย
= 10,000(0.7738) + 7,000(0.2250) − 4,000(0.0012)
= 7,738 + 1,575 − 4.80
= 9,308.20 บาทต่อสัปดาห์
```

4. **แปลผลเป็นภาษาคน:** เมื่อใช้ค่าที่ปัดไว้ 4 ตำแหน่งตามตารางสอบ กำไรเฉลี่ยประมาณ 9,308.20 บาทต่อสัปดาห์

> ตารางพิมพ์ค่าเป็นทศนิยม 4 ตำแหน่ง จึงได้ 9,308.20 บาท; ถ้าคิดจากความน่าจะเป็นเต็มก่อนปัด จะได้ประมาณ 9,308.60 บาท

## กับดักในข้อสอบ

- “อย่างน้อย 10” คือ `X≥10` จึงใช้ `1−F(9)`; อย่าลบ `F(10)` เพราะจะขาดกรณี 10
- “มากกว่า 3” คือ `X>3` จึงใช้ `1−F(3)`; ส่วน “อย่างน้อย 3” คือ `1−F(2)`
- “ตั้งแต่ 3 ถึง 8” รวมทั้ง 3 และ 8 จึงใช้ `F(8)−F(2)`
- “พอดี x” ต้องเอาค่าสะสมที่ x ลบค่าสะสมที่ x−1; ช่อง x ช่องเดียวไม่ใช่ `P(X=x)`
- อย่าลืม `C(n,x)` เมื่อใช้สูตรตรง ๆ; ถ้าลืมจะนับแค่ลำดับสำเร็จแบบเดียว
- `n` คือจำนวนทดลองทั้งหมด ส่วน `x` คือจำนวนสำเร็จที่ถาม
- กำหนดให้ชัดว่าอะไรคือ “สำเร็จ” เพื่อให้ `p` ตรงกับโจทย์
- ข้อ EX 4.4 ถามว่าได้แต้ม 1 ครั้งแรกและครั้งสุดท้าย ไม่ได้บอกว่าห้ามได้แต้ม 1 ตรงกลาง
- ห้ามอ่านค่าตารางสะสมเป็นความน่าจะเป็นพอดีค่า

## แบบฝึกหัดปิดหนังสือ

ลองทำโจทย์ก่อนเปิดเฉลย ตัวเลขในโจทย์ฝึกเป็นชุดใหม่ ไม่ซ้ำกับตัวอย่างจากสไลด์

1. **เขียนตอบ:** เครื่องหนึ่งตรวจชิ้นงาน 6 ชิ้น โอกาสที่ชิ้นหนึ่งผ่านคือ 0.30 จงหาโอกาสผ่านพอดี 2 ชิ้น ค่าเฉลี่ย และความแปรปรวน
2. **เขียนตอบ:** รถมาถึงป้ายตรงเวลาต่อเที่ยวด้วยโอกาส 0.25 ใน 8 เที่ยว จงหาโอกาสมาตรงเวลาอย่างน้อย 3 เที่ยว
3. **เขียนตอบ:** ลูกค้า 10 คนแต่ละคนซื้อสินค้าด้วยโอกาส 0.20 จงหาโอกาสที่มีคนซื้อ 2 ถึง 5 คน รวมขอบทั้งสอง
4. **ปรนัย:** ถ้าทำ 7 ครั้ง แต่ละครั้งสำเร็จด้วยโอกาส 0.20 โอกาสสำเร็จอย่างมาก 2 ครั้งเท่าไร? ก. 0.2753 ข. 0.4233 ค. 0.8520 ง. 0.9667
5. **ปรนัย:** ทำการทดลอง 4 ครั้ง โอกาสสำเร็จครั้งละ 0.40 โอกาสสำเร็จมากกว่า 1 ครั้งเท่าไร? ก. 0.4752 ข. 0.5248 ค. 0.8704 ง. 0.3456
6. **ปรนัย:** ทำการทดลอง 9 ครั้ง โอกาสสำเร็จครั้งละ 0.30 โอกาสสำเร็จพอดี 3 ครั้งเท่าไร? ก. 0.0032 ข. 0.2668 ค. 0.4628 ง. 0.7297

**ข้อ 1** ใช้ทวินาม `n=6`, `p=0.30`, `x=2`

```text
C(6,2) = 6!/[2!4!] = (6×5)/(2×1) = 15
P(X=2) = 15(0.30)²(0.70)⁴
       = 15(0.09)(0.2401)
       = 0.324135 ≈ 0.3241
μ = np = 6(0.30) = 1.8 ครั้ง
σ² = npq = 6(0.30)(0.70) = 1.26
```

โอกาสผ่านพอดี 2 ชิ้นคือ 0.3241; ค่าเฉลี่ย 1.8 ชิ้น และความแปรปรวน 1.26

**ข้อ 2** ให้ X เป็นจำนวนเที่ยวที่มาตรงเวลา `n=8`, `p=0.25`; อย่างน้อย 3 คือส่วนที่เหลือหลังหัก 0, 1, 2 เที่ยว

```text
P(X≥3) = 1−[P(X=0)+P(X=1)+P(X=2)]
P(X=0) = (0.75)⁸ = 0.100112915
P(X=1) = 8(0.25)(0.75)⁷ = 0.266967773
P(X=2) = C(8,2)(0.25)²(0.75)⁶
       = 28(0.0625)(0.177978516) = 0.311462402
P(X≥3) = 1−(0.100112915+0.266967773+0.311462402)
       = 1−0.678543090 = 0.321456910 ≈ 0.3215
```

โอกาสที่รถมาตรงเวลาอย่างน้อย 3 เที่ยวคือประมาณ 0.3215

**ข้อ 3** ให้ X เป็นจำนวนลูกค้าที่ซื้อ `n=10`, `p=0.20`; รวมตั้งแต่ 2 ถึง 5 จึงบวกค่าพอดี 2, 3, 4 และ 5

```text
P(X=2) = C(10,2)(0.20)²(0.80)⁸ = 45(0.04)(0.16777216) = 0.301989888
P(X=3) = C(10,3)(0.20)³(0.80)⁷ = 120(0.008)(0.2097152) = 0.201326592
P(X=4) = C(10,4)(0.20)⁴(0.80)⁶ = 210(0.0016)(0.262144) = 0.088080384

          = 0.617820979 ≈ 0.6178
```

โอกาสมีลูกค้าซื้อ 2 ถึง 5 คนคือประมาณ 0.6178

**ข้อ 4: ค. 0.8520** ใช้ค่าพอดี 0, 1, 2 แล้วบวกกัน เพราะถาม “อย่างมาก 2”

```text
P(X≤2) = (0.8)⁷ + 7(0.2)(0.8)⁶ + C(7,2)(0.2)²(0.8)⁵
       = 0.2097152 + 0.3670016 + 0.2752512
       = 0.851968 ≈ 0.8520
```

**ข้อ 5: ข. 0.5248** มากกว่า 1 หมายถึง 2, 3 หรือ 4 ครั้ง จึงหักโอกาส 0 หรือ 1 ครั้งออกจาก 1

```text
P(X>1) = 1−P(X≤1)
P(X=0) = (0.6)⁴ = 0.1296
P(X=1) = 4(0.4)(0.6)³ = 0.3456
P(X>1) = 1−(0.1296+0.3456) = 1−0.4752 = 0.5248
```

ก. คือโอกาสไม่เกิน 1; ค. คืออย่างน้อย 1; ง. คือพอดี 2 ครั้ง จึงเป็นการอ่านคนละเหตุการณ์

## สรุปจำสั้น

- ทวินามใช้เมื่อจำนวนครั้งคงที่ มีสองผล โอกาสสำเร็จเท่าเดิม และแต่ละครั้งอิสระ
- `n` คือจำนวนครั้งทั้งหมด, `p` คือโอกาสสำเร็จต่อครั้ง, `X` คือจำนวนสำเร็จ
- พอดี x ใช้ `C(n,x)pˣqⁿ⁻ˣ` โดย `q=1−p`
- ค่าเฉลี่ยคือ `np`; ความแปรปรวนคือ `npq`
- ตารางให้ `F(r)=P(X≤r)` จากศูนย์ถึง r
- อย่างน้อย r ใช้ `1−F(r−1)`; มากกว่า r ใช้ `1−F(r)`
- พอดี x ใช้ `F(x)−F(x−1)`; ช่วง a ถึง b ใช้ `F(b)−F(a−1)`
- ดูตัวเลขในตารางสอบให้ตรงทั้ง n, p และแถวจุดหยุด
