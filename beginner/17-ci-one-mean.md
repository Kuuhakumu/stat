# บทที่ 17: ช่วงความเชื่อมั่น (confidence interval) ของค่าเฉลี่ยหนึ่งประชากร

## เป้าหมาย

- เลือกวิธีทำช่วงความเชื่อมั่นของค่าเฉลี่ยประชากร (population mean) ได้ถูกตามข้อมูล
- แทนค่าลงสูตรและคำนวณขอบล่างกับขอบบนได้ทีละขั้น
- อ่านค่าวิกฤตจากตาราง Z และตาราง t ในข้อสอบได้

## ต้องรู้ก่อน

- [ค่าเฉลี่ยตัวอย่างก็มีการแจกแจงของมันเอง](11-sampling-distribution-of-mean.md) — ค่าเฉลี่ยตัวอย่างและส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยตัวอย่าง
- [การแจกแจงทีเมื่อตัวอย่างเล็ก](12-t-distribution.md) — ตาราง t และองศาความเป็นอิสระ
- [โค้งระฆังและตาราง Z](07-normal-and-z-table.md) — ตาราง Z และพื้นที่ใต้โค้ง
- [พื้นฐานการประมาณค่า](16-estimation-basics.md) — ความหมายของช่วงความเชื่อมั่นและระดับความเชื่อมั่น

## นึกภาพก่อน

นึกว่าโรงงานอยากรู้ว่าแบตเตอรี่รุ่นหนึ่งใช้ได้นานเฉลี่ยกี่ชั่วโมง แต่มีแบตเตอรี่เยอะมากจนวัดทุกก้อนไม่ไหว โรงงานจึงสุ่มมาวัดบางก้อนแล้วหาค่าเฉลี่ย

ค่าเฉลี่ยจากตัวอย่างเป็นเหมือนจุดเดา ถ้าสุ่มอีกชุดก็อาจได้ค่าไม่เท่ากัน ช่วงความเชื่อมั่นจึงเอาค่าเฉลี่ยที่คำนวณได้มาทำเป็นช่วงคร่าว ๆ ว่าค่าเฉลี่ยจริงของทั้งโรงงานน่าจะอยู่ตรงไหน

สูตรมีหน้าตาคล้ายกันทุกกรณี: เอาค่าเฉลี่ยตัวอย่างบวกและลบ “ระยะเผื่อ” ระยะเผื่อนี้ได้จากค่าวิกฤตคูณส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยตัวอย่าง

## สัญลักษณ์และกฎเลือกสูตร

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `μ` | มิว | ค่าเฉลี่ยจริงของประชากรที่เราต้องการประมาณ |
| `x̄` | เอ็กซ์บาร์ | ค่าเฉลี่ยที่คำนวณจากตัวอย่าง (sample mean) |
| `σ` | ซิกมา | ส่วนเบี่ยงเบนมาตรฐานจริงของประชากร (population standard deviation); โจทย์บอกเมื่อรู้ค่า |
| `σ²` | ซิกมากำลังสอง | ความแปรปรวนจริงของประชากร |
| `S` | เอส | ส่วนเบี่ยงเบนมาตรฐานตัวอย่าง (sample standard deviation) ใช้แทน `σ` เมื่อไม่รู้ค่า |
| `n` | เอ็น | จำนวนข้อมูลที่สุ่มมา (sample size) |
| `√n` | รากที่สองของเอ็น | รากที่สองของจำนวนข้อมูล |
| `Z` | แซดตัวใหญ่ | ค่าวิกฤตจากตารางโค้งปกติมาตรฐาน |
| `T` | ทีตัวใหญ่ | ค่าที่คำนวณเพื่อเทียบกับการแจกแจง t เมื่อไม่รู้ `σ` และตัวอย่างเล็ก |
| `t` | ทีตัวเล็ก | ค่าวิกฤตจากตารางการแจกแจง t (t distribution) |
| `α` | แอลฟา | โอกาสพลาดที่เหลืออยู่นอกช่วงความเชื่อมั่น |
| `Z_{α/2}` | แซดห้อยแอลฟาหารสอง | ค่าวิกฤต Z ที่แบ่งโอกาสพลาดครึ่งหนึ่งไว้ที่หางแต่ละข้าง |
| `t_{α/2,ν}` | ทีห้อยแอลฟาหารสองและนิว | ค่าวิกฤต t ที่เลือกจากค่า `α/2` และองศาความเป็นอิสระ |
| `ν` | นิว | องศาความเป็นอิสระ (degrees of freedom); กรณี t ของค่าเฉลี่ยหนึ่งกลุ่มเท่ากับ `n − 1` |
| `N(a,b)` | เอ็นของเอและบี | การแจกแจงปกติที่มีค่าเฉลี่ย `a` และความแปรปรวน `b` |
| `SE` | เอสอี | ส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยตัวอย่าง (standard error) หรือระยะที่ค่าเฉลี่ยตัวอย่างแกว่งโดยประมาณ |
| `E` | อี | ระยะเผื่อจากค่าเฉลี่ยตัวอย่างไปถึงขอบช่วง |
| `≥` | มากกว่าหรือเท่ากับ | รวมค่าที่เท่ากับเกณฑ์ด้วย |
| `<` | น้อยกว่า | ต่ำกว่าเกณฑ์และไม่รวมค่าเกณฑ์ |
| `±` | บวกหรือลบ | ใช้หาขอบล่างด้วยการลบ และขอบบนด้วยการบวก |
| `=` | เท่ากับ | ค่าทางซ้ายและขวามีค่าเดียวกัน |
| `−` | ลบ | หาผลต่างระหว่างสองค่า |
| `/`, `÷` | หาร | แบ่งค่าหนึ่งด้วยอีกค่าหนึ่ง |
| `×` | คูณ | คูณค่าหนึ่งกับอีกค่าหนึ่ง |
| `x²` | เอ็กซ์กำลังสอง | คูณค่าเอ็กซ์ด้วยตัวเอง ใช้ปุ่มนี้ตอนยกผลต่างกำลังสอง |
| `Z_{α/2}` | แซดห้อยแอลฟาหารสอง | ค่าวิกฤต Z ที่แบ่งโอกาสพลาดครึ่งหนึ่งไว้ที่หางแต่ละข้าง |
| `t_{α/2,ν}` | ทีห้อยแอลฟาหารสองและนิว | ค่าวิกฤต t ที่เลือกจากค่า `α/2` และองศาความเป็นอิสระ |

เวลาหาสูตร ให้ถามตามนี้ก่อน

```text
ต้องการช่วงของค่าเฉลี่ย μ
          |
          +-- รู้ σ หรือไม่?
                |
                +-- รู้ σ และประชากรมีการแจกแจงปกติ (normal distribution) -> ใช้ Z กับ σ/√n
                |
                +-- ไม่รู้ σ
                      |
                      +-- n ≥ 30 -> ใช้ Z กับ S/√n
                      |
                      +-- n < 30 และประชากรปกติ
                                      -> ใช้ t กับ ν = n − 1
```

ถ้าตัวอย่างเล็กและไม่รู้ `σ` ต้องมีเงื่อนไขว่าประชากรมีการแจกแจงปกติด้วย ถ้าโจทย์ไม่บอกเงื่อนไขนี้ ข้อมูลในสามกรณีของบทนี้ยังไม่พอให้เลือก t

## สูตรช่วงความเชื่อมั่น

หลักคือเอาค่าเฉลี่ยตัวอย่างบวกลบระยะเผื่อ โดยระยะเผื่อคือค่าวิกฤตคูณ `SE` ค่าวิกฤต (critical value) คือค่าที่อ่านจากตารางเพื่อกำหนดระยะเผื่อของช่วง

### รู้ส่วนเบี่ยงเบนมาตรฐานประชากร

ถ้าประชากรปกติและโจทย์ให้ `σ` มา ใช้ Z ได้แม้ `n` จะน้อยกว่า 30

ทฤษฎี 6.1 บอกว่า `x̄` มีการแจกแจง `N(μ, σ²/n)` และ
`Z = (x̄ − μ)/(σ/√n)` มีการแจกแจงปกติมาตรฐาน `N(0,1)`

```text
SE = σ/√n
E = Z_{α/2} × SE
ช่วงของ μ = x̄ ± E
```

แทน `E` ลงไปจะได้ `x̄ ± Z_{α/2}σ/√n`

### ไม่รู้ σ แต่ตัวอย่างใหญ่

ถ้าไม่รู้ `σ` และมีข้อมูลอย่างน้อย 30 ค่า ใช้ `S` ที่คำนวณจากตัวอย่าง แล้วใช้ Z

ทฤษฎี 6.2 ใช้ผลของตัวอย่างใหญ่ให้ `Z = (x̄ − μ)/(S/√n)` ใกล้เคียง `N(0,1)` จึงใช้ Z ได้ แม้ประชากรจะไม่ปกติ

```text
SE = S/√n
E = Z_{α/2} × SE
ช่วงของ μ = x̄ ± E
```

สูตรเต็มคือ `x̄ ± Z_{α/2}S/√n`

> ⚠️ สไลด์ CH6 p-12 หัวข้อเขียนว่า “ประชากรไม่มีการแจกแจงแบบปกติ” แต่ข้อความในทฤษฎี 6.2 บรรทัดถัดไปบอกว่าประชากรมีการแจกแจงแบบปกติ สองส่วนนี้ขัดกันเอง บทนี้ใช้กรณีตัวอย่างใหญ่ตามหัวข้อ: เมื่อ `n ≥ 30` ใช้ Z และแทน `σ` ที่ไม่รู้ด้วย `S` เพื่อประมาณการแกว่งของค่าเฉลี่ย

### ไม่รู้ σ และตัวอย่างเล็ก

ถ้าประชากรปกติ ไม่รู้ `σ` และ `n < 30` ใช้ t โดยองศาความเป็นอิสระคือ `ν = n − 1`

ทฤษฎี 6.3 บอกว่า `T = (x̄ − μ)/(S/√n)` มีการแจกแจง t ที่มีองศาอิสระ `ν = n − 1`

```text
SE = S/√n
ν = n − 1
E = t_{α/2,ν} × SE
ช่วงของ μ = x̄ ± E
```

สูตรเต็มคือ `x̄ ± t_{α/2,ν}S/√n`

## วิธีอ่านตาราง

ทุกตัวอย่างในบทนี้เป็นช่วงสองด้าน จึงแบ่งโอกาสพลาดครึ่งละ `α/2` ไปที่หางซ้ายและหางขวา

### ตาราง Z

ตาราง Z อยู่ที่ TABLES p-16 และ p-17 ในข้อสอบ ตารางแสดงพื้นที่สะสมทางซ้าย อ่านแถวเป็นหลักหน่วยกับทศนิยมตำแหน่งแรก แล้วอ่านคอลัมน์เป็นทศนิยมตำแหน่งที่สอง

เช่น ช่วง 95% มี `α = 0.05` จึงเหลือหางละ `0.025` และพื้นที่ทางซ้ายของค่าวิกฤตบวกคือ `0.9750` เปิด p-16 แถว `1.9` คอลัมน์ `0.06` จะพบ `0.9750` ดังนั้นใช้ `Z = 1.96`

ถ้าช่วง 99% พื้นที่ทางซ้ายคือ `0.9950` ตารางให้ `0.9949` ที่ `2.57` และ `0.9951` ที่ `2.58` จึงใช้ค่าที่พิมพ์ในตารางเป็น `Z = 2.58`

### ตาราง t

ตาราง t อยู่ที่ TABLES p-18 ใช้แถว `ν` และคอลัมน์ One-tail `α/2` ตัวอย่างเช่น ช่วง 99% มี `α/2 = 0.005`; ถ้า `ν = 9` ให้ดูแถว 9 คอลัมน์ `t₀.₉₉₅` จะได้ `3.250` ตามที่พิมพ์ในตาราง

## ตัวอย่างจากสไลด์ทำทีละขั้น

### EX 6.3 อายุหลอดไฟ (สไลด์ CH6 หน้า 11)

**1) โจทย์ถามอะไร / ข้อมูลที่มี**  ต้องการช่วงความเชื่อมั่น 99% ของอายุหลอดไฟ ประชากรปกติ รู้ `σ = 0.2`, สุ่มมา 15 หลอด และได้ข้อมูลหน่วยละ 10,000 ชั่วโมง: 1.3, 1.4, 1.2, 1.5, 1.5, 1.1, 1.4, 1.6, 1.3, 1.5, 1.5, 0.9, 1.1, 1.0, 1.8

**2) คำใบ้บอกให้ใช้วิธีไหน**  รู้ `σ` และประชากรปกติ จึงใช้ Z ได้ แม้ `n = 15` จะน้อยกว่า 30

**3) คำนวณทีละบรรทัด**

```text
รวมข้อมูล = 1.3 + 1.4 + 1.2 + 1.5 + 1.5 + 1.1 + 1.4 + 1.6
          + 1.3 + 1.5 + 1.5 + 0.9 + 1.1 + 1.0 + 1.8
          = 20.1
x̄ = 20.1 ÷ 15 = 1.34
α = 1 − 0.99 = 0.01
α/2 = 0.01 ÷ 2 = 0.005
Z = 2.58  (ตาราง Z p-16)
SE = 0.2 ÷ √15 = 0.05164
E = 2.58 × 0.05164 = 0.1332
ขอบล่าง = 1.34 − 0.1332 = 1.2068
ขอบบน   = 1.34 + 0.1332 = 1.4732
```

เครื่องคิดเลข: กด `0.2 ÷ √(15)` แล้วคูณคำตอบด้วย 2.58

**4) แปลผลเป็นภาษาคน**  ช่วงความเชื่อมั่น 99% ของอายุใช้งานเฉลี่ยอยู่ที่ประมาณ 1.2068 ถึง 1.4732 หน่วยละ 10,000 ชั่วโมง หรือประมาณ 12,068 ถึง 14,732 ชั่วโมง

### EX 6.4 ใยอาหารในน้ำผลไม้ (สไลด์ CH6 หน้า 13)

**1) โจทย์ถามอะไร / ข้อมูลที่มี**  ต้องการช่วงความเชื่อมั่น 95%; สุ่มน้ำผลไม้ 35 กล่อง ได้ค่าเฉลี่ย 22.25 กรัม และ `S = 3.57` กรัม

**2) คำใบ้บอกให้ใช้วิธีไหน**  ไม่รู้ `σ` แต่ `n = 35 ≥ 30` จึงใช้ Z และใช้ `S` แทน `σ`

**3) คำนวณทีละบรรทัด**

```text
α = 1 − 0.95 = 0.05
α/2 = 0.05 ÷ 2 = 0.025
Z = 1.96  (แถว 1.9 คอลัมน์ 0.06 ในตาราง Z p-16)
SE = 3.57 ÷ √35 = 0.60344
E = 1.96 × 0.60344 = 1.18274
ขอบล่าง = 22.25 − 1.18274 = 21.06726
ขอบบน   = 22.25 + 1.18274 = 23.43274
```

เครื่องคิดเลข: กด `3.57 ÷ √(35)`; คูณคำตอบด้วย `1.96` เพื่อได้ระยะเผื่อ

**4) แปลผลเป็นภาษาคน**  ช่วงความเชื่อมั่น 95% ของปริมาณใยอาหารเฉลี่ยอยู่ที่ประมาณ 21.0673 ถึง 23.4327 กรัม

### EX 6.5 ระยะทางรถบรรทุก (สไลด์ CH6 หน้า 16)

**1) โจทย์ถามอะไร / ข้อมูลที่มี**  ต้องการช่วงความเชื่อมั่น 99% ของระยะทางเฉลี่ยเป็นไมล์ต่อแกลลอน ข้อมูลรถ 10 คันคือ 18.6, 18.4, 19.2, 20.8, 19.4, 20.5, 18.7, 19.3, 19.6, 20.2

**2) คำใบ้บอกให้ใช้วิธีไหน**  ไม่รู้ `σ`, `n = 10 < 30` และบทนี้ใช้เงื่อนไขว่าประชากรปกติ จึงใช้ t โดย `ν = n − 1`

**3) คำนวณทีละบรรทัด**

```text
ผลรวม = 18.6 + 18.4 + 19.2 + 20.8 + 19.4 + 20.5 + 18.7 + 19.3 + 19.6 + 20.2
      = 194.7
x̄ = 194.7 ÷ 10 = 19.47
ผลต่างจาก x̄ = −0.87, −1.07, −0.27, 1.33, −0.07, 1.03, −0.77, −0.17, 0.13, 0.73
ยกกำลังสอง = 0.7569 + 1.1449 + 0.0729 + 1.7689 + 0.0049
           + 1.0609 + 0.5929 + 0.0289 + 0.0169 + 0.5329
           = 5.981
S = √(5.981 ÷ (10 − 1)) = √0.66456 = 0.81520
ν = 10 − 1 = 9
α = 1 − 0.99 = 0.01; α/2 = 0.01 ÷ 2 = 0.005
t = 3.250  (แถว ν=9, One-tail 0.005 ในตาราง t p-18)
SE = 0.81520 ÷ √10 = 0.25779
E = 3.250 × 0.25779 = 0.83782
ขอบล่าง = 19.47 − 0.83782 = 18.63218
ขอบบน   = 19.47 + 0.83782 = 20.30782
```

เครื่องคิดเลข: หาส่วนเบี่ยงเบนแต่ละค่าจาก 19.47 แล้วยกกำลังสองด้วยปุ่ม `x²`; บวกผลได้ 5.981 จากนั้นกด `√(5.981 ÷ 9)`. สุดท้ายกด `0.81520 ÷ √(10)` แล้วคูณ 3.250

**4) แปลผลเป็นภาษาคน**  ช่วงความเชื่อมั่น 99% ของระยะทางเฉลี่ยอยู่ที่ประมาณ 18.632 ถึง 20.308 ไมล์ต่อแกลลอน

## กับดักในข้อสอบ

- **ผิด:** เห็น `n < 30` แล้วเลือก t ทันที  **ถูก:** ถ้ารู้ `σ` และประชากรปกติ ใช้ Z ได้ ถึงตัวอย่างจะเล็ก
- **ผิด:** ไม่รู้ `σ` และ `n ≥ 30` แล้วเลือก t  **ถูก:** ใช้ Z โดยแทน `σ` ด้วย `S`
- **ผิด:** กรณีตัวอย่างใหญ่ใช้ `S/n`  **ถูก:** ใช้ `S/√n`; ต้องหารด้วยรากที่สองของจำนวนข้อมูล
- **ผิด:** กรณีตัวอย่างเล็กใช้ `ν = n`  **ถูก:** ใช้ `ν = n − 1` แล้วเลือกแถวนั้นในตาราง t
- **ผิด:** ใช้ `α` ทั้งหมดที่หางเดียวในช่วงสองด้าน  **ถูก:** แบ่งเป็น `α/2` ต่อหางก่อนหาค่าวิกฤต
- **ผิด:** อ่านตาราง t จากแถว `n` หรือคอลัมน์ 0.05 ในกรณี 99%  **ถูก:** อ่านแถว `ν`; 99% ใช้ One-tail 0.005
- **ผิด:** คิดว่าหัวข้อ p-12 กับทฤษฎีตรงกัน  **ถูก:** จำไว้ว่าหัวข้อบอกประชากรไม่ปกติ แต่ข้อความทฤษฎีบอกปกติ

## แบบฝึกหัดปิดหนังสือ

### คำถามเขียนวิธีทำ

1. ประชากรปกติ รู้ `σ = 1.2`; สุ่ม 16 ชิ้นได้ `x̄ = 48.6` มิลลิลิตร จงหาช่วงความเชื่อมั่น 90% ของ `μ`
2. สุ่ม 64 คน ได้ `x̄ = 250` คะแนนและ `S = 16` คะแนน โดยไม่รู้ `σ`; จงหาช่วงความเชื่อมั่น 95% ของ `μ`
3. ประชากรปกติ ไม่รู้ `σ`; สุ่ม 9 ถุงได้ `x̄ = 72` กรัมและ `S = 6` กรัม จงหาช่วงความเชื่อมั่น 95% ของ `μ`

<details>
<summary>เปิดดูเฉลยคำถามเขียนวิธีทำ</summary>

**ข้อ 1** รู้ `σ` และประชากรปกติ ใช้ Z แม้ `n = 16`

```text
Z = 1.645 สำหรับความเชื่อมั่น 90%
SE = 1.2 ÷ √16 = 1.2 ÷ 4 = 0.3
E = 1.645 × 0.3 = 0.4935
ขอบล่าง = 48.6 − 0.4935 = 48.1065
ขอบบน   = 48.6 + 0.4935 = 49.0935
```

ช่วงคือ 48.1065 ถึง 49.0935 มิลลิลิตร

**ข้อ 2** ไม่รู้ `σ` แต่ `n = 64 ≥ 30` ใช้ Z กับ `S`

```text
Z = 1.96 สำหรับความเชื่อมั่น 95%
SE = 16 ÷ √64 = 16 ÷ 8 = 2
E = 1.96 × 2 = 3.92
ขอบล่าง = 250 − 3.92 = 246.08
ขอบบน   = 250 + 3.92 = 253.92
```

ช่วงคือ 246.08 ถึง 253.92 คะแนน

**ข้อ 3** ไม่รู้ `σ`, `n = 9 < 30` และประชากรปกติ ใช้ t

```text
ν = n − 1 = 9 − 1 = 8
t = 2.306  (แถว ν=8, One-tail 0.025 ในตาราง t)
SE = 6 ÷ √9 = 6 ÷ 3 = 2
E = 2.306 × 2 = 4.612
ขอบล่าง = 72 − 4.612 = 67.388
ขอบบน   = 72 + 4.612 = 76.612
```

ช่วงคือ 67.388 ถึง 76.612 กรัม
</details>

### คำถามปรนัย

4. ประชากรปกติ โจทย์รู้ `σ` และมีตัวอย่าง 12 ค่า ควรเลือกแบบใด

ก. Z และใช้ `σ/√n`  
ข. t และใช้ `S/√n` เพราะ `n < 30`  
ค. Z และใช้ `S/n`  
ง. t และใช้ `σ/n`

5. ไม่รู้ `σ` และมีตัวอย่าง 40 ค่า สูตรระยะเผื่อข้อใดถูก

ก. `t × S/√n` เพราะไม่รู้ `σ`  
ข. `Z × S/√n`  
ค. `Z × S/n`  
ง. `Z × σ/√n`

6. ประชากรปกติ ไม่รู้ `σ`, `n = 8` และต้องการช่วง 95%; ต้องใช้ค่าใด

ก. `ν = 8`, `t = 2.306`  
ข. `ν = 7`, `Z = 1.96`  
ค. `ν = 7`, `t = 2.365`  
ง. `ν = 8`, `t = 1.895`

<details>
<summary>เปิดดูเฉลยคำถามปรนัย</summary>

**ข้อ 4 ตอบ ก.** รู้ `σ` และประชากรปกติจึงใช้ Z ได้ แม้ตัวอย่างเล็ก

- ข. ผิด เพราะ `n < 30` อย่างเดียวไม่พอจะบังคับให้ใช้ t; ที่นี่รู้ `σ`
- ค. ผิด เพราะโจทย์ให้ `σ` จึงไม่ต้องแทนด้วย `S`; และตัวส่วนต้องมี `√n`
- ง. ผิด เพราะใช้ t เมื่อไม่รู้ `σ` และตัวอย่างเล็กภายใต้ประชากรปกติ; อีกทั้งตัวส่วนต้องเป็น `√n`

**ข้อ 5 ตอบ ข.** ตัวอย่างใหญ่ใช้ Z และเมื่อไม่รู้ `σ` ให้ใช้ `S`; ส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยคือ `S/√n`

- ก. ผิด เพราะในกฎของบทนี้ `n ≥ 30` ใช้ Z แม้ไม่รู้ `σ`
- ค. ผิด เพราะลืมรากที่สอง ทำให้ระยะเผื่อน้อยเกินไป
- ง. ผิด เพราะ `σ` เป็นค่าที่โจทย์ไม่รู้ จึงแทนลงไปไม่ได้

**ข้อ 6 ตอบ ค.** `ν = n − 1 = 8 − 1 = 7`; ช่วง 95% มี One-tail `α/2 = 0.025`; แถว 7 คอลัมน์นี้ให้ `t = 2.365`

- ก. ผิด เพราะองศาความเป็นอิสระต้องเป็น `n − 1` ไม่ใช่ `n`
- ข. ผิด เพราะกรณีตัวอย่างเล็ก ไม่รู้ `σ` และประชากรปกติ ใช้ t ไม่ใช่ Z
- ง. ผิด เพราะใช้แถว `ν = 8` และคอลัมน์ 0.05 ซึ่งเป็นพื้นที่หางของช่วง 90% ไม่ใช่ 95%
</details>

## สรุปจำสั้น ๆ

- รู้ `σ` และประชากรปกติ → Z ใช้ `σ/√n`
- ไม่รู้ `σ`, `n ≥ 30` → Z ใช้ `S/√n`
- ไม่รู้ `σ`, `n < 30`, ประชากรปกติ → t ใช้ `S/√n` และ `ν = n − 1`
- ช่วง = `x̄ ± ค่าวิกฤต × SE`
- ช่วงสองด้านแบ่งโอกาสพลาด `α` เป็น `α/2` สองหาง
- ตาราง Z อยู่ TABLES p-16–17; ตาราง t อยู่ p-18
- p-12 มีหัวข้อกับข้อความทฤษฎีที่ขัดกัน ให้สังเกตไว้
