# บทที่ 13: การแจกแจงของสัดส่วนตัวอย่าง
## เป้าหมาย
- เปลี่ยน “นับกี่คนที่มีลักษณะนี้” ให้เป็นสัดส่วนจากตัวอย่าง
- จำค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานของสัดส่วนได้
- เช็กเงื่อนไขตัวอย่างใหญ่ แล้วแปลงสัดส่วนเป็นค่ามาตรฐานเพื่อหาความน่าจะเป็น

- [สุ่มตัวอย่างและสถิติจากข้อมูล](10-sampling-and-statistics.md) — ประชากร ตัวอย่าง และสถิติ

## นึกภาพก่อน
โรงงานผลิตแบตเตอรี่จำนวนมาก เราอยากรู้ว่า “ของเสียมีสัดส่วนเท่าไร” แต่ตรวจทุกก้อนไม่ไหว จึงสุ่มมาตรวจแบตเตอรี่เป็นชุดหนึ่ง แล้วนับว่ามีของเสียกี่ก้อน จากนั้นเอาจำนวนเสียหารด้วยจำนวนที่ตรวจ

ถ้าสุ่มใหม่หลาย ๆ ครั้ง จำนวนของเสียแต่ละครั้งไม่เท่ากัน สัดส่วนที่คำนวณได้ก็แกว่งไปมา สัดส่วนเหล่านี้รวมกันเป็น **การแจกแจงของสัดส่วนตัวอย่าง** (sampling distribution of a proportion) จุดสำคัญคือ ถ้าตัวอย่างใหญ่พอ รูปร่างจะใกล้โค้งปกติ และเราใช้ตารางมาตรฐานได้

ในบททวินาม แต่ละหน่วยมีสองผล: “สนใจ” หรือ “ไม่สนใจ” ให้ `Xᵢ` อ่านว่า “เอ็กซ์ไอ” = ตัวชี้วัดของหน่วยที่ `i` โดยให้ค่า 1 เมื่อสนใจ และ 0 เมื่อไม่สนใจ การนับผลรวม `X = ΣXᵢ` จึงเป็นจำนวนหน่วยที่สนใจ และมีแนวคิดเดียวกับทวินามใน [บทที่ 04](04-binomial.md)

คราวนี้เราไม่ได้ถามแค่จำนวน `X` แต่ถามเป็น **สัดส่วน** จึงเอาจำนวนที่สนใจหารด้วยจำนวนที่ตรวจทั้งหมด

## นิยามสัดส่วนประชากรและสัดส่วนตัวอย่าง
ให้ตัวชี้วัดของประชากรแต่ละหน่วยเป็น 1 หรือ 0 แล้วหารด้วยจำนวนหน่วยทั้งหมด นิยาม 5.7 จึงเขียนได้ว่า

```text
p = (Σ Xᵢ จาก i=1 ถึง N) / N
p̂ = (Σ Xᵢ จาก i=1 ถึง n) / n
```

ถ้าในตัวอย่างนับได้ `x` หน่วยที่สนใจ สูตรบรรทัดที่สองก็คือ

```text
p̂ = x/n
```

ตัวอย่าง ตรวจสินค้า 200 ชิ้น พบเสีย 16 ชิ้น

```text
x = 16
n = 200
p̂ = x/n
   = 16/200
   = 0.08
```
ดังนั้นสัดส่วนตัวอย่างคือ 0.08 หรือ 8% อย่าเขียน 8 แทน 0.08 เพราะ `p` และ `p̂` อยู่ในรูปสัดส่วนจาก 0 ถึง 1

## ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานของ p̂
ลองสุ่มซ้ำจากประชากรเดิมหลายครั้ง บางครั้งได้สัดส่วนสูง บางครั้งต่ำ แต่ค่าเฉลี่ยระยะยาวจะกลับไปที่สัดส่วนจริงของประชากร

ทฤษฎี 5.6 ให้สูตรสำคัญสองบรรทัด

```text
E(p̂) = μₚ̂ = p
Var(p̂) = σ²ₚ̂ = p(1−p)/n
```

ถ้าต้องการส่วนเบี่ยงเบนมาตรฐาน ให้ถอดรากของความแปรปรวน

```text
SE(p̂) = σₚ̂
      = √[p(1−p)/n]
```
`p(1−p)` แปลว่า โอกาสสนใจคูณโอกาสไม่สนใจ ส่วน `n` อยู่ใต้เส้นหาร เพราะตัวอย่างยิ่งใหญ่ สัดส่วนยิ่งแกว่งน้อย

> ⚠️ สไลด์ CH5 หน้า 38 พิมพ์ `μₚ̂ = μ` แต่ที่ถูกคือ `μₚ̂ = p` เพราะค่าเฉลี่ยของสัดส่วนตัวอย่างต้องเท่ากับสัดส่วนประชากร `p` ไม่ใช่ค่าเฉลี่ยประชากร `μ` ของข้อมูลชนิดอื่น

### ตัวอย่างสั้น ๆ หา SE
ถ้า `p=0.20` และ `n=100`

```text
SE(p̂) = √[p(1−p)/n]
       = √[0.20(1−0.20)/100]
       = √[0.20×0.80/100]
       = √[0.16/100]
       = √0.0016
       = 0.04
```

ความหมายคือ สัดส่วนตัวอย่างมักห่างจาก `p=0.20` ประมาณ 0.04 ต่อหนึ่งส่วนเบี่ยงเบนมาตรฐาน

## เงื่อนไขตัวอย่างใหญ่และสูตร Z
สไลด์หน้า 39 บอกให้ใช้ตัวอย่างขนาดใหญ่ เพื่อให้การแจกแจงของ `p̂` ใกล้ปกติ ในโจทย์ข้อสอบให้เช็กจำนวนคาดหมายสองฝั่งด้วย

```text
จำนวนที่คาดว่าจะสนใจ   = np
จำนวนที่คาดว่าจะไม่สนใจ = n(1−p)
```

ให้ทั้งสองจำนวนมากพอ โดยเกณฑ์ใช้งานทั่วไปคืออย่างน้อย 5 (ถ้าอาจารย์กำหนด 10 ให้ใช้ 10) ถ้าอย่างใดอย่างหนึ่งเล็ก อย่าใช้การประมาณด้วยโค้งปกติแบบบทนี้ ให้กลับไปพิจารณาทวินามจาก [บทที่ 04](04-binomial.md)

เมื่อเงื่อนไขผ่าน ทฤษฎี 5.7 ให้แปลง `p̂` เป็น Z ด้วย

```text
Z = (p̂ − p) / √[p(1−p)/n]
  = (p̂ − p) / SE(p̂)
```

แล้วถือว่า `Z ~ N(0,1)` ซึ่งแปลว่าใช้ตารางปกติมาตรฐานได้ เครื่องหมายของ Z บอกทิศทาง: ถ้า `p̂` สูงกว่า `p` จะได้ Z บวก ถ้าต่ำกว่าจะได้ Z ลบ

## วิธีอ่านตาราง Z หน้า p-16 และ p-17
เปิด [ตาราง Z หน้า p-16](../sources/pages/TABLES/p-16.png) และ [ตาราง Z หน้า p-17](../sources/pages/TABLES/p-17.png) ตารางนี้ให้ `Φ(z)` หรือพื้นที่สะสมทางซ้าย และพิมพ์ค่าถึง 4 ตำแหน่ง

1. คำนวณ Z แล้วปัด Z เป็น 2 ตำแหน่งก่อนเปิดตาราง
2. Z บวก: ใช้ p-16 เช่น แถว 0.7 กับคอลัมน์ 0.05 คือ `z=0.75` ได้ `Φ(0.75)=0.7734`
3. Z ลบ: ใช้ p-17 เช่น แถว −1.2 กับคอลัมน์ 0.09 คือ `z=−1.29` ได้ `Φ(−1.29)=0.0985`
4. ถ้าถามหางขวา ให้เอาพื้นที่ซ้ายออกจาก 1: `P(Z>z)=1−Φ(z)`
5. ถ้าถามช่วง ให้เอาพื้นที่ซ้ายของขอบบนลบขอบล่าง: `P(a<Z<b)=Φ(b)−Φ(a)`

สำหรับโค้งต่อเนื่อง `>` กับ `≥` ให้คำตอบเดียวกัน และ `<` กับ `≤` ก็เช่นกัน แต่ต้องแปลคำในโจทย์ให้ทิศถูกก่อน

## ตัวอย่างจากสไลด์ทำทีละขั้น
### EX 5.9: แบตเตอรี่ชำรุด (สไลด์ CH5 หน้า 40)
บริษัทผลิตแบตเตอรี่โดยมีอัตราชำรุดจริง 10% สุ่มมา 500 อัน จงประมาณความน่าจะเป็นที่สัดส่วนแบตเตอรี่ชำรุดมากกว่า 11%

**1) โจทย์ถามอะไร / ข้อมูลที่มี**

```text
p = 0.10
n = 500
ต้องหา P(p̂ > 0.11)
```

**2) คำใบ้ในโจทย์บอกว่าใช้วิธีไหน**

เป็นสัดส่วนตัวอย่าง และตัวอย่างใหญ่ ตรวจเงื่อนไขได้ว่า `np=500×0.10=50` กับ `n(1−p)=500×0.90=450` ทั้งคู่มากพอ จึงใช้การประมาณด้วยโค้งปกติ (normal approximation) และ Z

**3) คำนวณทีละบรรทัด**

```text
SE(p̂) = √[0.10(1−0.10)/500]
       = √[0.10×0.90/500]
       = √(0.09/500)
       = √0.00018
       ≈ 0.013416

z = (0.11−0.10)/0.013416
  ≈ 0.7454
```

ปัด `z=0.7454` เป็น `0.75` ก่อนอ่านตาราง p-16

```text
Φ(0.75) = 0.7734
P(p̂>0.11) = 1−Φ(0.75)
            = 1−0.7734
            = 0.2266
```

**4) แปลผลเป็นภาษาคน**

โอกาสที่สัดส่วนแบตเตอรี่เสียจะมากกว่า 11% ประมาณ **0.2266 หรือ 22.66%** ตามค่าที่อ่านจากตารางสอบ ค่าที่คำนวณโดยไม่ปัด Z ละเอียดกว่านี้ประมาณ 0.2280 แต่คำตอบที่ยึดตารางคือ 0.2266

### EX 5.10: ผู้ป่วยมะเร็งปอดที่สูบบุหรี่ (สไลด์ CH5 หน้า 41)
ทราบว่าร้อยละ 80 ของผู้ป่วยมะเร็งปอดเกิดจากการสูบบุหรี่ สุ่มผู้ป่วย 205 คน จงหาความน่าจะเป็นที่สัดส่วนตัวอย่างเป็นผู้ป่วยจากการสูบบุหรี่อย่างน้อย 86%

**1) โจทย์ถามอะไร / ข้อมูลที่มี**

```text
p = 0.80
n = 205
ต้องหา P(p̂ ≥ 0.86)
```

**2) คำใบ้ในโจทย์บอกว่าใช้วิธีไหน**

เป็น `p̂` และตัวอย่างใหญ่ ตรวจได้ว่า `np=205×0.80=164` กับ `n(1−p)=205×0.20=41` จึงใช้การประมาณด้วยโค้งปกติของสัดส่วนได้ คำว่า “อย่างน้อย” แปลเป็น `≥`

**3) คำนวณทีละบรรทัด**

```text
SE(p̂) = √[0.80(1−0.80)/205]
       = √[0.80×0.20/205]
       = √(0.16/205)
       ≈ 0.02794

z = (0.86−0.80)/0.02794
  ≈ 2.1477
```

ปัด `z=2.1477` เป็น `2.15` แล้วอ่าน p-16 ได้ `Φ(2.15)=0.9842`

```text
P(p̂≥0.86) = 1−Φ(2.15)
            = 1−0.9842
            = 0.0158
```

**4) แปลผลเป็นภาษาคน**

โอกาสที่สัดส่วนจะอย่างน้อย 86% ประมาณ **0.0158 หรือ 1.58%** ตามตารางสอบ ค่าจากการคำนวณละเอียดประมาณ 0.0159 จึงต่างกันเพราะการปัด Z ก่อนอ่านตาราง

## กับดักในข้อสอบ
- **คิดผิด:** ใช้ `x/n` โดยไม่รู้ว่า `x` คือจำนวนที่สนใจ **คิดให้ถูก:** นับจำนวนที่สนใจก่อน แล้วจึงหารด้วย `n`
- **คิดผิด:** เขียน 10% เป็น `p=10` **คิดให้ถูก:** เปลี่ยนเปอร์เซ็นต์เป็นทศนิยม เช่น 10% = 0.10
- **คิดผิด:** สลับ `p` กับ `p̂` **คิดให้ถูก:** `p` คือค่าจริงของประชากร ส่วน `p̂` คือค่าที่สุ่มได้
- **คิดผิด:** ใช้ `p̂(1−p̂)/n` ในโจทย์ที่ให้ `p` จริงเพื่อหาการแจกแจง **คิดให้ถูก:** ใช้ `p(1−p)/n` ตามสูตรบทนี้
- **คิดผิด:** ใช้ Z ทั้งที่ `np` หรือ `n(1−p)` เล็ก **คิดให้ถูก:** เช็กจำนวนคาดหมายสองฝั่งก่อน
- **คิดผิด:** ใช้ `n` หารแทน `√n` ใน SE **คิดให้ถูก:** `SE=√[p(1−p)/n]`
- **คิดผิด:** อ่านตาราง Z เป็นพื้นที่ระหว่าง 0 กับ z **คิดให้ถูก:** ตาราง p-16/p-17 ให้พื้นที่สะสมทางซ้าย
- **คิดผิด:** เห็น “มากกว่า” แล้วใช้ค่าในตารางตรง ๆ **คิดให้ถูก:** หางขวาคือ `1−Φ(z)`
- **คิดผิด:** ไม่ปัด Z ก่อนเปิดตาราง **คิดให้ถูก:** ปัดเป็น 2 ตำแหน่งตามกติกาข้อสอบ แล้วใช้ค่าที่พิมพ์ในตาราง
- **คิดผิด:** “อย่างน้อย” แปลเป็น `<` **คิดให้ถูก:** อย่างน้อยคือ `≥` และอย่างมากคือ `≤`
- **คิดผิด:** คิดว่าคำตอบ 0.2280 ของ EX 5.9 ผิดเมื่อเห็นตารางได้ 0.2266 **คิดให้ถูก:** ทั้งคู่ต่างกันจากการปัด Z; ข้อสอบให้ยึดค่าตาราง 0.2266

## แบบฝึกหัดปิดหนังสือ
ลองทำก่อนเปิดเฉลย ทุกค่า Z ต้องปัด 2 ตำแหน่งก่อนอ่านตาราง p-16/p-17

### คำถามเขียนตอบ
1. ประชากรมีสัดส่วนจริง `p=0.25` สุ่ม `n=400` หน่วย จงหา `P(p̂>0.28)`
2. ประชากรมี `p=0.60` สุ่ม `n=100` หน่วย จงหา `P(0.55<p̂<0.65)`
3. ประชากรมี `p=0.40` สุ่ม `n=250` หน่วย จงหา `P(p̂≤0.36)`

<details><summary>เปิดดูเฉลยคำถามเขียนตอบ</summary>

**ข้อ 1**

```text
SE = √[0.25(0.75)/400]
   = √(0.1875/400)
   ≈ 0.02165
z = (0.28−0.25)/0.02165
  ≈ 1.3856 ≈ 1.39
Φ(1.39) = 0.9177
P(p̂>0.28) = 1−0.9177 = 0.0823
```
ตอบ **0.0823** การใช้ Z ได้เพราะ `np=100` และ `n(1−p)=300` มากพอ ค่าละเอียดก่อนปัด Z ประมาณ 0.0829

**ข้อ 2**

```text
SE = √[0.60(0.40)/100]
   = √0.0024
   ≈ 0.04899
zล่าง = (0.55−0.60)/0.04899 ≈ −1.02
zบน  = (0.65−0.60)/0.04899 ≈  1.02
Φ(1.02) = 0.8461
Φ(−1.02) = 0.1539
P = 0.8461−0.1539 = 0.6922
```
ตอบ **0.6922** ค่าละเอียดก่อนปัด Z ประมาณ 0.6926

**ข้อ 3**

```text
SE = √[0.40(0.60)/250]
   = √(0.24/250)
   ≈ 0.03098
z = (0.36−0.40)/0.03098
  ≈ −1.291 ≈ −1.29
Φ(−1.29) = 0.0985
P(p̂≤0.36) = 0.0985
```
ตอบ **0.0985** ใช้ตาราง p-17 แถว −1.2 คอลัมน์ 0.09 ค่าละเอียดก่อนปัด Z ประมาณ 0.0984

### คำถามเลือกตอบ
4. ถ้า `p=0.30` และ `n=100` ค่าเฉลี่ยของ `p̂` เท่ากับเท่าไร — ก. 0.03  ข. 0.30  ค. 0.70  ง. 30

5. ถ้า `p=0.50` และ `n=400` ค่า `SE(p̂)` เท่ากับเท่าไร — ก. 0.0125  ข. 0.025  ค. 0.050  ง. 200

6. ถ้า `p=0.20` และ `n=100` จงหา `P(p̂>0.24)` — ก. 0.8413  ข. 0.3413  ค. 0.1587  ง. 0.2400

<details><summary>เปิดดูเฉลยคำถามเลือกตอบ</summary>

**ข้อ 4 ตอบ ข. 0.30**

```text
E(p̂) = p = 0.30
```

ก. ลืมตำแหน่งทศนิยม, ค. ใช้ `1−p`, ง. ใช้ 30 แทนสัดส่วนจาก 100

**ข้อ 5 ตอบ ข. 0.025**

```text
SE = √[0.50(1−0.50)/400]
   = √(0.25/400)
   = √0.000625
   = 0.025
```

ก. หารด้วย `n` เพิ่มอีกครั้ง, ค. ลืมรากที่สอง, ง. คูณด้วย `n` แทนการหาร

**ข้อ 6 ตอบ ค. 0.1587**

```text
SE = √[0.20(0.80)/100]
   = √0.0016
   = 0.04
z = (0.24−0.20)/0.04
  = 1.00
Φ(1.00) = 0.8413
P(p̂>0.24) = 1−0.8413 = 0.1587
```

ก. เป็นพื้นที่ซ้าย ลืม `1−`; ข. เป็นพื้นที่ระหว่าง 0 ถึง 1 โดยไม่ใช่หางขวา; ง. ตอบเป็นค่าจุดตัด ไม่ใช่ความน่าจะเป็น

</details>

## สรุปจำสั้น ๆ
- `p` = สัดส่วนจริงของประชากร, `p̂=x/n` = สัดส่วนจากตัวอย่าง
- จากทวินาม `X` นับจำนวนที่สนใจ แล้ว `p̂=X/n`
- ค่าเฉลี่ยของ `p̂` คือ `E(p̂)=p`
- ความแปรปรวนคือ `p(1−p)/n`; SE คือ `√[p(1−p)/n]`
- เช็ก `np` และ `n(1−p)` ให้มากพอก่อนใช้โค้งปกติ
- สูตรคือ `Z=(p̂−p)/√[p(1−p)/n]`
- ปัด Z เป็น 2 ตำแหน่ง แล้วอ่านพื้นที่สะสมซ้ายจากตาราง p-16 หรือ p-17
- หางขวาใช้ `1−Φ(z)` และคำตอบจากตารางต้องใช้ค่าที่พิมพ์ไว้
