## นึกภาพก่อน

ลองนึกถึงคะแนนสอบของคนทั้งห้อง ถ้าคนส่วนใหญ่อยู่แถวคะแนนกลาง จะมีคนค่อย ๆ น้อยลงเมื่อคะแนนห่างจากกลางไปทางต่ำหรือสูง กราฟจะคล้ายระฆังคว่ำและสมมาตรซ้ายขวา

ถ้าโจทย์ถามสัดส่วนคนที่ได้ต่ำกว่าคะแนนหนึ่ง เราระบายพื้นที่ใต้โค้งทางซ้ายของคะแนนนั้น ถ้าถามสูงกว่า ก็ระบายด้านขวา ตาราง Z ช่วยบอกพื้นที่เหล่านี้โดยไม่ต้องหาพื้นที่จากกราฟเอง

## โค้งปกติหน้าตาเป็นอย่างไร

โค้งปกติมีจุดสูงสุดตรงกลาง และสองข้างมีรูปเหมือนกัน จุดกลางคือค่าเฉลี่ย และพื้นที่ใต้โค้งทั้งหมดรวมกันเป็น 1 หรือ 100% ค่าเฉลี่ย มัธยฐาน และฐานนิยมอยู่จุดเดียวกัน ปลายโค้งทั้งสองข้างค่อย ๆ เข้าใกล้แกนนอน จุดที่โค้งเปลี่ยนความโค้งอยู่ห่างจากจุดกลางหนึ่งส่วนเบี่ยงเบนมาตรฐานทางซ้ายและขวา

สัญลักษณ์ที่ใช้:

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `X` | เอ็กซ์ตัวใหญ่ | ค่าที่วัดได้ เช่น คะแนน น้ำหนัก หรือความยาว |
| `x` | เอ็กซ์ตัวเล็ก | ค่าหนึ่งค่าที่กำลังถามถึง |
| `Z` | ซีตัวใหญ่ | ค่าของ X หลังแปลงให้เป็นมาตรฐานแล้ว |
| `z` | แซดตัวเล็ก | จุดหนึ่งบนแกน Z ที่ใช้เป็นขอบเขตพื้นที่ |
| `μ` | มิว | ค่าเฉลี่ยและจุดกลางของโค้ง |
| `σ` | ซิกมา | ส่วนเบี่ยงเบนมาตรฐาน บอกว่าโค้งกว้างแค่ไหน |
| `σ²` | ซิกมากำลังสอง | ความแปรปรวน ซึ่งเท่ากับส่วนเบี่ยงเบนมาตรฐานยกกำลังสอง |
| `N(μ, σ²)` | เอ็นของมิวกับซิกมากำลังสอง | บอกว่า X มีการแจกแจงปกติ ค่าเฉลี่ย μ และความแปรปรวน σ² |
| `~` | มีการแจกแจงแบบ | บอกชนิดการแจกแจงของตัวแปร |
| `P( )` | พีของ | ความน่าจะเป็นของสิ่งที่อยู่ในวงเล็บ |
| `<`, `≤` | น้อยกว่า, น้อยกว่าหรือเท่ากับ | บอกด้านซ้ายของจุดที่กำหนด |
| `>` | มากกว่า | บอกด้านขวาของจุดที่กำหนด |
| `≈` | ประมาณเท่ากับ | ค่าที่ปัดแล้วหรืออ่านจากตาราง |
| `+`, `−` | บวก, ลบ | ใช้บวกหรือลบค่าตามลำดับ |
| `±` | บวกลบ | ให้ใช้ค่าบวกและค่าลบที่มีขนาดเท่ากัน เช่น จาก −1 ถึง +1 |

เพราะ X เป็นค่าต่อเนื่อง จุดเดียวมีพื้นที่เป็นศูนย์ ดังนั้น `P(X < x)` และ `P(X ≤ x)` ได้ค่าเท่ากัน ใช้เครื่องหมายที่โจทย์ให้มาได้เลย

## สูตรบนสไลด์ที่ต้องรู้

ถ้า `X` เป็นค่าต่อเนื่องที่มีค่าเฉลี่ย `μ` และส่วนเบี่ยงเบนมาตรฐาน `σ` ความหนาแน่นของโค้งปกติคือ

`f(x; μ,σ)` อ่านว่า “เอฟของเอ็กซ์ เมื่อมิวกับซิกมา” = ความสูงของโค้งที่ตำแหน่ง `x` ส่วน `π` อ่านว่า “พาย” = ค่าคงที่ประมาณ 3.14159 และ `e` อ่านว่า “อี” = ค่าคงที่ประมาณ 2.71828

```text
f(x; μ,σ) = [1/(σ√(2π))] e^(−(1/2)[(x−μ)/σ]²)
```

`∞` อ่านว่า “อนันต์” = ไปได้ไกลไม่สิ้นสุด; ค่าของ `x` จึงอยู่ตั้งแต่ `−∞` ถึง `∞` และต้องมี `σ>0` (ซิกมาต้องมากกว่าศูนย์)

ทฤษฎีบนสไลด์ p-37 บอกว่า

```text
E(X) = μ
Var(X) = σ²
```

`E(X)` อ่านว่า “อีของเอ็กซ์” = ค่าเฉลี่ย และ `Var(X)` อ่านว่า “แวเรียนซ์ของเอ็กซ์” = ความแปรปรวน

สไลด์ p-39 เขียนพื้นที่ระหว่างขอบสองจุดด้วยอินทิกรัล ให้ `x₁` และ `x₂` อ่านว่า “เอ็กซ์หนึ่ง” และ “เอ็กซ์สอง” = ขอบล่างและขอบบน, `∫` อ่านว่า “อินทิกรัล” = การรวมพื้นที่เล็ก ๆ ต่อกัน และ `dx` อ่านว่า “ดีเอ็กซ์” = ชิ้นเล็ก ๆ บนแกน x:

```text
P(x₁ < X < x₂) = ∫ₓ₁^ₓ₂ f(x) dx
```

เราไม่ต้องกดอินทิกรัลเอง เพราะจะแปลงเป็น `Z` แล้วอ่านตารางแทน

## กฎ 68–95–99.7

ลองขีดเส้นจากจุดกลางออกไปทางซ้ายและขวาทีละหนึ่งส่วนเบี่ยงเบนมาตรฐาน พื้นที่ระหว่างเส้นจะมากขึ้นเมื่อขยับออกไป:

| ช่วงรอบค่าเฉลี่ย | พื้นที่ในช่วง | คิดเป็นเปอร์เซ็นต์ |
|---|---:|---:|
| `μ − σ` ถึง `μ + σ` | 0.6826 | 68.26% |
| `μ − 2σ` ถึง `μ + 2σ` | 0.9544 | 95.44% |
| `μ − 3σ` ถึง `μ + 3σ` | 0.9974 | 99.74% |

ค่าเหล่านี้มาจากรูปบนสไลด์ CH4 หน้า 43 ไม่ใช่ค่าที่ต้องคำนวณใหม่เอง เช่น ถ้าคะแนนเป็นโค้งปกติ จะมีประมาณ 95.44% อยู่ห่างจากค่าเฉลี่ยไม่เกิน 2 ส่วนเบี่ยงเบนมาตรฐาน พื้นที่ที่เหลืออยู่นอกช่วงรวมกันคือ `1 − 0.9544 = 0.0456` หรือ 4.56% แบ่งข้างละ 2.28% เพราะโค้งสมมาตร

## แปลงค่า X เป็น Z

ค่า X อาจใช้หน่วยเดิมของโจทย์ ส่วน Z บอกว่าค่านั้นห่างจากค่าเฉลี่ยกี่ส่วนเบี่ยงเบนมาตรฐาน คิดง่าย ๆ คือ ลบค่าเฉลี่ยก่อน แล้วหารด้วยส่วนเบี่ยงเบนมาตรฐาน

```text
Z = (X − μ) / σ
```

อ่านสัญลักษณ์ในสูตร:

| สัญลักษณ์ | อ่านว่า | หมายถึง |
|---|---|---|
| `Z` | ซี | ค่ามาตรฐาน บอกระยะจากค่าเฉลี่ยเป็นหน่วย σ |
| `−` | ลบ | หาระยะจากค่าเฉลี่ย โดยเอาค่าที่สนใจลบค่าเฉลี่ย |
| `/` | หารด้วย | แบ่งระยะนั้นด้วยขนาดของ σ |

ถ้า `Z` เป็นบวก ค่าอยู่ทางขวาของค่าเฉลี่ย ถ้าเป็นลบ ค่าอยู่ทางซ้าย ถ้าเป็นศูนย์ ค่าอยู่ตรงกลาง หลังแปลงแล้ว Z มีค่าเฉลี่ย 0 และความแปรปรวน 1 เขียนว่า `Z ~ N(0, 1)` โดย `~` อ่านว่า “มีการแจกแจงแบบ”

สำหรับ `Z` มาตรฐาน ความหนาแน่นบนสไลด์ p-41 เขียนสั้นลงเป็น

```text
f(z) = [1/√(2π)] e^(−z²/2)
```

`z` อ่านว่า “แซดเล็ก” = ค่าหนึ่งบนแกนมาตรฐาน และ `z²` คือ z คูณตัวเอง; z ก็อยู่ตั้งแต่ `−∞` ถึง `∞`

ถ้าต้องแปลงขอบเขตสองค่า ให้ทำทีละขอบเขต แล้วใช้ค่ามาตรฐานสองค่านั้นแทนขอบเขตเดิม เช่น จาก `x₁ < X < x₂` จะได้ `z₁ < Z < z₂` สัญลักษณ์ `x₁`, `x₂` อ่านว่าเอ็กซ์หนึ่งและเอ็กซ์สอง เป็นขอบล่างกับขอบบนของค่าที่ถาม ส่วน `z₁`, `z₂` คือค่ามาตรฐานของขอบทั้งสอง

```text
z₁ = (x₁ − μ) / σ
z₂ = (x₂ − μ) / σ
```

## อ่านตาราง Z

ตารางในข้อสอบมีสองหน้า: ตารางค่าบวกอยู่ใน [ตาราง p-16](../sources/pages/TABLES/p-16.png) และค่าลบอยู่ใน [ตาราง p-17](../sources/pages/TABLES/p-17.png) หัวตารางเขียน `Cumulative Probability P(Z < z)` หมายถึงพื้นที่ใต้โค้งตั้งแต่ซ้ายสุดมาจนถึง z ไม่ใช่พื้นที่ระหว่าง 0 กับ z

สัญลักษณ์ `Φ(z)` อ่านว่า “ฟีของแซด” และหมายถึงพื้นที่ทางซ้ายของ z ซึ่งก็คือ `P(Z < z)` หรือ `P(Z ≤ z)` สำหรับตัวแปรต่อเนื่อง เขียนย่อได้ว่า

```text
Φ(z) = P(Z≤z)
```

ค่า z เลือกจากแถวและคอลัมน์:

- แถวเป็นหลักหน่วยกับทศนิยมหลักแรก เช่น 1.2
- คอลัมน์เป็นทศนิยมหลักที่สอง เช่น .07
- แถว 1.2 กับคอลัมน์ .07 จึงหมายถึง z = 1.27
- สำหรับ z ติดลบ ใช้หน้า p-17 เช่น แถว −1.2 คอลัมน์ .05 หมายถึง z = −1.25

ตัวอย่างที่ตรวจได้จากหน้าตาราง: แถว 1.1 คอลัมน์ .07 ได้ `Φ(1.17) = 0.8790`; แถว −1.2 คอลัมน์ .05 ได้ `Φ(−1.25) = 0.1056` ค่าทุกตัวที่อ่านด้านล่างใช้เลขสี่หลักตามที่พิมพ์ในตารางข้อสอบ

## เลือกพื้นที่ให้ตรงกับโจทย์

ให้ `a` อ่านว่าเอ และ `b` อ่านว่าบี หมายถึงค่าขอบเขตบนแกน Z โดย a เป็นขอบล่างและ b เป็นขอบบน ถ้าต้องการใช้สัญลักษณ์ตาราง ให้แทน `Φ(z)` ด้วยพื้นที่สะสมทางซ้าย

ในข้อย้อนตาราง `z₀` อ่านว่าแซดศูนย์ และ `z₁` อ่านว่าแซดหนึ่ง ใช้แทนขอบเขตที่โจทย์ยังไม่บอกค่า

| โจทย์ถาม | รูปพื้นที่ในใจ | วิธีหา |
|---|---|---|
| `P(Z < z)` พื้นที่ซ้าย | ระบายจากซ้ายสุดถึง z | อ่าน `Φ(z)` ตรง ๆ |
| `P(Z > z)` พื้นที่ขวา | ระบายจาก z ไปขวาสุด | `1 − Φ(z)` |
| `P(a < Z < b)` อยู่ระหว่าง | ระบายจาก a ถึง b | `Φ(b) − Φ(a)` |
| อยู่นอกช่วง a ถึง b | ระบายซ้ายของ a และขวาของ b | `Φ(a) + [1 − Φ(b)]`, หรือ `1 − [Φ(b) − Φ(a)]` |
| สมมาตรจาก −z ถึง +z | ระบายตรงกลางรอบ 0 | `Φ(z) − Φ(−z)`, หรือ `2Φ(z) − 1` |
| อยู่นอก −z ถึง +z | ระบายหางทั้งสอง | `1 − [2Φ(z) − 1]`, หรือ `2[1 − Φ(z)]` |

เครื่องหมาย `+` อ่านว่าบวก และ `−` อ่านว่าลบ ส่วนเลข 1 ในสูตรหมายถึงพื้นที่ทั้งหมดใต้โค้ง ตัวอย่าง ถ้าตารางบอกว่าซ้ายมีพื้นที่ 0.80 พื้นที่ที่เหลือทางขวาจึงเป็น `1 − 0.80 = 0.20`

เมื่อขอบเป็นค่าติดลบ ใช้หน้าค่าลบได้ตรง ๆ หรือใช้ความสมมาตรของโค้ง:

```text
Φ(−z) = 1 − Φ(z)
```

ดังนั้นพื้นที่ซ้ายของ −1.61 เท่ากับ `1 − Φ(1.61)` พื้นที่ขวาของ −1.61 เท่ากับพื้นที่ซ้ายของ +1.61 คือ `Φ(1.61)` ระวังอย่าสลับด้าน

## ย้อนจากพื้นที่ไปหา z

ถ้าโจทย์ให้พื้นที่มา ให้เปลี่ยนเป็นพื้นที่ซ้ายก่อน เพราะตารางทุกหน้าบอกพื้นที่ซ้าย:

1. ถ้าพื้นที่ซ้ายให้มาตรง ๆ เช่น 0.9750 ให้หาค่านี้ในตัวตาราง
2. ถ้าให้พื้นที่ขวา เช่น 0.05 ให้ลบจาก 1 ก่อน ได้พื้นที่ซ้าย 0.95
3. ถ้าพื้นที่ซ้ายน้อยกว่า 0.5000 ค่าที่หาอยู่ฝั่งลบ ให้ใช้หน้า p-17
4. เลือกค่าตารางที่ใกล้พื้นที่เป้าหมายที่สุด แล้วอ่าน z จากแถวและคอลัมน์

ถ้าค่าที่ต้องการอยู่ครึ่งทางระหว่างสองช่อง ให้ตอบ z อยู่ระหว่างค่านั้น หรือใช้ค่ากลางโดยประมาณเมื่อโจทย์ต้องการเลขเดียว ตารางมีค่าพื้นที่สี่ตำแหน่ง จึงไม่ควรเขียนคำตอบละเอียดเกินกว่าที่ตารางรองรับ

### EX 4.17: พื้นที่ของ Z (สไลด์ CH4 หน้า 45)

1. **โจทย์ถามอะไร / มีข้อมูลอะไร:** ให้ Z มีการแจกแจงปกติมาตรฐาน `Z ~ N(0, 1)` แล้วหาความน่าจะเป็นสี่ข้อ: พื้นที่ซ้ายของ 1.17, ขวาของ 2.23, ระหว่าง 0.42 กับ 1.61, และระหว่าง −1.61 กับ 0.59
2. **คำใบ้บอกวิธีไหน:** ตารางให้พื้นที่ด้านซ้ายเสมอ ข้อด้านขวาจึงใช้ส่วนที่เหลือจาก 1 ส่วนข้อที่อยู่ระหว่างให้ลบพื้นที่ซ้ายสองจุด
3. **คำนวณทีละบรรทัด:**

```text
(1) P(Z ≤ 1.17) = Φ(1.17)
                 = 0.8790
    อ่านหน้า p-16 แถว 1.1 คอลัมน์ .07

(2) P(Z > 2.23) = 1 − Φ(2.23)
                 = 1 − 0.9871
                 = 0.0129
    อ่านหน้า p-16 แถว 2.2 คอลัมน์ .03

(3) P(0.42 < Z < 1.61) = Φ(1.61) − Φ(0.42)
                        = 0.9463 − 0.6628
                        = 0.2835
    อ่านหน้า p-16 แถว 1.6 คอลัมน์ .01 และแถว 0.4 คอลัมน์ .02

(4) P(−1.61 < Z < 0.59) = Φ(0.59) − Φ(−1.61)
                         = 0.7224 − 0.0537
                         = 0.6687
    Φ(−1.61) = 1 − Φ(1.61) = 1 − 0.9463 = 0.0537
    อ่าน Φ(0.59) จากหน้า p-16 แถว 0.5 คอลัมน์ .09
```

4. **แปลผลเป็นภาษาคน:** คำตอบตามลำดับคือ 0.8790, 0.0129, 0.2835 และ 0.6687 หรือคิดเป็น 87.90%, 1.29%, 28.35% และ 66.87% สไลด์ให้โจทย์โดยไม่พิมพ์เฉลย ตัวเลขพื้นที่ทุกค่าข้างต้นตรงกับตารางข้อสอบ

### EX 4.20: ย้อนจากพื้นที่ไปหา z (สไลด์ CH4 หน้า 48)

1. **โจทย์ถามอะไร / มีข้อมูลอะไร:** ให้ Z มีการแจกแจงปกติมาตรฐาน แล้วให้พื้นที่หรือพื้นที่ช่วงมาเพื่อย้อนหาขอบเขต z
2. **คำใบ้บอกวิธีไหน:** หาเลขพื้นที่ในตารางโดยตรงถ้าเป็นพื้นที่ซ้าย ถ้าเป็นหางขวาให้แปลงเป็นพื้นที่ซ้ายก่อน ส่วนพื้นที่กลางข้อสุดท้ายบอกแค่ระยะช่วง จึงต้องมีสมมติฐานเพิ่มเพื่อได้คู่ขอบเขตเดียว
3. **คำนวณทีละบรรทัด:**

```text
(1) P(Z ≤ z₀) = 0.975
    หาในตารางพื้นที่ 0.9750 ได้ z₀ = 1.96
    (แถว 1.9 คอลัมน์ .06 ให้ 0.9750)

(2) P(Z < z₀) = 0.1977
    หาค่า 0.1977 ในหน้า p-17 ได้ z₀ = −0.85
    (แถว −0.8 คอลัมน์ .05 ให้ 0.1977)

(3) P(Z > z₀) = 0.05
    พื้นที่ซ้าย = 1 − 0.05 = 0.9500
    ในตาราง 1.64 ให้ 0.9495 และ 1.65 ให้ 0.9505
    0.9500 ห่างจากทั้งคู่เท่ากัน จึงประมาณ z₀ ≈ 1.645

(4) P(z₀ < Z < z₁) = 0.9544
    ถ้าสมมติว่าช่วงสมมาตรรอบ 0, ใช้ขอบ −2 กับ +2
    Φ(2) − Φ(−2) = 0.9772 − 0.0228 = 0.9544
```

4. **แปลผลเป็นภาษาคน:** สามข้อแรกได้ z₀ เท่ากับ 1.96, −0.85 และประมาณ 1.645 ตามลำดับ ข้อสุดท้ายได้คู่ขอบเขต (−2, 2) เมื่อกำหนดว่าช่วงสมมาตรรอบศูนย์

> ⚠️ EX 4.20(4) บนสไลด์ให้ `P(z₀ < Z < z₁) = 0.9544` แต่ถามหาค่า z₀ ทั้งที่มีขอบเขตไม่ทราบค่าสองตัว สมการพื้นที่หนึ่งสมการยังระบุขอบทั้งคู่ไม่ได้ คำตอบ (−2, 2) ใช้ได้เมื่อเพิ่มเงื่อนไขว่าช่วงสมมาตรรอบ 0 เท่านั้น

## กับดักในข้อสอบ

- **ตารางเป็นพื้นที่ซ้าย:** อย่าอ่านตัวเลขในตารางเป็นพื้นที่ระหว่าง 0 กับ z ถ้าโจทย์ถามขวา ให้ใช้ `1 − Φ(z)`
- **z ติดลบอยู่ซ้ายของค่าเฉลี่ย:** อย่าลืมเครื่องหมายลบหลังคำนวณ `(x − μ) / σ`; ถ้าสลับเป็นบวกจะได้คนละด้านของโค้ง
- **พื้นที่ระหว่างสองค่าคือเอาพื้นที่ซ้ายมาลบ:** ใช้พื้นที่ขอบขวาลบพื้นที่ขอบซ้าย อย่าบวกพื้นที่สองค่าตรง ๆ
- **พื้นที่นอกช่วงมีสองหาง:** คิดเป็นหางซ้ายบวกหางขวา หรือเอา 1 ลบพื้นที่กลาง อย่าใช้แค่หางเดียว
- **ย้อนจากหางขวาต้องกลับเป็นซ้ายก่อน:** EX 4.20(3) ให้หางขวา 0.05 จึงค้นพื้นที่ซ้าย 0.95 และได้ z บวก ไม่ใช่ z ลบ
- **EX 4.20(4) ยังขาดข้อมูล:** พื้นที่ 0.9544 อย่างเดียวไม่ได้บังคับให้ขอบเขตสมมาตร คำตอบ −2 กับ +2 ต้องมีเงื่อนไขสมมาตร
- **อ่านแถวและคอลัมน์ให้ครบ:** z = 1.27 ใช้แถว 1.2 และคอลัมน์ .07 ไม่ใช่แถว 1.27 หรือคอลัมน์ .7

## แบบฝึกหัดปิดหนังสือ

ลองทำเองก่อนเปิดเฉลย ทุกข้อใช้ค่าพื้นที่ที่พิมพ์ในตารางสอบ

### คำถามเขียนตอบ

1. คะแนน X มีการแจกแจงปกติ ค่าเฉลี่ย 50 คะแนน และส่วนเบี่ยงเบนมาตรฐาน 10 คะแนน จงหาโอกาสที่คะแนนต่ำกว่า 65
2. น้ำหนัก X มีการแจกแจงปกติ ค่าเฉลี่ย 80 กรัม และส่วนเบี่ยงเบนมาตรฐาน 8 กรัม จงหาโอกาสที่น้ำหนักอยู่ระหว่าง 72 ถึง 88 กรัม
3. จงหาโอกาสที่ Z อยู่ต่ำกว่า −1.25 หรือสูงกว่า 1.25 แล้วบอกว่าเป็นพื้นที่รูปร่างใด

### คำถามเลือกตอบ

4. ถ้า `P(Z < z) = 0.6915` ค่า z ที่ใกล้ที่สุดคือข้อใด

   ก. −0.50  ข. 0.00  ค. 0.50  ง. 1.50

5. ถ้า Z เป็นปกติมาตรฐาน จงหา `P(Z > −1.20)`

   ก. 0.1151  ข. 0.5000  ค. 0.8849  ง. 0.9192

6. ถ้า Z เป็นปกติมาตรฐาน จงหา `P(Z > 1.40)`

   ก. 0.0808  ข. 0.4192  ค. 0.9192  ง. 0.0404

<details>
<summary>เปิดดูเฉลย</summary>

**ข้อ 1** ต้องแปลงคะแนน 65 เป็น Z ก่อน แล้วหาพื้นที่ซ้าย

```text
z = (65 − 50) / 10
  = 15 / 10
  = 1.50
P(X < 65) = P(Z < 1.50)
          = Φ(1.50)
          = 0.9332
```

ตอบ 0.9332 หรือ 93.32% ตารางหน้า p-16 แถว 1.5 คอลัมน์ .00 ให้ 0.9332

**ข้อ 2** แปลงขอบทั้งสอง แล้วลบพื้นที่ซ้าย

```text
z₁ = (72 − 80) / 8 = −8 / 8 = −1.00
z₂ = (88 − 80) / 8 =  8 / 8 =  1.00
P(72 < X < 88) = Φ(1.00) − Φ(−1.00)
               = 0.8413 − 0.1587
               = 0.6826
```

ตอบ 0.6826 หรือ 68.26% ซึ่งตรงกับพื้นที่ในช่วง ±1 ส่วนเบี่ยงเบนมาตรฐาน ตารางใช้หน้า p-16 สำหรับ 1.00 และหน้า p-17 สำหรับ −1.00

**ข้อ 3** เป็นพื้นที่นอกช่วงสมมาตร มีหางซ้ายและขวา

```text
พื้นที่กลาง = Φ(1.25) − Φ(−1.25)
            = 0.8944 − 0.1056
            = 0.7888
พื้นที่นอกช่วง = 1 − 0.7888
               = 0.2112
```

ตอบ 0.2112 หรือ 21.12% เป็นพื้นที่หางสองข้างรวมกัน อ่านค่า 0.8944 จากหน้า p-16 และ 0.1056 จากหน้า p-17

**ข้อ 4: ค. 0.50** แถว 0.5 คอลัมน์ .00 ในหน้า p-16 ให้พื้นที่ซ้าย 0.6915

- ก. −0.50 ให้พื้นที่ซ้าย 0.3085 จึงติดเครื่องหมายผิดด้าน
- ข. 0.00 ให้พื้นที่ซ้าย 0.5000 ซึ่งน้อยเกินไป
- ค. 0.50 ให้พื้นที่ตรงกับโจทย์
- ง. 1.50 ให้พื้นที่ซ้าย 0.9332 ซึ่งมากเกินไป

**ข้อ 5: ค. 0.8849** ตารางหน้า p-17 ให้พื้นที่ซ้ายของ −1.20 เป็น 0.1151 จึงเอาส่วนที่เหลือทางขวา

```text
P(Z > −1.20) = 1 − Φ(−1.20)
              = 1 − 0.1151
              = 0.8849
```

- ก. 0.1151 เป็นพื้นที่ซ้าย ไม่ใช่ด้านขวา
- ข. 0.5000 เป็นพื้นที่ข้างหนึ่งของจุดกลาง ไม่ใช่พื้นที่ตั้งแต่ −1.20 ไปขวา
- ค. 0.8849 เป็นส่วนเติมเต็มที่ถูกต้อง
- ง. 0.9192 คือพื้นที่ซ้ายของ +1.40 จากอีกโจทย์หนึ่ง ไม่ใช่ขอบ −1.20

**ข้อ 6: ก. 0.0808** พื้นที่ซ้ายของ 1.40 จากหน้า p-16 คือ 0.9192

```text
             = 1 − 0.9192
             = 0.0808
```

- ก. 0.0808 เป็นหางขวาที่ต้องการ
- ข. 0.4192 เอา 0.9192 ไปลบ 0.5 จึงได้แค่พื้นที่ระหว่าง 0 กับ 1.40
- ค. 0.9192 เป็นพื้นที่ซ้าย จึงกลับหาง

## สรุปจำสั้น ๆ

- โค้งปกติสมมาตรรอบค่าเฉลี่ย และพื้นที่ทั้งหมดใต้โค้งเท่ากับ 1
- กฎ 68–95–99.7 ให้พื้นที่ประมาณ ±1σ, ±2σ, ±3σ
- แปลงค่าเป็นมาตรฐานด้วย `Z = (X − μ) / σ`
- ตาราง p-16 และ p-17 ให้พื้นที่สะสมทางซ้าย `Φ(z)`
- พื้นที่ขวา = 1 ลบพื้นที่ซ้าย; พื้นที่ระหว่าง = ขอบขวาลบขอบซ้าย
- พื้นที่นอกช่วง = พื้นที่หางสองข้างรวมกัน
- ย้อนหาค่า z โดยหาเลขพื้นที่ที่ใกล้ที่สุด
- พื้นที่กลาง 0.9544 ให้ขอบ −2 และ +2 เมื่อช่วงสมมาตรรอบศูนย์
